# 字符串的基本概念

> 最近修订：2026-08-17 01:11 +10:00（未审阅）

字符串是按照顺序排列的一列字符。模式匹配、回文、KMP、后缀数组等算法会反复使用前缀、后缀、子串和子序列；如果这些词没有统一定义，同一句“出现在字符串中”就可能被理解成完全不同的问题。

本篇只建立术语和区间表示，不提前讲具体匹配算法。

## 字符串与长度

字符串 `algorithm` 由九个字符依次组成。字符的先后顺序属于字符串本身，交换两个位置通常会得到另一个字符串。

字符串 $s$ 的长度记作：

$$
|s|.
$$

若长度为 $n$，本书自定义的字符串算法使用 1-based 位置：

```text
s[1], s[2], ..., s[n]
```

C++ 原生 `string` 使用 0-based 下标 `0..size()-1`。进入自定义算法时，可以先保存真实长度，再在开头补一个占位字符：

```cpp
string s;
cin >> s;

int n = s.size();
s = " " + s;
```

此后 `s[1..n]` 是真实字符，`s[0]` 只是占位。已经补位后，`s.size()` 还包含占位字符，不能再把它当成真实长度。

竞赛输入通常使用 ASCII 范围内字符。`string::size()` 实际统计存储单元数量，不会自动把 UTF-8 编码的一个中文字符识别成单个自然语言字符；处理 Unicode 需要另行说明编码规则。

## 空串

长度为 $0$ 的字符串称为**空串**，常记作 $arepsilon$，在 C++ 中可以写成：

```cpp
string empty = "";
```

空串不含字符，但仍然是一个合法字符串。它与只含一个空格的字符串不同：

```text
""   长度为 0
" "  长度为 1，唯一字符是空格
```

许多定义允许空串作为前缀、后缀或子串。题目若只讨论非空对象，会显式增加“非空”条件。

## 前缀

字符串 $s$ 的前缀是从开头连续取得的部分。

对：

```text
s = abcde
```

所有前缀是：

```text
"", "a", "ab", "abc", "abcd", "abcde"
```

长度为 $k$ 的前缀是 `s[1..k]`，其中 `k` 可以从 `0` 到 `n`。因此长度为 $n$ 的字符串共有 $n+1$ 个前缀；`k = 0` 对应空串，`k = n` 对应整个字符串。

## 后缀

字符串 $s$ 的后缀是连续延伸到结尾的部分。

`abcde` 的所有后缀是：

```text
"", "e", "de", "cde", "bcde", "abcde"
```

非空后缀可以写成 `s[l..n]`。空后缀位于最后一个字符之后，概念上不需要给它访问下标。

前缀固定左端点，后缀固定右端点。整个字符串同时是自己的前缀和后缀，空串也同时是两者。

## 子串

字符串的**子串**是从原串中连续截取的一段字符。非空子串使用闭区间表示：

```text
s[l..r]
```

其中：

$$
1\le l\le r\le n.
$$

例如 `s = abcde`：

- `s[2..4] = bcd` 是子串；
- `ace` 不是子串，因为三个字符在原串中不连续；
- 每个前缀和后缀都是子串；
- 普通子串不一定接触开头或结尾。

同一段内容可以在不同位置出现。例如 `s = ababa` 中，子串 `aba` 出现在区间 `[1,3]` 和 `[3,5]`。字符串算法不仅可能关心内容，也可能关心每一次出现的位置。

C++ 原生 `substr(position, count)` 使用 0-based 起点和长度。把本书闭区间 `[l,r]` 转换过去：

```cpp
string part = original.substr(l - 1, r - l + 1);
```

第一个参数 `l - 1` 是 0-based 起点，第二个参数是闭区间长度。

## 真子串与非空真子串

**真子串**只排除整个原字符串。因此，在允许空串的定义下：

- 空串是真子串；
- 任意长度小于 $n$ 的子串是真子串；
- 原串本身不是真子串。

**非空真子串**同时排除空串和整个原字符串，长度必须满足：

$$
1\le |t|<|s|.
$$

对 `s = abc`：

| 候选 | 是子串 | 是真子串 | 是非空真子串 |
| --- | --- | --- | --- |
| `""` | 是 | 是 | 否 |
| `"a"` | 是 | 是 | 是 |
| `"bc"` | 是 | 是 | 是 |
| `"abc"` | 是 | 否 | 否 |

“真”只表示不等于整个对象，不自动表示非空。题目若使用自己的约定，应以题面定义为准。

真前缀与真后缀使用相同规则：排除整个字符串。后续 KMP 中常见的“既是前缀又是后缀”通常还会明确要求非空真前缀与非空真后缀。

## 子序列

字符串的**子序列**可以从原串删除若干字符，但剩余字符的相对顺序不能改变；它不要求连续。

对：

```text
s = abcde
```

- `ace` 是子序列，选择位置 `1,3,5`；
- `bde` 是子序列，选择位置 `2,4,5`；
- `aec` 不是子序列，因为位置顺序无法保持；
- `bcd` 既是子串，也是子序列。

每个子串都是子序列，但子序列不一定是子串。两者最关键的区别是：

```text
子串要求连续；子序列只要求相对顺序不变。
```

模式串连续出现在文本中的问题寻找子串，不是在寻找子序列。

## 回文

正着读与反着读完全相同的字符串称为**回文串**：

```text
"a"
"level"
"abba"
```

判断闭区间 `s[l..r]` 是否回文，只需从两端向中间比较：

```cpp
while (l < r) {
    if (s[l] != s[r]) {
        return false;
    }
    l++;
    r--;
}
return true;
```

若第一次出现不同字符，就不是回文；若所有对称位置都相同，则是回文。

长度为 `0` 或 `1` 的字符串没有不相等的对称字符，通常都定义为回文。具体题目如果只统计非空回文子串，会另行排除空串。

## 文本、模式与出现

模式匹配中，较长字符串通常称为**文本串** `text`，要寻找的较短字符串称为**模式串** `pattern`。

模式串从位置 `start` 出现，表示它等于文本的连续子串：

```text
text[start..start + pattern_length - 1]
```

同一个模式可以在多个位置出现，出现区间也可能重叠。完整枚举与匹配过程属于后续[朴素字符串匹配](naive-pattern-matching.md)的内容。

## 完整代码

下面读入一个小写字符串，再回答若干个闭区间是否为回文。输入位置从 `1` 开始，与正文定义一致。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
string s;

bool is_palindrome(int l, int r) {
    while (l < r) {
        if (s[l] != s[r]) {
            return false;
        }
        l++;
        r--;
    }
    return true;
}

void solve() {
    cin >> s;

    n = s.size();
    s = " " + s;

    int q;
    cin >> q;

    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << (is_palindrome(l, r) ? "Yes" : "No") << '\n';
    }
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
abacaba
3
1 7
2 6
2 4
```

输出：

```text
Yes
Yes
No
```

单次查询最多比较子串长度的一半，时间复杂度是 $O(r-l+1)$，额外空间是 $O(1)$。

## 需要记住什么

1. 长度为 $n$ 的字符串为什么有 $n+1$ 个前缀？
2. 前缀、后缀和一般子串分别固定哪些边界？
3. 真子串与非空真子串分别排除了什么？
4. 子串和子序列最关键的区别是什么？
5. 每个子串是否都是子序列？反过来是否成立？
6. 什么是回文串？怎样从两端检查一个闭区间？
7. 模式串“出现”在文本中为什么要求连续？
