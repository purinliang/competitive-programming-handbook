# 字符串：比较与字典序

> 最近修订：2026-08-13 23:02 +10:00（未审阅）

题目经常需要判断两个字符串是否相同、把单词排序、寻找字典序最小答案，或者在多个候选结果中选择最小的一个。字符串不是把所有字符编号相加以后比较，而是从左到右寻找最早能够区分两者的位置。

本篇只处理由小写英文字母组成的 `string`，推导相等判断与字典序，再说明 C++ 比较运算符和 `sort` 怎样直接使用这套规则。模式串是否出现在文本中是另一个问题，会在下一篇单独学习。

## 内容相等

两个字符串内容相等，需要同时满足：

1. 字符数量相同；
2. 每个相同下标的字符都相同。

例如 `apple` 与 `apple` 相等，`apple` 与 `apply` 在最后一个字符不同，`app` 与 `apple` 的长度不同，所以都不相等。

手工判断可以先比较长度，再逐个比较字符：

```cpp
bool equal_strings(const string& a, const string& b) {
    int a_length = a.size();
    int b_length = b.size();

    if (a_length != b_length) {
        return false;
    }

    for (int i = 0; i < a_length; i++) {
        if (a[i] != b[i]) {
            return false;
        }
    }
    return true;
}
```

`string` 是 STL 原生类型，字符下标从 `0` 开始。循环结束仍未发现差异，才能确定全部字符相同。

C++ 已经提供相同语义的运算符：

```cpp
if (a == b) {
    cout << "equal\n";
}

if (a != b) {
    cout << "different\n";
}
```

竞赛代码直接使用 `==` 和 `!=`，不需要为 `string` 调用 C 字符串的 `strcmp`。

## 字典序

字典序（lexicographic order）按照以下步骤比较字符串 `a` 和 `b`：

1. 从下标 `0` 开始同时查看两个字符串；
2. 遇到第一个不同字符时，字符较小的字符串较小；
3. 若较短字符串的全部字符都相同，也就是它是另一个字符串的前缀，则较短字符串较小；
4. 长度也相同时，两个字符串相等。

这与查英语词典时先比较第一个字母、相同再比较第二个字母的过程相似，但程序只执行字符编号规定的顺序，不理解自然语言含义。

## 第一个不同字符

比较：

```text
apple
apply
```

前四个字符 `a,p,p,l` 完全相同，第一个不同位置是下标 `4`：

```text
apple
    ^ e
apply
    ^ y
```

因为 `'e' < 'y'`，所以：

```cpp
"apple" < "apply"
```

第一个不同字符以前，两边前缀完全相同，对排序没有区分作用。第一个不同字符已经决定先后，后面的字符不再查看。

例如 `azzz` 与 `baaa` 在第一个字符就不同。虽然 `azzz` 后面的字符都很大，仍然有：

```text
azzz < baaa
```

不能统计字符总和、较大字符数量或整个字符串的最大字符来决定字典序。

## 前缀情况

比较：

```text
app
apple
```

共同范围内的三个字符全部相同，但 `app` 已经结束。此时较短字符串更小：

```cpp
"app" < "apple"
```

空字符串是任意字符串的前缀，所以空字符串小于任意非空字符串。

长度只能在共同前缀完全相同时决定结果。不能一开始就认为较短字符串一定更小，例如：

```text
z > aa
```

第一个字符 `'z'` 已经大于 `'a'`，无需比较长度。

## 手工比较函数

可以让函数返回三种结果：

- `-1`：`a` 的字典序更小；
- `0`：两个字符串相等；
- `1`：`a` 的字典序更大。

先扫描共同长度内的字符：

```cpp
int lexicographic_compare(const string& a, const string& b) {
    int a_length = a.size();
    int b_length = b.size();
    int common_length = min(a_length, b_length);

    for (int i = 0; i < common_length; i++) {
        if (a[i] < b[i]) {
            return -1;
        }
        if (a[i] > b[i]) {
            return 1;
        }
    }

    if (a_length < b_length) {
        return -1;
    }
    if (a_length > b_length) {
        return 1;
    }
    return 0;
}
```

若循环内部返回，结果由第一个不同字符决定。若循环完整结束，共同前缀完全相同，再比较长度；长度也相同就说明内容相等。

这个返回约定属于本文函数。其他比较函数若只保证“负数、零、正数”，不能假设它们一定精确返回 `-1` 或 `1`。

## C++ 比较运算符

`string` 已经按照字典序定义了六个比较运算符：

```cpp
a == b
a != b
a < b
a > b
a <= b
a >= b
```

在主流竞赛环境使用的 ASCII 兼容编码中，对于本篇只包含小写英文字母的字符串，字符顺序就是：

```text
a < b < c < ... < z
```

因此手工比较函数与 `string` 运算符得到相同结果。实际竞赛代码应直接写：

```cpp
if (a < b) {
    cout << a << '\n';
} else {
    cout << b << '\n';
}
```

若输入混合大写字母、数字、标点或其他编码，字符顺序未必等于自然语言词典顺序，应按题目给出的字符集和规则处理。本篇不讨论本地化排序与 Unicode 语言规则。

## 数字字符串

字符串比较不把文本自动转换成整数。例如：

```cpp
"10" < "2"
```

结果为 `true`，因为第一个字符 `'1' < '2'`。整数大小则是 $10>2$。

若题目给出没有前导零的非负整数字符串，并要求按数值比较，可以先比较长度，长度相同再比较字典序；但这是利用十进制整数表示的额外性质，不是普通字符串字典序定义。

## 字符串排序

给定若干小写单词，要求按字典序输出。`sort` 默认使用元素的 `<` 运算符，所以 `vector<string>` 可以直接排序：

```cpp
sort(words.begin(), words.end());
```

本书自己定义的单词序列使用逻辑下标 `1..n`，并保留 `+5` 容量余量：

```cpp
vector<string> words(n + 5);
```

其中 `words[0]` 与末尾余量都不属于输入。调用 STL `sort` 时，把闭区间 `1..n` 转换成迭代器要求的左闭右开区间：

```cpp
sort(words.begin() + 1, words.begin() + n + 1);
```

起点指向 `words[1]`，终点指向最后一个元素之后的 `words[n + 1]`。不能排序整个带余量的 `vector`，否则多个默认构造的空字符串也会进入结果。

## 重复字符串

相等字符串互相既不小于也不大于。排序不会删除重复项：

```text
banana
banana
```

仍然保留两次。

`sort` 不保证相等元素保持原输入顺序。若每个字符串还绑定了不同编号，并且题目要求相同字符串按照原顺序输出，应使用稳定排序或在比较规则中加入编号；仅排序纯字符串时，两个相同文本无法从输出上区分。

## 正确性

手工比较函数先扫描两个字符串的共同范围。

若在位置 `i` 第一次发现不同，则 `0..i-1` 的前缀完全相同，位置 `i` 是最早能够区分两者的字符。函数按照 `a[i]` 与 `b[i]` 的顺序返回，符合字典序定义，后缀不可能改变结果。

若共同范围内没有不同字符，较短字符串是较长字符串的完整前缀，函数按照长度返回；长度也相同则所有字符一一相等，返回 `0`。三种情况互斥并覆盖所有字符串对，所以比较结果正确。

`sort` 使用 `string` 的 `<` 对整个单词表重新排列。排序结束后任意相邻两个单词都满足前者不大于后者，因此输出顺序就是字典序非递减顺序；相等单词可以相邻保留。

## 完整代码

输入 `n` 个只含小写英文字母的非空单词，按字典序输出。保证 `1 <= n <= 2 * 10^5`，所有单词的字符总数不超过 `2 * 10^5`。程序统一使用 `cin` / `cout` 处理 `string`，不与 C 风格输入输出混用。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<string> words(n + 5);
    for (int i = 1; i <= n; i++) {
        cin >> words[i];
    }

    sort(words.begin() + 1, words.begin() + n + 1);

    for (int i = 1; i <= n; i++) {
        cout << words[i] << '\n';
    }
    return 0;
}
```

输入：

```text
6
banana
app
apple
apricot
banana
apply
```

输出：

```text
app
apple
apply
apricot
banana
banana
```

## 复杂度

比较两个长度分别为 $a$、$b$ 的字符串，最坏要扫描完整共同前缀，时间复杂度是 $O(\min(a,b))$；若一方为另一方前缀，扫描共同长度后再做一次长度比较。

对 `n` 个单词排序需要 $O(n\log n)$ 次字符串比较。若每个单词长度至多为 $L$，字符比较总时间上界为 $O(nL\log n)$。保存所有输入字符串需要与字符总数成正比的空间。

许多实际比较会在前几个字符就发现差异，所以不一定每次都扫描到长度上限；复杂度分析仍使用最坏情况。

## 常见错误

### 一开始先比较长度

只有一方是另一方前缀时，长度才决定字典序。`z` 虽然比 `aa` 短，字典序却更大。

### 比较字符总和

字典序由第一个不同字符决定，不由所有字符编号之和决定。不同字符串也可能具有相同字符总和。

### 把数字字符串当成整数

`"10" < "2"` 按字符串为真。需要数值顺序时必须根据整数文本规则另外处理。

### 排序完整余量数组

`vector<string> words(n + 5)` 只有 `1..n` 是真实单词。对整个 `vector` 排序会把空字符串哨兵和余量一起排到前面。

### 手写比较器使用小于等于

`sort` 的比较器必须表达严格的小于关系。相等时返回 `true` 会破坏排序要求；直接使用 `string` 默认 `<` 最安全。

### 混用输入输出体系

本篇使用 `cin` 读取 `string`，完整程序就统一使用 `cin` / `cout`。不要在同一程序中再混入 `scanf` / `printf`。

## 基础练习

1. 手动比较 `apple` 与 `apply`、`app` 与 `apple`、`z` 与 `aa`，指出决定结果的步骤。
2. 实现 `lexicographic_compare`，与 `string` 的 `<`、`==`、`>` 随机比较结果。
3. 把完整程序改成从大到小输出，并写出正确的严格比较器。
4. 对没有前导零的非负整数字符串按数值大小排序，处理长度相同与不同两种情况。
5. 给每个单词附带原输入编号，在文本相同时按照编号从小到大排序。
6. 比较 `sort` 与 `stable_sort` 对相同键、不同附加编号记录的输出差异。

## 需要记住什么

1. 两个字符串内容相等需要满足哪两个条件？
2. 字典序由哪个不同字符决定？
3. 什么情况下才由字符串长度决定大小？
4. 为什么 `z` 大于 `aa`？
5. C++ `string` 提供哪些比较运算符？
6. 字符串形式的数字为什么不自动按照数值比较？
7. `sort` 怎样使用 `string` 的字典序？
8. 逻辑区间 `words[1..n]` 怎样转换成 STL 半开迭代器区间？
9. 为什么不能把比较器写成“小于等于”？

自然语言词典可能忽略大小写、重音符号或标点，并受语言环境影响；这些本地化规则不属于普通算法竞赛字符串比较。本篇只固定小写英文字母的逐字符字典序。
