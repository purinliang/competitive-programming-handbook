# Z 函数

> 最近修订：2026-08-17 04:17 +10:00（未审阅）

KMP 的前缀函数询问“每个前缀的后缀与开头相同多少”，Z 函数换一个观察方向：

> 从每个位置开始的后缀，与整个字符串的开头相同多少？

这个定义直接回答“字符串前缀从哪些位置再次出现”，也能通过拼接模式串和文本串
完成线性时间模式匹配。

## 定义

对字符串 `s[1..n]`，`z[i]` 表示 `s` 与后缀 `s[i..n]` 的最长公共前缀
长度，即最大的 $k$，使得：

$$
s[1..k]=s[i..i+k-1].
$$

例如：

```text
s = a a b a a b
```

- `z[2] = 1`，因为 `s[2..]` 与原串开头只有第一个 `a` 相同；
- `z[4] = 3`，因为两个串都以 `aab` 开头；
- `z[6] = 0`，因为 `b != a`。

`z[1]` 比较字符串与自身，本文约定 `z[1] = n`。有些资料把它定义为 `0`，
使用模板前需要先确认约定。

## 朴素计算

对每个位置从头比较：

```cpp
while (i + z[i] <= n &&
       s[1 + z[i]] == s[i + z[i]]) {
    z[i]++;
}
```

这段代码准确表达定义，但每个位置可能重新比较很长一段，总复杂度最坏为
$O(n^2)$。线性算法的关键是复用已经确认相等的区间。

## Z 区间

处理位置 `i` 以前，维护右端点最远的匹配区间 `[l,r]`，满足：

$$
s[l..r]=s[1..r-l+1].
$$

这意味着区间中的内容是字符串前缀的一份副本。`r` 越靠右，能够复用的已知
信息越多。

### 当前位置在区间外

若 `i > r`，没有现成信息，令 `z[i] = 0`，按照定义从头比较。

### 当前位置在区间内

若 `i <= r`，位置 `i` 在前缀副本中的对应位置是：

$$
i-l+1.
$$

因此可以先复制：

```cpp
z[i] = min(r - i + 1, z[i - l + 1]);
```

为什么要取最小值？

- `z[i-l+1]` 是对应前缀位置已经知道的匹配长度；
- `r-i+1` 是当前已知 Z 区间内还剩多少字符；
- 超过 `r` 的部分尚未比较，不能直接相信。

完成初始化以后，再从 `i + z[i]` 向右暴力扩展。这样每次真正产生新比较成果时，
都会推动最右端点 `r` 向右。

## 更新区间

扩展完成后，当前匹配区间是：

```text
[i, i + z[i] - 1]
```

若它比原来的 `r` 更远，就更新：

```cpp
if (i + z[i] - 1 > r) {
    l = i;
    r = i + z[i] - 1;
}
```

完整过程：

```cpp
for (int i = 2; i <= n; i++) {
    if (i <= r) {
        z[i] = min(r - i + 1, z[i - l + 1]);
    }

    while (i + z[i] <= n &&
           s[1 + z[i]] == s[i + z[i]]) {
        z[i]++;
    }

    if (i + z[i] - 1 > r) {
        l = i;
        r = i + z[i] - 1;
    }
}
```

## 为什么是线性时间

区间内部能够确认的字符由已有 `z` 值直接复制，不会重新逐字符比较。`while`
只有在尝试越过当前最右端点时才可能成功，而每次成功都会让 `r` 增加。

`r` 最多从 `1` 增加到 `n`，所以所有成功扩展总计 $O(n)$ 次；每个位置最多再
发生一次终止扩展的失败比较。因此总时间复杂度是 $O(n)$。

## 用 Z 函数匹配模式串

把模式串、一个不会出现在输入中的分隔符和文本串拼起来：

```text
pattern#text
```

对拼接串计算 Z 函数。文本中的某个位置若满足 `z[i] >= m`，说明从该位置开始
的至少 `m` 个字符等于整个拼接串的前 `m` 个字符，也就是模式串。

若拼接串使用 1-based 下标：

- 模式占 `[1,m]`；
- 分隔符位于 `m+1`；
- 文本位置 `k` 对应拼接位置 `m+1+k`。

所以拼接位置 `i` 对应的文本起点为：

$$
i-m-1.
$$

分隔符必须不在模式串和文本串中，否则一次匹配可能跨过边界继续延伸。本篇输入
只含小写英文字母，因此使用 `#`。

## 完整代码

下面用 Z 函数输出模式串在文本串中的所有 1-based 起点，包括重叠出现。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
string s;
vector<int> z;

void build_z_function() {
    z.assign(n + 5, 0);
    z[1] = n;

    int l = 1;
    int r = 1;

    for (int i = 2; i <= n; i++) {
        if (i <= r) {
            z[i] = min(r - i + 1, z[i - l + 1]);
        }

        while (i + z[i] <= n &&
               s[1 + z[i]] == s[i + z[i]]) {
            z[i]++;
        }

        if (i + z[i] - 1 > r) {
            l = i;
            r = i + z[i] - 1;
        }
    }
}

void solve() {
    string text, pattern;
    cin >> text >> pattern;

    int pattern_length = pattern.size();
    string combined = pattern + "#" + text;

    n = combined.size();
    s = " " + combined;
    build_z_function();

    vector<int> occurrences;

    for (int i = pattern_length + 2; i <= n; i++) {
        if (z[i] >= pattern_length) {
            occurrences.push_back(i - pattern_length - 1);
        }
    }

    cout << occurrences.size() << '\n';
    for (int position : occurrences) {
        cout << position << ' ';
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```

## 常见错误

- 不先确认资料采用的 `z[1]` 约定；
- 当前位置在 Z 区间内时忘记用 `r-i+1` 限制复制长度；
- 把对应位置写错，1-based 下应为 `i-l+1`；
- 扩展时把右端边界 `i+z[i] <= n` 写错；
- 拼接时使用可能出现在输入中的分隔符；
- 忘记拼接位置转换回文本位置时还要跨过分隔符。

## 需要记住什么

- `z[i]` 比较的是哪两个字符串？
- Z 区间 `[l,r]` 保存了什么已经确认的信息？
- 为什么区间内初始化要取
  `min(r-i+1, z[i-l+1])`？
- 为什么所有向右暴力扩展合计只有线性次数？
- `pattern#text` 怎样把模式匹配变成前缀匹配？
