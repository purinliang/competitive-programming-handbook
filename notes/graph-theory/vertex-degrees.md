# 度数

> 最近修订：2026-08-17 11:48 +10:00（未审阅）

只知道一张图有哪些点和边之后，我们经常还要描述某个点连接了多少条边。这个数量称为点的度数（degree）。

## 无向图的度数

在无向图中，与点 $u$ 相连的边数称为点 $u$ 的度数，记作 $\deg(u)$。

![无向图的度数](../assets/graph-theory/undirected-degrees.svg)

上图中：

- 点 $1$ 与两条边相连，所以 $\deg(1)=2$；
- 点 $2$ 与两条边相连，所以 $\deg(2)=2$；
- 点 $3$ 与三条边相连，所以 $\deg(3)=3$；
- 点 $4$ 除了连接点 $3$，还有一个自环。自环的两端都落在点 $4$ 上，因此对度数贡献 $2$，所以 $\deg(4)=3$。

每条普通无向边分别让两个端点的度数增加 $1$，自环则让同一个点的度数增加两次。因此，把所有点的度数相加，每条边都会被计算两次：

$$
\sum_{u\in V}\deg(u)=2|E|
$$

所以，无向图中奇数度数的点一定有偶数个。

这个“所有点的度数之和等于边数的两倍”的结论称为握手定理。

## 有向图的入度与出度

有向边区分起点和终点，因此有向图的度数也要分成两种：

- 以点 $u$ 为终点的边数称为入度（in-degree），记作 $\deg^-(u)$；
- 以点 $u$ 为起点的边数称为出度（out-degree），记作 $\deg^+(u)$。

![有向图的入度与出度](../assets/graph-theory/directed-degrees.svg)

观察点 $2$：点 $1$、点 $3$ 和点 $4$ 各有一条边指向它，它还有一个自环，所以 $\deg^-(2)=4$；它有边指向点 $3$ 和点 $4$，自环也从它出发，所以 $\deg^+(2)=3$。

一条自环的起点和终点是同一个点，因此它会让该点的入度和出度各增加 $1$。

每条有向边恰好给一个点贡献一次出度，同时给一个点贡献一次入度，所以：

$$
\sum_{u\in V}\deg^-(u)=\sum_{u\in V}\deg^+(u)=|E|
$$

有时会把入度与出度之和称为有向图中一个点的总度数，但实际解题时通常直接区分入度和出度。

## 从边直接统计

只求度数时不必先建立完整邻接表。读到无向边 `u,v`，给两个端点各增加一次：

```cpp
degree[u]++;
degree[v]++;
```

当 `u == v` 时，两行代码会给同一个点增加两次，恰好符合无向自环对度数贡献 $2$ 的定义。

有向边则分别更新起点的出度和终点的入度：

```cpp
out_degree[u]++;
in_degree[v]++;
```

下面的程序读入一张从 $1$ 开始编号的无向图并输出每个点的度数：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n, m;
    scanf("%d%d", &n, &m);

    vector<int> deg(n + 5);
    for (int i = 1; i <= m; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        deg[u]++;
        deg[v]++;
    }

    for (int u = 1; u <= n; u++) {
        printf("%d%c", deg[u], u == n ? '\n' : ' ');
    }
}

int main() {
    solve();
    return 0;
}
```

正文推导使用完整名称 `degree` 表达含义；最终竞赛代码按照图论中的常见缩写写成
`deg`。需要同时维护入度与出度时，相应使用 `indeg` 和 `outdeg`。

输入：

```text
4 4
1 2
2 3
3 1
4 4
```

输出：

```text
2 2 2 2
```

前三条边构成三角形，最后一条自环让点 $4$ 的度数一次增加 $2$。读边和输出各进行一次线性扫描，时间复杂度为 $O(n+m)$，度数数组使用 $O(n)$ 空间。

## 基础练习

1. 画一张含五个点的无向图，逐点统计度数，再用握手定理检查总和。
2. 在图中加入一个自环，比较加入前后该点度数与总度数的变化。
3. 证明无向图中奇数度数的点一定有偶数个。
4. 对同一组有向边分别统计入度和出度，检查两者总和是否都等于边数。
5. 修改完整程序，使它读入有向图并逐点输出入度与出度。

## 需要记住什么

- 无向图中一个点的度数如何计算？
- 为什么无向图中的自环对度数贡献 $2$？
- 有向图的入度和出度分别计算哪些边？
- 为什么一条有向自环会让入度和出度各增加 $1$？
- 所有点的度数之和与边数有什么关系？
