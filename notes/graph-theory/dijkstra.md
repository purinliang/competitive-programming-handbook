# 最短路：Dijkstra

> 最近修订：2026-08-17 04:02 +10:00（未审阅）

在带权图中，从起点到另一个点可能有许多条路径。经过边数最少的路径不一定具有
最小权值和，因此普通 BFS 不能直接解决一般的非负边权最短路。

Dijkstra 算法反复选出当前距离最小的未处理点，用它的出边继续松弛其他点。只要
所有边权非负，这个最小距离一旦被选出就不可能再被后续路径改善。

本篇使用 `priority_queue` 实现稀疏图上的 Dijkstra，时间复杂度为
$O((n+m)\log n)$。

## 最短距离与松弛

令：

```cpp
dist[u]
```

表示起点 `s` 到点 `u` 的当前最短距离。初始只有起点已知：

```cpp
dist.assign(n + 5, INF);
dist[s] = 0;
```

假设已经有一条长度为 `dist[u]` 的路径到达点 `u`，再经过边
$u\xrightarrow{w}v$，就得到一条到点 `v` 的候选路径：

$$
\text{candidate}=\text{dist}[u]+w.
$$

若候选值更小，就更新 `dist[v]`：

```cpp
ll candidate = dist[u] + w;
if (candidate < dist[v]) {
    dist[v] = candidate;
}
```

这一步称为 **松弛**。松弛只说明发现了一条更好的路径；在 Dijkstra 选中点
`v` 以前，`dist[v]` 仍可能继续变小。

## 为什么要先处理距离最小的点

设当前所有未处理点中，点 `u` 的 `dist[u]` 最小。假设还存在一条尚未发现的
更短路径到达 `u`。

沿这条路径从起点向后走，找到第一个尚未处理的点 `x`，并令它前面的点为 `p`。
点 `p` 已经处理过，所以算法当时已经检查边 $p\to x$，得到：

$$
\text{dist}[x]\le
\text{dist}[p]+w(p,x).
$$

由于所有边权非负，从 `x` 继续走到 `u` 不会让路径长度减少，因此这条更短路径
到达 `x` 时的长度不大于它到达 `u` 时的长度。于是应有：

$$
\text{dist}[x]<\text{dist}[u].
$$

这与 `u` 是当前距离最小的未处理点矛盾。因此，选中 `u` 时
`dist[u]` 已经是最终答案。

这个证明最关键的条件就是 **边权非负**。若存在负边，从 `x` 到 `u` 的后半段
可能让距离继续下降，上述结论便不成立。

## 朴素地寻找最小距离

可以每轮扫描所有点，寻找未处理且距离最小的点，再枚举它的出边。选出一个点需要
$O(n)$，共选出至多 $n$ 个点，因此仅寻找最小值就需要 $O(n^2)$。

邻接矩阵上的朴素 Dijkstra 正好是 $O(n^2)$，在稠密图中可能足够；但竞赛常见
稀疏图只有 $O(n)$ 或 $O(n\log n)$ 条边，继续扫描所有点会浪费大量时间。

我们真正需要的操作是：

1. 加入一个新的候选距离；
2. 反复取出当前最小的候选距离。

这正是小根优先队列提供的操作。

## 优先队列保存距离快照

优先队列中的每项保存：

```cpp
pair<ll, int>{current_dist, u}
```

`pair` 先比较第一项，因此小根优先队列会优先取出距离最小的状态：

```cpp
priority_queue<pair<ll, int>,
               vector<pair<ll, int>>,
               greater<pair<ll, int>>> q;
```

初始化时只加入起点：

```cpp
q.push({0, s});
```

一次成功松弛后，把新的距离快照加入队列：

```cpp
dist[v] = candidate;
q.push({dist[v], v});
```

优先队列不能直接找到并修改旧状态。若点 `v` 先以距离 `10` 入队，后来又得到
距离 `7`，队列中会同时保留 `(10,v)` 和 `(7,v)`。

## 过期状态

弹出状态时比较快照与当前答案：

```cpp
auto [current_dist, u] = q.top();
q.pop();

if (current_dist != dist[u]) {
    continue;
}
```

若两者不同，说明这个队列项已经被更短路径取代，只需丢弃。若相同，它就是当前
距离最小的有效状态，可以展开 `g[u]`。

这种做法称为懒删除：不在更新时寻找旧项，而在旧项到达队首时判断是否过期。
每次成功松弛只多加入一个状态，代码简单，也不会改变渐进复杂度。

不要只在第一次发现点 `v` 时入队。Dijkstra 与普通 BFS 不同，一个点可能先通过
较长路径被发现，随后再被更短路径改善。

## 完整循环

把取最小值、跳过过期状态和松弛组合起来：

```cpp
while (!q.empty()) {
    auto [current_dist, u] = q.top();
    q.pop();

    if (current_dist != dist[u]) {
        continue;
    }

    for (auto& [v, w] : g[u]) {
        ll candidate = current_dist + w;
        if (candidate >= dist[v]) {
            continue;
        }

        dist[v] = candidate;
        q.push({dist[v], v});
    }
}
```

有效状态使用自己的 `current_dist` 计算候选值。由于它已经等于 `dist[u]`，
两种写法数值相同；使用快照能让“本次展开的路径长度”更明确。

## 一个处理过程

考虑以下有向边：

```text
1 -> 2 (10)
1 -> 3 (3)
3 -> 2 (4)
2 -> 4 (2)
3 -> 4 (8)
```

从点 `1` 出发：

1. 初始 `dist[1]=0`；
2. 处理点 `1`，得到 `dist[2]=10`、`dist[3]=3`；
3. 队列先取出点 `3`，经 `3 -> 2` 把 `dist[2]` 改成 `7`；
4. 再经 `3 -> 4` 得到 `dist[4]=11`；
5. 处理距离为 `7` 的点 `2`，把 `dist[4]` 改成 `9`；
6. 旧状态 `(10,2)` 和 `(11,4)` 以后弹出时都已经过期。

最终距离是：

| 点 | 1 | 2 | 3 | 4 |
| ---: | ---: | ---: | ---: | ---: |
| `dist` | 0 | 7 | 3 | 9 |

“先发现”不等于“已经最短”；优先队列保证的是当前最小的有效候选先被确认。

## 不可达点与整数范围

不可达点始终保持 `INF`。完整代码使用：

```cpp
const ll INF = 1LL << 62;
```

它远大于常见题目中的最短路，又给 64 位整数上界留出余量。即使如此，仍应先根据
点数和最大边权估算最长可能答案；若合法路径本身可能接近 $2^{63}-1$，普通
64 位整数就不再足够。

算法只从优先队列中弹出的有限距离出发进行加法，不会用 `INF + w` 松弛边。

## 正确性

每次弹出的有效状态都是所有未确认点中距离最小的点。由非负边权条件，任何尚未
展开的路径都不可能先到达另一个距离不小于它的点，再通过后续边把总长度降到
`dist[u]` 以下，因此本次距离已经最终确定。

算法会检查每个最终确定点的全部出边。对任意可达点 `v`，取一条从 `s` 到 `v`
的最短路；路径上的点会从起点开始依次被确认，每条相邻边都会在前一个点确认时
尝试松弛，于是 `v` 最终一定得到这条最短路的长度。

结合两点可知，所有可达点的 `dist` 都等于最短距离，不可达点保持 `INF`。

## 复杂度

每次成功松弛至多加入一个优先队列状态，而成功松弛次数不超过边检查次数
$O(m)$。每个状态至多入队、出队一次，每次优先队列操作需要 $O(\log m)$；
通常写成：

$$
O((n+m)\log n).
$$

邻接表占 $O(n+m)$ 空间，距离数组和优先队列占 $O(n+m)$ 空间。

## 完整代码

程序读取一张带非负边权的有向图，输出起点到每个点的最短距离；不可达点输出
`-1`。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

const ll INF = 1LL << 62;

int n, m, s;
vector<vector<pair<int, ll>>> g;
vector<ll> dist;

void dijkstra() {
    dist.assign(n + 5, INF);

    priority_queue<pair<ll, int>,
                   vector<pair<ll, int>>,
                   greater<pair<ll, int>>> q;
    dist[s] = 0;
    q.push({0, s});

    while (!q.empty()) {
        auto [current_dist, u] = q.top();
        q.pop();

        if (current_dist != dist[u]) {
            continue;
        }

        for (auto& [v, w] : g[u]) {
            ll candidate = current_dist + w;
            if (candidate >= dist[v]) {
                continue;
            }

            dist[v] = candidate;
            q.push({dist[v], v});
        }
    }
}

int main() {
    scanf("%d%d%d", &n, &m, &s);

    g.assign(n + 5, {});
    for (int i = 1; i <= m; i++) {
        int u, v;
        ll w;
        scanf("%d%d%lld", &u, &v, &w);
        g[u].push_back({v, w});
    }

    dijkstra();

    for (int u = 1; u <= n; u++) {
        if (dist[u] == INF) {
            printf("-1");
        } else {
            printf("%lld", dist[u]);
        }
        printf("%c", " \n"[u == n]);
    }
    return 0;
}
```

输入：

```text
4 5 1
1 2 10
1 3 3
3 2 4
2 4 2
3 4 8
```

输出：

```text
0 7 3 9
```

## 常见错误

### 图中存在负边

Dijkstra 的正确性依赖边权非负。即使样例碰巧通过，也不能把它用于含负边的图。

### 使用大根优先队列

默认 `priority_queue` 先取最大值。Dijkstra 需要小根优先队列，必须写出
`greater<pair<ll, int>>`，或采用另一套明确的反序比较。

### 忘记跳过过期状态

不跳过过期状态通常仍可能得到正确距离，但会反复展开已经被淘汰的路径，复杂度和
实际运行时间都可能显著恶化。

### 用 `int` 保存路径长度

一条边权能放入 32 位整数，不表示多条边权之和也能放入。距离和候选值应按题目
上界选择 64 位整数。
