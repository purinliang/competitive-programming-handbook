# 树的遍历：深度优先搜索（DFS）

> 最近修订：2026-08-16 16:30 +10:00（未审阅）

[有根树](rooted-trees.md) 定义了父节点、深度和子树，但输入通常只给出一棵无根树
的 $n-1$ 条边。若要得到以节点 $1$ 为根时的全部层级关系，需要从根出发沿边访问
每个节点，并在访问过程中确定它从哪里来、位于第几层以及下方包含多少节点。

深度优先搜索（depth-first search，DFS）会先沿当前分支不断深入，走到叶节点后
再逐层返回。这个“先进入子树，处理完整棵子树后再返回”的过程，正好适合计算树上
的层级与子树信息。

## 深入一棵子树

下面仍把节点 $1$ 作为根。每个圆中的 `u · #k` 表示节点编号为 `u`，并且它是
DFS 第 $k$ 个进入的节点。

![树的深度优先搜索顺序](../assets/graph-theory/tree-depth-first-search.svg)

如果每个节点按照图中从左到右的顺序处理相邻节点，DFS 的进入顺序是：

```text
1 2 5 6 3 7 4 8
```

从节点 $1$ 进入节点 $2$ 后，搜索不会立即返回根节点去看节点 $3$，而是继续进入
节点 $5$。节点 $5$ 没有子节点，搜索才返回节点 $2$，再进入节点 $6$。只有节点
$2$ 的整棵子树都处理完成，搜索才会回到节点 $1$。

这个顺序不是树本身唯一确定的。交换邻接表中两个相邻节点的存储顺序，可能改变
DFS 的先后顺序，但不会改变父子关系以外的树本身，也不会让任何节点漏掉或重复。

## 不能递归到所有相邻节点

先尝试从当前节点 `u` 递归到 `g[u]` 中的每个相邻节点：

```cpp
vector<vector<int>> g;

void dfs(int u) {
    printf("%d ", u);

    for (int v : g[u]) {
        dfs(v);
    }
}
```

无向边 $(u,v)$ 在邻接表中保存为两个方向。从 `u` 进入 `v` 后，`g[v]` 又会看见
`u`，于是函数立即沿原边返回，再次进入 `v`，不断重复。

我们需要区分当前节点的父节点和真正通向下方子树的边。

## 跳过父节点

进入节点 `u` 时，同时记录它是从哪个父节点 `p` 过来的。枚举邻居 `v` 时，如果
当前邻居就是父节点，跳过这条原路返回的边：

```cpp
void dfs(int u, int p) {
    printf("%d ", u);

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }
        dfs(v, u);
    }
}
```

第一次从根节点开始时，根没有父节点。真实节点从 $1$ 开始编号，所以用不存在的
节点 `0` 表示这个空关系：

```cpp
dfs(1, 0);
```

树是连通且无环的。从根到任何非根节点 `v` 都有唯一一条路径，因此第一次进入
`v` 时，路径上的前一个节点就是它唯一的父节点。除父节点以外，`v` 的每个邻居
都位于一棵尚未访问的子树中；跳过父节点以后不可能从另一条边绕回已经访问的节点。

这就是树上 DFS 不需要 `visited` 数组的原因。一般图可能有环，需要使用完整的
访问标记；如果输入并不保证是一棵树，只跳过父节点并不安全。

## 进入节点时确定层级

父节点参数已经给出了 `parent[u]`：

```cpp
parent[u] = p;
```

根节点的深度为 $0$。从 `u` 进入子节点 `v` 前，可以确定 `v` 比 `u` 深一层：

```cpp
depth[v] = depth[u] + 1;
dfs(v, u);
```

这些操作发生在第一次进入节点或即将进入子节点时，不需要等待子树处理完成。把
操作写在递归调用以前，通常称为进入时或前序位置的操作。

## 返回以后合并子树

每个节点自己的子树至少包含它自己，因此第一次进入 `u` 时令：

```cpp
subtree_size[u] = 1;
```

`dfs(v, u)` 返回时，节点 `v` 的整棵子树已经处理完成，
`subtree_size[v]` 也已经得到。此时才能把它加入当前节点：

```cpp
dfs(v, u);
subtree_size[u] += subtree_size[v];
```

一个节点的子树由它自己和每棵子树互不重叠地组成，所以最终有：

$$
\mathrm{subtree\_size}(u)
=1+\sum_{v\text{ 是 }u\text{ 的子节点}}
\mathrm{subtree\_size}(v)
$$

写在递归调用之后的操作要等子树完成才能执行，通常称为返回时或后序位置的操作。
以后树形 DP 会用同样的结构，把每个子节点已经算出的状态合并到父节点。

## 完整 DFS 函数

把三个任务合在一起：

```cpp
vector<vector<int>> g;
vector<int> parent;
vector<int> depth;
vector<int> subtree_size;

void dfs(int u, int p) {
    parent[u] = p;
    subtree_size[u] = 1;
    printf("%d ", u);

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }

        depth[v] = depth[u] + 1;
        dfs(v, u);
        subtree_size[u] += subtree_size[v];
    }
}
```

`g`、`parent`、`depth` 和 `subtree_size` 都描述整道题中的同一棵树，并且会被
`solve` 与 DFS 共同维护，因此声明为题目级全局状态。函数参数只保留当前节点 `u`
和父节点 `p`，不在每一层递归中重复传递同一批容器。

`parent[u]` 和 `depth[v]` 在进入阶段确定；`subtree_size[v]` 必须等递归返回以后
才能使用。每一行的位置都由信息何时可用决定，而不是需要背诵的固定格式。

## 完整代码

下面的程序读取一棵树，以节点 $1$ 为根，输出 DFS 进入顺序，再输出每个节点的
父节点、深度和子树大小。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<vector<int>> g;
vector<int> parent;
vector<int> depth;
vector<int> subtree_size;

void dfs(int u, int p) {
    parent[u] = p;
    subtree_size[u] = 1;
    printf("%d ", u);

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }

        depth[v] = depth[u] + 1;
        dfs(v, u);
        subtree_size[u] += subtree_size[v];
    }
}

void solve() {
    scanf("%d", &n);

    g.resize(n + 5);
    parent.resize(n + 5);
    depth.resize(n + 5);
    subtree_size.resize(n + 5);

    for (int i = 1; i < n; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    dfs(1, 0);
    printf("\n");

    for (int u = 1; u <= n; u++) {
        printf("%d %d %d %d\n", u, parent[u], depth[u], subtree_size[u]);
    }
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
8
1 2
1 3
1 4
2 5
2 6
3 7
4 8
```

输出：

```text
1 2 5 6 3 7 4 8
1 0 0 8
2 1 1 3
3 1 1 2
4 1 1 2
5 2 2 1
6 2 2 1
7 3 2 1
8 4 2 1
```

后八行依次表示节点编号、父节点、深度和子树大小。根节点的父节点是哨兵 `0`，
整棵树就是根节点的子树，所以 `subtree_size[1] = 8`。

## 正确性

从根节点开始，根显然会被访问。假设节点 `u` 已经访问：它跳过唯一的父节点，
随后递归进入其余每个邻居，也就是全部子节点。树中每个非根节点都有唯一父节点，
所以它只会从父节点进入一次。由树的连通性，所有节点最终都会被访问；由无环性和
父节点判断，没有节点会重复进入。

深度在父节点的正确深度上加一，因此沿根到节点的唯一路径逐层得到正确值。叶节点
的子树大小初始化为 $1$；对于非叶节点，递归返回后每棵子树大小都已经正确，把互不
重叠的子树与节点自身相加，就得到当前节点的正确子树大小。

## 复杂度

一棵有 $n$ 个节点的树有 $n-1$ 条边。邻接表把每条无向边保存两次，DFS 查看
$2(n-1)$ 个邻接项，因此时间复杂度是 $O(n)$。邻接表和三个结果数组占用 $O(n)$
空间，递归调用栈最坏也占用 $O(n)$ 空间。

> 当树退化成一条长链时，递归深度可能达到 $n$，受到评测环境调用栈大小的限制。
> 基础阶段先掌握递归结构；题目规模确实可能导致栈溢出时，再改用显式栈模拟同样
> 的进入与返回过程。

## 常见错误

### 不跳过父节点

无向边同时保存在两个方向。不跳过 `p` 会让递归沿同一条边来回调用，无法结束。

### 把 `p` 当成当前节点

本书统一用 `u` 表示当前节点，`p` 表示父节点。递归进入邻居时应写
`dfs(v, u)`，因为原来的当前节点 `u` 会成为 `v` 的父节点。

### 递归以前累加子树大小

进入 `v` 以前，`subtree_size[v]` 还没有计算完成。必须等 `dfs(v, u)`
返回以后再累加。

### 把 DFS 顺序当成树的固定属性

邻接表顺序会影响先进入哪个子节点。题目没有规定顺序时，不能假设 DFS 一定产生
某个唯一序列。

## 基础练习

1. 从节点 $1$ 以外的节点作为根，重新计算父节点、深度和子树大小。
2. 增加数组 `leaf_count[u]`，在递归返回时计算每棵子树包含多少叶节点。
3. 对每个非根节点输出它与父节点形成的边，观察这些边为什么恰好有 $n-1$ 条。
