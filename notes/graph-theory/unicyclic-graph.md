# 基环树

> 最近修订：2026-08-17 06:29 +10:00（未审阅）

一棵含 `n` 个点的树有 `n-1` 条边，并且没有环。若在树上再加入一条连接已有
两点的边，就会恰好产生一个环。

这种连通无向图称为基环树：它只有一个简单环，环上的每个点还可能挂着若干棵普通
树。识别出唯一的环以后，许多问题就能拆成“环上处理”和“树上处理”两部分。

## 基环树的结构

本篇约定基环树满足：

- 图是无向、连通的；
- 有 `n` 个点和 `n` 条边；
- 图中恰好有一个简单环。

“连通且有 `n` 个点、`n` 条边”已经能推出恰好一个独立的环。因为树从
`n-1` 条边开始，每增加一条连接已有点的边，独立环数量增加一个。

删去唯一环上的所有边以后，剩余每个连通部分都是一棵树，并且各自通过一个环上点
挂在环上：

```text
      tree
       |
tree--cycle--tree
       |
      tree
```

环称为基环，整张图因此得名。

若图不保证连通，每个连通分量都满足“点数等于边数”，得到的是基环树森林或
每个分量都含一个环的伪森林；本篇完整代码只处理连通基环树。

## 为什么普通树遍历需要调整

树的 DFS 只需跳过父节点，因为树中没有其他回边。基环树存在一个环，仅判断
`v == p` 不足以阻止沿环再次回到已经访问的点。

因此可以：

1. 对整张图使用 `vis`；
2. 先找出环，再把环边与挂在环上的树分开处理。

第二种方法更能暴露结构，也是动态规划、最短路和计数问题中的常见入口。

## 反复删除叶子

唯一环上的点在基环内部都有两个环上邻居；环外树的最外层则一定有度数为 `1` 的
叶子。

把所有当前度数为 `1` 的点加入队列并删除：

1. 删除叶子 `u`；
2. 它的未删除邻居 `v` 的度数减少 `1`；
3. 若 `v` 也变成叶子，就继续加入队列。

树枝会从外向内逐层剥掉，而环上的点始终至少保留两个环上邻居，不会进入队列。
最终剩下的点恰好是基环。

这个过程与拓扑排序不断删除零入度点很相似，只是无向图中删除的是当前度数为
`1` 的叶子。

## 维护当前度数

读入无向边时同时统计两个端点的度数：

```cpp
g[u].push_back(v);
g[v].push_back(u);
deg[u]++;
deg[v]++;
```

开始时假设所有点都可能在环上：

```cpp
on_cycle.assign(n + 5, true);
```

初始叶子入队：

```cpp
for (int u = 1; u <= n; u++) {
    if (deg[u] == 1) {
        q.push(u);
    }
}
```

弹出点时把它标记为非环点，再更新仍未删除的邻居：

```cpp
on_cycle[u] = false;
for (int v : g[u]) {
    if (!on_cycle[v]) {
        continue;
    }
    deg[v]--;
    if (deg[v] == 1) {
        q.push(v);
    }
}
```

`on_cycle` 在剥叶过程中也表示“尚未删除”。队列结束以后，尚未删除与位于环上
是同一件事。

## 一个剥叶过程

考虑：

```text
1 - 2 - 3
    |   |
    5 - 4 - 6 - 7
```

其中基环是 `2-3-4-5-2`，点 `1` 挂在 `2` 上，链 `6-7` 挂在 `4` 上。

初始叶子是 `1` 和 `7`：

1. 删除 `1`，点 `2` 仍有两个环上邻居；
2. 删除 `7` 后，点 `6` 的当前度数变成 `1`；
3. 删除 `6`，点 `4` 仍有两个环上邻居；
4. 队列为空，剩下 `2,3,4,5`。

树枝不论多深，都会从最外层逐步传播到环边界。

## 为什么剩下的恰好是环

先看环外节点。删去基环边后，它位于某棵有限树中。树一定有叶子；删除外层叶子后，
剩余部分仍是树或空图，所以所有环外节点最终都会被逐层删除。

再看环上节点。它始终保留左右两个环上邻居。删除挂在它上面的树枝只会去掉额外
邻居，不会让当前度数低于 `2`，因此它不会作为叶子入队。

所以算法不会误删环点，也不会遗留树点。

## 找到环以后能做什么

环点集合只是结构分解的第一步。常见后续包括：

- 从所有环点同时开始 BFS，求每个点到基环的距离；
- 把每个环点当作一棵挂树的根，分别进行树形 DP；
- 在环上再做一维 DP，并合并每棵挂树提供的信息；
- 判断两点路径是否必须经过环，或比较绕环的两个方向。

若需要环上的循环顺序，可以任选一个环点开始，只沿 `on_cycle[v]` 为真的邻居
移动，并跳过上一个点，直到回到起点。只知道环点集合时，输出顺序通常不重要。

## 复杂度

每个点至多入队一次，每条无向边的两个邻接项各检查一次，时间复杂度为 $O(n)$；
邻接表、度数、队列和标记数组占用 $O(n)$ 空间。这里使用了基环树边数
`m=n` 的条件；一般图上同一过程写作 $O(n+m)$。

## 完整代码

程序读取一棵含 `n` 个点、`n` 条边的连通基环树，输出基环上的点。输出按点编号
递增，不表示环上的相邻顺序。

```cpp
#include <bits/stdc++.h>

using namespace std;

int n;
vector<vector<int>> g;
vector<int> deg;
vector<bool> on_cycle;

void find_cycle_vertices() {
    queue<int> q;
    on_cycle.assign(n + 5, true);

    for (int u = 1; u <= n; u++) {
        if (deg[u] == 1) {
            q.push(u);
        }
    }

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        on_cycle[u] = false;
        for (int v : g[u]) {
            if (!on_cycle[v]) {
                continue;
            }

            deg[v]--;
            if (deg[v] == 1) {
                q.push(v);
            }
        }
    }
}

int main() {
    scanf("%d", &n);

    g.assign(n + 5, {});
    deg.assign(n + 5, 0);
    for (int i = 1; i <= n; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
        deg[u]++;
        deg[v]++;
    }

    find_cycle_vertices();

    vector<int> cycle_vertices;
    for (int u = 1; u <= n; u++) {
        if (on_cycle[u]) {
            cycle_vertices.push_back(u);
        }
    }

    printf("%d\n", (int)cycle_vertices.size());
    for (int i = 0; i < (int)cycle_vertices.size(); i++) {
        printf("%d%c", cycle_vertices[i],
               " \n"[i + 1 == (int)cycle_vertices.size()]);
    }
    return 0;
}
```

输入：

```text
7
1 2
2 3
3 4
4 5
5 2
4 6
6 7
```

输出：

```text
4
2 3 4 5
```

## 常见错误

### 把原始度数当成始终不变

剥叶依赖删除节点后的 **当前度数**。邻居失去一条边时必须递减 `deg[v]`。

### 初始只加入一个叶子

所有树枝必须同时向内剥离，应把全部初始度数为 `1` 的点加入队列。

### 用树 DFS 只跳过父节点

基环树不是树。沿唯一环遍历时还会回到更早访问的祖先，必须使用访问标记或先分离
环。

### 把剩余点的编号顺序当成环顺序

按编号输出只表示集合。需要相邻顺序时必须沿剩余环边再走一圈。
