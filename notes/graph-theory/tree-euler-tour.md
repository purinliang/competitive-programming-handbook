# 树的 DFS 序与子树区间

> 最近修订：2026-08-17 06:03 +10:00（未审阅）

树上的节点按照父子关系分散在不同邻接表中。若题目反复询问或修改某个节点的整棵
子树，逐次 DFS 会重复访问大量节点。

对有根树进行深度优先搜索时，在第一次到达节点的瞬间给它编号。DFS 会完整处理
当前节点的子树以后才返回父节点，因此同一子树中的所有节点会得到一段连续编号。

这段编号通常称为 DFS 序；它把子树问题转换成普通数组上的区间问题。

## 按第一次到达的顺序编号

准备计时器：

```cpp
int timer = 0;
```

第一次进入节点 `u` 时：

```cpp
dfn[u] = ++timer;
rev[timer] = u;
```

`dfn[u]` 表示节点 `u` 在 DFS 序中的位置；`rev[i]` 表示 DFS 序第 `i` 个位置
对应哪个原树节点。二者互为反向映射：

```text
rev[dfn[u]] = u
```

本书自定义的节点和数组都使用 1-based 编号，所以计时器先增加再赋值。

## 为什么一棵子树是连续区间

DFS 进入节点 `u` 后，会依次递归处理它的每个儿子。在处理完整棵 `u` 的子树
以前，递归不会返回 `u` 的父节点，也不会进入 `u` 子树外的其他分支。

因此从 `dfn[u]` 开始，接下来得到编号的恰好是 `u` 的全部后代；所有后代处理完
以后，才会出现子树外的节点。

如果 `siz[u]` 表示 `u` 子树的节点数量，那么它对应的闭区间就是：

$$
[\text{dfn}[u],\ \text{dfn}[u]+\text{siz}[u]-1].
$$

左端点是 `u` 自己，区间长度是整棵子树大小。

## 在同一次 DFS 中计算子树大小

进入节点时，子树至少包含自己：

```cpp
siz[u] = 1;
```

每处理完一个儿子 `v`，它的整棵子树已经统计完成：

```cpp
dfs(v, u);
siz[u] += siz[v];
```

于是 DFS 返回以前，`siz[u]` 就等于所有儿子子树大小之和再加自己。

完整过程为：

```cpp
void dfs(int u, int p) {
    par[u] = p;
    dfn[u] = ++timer;
    rev[timer] = u;
    siz[u] = 1;

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }
        dfs(v, u);
        siz[u] += siz[v];
    }
}
```

无向树的邻接表同时保存两个方向，所以必须跳过父节点。树没有其他环，不需要额外
`vis` 数组。

## 一个具体例子

以点 `1` 为根，按照邻接表顺序遍历：

```text
1
├── 2
│   ├── 4
│   └── 5
└── 3
    ├── 6
    └── 7
```

第一次到达顺序为：

```text
1, 2, 4, 5, 3, 6, 7
```

对应关系：

| 节点 `u` | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `dfn[u]` | 1 | 2 | 5 | 3 | 4 | 6 | 7 |
| `siz[u]` | 7 | 3 | 3 | 1 | 1 | 1 | 1 |

点 `2` 的子树区间是：

$$
[2,\ 2+3-1]=[2,4].
$$

在 `rev` 中查看位置 `2..4`，得到节点 `2,4,5`，正好是点 `2` 的整棵子树。

点 `3` 的区间是 $[5,7]$；两棵兄弟子树形成互不相交的连续区间。

## 进入时间与离开时间

也可以在处理完整棵子树以后记录：

```cpp
out[u] = timer;
```

此时：

$$
\text{out}[u]=\text{dfn}[u]+\text{siz}[u]-1.
$$

所以维护 `out` 与维护 `siz` 都能表示子树右端点。`siz` 还直接提供子树大小，
通常更有用；若某些算法更强调进入、离开时刻，使用 `dfn` 和 `out` 也很自然。

不要把这里的离开时间和“进入、退出各记录一次”的长度 `2n` 欧拉序混为一谈。
本篇 DFS 序只在第一次进入节点时记录一次，总长度恰好是 `n`。

## 把节点权值排成数组

若每个节点 `u` 有权值 `value[u]`，建立：

```cpp
order_value[dfn[u]] = value[u];
```

那么 `u` 子树内全部权值就位于数组区间：

```cpp
int l = dfn[u];
int r = dfn[u] + siz[u] - 1;
```

这一步称为把树拍平。之后可以按问题需求使用：

- 前缀和回答静态子树和；
- 树状数组处理单点修改与子树和查询；
- 线段树处理区间修改、区间查询；
- 其他数组数据结构处理相应区间信息。

DFS 序只负责把从属关系转换成区间，不负责具体维护哪种信息。

## 祖先关系

节点 `u` 是节点 `v` 的祖先，当且仅当 `v` 位于 `u` 的子树区间：

$$
\text{dfn}[u]\le\text{dfn}[v]
\le\text{dfn}[u]+\text{siz}[u]-1.
$$

代码可以写成：

```cpp
bool is_ancestor(int u, int v) {
    return dfn[u] <= dfn[v] &&
           dfn[v] < dfn[u] + siz[u];
}
```

第二个条件写成严格小于右端点后一位，与上面的闭区间完全等价。这里使用加法形式
可以少写一次 `-1`；它不改变本书对子树区间采用闭区间的约定。

## DFS 序取决于邻接顺序

同一棵树若以不同顺序枚举儿子，具体 `dfn` 会变化，但每棵子树仍然连续。

因此题目只要求子树区间时，不需要追求唯一 DFS 序。若题目要求按节点编号较小的
儿子先访问，就要预先排序邻接表；排序会增加 $O(n\log n)$ 量级的时间。

根节点也会改变父子关系和子树定义。建立 DFS 序以前必须先确定题目指定的根；
无指定时才自行选择常见的点 `1`。

## 正确性

对递归结构归纳。

叶节点进入时立刻获得一个编号，`siz[u]=1`，其子树区间只含自己，结论成立。

对非叶节点 `u`，假设每个儿子 `v` 的递归会生成一段长度为 `siz[v]` 的连续
区间。DFS 在进入 `u` 后依次完整执行这些递归，中间不会访问 `u` 子树外的节点，
所以 `u` 自己和所有儿子区间首尾相接，组成一段长度为：

$$
1+\sum \text{siz}[v]=\text{siz}[u]
$$

的连续区间，左端点为 `dfn[u]`。因此右端点是
`dfn[u]+siz[u]-1`。

归纳到根节点后，所有子树区间结论成立。

## 复杂度

DFS 访问每个点一次，并检查无向树的每个邻接项一次，时间复杂度为 $O(n)$。
邻接表和所有数组占用 $O(n)$ 空间，递归调用栈最坏为 $O(n)$。

链状树可能使递归深度接近 `n`。若题目栈空间很小，需要改为显式栈遍历；这不会
改变 DFS 序和子树区间原理。

## 完整代码

程序读取以 `root` 为根的无向树，再回答若干查询。每个查询给出节点 `u`，输出
它在 DFS 序中的子树闭区间。

```cpp
#include <bits/stdc++.h>

using namespace std;

int n, root, query_count;
int timer;
vector<vector<int>> g;
vector<int> par;
vector<int> dep;
vector<int> siz;
vector<int> dfn;
vector<int> rev;

void dfs(int u, int p) {
    par[u] = p;
    dep[u] = dep[p] + 1;
    dfn[u] = ++timer;
    rev[timer] = u;
    siz[u] = 1;

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }
        dfs(v, u);
        siz[u] += siz[v];
    }
}

int main() {
    scanf("%d%d%d", &n, &root, &query_count);

    g.assign(n + 5, {});
    for (int i = 1; i <= n - 1; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    par.assign(n + 5, 0);
    dep.assign(n + 5, 0);
    siz.assign(n + 5, 0);
    dfn.assign(n + 5, 0);
    rev.assign(n + 5, 0);
    timer = 0;
    dfs(root, 0);

    while (query_count--) {
        int u;
        scanf("%d", &u);

        int l = dfn[u];
        int r = dfn[u] + siz[u] - 1;
        printf("%d %d\n", l, r);
    }
    return 0;
}
```

输入：

```text
7 1 3
1 2
1 3
2 4
2 5
3 6
3 7
2
3
4
```

输出：

```text
2 4
5 7
3 3
```

## 常见错误

### 在退出节点时才记录唯一编号

子树区间通常使用第一次进入顺序。若改用其他遍历时刻，必须重新证明对应区间性质，
不能沿用本篇公式。

### 忘记把节点自己计入子树大小

`siz[u]` 初始应为 `1`，不是 `0`。

### 无向树中没有跳过父节点

邻接表包含反向边；不跳过 `p` 会让递归在父子之间无限往返。

### 混淆 `dfn` 与 `rev`

`dfn` 从原节点映射到序列位置，`rev` 从序列位置映射回原节点。
