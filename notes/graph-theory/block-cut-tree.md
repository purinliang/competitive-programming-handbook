# 圆方树

> 最近修订：2026-08-23 05:35 +10:00（未审阅）

《[点双连通分量](vertex-biconnected-components.md)》把无向图划分成若干点双连通
分量，但分量并不是互不相交的：一个割点可以同时属于多个分量。若继续直接在“分量
集合”上做路径查询，很难表达这些共享关系。

圆方树把每个原图点和每个点双连通分量都变成节点，再用包含关系连接两类节点。复杂
无向图因此变成树或森林，后续可以复用 LCA、树上差分和树形 DP。

## 圆点与方点

保留原图点编号 $1\ldots n$，称为圆点。若一共有 `component_count` 个点双连通
分量，就把第 `i` 个分量编号为：

```cpp
int component_node = n + i;
```

这些新节点称为方点。若原图点 `u` 属于第 `i` 个分量，就连接：

```text
圆点 u -- 方点 n+i
```

圆方树是二部图：每条边都连接一个原图点与一个分量节点，不会出现圆点—圆点或
方点—方点的边。

## 为什么保留所有原图点

有些资料只保留割点和分量节点，因为普通点只属于一个分量，可以附着在对应方点上。
本文保留所有原图点，原因是语义更直接：

- 原图中查询的点仍使用原编号；
- 点权可以继续放在圆点上；
- 方点只代表分量，不需要同时充当一批普通点；
- 从圆方树路径上可以直接辨认经过了哪些割点和分量。

代价只是多保留一些叶状圆点，仍为线性空间。

## 为什么得到树

先看原图的一个连通分量。圆方结构显然连通，因为原图每条边都属于某个点双连通
分量，相邻原图点可以经过对应方点相连。

它也不可能含环。如果若干方点和共享圆点形成环，那么这些分量之间存在绕过任意一个
共享点的替代路线，它们就不应是彼此分开的极大点双连通分量。

所以一个原连通分量对应一棵圆方树；原图不连通时得到圆方森林。

## 从分量列表建树

点双分解已经得到：

```cpp
vector<vector<int>> component;
```

其中 `component[i]` 列出第 `i` 个分量包含的全部原图点。建树只需枚举所有包含
关系：

```cpp
for (int i = 0; i < component.size(); ++i) {
    int component_node = n + i + 1;
    for (int u : component[i]) {
        tree[u].push_back(component_node);
        tree[component_node].push_back(u);
    }
}
```

同一个割点出现在多个分量列表中，于是自然连接多个方点；普通点只连接自己的唯一
方点。

## 路径语义

圆方树上一条圆点到圆点的路径交替经过：

```text
原图点 -> 点双分量 -> 共享点 -> 点双分量 -> ... -> 原图点
```

路径内部出现的圆点都是原图中无法绕开的割点。方点则表示路径进入了哪个点双连通
区域；在同一方点内部，原图可能存在许多不同走法，圆方树只保留它们共同的连通结构。

因此圆方树适合处理“两个点之间必经多少割点”“经过哪些点双分量”等问题。它不保留
分量内部的具体最短路长度，不能把圆方树边数直接当成原图距离。

## 完整代码

下面的独立程序读入已经求好的点双连通分量列表，并输出圆方树边。真实题目中，这个
列表直接来自上一篇的 Tarjan 过程，不需要把它写入输入。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, component_count;
    cin >> n >> component_count;

    vector<vector<int>> component(component_count);
    for (vector<int>& current : component) {
        int size;
        cin >> size;
        current.resize(size);
        for (int& u : current) {
            cin >> u;
        }
    }

    vector<vector<int>> tree(n + component_count + 5);

    for (int i = 0; i < component_count; ++i) {
        int component_node = n + i + 1;
        for (int u : component[i]) {
            tree[u].push_back(component_node);
            tree[component_node].push_back(u);
        }
    }

    cout << n + component_count << '\n';
    for (int u = 1; u <= n + component_count; ++u) {
        for (int v : tree[u]) {
            if (u < v) {
                cout << u << ' ' << v << '\n';
            }
        }
    }
    return 0;
}
```

## 复杂度

设所有分量大小之和为 $s$。建立圆方树需要 $O(s)$ 时间和空间。点双分解中每条
DFS 树边只归入一个分量，只有割点会重复出现，因此 $s=O(n+m)$；连同上一篇
Tarjan，完整构造仍为 $O(n+m)$。

## 常见错误

- 把方点当成割点；方点表示整个点双连通分量；
- 只连接方点与割点，随后又期望普通原图点能直接参与树上查询；
- 为同一个分量中的原图点两两连边，重新造出稠密图；
- 把圆方树边数或树上距离当成原图最短路长度；
- 原图不连通时只从一个圆点预处理，漏掉其他圆方树；
- 把圆方树与边双连通分量缩点混为一谈。边双分量通常直接缩成一个点，桥连接这些点。
