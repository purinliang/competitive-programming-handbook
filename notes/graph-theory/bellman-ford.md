# 最短路：Bellman–Ford 与负环

> 最近修订：2026-08-17 04:28 +10:00（未审阅）

Dijkstra 依赖边权非负。若一条边的权值为负，后来经过这条边的路径可能把一个已经
很小的距离继续降低，不能再按“当前最小点已经确定”的顺序处理。

Bellman–Ford 不尝试提前确认某个点。它反复扫描全部边，让最短路信息每轮向前传播
至少一条边，因此可以处理负边，并能判断起点可达范围内是否存在负环。

## 负边与负环

负边本身并不让最短路失去意义。例如：

```text
1 -> 2 (5)
1 -> 3 (2)
2 -> 3 (-4)
```

从 `1` 到 `3` 的最短路是 `1 -> 2 -> 3`，长度为 `1`。它只是包含一条负边，
答案仍然有限。

若存在一个边权和为负数的有向环，并且从起点能够到达这个环，那么每多绕一圈，
路径长度都会继续减小。此时受它影响的点没有有限最短距离。

例如：

```text
2 -> 3 (-2)
3 -> 2 (1)
```

环的总权值是 `-1`。若起点能到达点 `2`，就可以反复绕环，使距离任意小。

本篇所说“存在负环”默认指 **从起点可达的负环**。图中一个完全不可达的负环不会
影响单源最短路。

## 仍然使用松弛

Bellman–Ford 与 Dijkstra 使用同一个松弛条件。对边
$u\xrightarrow{w}v$：

```cpp
if (dist[u] != INF && dist[u] + w < dist[v]) {
    dist[v] = dist[u] + w;
}
```

必须先判断 `dist[u] != INF`。若起点还不能到达 `u`，就不能凭一条从 `u` 出发
的边声称已经找到到达 `v` 的路径。

代码使用边集：

```cpp
struct Edge {
    int u;
    int v;
    ll w;
};

vector<Edge> edges;
```

因为每一轮都要按相同方式遍历全部边，不需要按起点分组访问邻接表。

## 一轮扫描能传播什么

初始时只有 `dist[s]=0`。扫描一遍全部边后，至少能保证所有只含一条边的最短路
已经被发现。

第二轮再扫描全部边，便能在第一轮结果的基础上继续经过一条边，保证所有只含至多
两条边的最短路已经被发现。

一般地，第 `k` 轮结束后，所有能够用至多 `k` 条边到达的有限最短路都已经正确。

在一次扫描内部，新更新的值还可能被本轮后面的边继续使用，所以某些信息会一次
传播多条边。这只会让算法提前得到正确结果，不会破坏“至少传播一条边”的保证。

## 为什么只需要 `n-1` 轮

若起点到点 `v` 存在有限最短路，就可以选择一条不重复经过点的最短路。

如果一条路径重复经过某个点，它包含一个环：

- 环权为正，删除后路径更短；
- 环权为零，删除后长度不变；
- 环权为负，则不存在有限最短路。

在不存在可达负环的前提下，总能删除重复部分并保留一条简单最短路。含 `n` 个点
的简单路径最多经过 `n-1` 条边，因此执行 `n-1` 轮松弛已经足够。

```cpp
for (int round = 1; round <= n - 1; round++) {
    for (auto& edge : edges) {
        // 尝试松弛 edge
    }
}
```

## 提前结束

若某一整轮没有任何距离变化，继续扫描也不会产生新结果：

- 所有边当前都无法松弛；
- 下一轮开始时距离数组完全相同；
- 相同输入会得到相同的“仍然无法松弛”结论。

因此可以记录：

```cpp
bool changed = false;
```

成功松弛时设为 `true`；一轮结束仍为 `false` 就立即退出。

最坏复杂度没有变化，但很多没有长依赖链的图会远早于 `n-1` 轮稳定。

## 用第 `n` 轮检测负环

执行 `n-1` 轮后，再扫描全部边一次。若仍存在可达边可以成功松弛，说明存在一条
使用至少 `n` 条边的更短路径。

一条经过至少 `n` 条边的路径会访问至少 `n+1` 个点；图中只有 `n` 个点，因此
必然重复某个点并包含环。若删除这个环不会让路径变长，就不需要靠第 `n` 轮继续
改善；现在确实得到更短值，只可能是因为其中存在负权环。

所以：

```cpp
for (auto& [u, v, w] : edges) {
    if (dist[u] != INF && dist[u] + w < dist[v]) {
        return false;
    }
}
```

返回 `false` 表示从起点能够到达负环。

这里同样保留 `dist[u] != INF`。去掉它会把与起点无关的负环也算进单源问题。

## 正确性

对轮数 `k` 进行归纳：

- `k=0` 时，只有起点能用零条边到达，`dist[s]=0` 正确；
- 假设第 `k-1` 轮后，至多使用 `k-1` 条边的最短路径都已得到；
- 任取一条至多使用 `k` 条边的最短路径，去掉最后一条边
  $u\to v$ 后，前缀至多使用 `k-1` 条边；
- 根据归纳假设，扫描到 $u\to v$ 时，前缀距离已经不大于这条路径的前缀长度，
  松弛会让 `dist[v]` 不大于整条路径长度。

`dist` 只由真实路径产生，不可能小于真正的有限最短距离。因此第 `k` 轮结束后，
结论成立。

不存在可达负环时，每个有限最短距离都有至多 `n-1` 条边的简单最短路，所以
`n-1` 轮后全部答案正确。第 `n` 轮仍能改善，当且仅当某条可达路径可以借助负环
继续降低。

## 复杂度

最多执行 `n-1` 轮，每轮检查 `m` 条边，时间复杂度为：

$$
O(nm).
$$

边集和距离数组占用 $O(n+m)$ 空间。

Bellman–Ford 明显慢于非负边权图上的 Dijkstra。选择算法时应先看边权条件：

- 无权图使用 BFS；
- 边权只有 `0` 和 `1` 使用 0-1 BFS；
- 边权非负使用 Dijkstra；
- 存在负边且规模允许 $O(nm)$ 时使用 Bellman–Ford。

## 完整代码

程序读取一张带权有向图。若从起点能到达负环，输出 `NEGATIVE CYCLE`；否则输出
各点最短距离，不可达点输出 `-1`。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

const ll INF = 1LL << 62;

struct Edge {
    int u;
    int v;
    ll w;
};

int n, m, s;
vector<Edge> edges;
vector<ll> dist;

bool bellman_ford() {
    dist.assign(n + 5, INF);
    dist[s] = 0;

    for (int round = 1; round <= n - 1; round++) {
        bool changed = false;

        for (auto& [u, v, w] : edges) {
            if (dist[u] == INF) {
                continue;
            }

            ll candidate = dist[u] + w;
            if (candidate >= dist[v]) {
                continue;
            }

            dist[v] = candidate;
            changed = true;
        }

        if (!changed) {
            break;
        }
    }

    for (auto& [u, v, w] : edges) {
        if (dist[u] != INF && dist[u] + w < dist[v]) {
            return false;
        }
    }
    return true;
}

int main() {
    scanf("%d%d%d", &n, &m, &s);

    edges.clear();
    edges.reserve(m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        ll w;
        scanf("%d%d%lld", &u, &v, &w);
        edges.push_back({u, v, w});
    }

    if (!bellman_ford()) {
        printf("NEGATIVE CYCLE\n");
        return 0;
    }

    for (int u = 1; u <= n; u++) {
        if (dist[u] == INF) {
            printf("-1");
        } else {
            printf("%lld", dist[u]);
        }
        printf("%c", " \n"[u == n]);
    }
    return 0;
}
```

输入：

```text
4 5 1
1 2 5
1 3 2
2 3 -4
3 4 3
2 4 10
```

输出：

```text
0 5 1 4
```

## 常见错误

### 忘记判断起点是否能到达边的起点

`INF + w` 不是一条真实路径。每次松弛和负环检查前都要先判断
`dist[u] != INF`。

### 把任意负环都报告出来

单源最短路只受起点可达负环影响。若题目要求检测整张图中的任意负环，可以人为
加入一个向所有点连零权边的超级源点，再从它运行算法。

### 只做一轮松弛

一轮只能保证信息至少跨过一条边。路径可能包含接近 `n-1` 条边，必须反复扫描。

### 存在可达负环仍输出有限距离

负环可让部分路径无限下降，此时 `dist` 只是扫描到当前轮数的临时值，不是最短
距离。
