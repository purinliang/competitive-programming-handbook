# 函数图

> 最近修订：2026-08-17 11:14 +10:00（未审阅）

有些状态从当前位置出发只有唯一下一步。例如每个点都指定一个后继，重复执行
`u = next[u]`；或者一个确定性过程不断把当前状态映射到下一个状态。

把状态看成点，并从每个点向它的唯一后继连一条有向边，就得到函数图
（functional graph）。它的名字来自数组 `next` 本质上定义了一个函数：

$$
f(u)=\text{next}[u].
$$

## 每个点恰好有一条出边

函数图的定义是：

- 每个点的出度恰好为 `1`；
- 入度可以是 `0`、`1` 或更大；
- 自环是合法的，它表示 `next[u]=u`。

代码不需要邻接表就能表示出边：

```cpp
vector<int> nxt(n + 5);
```

从点 `u` 走一步到 `nxt[u]`，走两步到 `nxt[nxt[u]]`。

注意这里的 `nxt` 是题目给出的确定后继，不是链式前向星中表示“下一条边”的同名
字段。

## 每个连通部分都是环加内向树

从任意点不断沿唯一出边向前走。点数有限，所以迟早会再次到达一个已经出现的点；
两次出现之间的部分形成一个有向环。

在忽略边方向后的一个连通分量中，每个点贡献一条出边，因此边数等于点数。这个
无向连通图恰好是一棵基环树，所以只能有一个环。

方向又保证：

- 环上每条边沿同一方向首尾相接；
- 环外节点沿出边最终流向环；
- 把边方向反过来看，环上每个点挂着若干棵有根树。

因此一个函数图连通分量可以画成：

```text
in-tree -> cycle <- in-tree
             ^
             |
          in-tree
```

与普通基环树不同，函数图可能不连通；每个弱连通分量各有一个有向环。

## 直接走 `k` 步太慢

询问“从点 `u` 出发走 `k` 步到哪里”时，朴素循环是：

```cpp
while (k--) {
    u = nxt[u];
}
```

单次需要 $O(k)$ 时间。若 `k` 接近 $10^{18}$，无法逐步模拟。

需要把“走一步”预先合成为“走 $2^j$ 步”，这就是倍增。

## 倍增后继

定义：

```cpp
up[bit][u]
```

表示从点 `u` 出发走 $2^{bit}$ 步后到达的点。

走 $2^0=1$ 步就是直接后继：

```cpp
up[0][u] = nxt[u];
```

走 $2^{bit}$ 步，可以先走 $2^{bit-1}$ 步到中间点，再从中间点走同样距离：

```cpp
up[bit][u] = up[bit - 1][up[bit - 1][u]];
```

这与倍增 LCA 的表结构相同，但含义不同：LCA 向父节点跳，函数图沿唯一出边跳。
函数图可以进入环后继续无限行走，不存在“超过根节点”的空位置。

## 按 `k` 的二进制位跳转

把 `k` 写成二进制。若第 `bit` 位为 `1`，就走对应的 $2^{bit}$ 步：

```cpp
for (int bit = 0; bit < LOG; bit++) {
    if ((k >> bit) & 1LL) {
        u = up[bit][u];
    }
}
```

例如：

$$
13=8+4+1=2^3+2^2+2^0.
$$

因此依次使用 `up[0]`、`up[2]` 和 `up[3]`，总步数就是 `13`。这些跳跃可以
按任意顺序组合，因为它们都表示沿同一个确定函数继续向前。

当 `k\le 10^{18}` 时，二进制最高位小于 `60`。代码保留 `0..60` 共 `61` 层。

## 用入度剥离找到所有环点

若只需要判断哪些点位于环上，可以统计每个点的入度，把所有入度为零的点加入队列。

删除点 `u` 时，它唯一后继 `v=nxt[u]` 的当前入度减少 `1`；若 `v` 也变成零，
继续删除。所有环外内向树会从没有前驱的叶子开始逐层剥掉，最终剩下的点恰好是
各个有向环。

```cpp
vector<int> indegree(n + 5, 0);
vector<int> on_cycle(n + 5, 1);

for (int u = 1; u <= n; u++) {
    indegree[nxt[u]]++;
}

queue<int> q;
for (int u = 1; u <= n; u++) {
    if (indegree[u] == 0) {
        q.push(u);
    }
}

while (!q.empty()) {
    int u = q.front();
    q.pop();
    on_cycle[u] = 0;

    int v = nxt[u];
    indegree[v]--;
    if (indegree[v] == 0) {
        q.push(v);
    }
}
```

开始时先把所有点视为可能位于环上。每剥离一个点，就把 `on_cycle[u]` 设为
`0`；队列结束后，仍为 `1` 的点恰好是所有环点。

这里删除的是入度为零的点；无向基环树剥叶删除的是当前度数为一的点。两者原理
相似，但条件不能混用。

## 环前距离与环长度

从一个点不断沿后继走，路径可以分成两段：

1. 进入环以前的一条链；
2. 进入环以后不断循环。

若第一次进入环需要 `d` 步，环长为 `c`，那么：

- `k<d` 时，答案仍在入环链上；
- `k\ge d` 时，先走 `d` 步入环，再在环上走
  $(k-d)\bmod c$ 步。

这可以用于处理极大的十进制步数或分析首次重复位置。对普通 64 位 `k`，倍增已经
足够简单，不必为了利用环结构而额外分类。

## 正确性

倍增表对 `bit` 归纳。

`bit=0` 时，`up[0][u]=nxt[u]`，正好走一步。假设第 `bit-1` 层能正确走
$2^{bit-1}$ 步，先从 `u` 跳到 `up[bit-1][u]`，再从该点使用同一层继续跳，
总共走：

$$
2^{bit-1}+2^{bit-1}=2^{bit}
$$

步，所以递推正确。

查询时，`k` 的二进制展开把步数唯一分解成若干不同的二次幂。对每个为一的位使用
相应倍增跳跃，执行的总步数恰好为 `k`，最终节点正确。

## 复杂度

预处理 `LOG` 层、每层 `n` 个点，时间和空间复杂度都是
$O(n\log K)$，其中 `K` 是最大查询步数。

每次查询只检查 `LOG` 个二进制位，时间复杂度为 $O(\log K)$。当
`K\le10^{18}` 时，`LOG=61` 是固定小常数。

## 完整代码

程序读取一张函数图，再回答若干询问：从点 `u` 出发沿后继走 `k` 步会到达哪个
点。输入保证 `0\le k\le10^{18}`。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

const int LOG = 61;

int n, query_count;
vector<int> nxt;
vector<vector<int>> up;

void build() {
    up.assign(LOG, vector<int>(n + 5, 0));

    for (int u = 1; u <= n; u++) {
        up[0][u] = nxt[u];
    }

    for (int bit = 1; bit < LOG; bit++) {
        for (int u = 1; u <= n; u++) {
            up[bit][u] = up[bit - 1][up[bit - 1][u]];
        }
    }
}

int jump(int u, ll k) {
    for (int bit = 0; bit < LOG; bit++) {
        if ((k >> bit) & 1LL) {
            u = up[bit][u];
        }
    }
    return u;
}

int main() {
    scanf("%d%d", &n, &query_count);

    nxt.assign(n + 5, 0);
    for (int u = 1; u <= n; u++) {
        scanf("%d", &nxt[u]);
    }

    build();

    while (query_count--) {
        int u;
        ll k;
        scanf("%d%lld", &u, &k);
        printf("%d\n", jump(u, k));
    }
    return 0;
}
```

输入：

```text
6 4
2 3 4 2 6 6
1 0
1 4
5 3
5 1000000000000000000
```

输出：

```text
1
2
6
6
```

点 `2,3,4` 形成长度为 `3` 的环，点 `1` 指向这个环；点 `6` 是自环，点 `5`
一步进入它。

## 常见错误

### 把出度为一误写成入度为一

函数图只保证每个点恰好有一个后继；同一个点可以被任意多个点指向。

### 使用 32 位整数保存 `k`

查询步数可能达到 $10^{18}$，必须使用 64 位整数，并让 `LOG` 覆盖它的最高位。

### 倍增递推的两次跳跃起点相同

第二段必须从第一段的终点继续：

```cpp
up[bit - 1][up[bit - 1][u]]
```

而不是把两个相同值做普通加法。

### 混淆无向剥叶与有向剥离

函数图按当前入度为零剥离；无向基环树按当前度数为一剥离。
