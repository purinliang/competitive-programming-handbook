# 最短路：Floyd–Warshall

> 最近修订：2026-08-17 04:51 +10:00（未审阅）

若题目只询问一个起点到其他点的距离，可以运行一次单源最短路。但有些问题会询问
任意两点之间的最短距离，甚至要求在得到完整距离以后继续判断哪些点对可达。

对每个点分别运行 Dijkstra 可以处理稀疏、非负边权图；当点数较小，或图中允许
负边时，Floyd–Warshall 用一个更规整的 $O(n^3)$ 动态规划一次求出所有点对之间的
最短距离。

## 从邻接矩阵开始

建立：

```cpp
dist[u][v]
```

表示当前已知的点 `u` 到点 `v` 的最短距离。

在允许使用任何中间点以前，只能直接从 `u` 沿一条边走到 `v`：

- `dist[u][u] = 0`，不经过边即可从自己到自己；
- 若存在边 `u -> v`、边权为 `w`，令 `dist[u][v]` 取最小的 `w`；
- 其他位置初始化为 `INF`，表示尚不可达。

```cpp
dist.assign(n + 5, vector<ll>(n + 5, INF));
for (int u = 1; u <= n; u++) {
    dist[u][u] = 0;
}
```

同一对点之间可能有多条平行边，读入时必须取最小值：

```cpp
dist[u][v] = min(dist[u][v], w);
```

无向边则同时更新 `dist[u][v]` 与 `dist[v][u]`。

## 把中间点逐个开放

一条从 `u` 到 `v` 的路径，除了两个端点外，还可能经过若干中间点。

定义阶段 `k`：只允许编号 `1..k` 的点作为中间点。处理完阶段 `k` 后，
`dist[u][v]` 表示在这个限制下的最短距离。

从阶段 `k-1` 到阶段 `k` 时，最短路径只有两种可能：

1. 不经过点 `k`，答案仍是原来的 `dist[u][v]`；
2. 经过点 `k`，路径可以拆成 `u -> k` 与 `k -> v` 两段。

因此转移为：

$$
\text{dist}[u][v]
=\min\left(
\text{dist}[u][v],
\text{dist}[u][k]+\text{dist}[k][v]
\right).
$$

这里的“经过 `k`”只需要考虑一次。若最短路径重复经过 `k`，中间就包含环；
在不存在相关负环的有限最短路问题中，可以删除不必要的重复部分。

## 为什么 `k` 必须在最外层

代码严格按照动态规划阶段书写：

```cpp
for (int k = 1; k <= n; k++) {
    for (int u = 1; u <= n; u++) {
        for (int v = 1; v <= n; v++) {
            // 用点 k 更新 dist[u][v]
        }
    }
}
```

`k` 表示“现在开放哪个新中间点”，必须完整处理所有点对以后才能进入下一阶段。
若把 `k` 放到内层，某些状态会在尚未完成当前阶段时使用未来阶段的数据，简单的
原地转移证明不再成立，也可能得到错误答案。

`u` 和 `v` 两层可以互换，因为在固定 `k` 时，它们只是枚举所有有序点对。

## 不可达状态不能相加

只有两段都可达时，经过 `k` 的候选路径才真实存在：

```cpp
if (dist[u][k] == INF || dist[k][v] == INF) {
    continue;
}
dist[u][v] = min(dist[u][v], dist[u][k] + dist[k][v]);
```

这个判断既表达路径含义，也避免拿哨兵值参与加法。

若题目边权和路径长度上界接近 64 位整数极限，还要重新选择 `INF` 或使用更宽的
中间类型。本篇使用 `1LL << 62`，并假设所有有限路径绝对值远小于它。

## 原地更新为什么安全

概念上的转移从阶段 `k-1` 读数据，向阶段 `k` 写数据；代码却只维护一张矩阵。

固定 `k` 时，可能被当前阶段改动并再次读取的是 `dist[u][k]` 和
`dist[k][v]`。但：

$$
\text{dist}[u][k]
=\min(\text{dist}[u][k],\text{dist}[u][k]+\text{dist}[k][k]),
$$

$$
\text{dist}[k][v]
=\min(\text{dist}[k][v],\text{dist}[k][k]+\text{dist}[k][v]).
$$

在不存在负环时，`dist[k][k]=0`，它们不会因当前阶段变小。因此原地更新和保留
两层数组得到相同结果。

若存在负环，有限最短距离本来就没有正常定义；算法仍能通过对角线发现它。

## 负边与负环

Floyd–Warshall 可以处理负边，因为它不依赖“当前最小距离已经最终确定”。

初始化时 `dist[u][u]=0`。若算法结束后：

```cpp
dist[u][u] < 0
```

说明存在一条从 `u` 出发又回到 `u`、总权值为负的路径，也就是负环。

若只关心整张图是否存在任意负环，只需检查是否有一个对角元素小于零。若还要判断
哪些点对的最短距离会被负环影响，则需要进一步检查是否存在负环点 `k`，满足
`u` 能到达 `k` 且 `k` 能到达 `v`。

本篇完整程序只报告图中是否存在负环，不继续表示“负无穷”的点对。

## 正确性

对阶段 `k` 归纳。

初始阶段 `k=0` 不允许任何中间点，矩阵只包含零条边的自身路径和直接边，因此
定义成立。

假设处理 `k` 前，`dist[u][v]` 已经是不使用编号大于等于 `k` 的中间点的最短
距离。开放点 `k` 后，任意合法最短路径要么不经过 `k`，要么可以在 `k` 处分成
两段；两段的内部中间点编号都不超过 `k-1`，已由上一阶段正确求出。

转移取两种可能的较小值，所以处理完 `k` 后定义继续成立。最终 `k=n` 时，所有点
都允许作为中间点，矩阵就是全源最短距离。

## 复杂度

三层循环分别枚举中间点和有序点对，时间复杂度为：

$$
O(n^3).
$$

距离矩阵占用：

$$
O(n^2)
$$

空间。这使它通常只适用于几百个点的图。即使边数很少，三层循环仍会完整执行；
大规模稀疏非负图应优先考虑多次 Dijkstra。

## 完整代码

程序读取一张带权有向图。若图中存在任意负环，输出 `NEGATIVE CYCLE`；否则输出
全源最短距离矩阵，不可达位置输出 `INF`。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

const ll INF = 1LL << 62;

int n, m;
vector<vector<ll>> dist;

void floyd_warshall() {
    for (int k = 1; k <= n; k++) {
        for (int u = 1; u <= n; u++) {
            if (dist[u][k] == INF) {
                continue;
            }

            for (int v = 1; v <= n; v++) {
                if (dist[k][v] == INF) {
                    continue;
                }

                ll candidate = dist[u][k] + dist[k][v];
                if (candidate < dist[u][v]) {
                    dist[u][v] = candidate;
                }
            }
        }
    }
}

int main() {
    scanf("%d%d", &n, &m);

    dist.assign(n + 5, vector<ll>(n + 5, INF));
    for (int u = 1; u <= n; u++) {
        dist[u][u] = 0;
    }

    for (int i = 1; i <= m; i++) {
        int u, v;
        ll w;
        scanf("%d%d%lld", &u, &v, &w);
        dist[u][v] = min(dist[u][v], w);
    }

    floyd_warshall();

    for (int u = 1; u <= n; u++) {
        if (dist[u][u] < 0) {
            printf("NEGATIVE CYCLE\n");
            return 0;
        }
    }

    for (int u = 1; u <= n; u++) {
        for (int v = 1; v <= n; v++) {
            if (dist[u][v] == INF) {
                printf("INF");
            } else {
                printf("%lld", dist[u][v]);
            }
            printf("%c", " \n"[v == n]);
        }
    }
    return 0;
}
```

输入：

```text
4 5
1 2 5
1 3 10
2 3 -2
3 4 1
1 4 20
```

输出：

```text
0 5 3 4
INF 0 -2 -1
INF INF 0 1
INF INF INF 0
```

## 常见错误

### 忘记初始化对角线

从一个点到自身的空路径长度为零。若不设置 `dist[u][u]=0`，许多经过自身的转移
和负环判断都会失去正确含义。

### 重边直接覆盖

后读到的平行边不一定更短。初始化时必须使用 `min`。

### 把 `k` 放到内层

`k` 是动态规划阶段，不是普通的第三个无序枚举变量。它必须位于最外层。

### 用 Floyd–Warshall 处理过大的图

$O(n^3)$ 增长很快。点数达到几千时，即使代码很短也通常无法运行。
