# 最小生成树：Kruskal

> 最近修订：2026-08-17 05:16 +10:00（未审阅）

要用若干条无向边把图中的所有点连接起来，最直接的办法是保留原图全部边。但如果
每条边都有建设费用，我们希望删掉多余边，同时让保留边的总权值尽量小。

Kruskal 算法把所有边按权值从小到大考虑。只要当前边连接两个不同连通分量，就把
它加入答案；若两端已经连通，加入它只会形成环，因此跳过。

## 生成树

在一张连通无向图中，包含全部 `n` 个点并且连通、无环的子图称为生成树。

树的基本性质告诉我们：含 `n` 个点的树恰好有 `n-1` 条边。因此生成树是在保持
全部点连通的前提下，删去所有冗余边后的结构。

若边带权，边权和最小的生成树称为 **最小生成树**（Minimum Spanning Tree，
MST）。

最小生成树可能不唯一。只要不同生成树具有相同的最小总权值，它们都是正确答案。
若原图不连通，则不存在覆盖全部点的生成树，只能在每个连通分量内得到一棵树，
合起来称为生成森林。

## 从最小边开始尝试

先把边按权值非递减排序：

```cpp
sort(edges.begin(), edges.end());
```

依次检查边 $(u,v,w)$：

- 若 `u` 与 `v` 目前不连通，加入这条边会合并两个连通分量，不形成环；
- 若两端已经连通，当前已选边中已经存在一条 `u` 到 `v` 的路径，再加入这条边
  会形成环。

所以核心判断是：

```cpp
if (dsu.merge(u, v)) {
    answer += w;
    edge_count++;
}
```

并查集的 `merge` 返回 `true`，恰好表示两个端点原本属于不同连通分量。

## 为什么贪心选择安全

设当前准备连接两个不同连通分量的最小可用边为 `e`。假设存在一棵最小生成树
`T` 没有选择 `e`。

把 `e` 加入 `T` 后会形成一个环。这个环必须还包含另一条跨越这两个连通分量的边
`f`，否则环无法从一个分量走到另一个分量再返回。

Kruskal 按权值从小到大处理，`e` 是此时最小的跨分量边，因此：

$$
w(e)\le w(f).
$$

从 `T` 中删除 `f`、加入 `e`，图仍然连通且边数不变，仍是一棵生成树；总权值
不会增加。于是总存在一棵最小生成树包含 `e`。

这称为交换论证，也可以表述为最小生成树的割性质：对任意把点划分成两部分的割，
跨越这个割的最小权边可以安全地出现在某棵最小生成树中。

Kruskal 当前的每个连通分量正好形成一种划分。每次选择连接不同分量的最小边，都
不会排除所有最优解。

## 为什么跳过成环边

若 `u` 和 `v` 已经连通，已选边中存在一条从 `u` 到 `v` 的路径。加入边
$(u,v)$ 会形成环。

生成树不能含环；而且环上任意删除一条边，环内各点仍然连通，所以环中至少有一条
边是冗余的。当前边已经不再承担合并连通分量的作用，没有选择它的必要。

这个判断与边权是否为负无关。Kruskal 可以处理负边：负边会排在前面，只要不成环
就会被选择。最小生成树要求的是总权值最小，不要求每条边非负。

## 什么时候停止

每次成功合并，选中边数增加 `1`，连通分量数减少 `1`。从 `n` 个单点分量变成
一个连通分量，恰好需要 `n-1` 次成功合并。

因此：

```cpp
if (edge_count == n - 1) {
    break;
}
```

扫描结束后若 `edge_count != n - 1`，说明原图不连通，不存在生成树。

不能只凭“边已经扫描完”输出当前权值；当前结果可能只是最小生成森林。

## 重边、自环与负边

Kruskal 不需要特别删除这些边：

- 平行边会按权值排序，较小边通常先连接分量，较大边以后因两端已连通被跳过；
- 自环的两个端点相同，并查集始终认为它们已连通，所以不会被选择；
- 负边正常参与排序，只要不形成环就可以进入最小生成树。

输入一条无向边时，边集中只保存一份 $(u,v,w)$。Kruskal 处理的是原始无向边，
不需要像邻接表那样额外保存反向邻接项。

## 正确性

算法始终保持两个不变量：

1. 已选边不含环；
2. 已选边可以扩充成某棵最小生成树。

初始没有边，两个不变量显然成立。

若当前边两端已连通，跳过它不会改变已选集合。若两端不连通，根据交换论证，总能
从一棵包含此前全部选择的最小生成树中，用当前边替换一条不更轻的跨分量边，得到
另一棵仍包含全部新选择的最小生成树；同时连接不同分量不会形成环。

因此两个不变量一直成立。选中 `n-1` 条边后，结果已经连通且无环，是一棵生成树；
它又能扩充成最小生成树，而边数已经相同，所以它本身就是最小生成树。

## 复杂度

排序 `m` 条边需要：

$$
O(m\log m).
$$

并查集的全部操作总计接近 $O(m)$，不会超过排序的主复杂度。因此总时间复杂度是
$O(m\log m)$，空间复杂度为 $O(n+m)$。

## 完整代码

程序读取一张带权无向图。存在最小生成树时输出总权值；图不连通时输出 `-1`。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

struct Edge {
    int u;
    int v;
    ll w;

    bool operator<(const Edge& other) const {
        return w < other.w;
    }
};

struct DSU {
    vector<int> parent;
    vector<int> siz;

    DSU(int n) : parent(n + 5), siz(n + 5, 1) {
        for (int u = 1; u <= n; u++) {
            parent[u] = u;
        }
    }

    int find(int u) {
        if (parent[u] == u) {
            return u;
        }
        return parent[u] = find(parent[u]);
    }

    bool merge(int u, int v) {
        u = find(u);
        v = find(v);
        if (u == v) {
            return false;
        }

        if (siz[u] < siz[v]) {
            swap(u, v);
        }
        parent[v] = u;
        siz[u] += siz[v];
        return true;
    }
};

int n, m;
vector<Edge> edges;

pair<bool, ll> kruskal() {
    sort(edges.begin(), edges.end());

    DSU dsu(n);
    ll answer = 0;
    int edge_count = 0;

    for (auto& [u, v, w] : edges) {
        if (!dsu.merge(u, v)) {
            continue;
        }

        answer += w;
        edge_count++;
        if (edge_count == n - 1) {
            break;
        }
    }

    return {edge_count == n - 1, answer};
}

int main() {
    scanf("%d%d", &n, &m);

    edges.clear();
    edges.reserve(m);
    for (int i = 1; i <= m; i++) {
        int u, v;
        ll w;
        scanf("%d%d%lld", &u, &v, &w);
        edges.push_back({u, v, w});
    }

    auto [exists, answer] = kruskal();
    if (!exists) {
        printf("-1\n");
    } else {
        printf("%lld\n", answer);
    }
    return 0;
}
```

输入：

```text
5 7
1 2 3
1 3 4
2 3 1
2 4 6
3 4 5
3 5 2
4 5 7
```

输出：

```text
11
```

可以选择权值为 `1、2、3、5` 的四条边，总权值为 `11`。

## 常见错误

### 把无向边保存两次

邻接表遍历通常保存两个方向；Kruskal 的边集只需要每条原始无向边一份。保存两份
一般不会改变答案，但会浪费排序时间和空间。

### 只判断点编号不同

`u != v` 不能说明加入边不会成环。必须比较两个点当前所在连通分量的代表元。

### 忘记检查选中边数

不连通图也会得到一个权值和，但那是生成森林，不是覆盖全部点的生成树。

### 用 32 位整数保存总权值

单条边权能放入 32 位整数，`n-1` 条边的和仍可能溢出，答案使用 64 位整数。
