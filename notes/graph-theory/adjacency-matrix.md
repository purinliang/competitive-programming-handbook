# 图的存储：邻接矩阵

> 最近修订：2026-08-17 00:49 +10:00（未审阅）

[图的存储：基础概念](graph-representation.md) 已经介绍三种基础存储方法。邻接矩阵为每一对点 `(u, v)` 准备一个格子，用 $O(n^2)$ 空间换取 $O(1)$ 的直接连边查询。

本篇把无权、有权、有向和无向图分别落实成代码，并说明矩阵中的一个格子究竟保存什么。

## 无权有向图

无权图只需记录边是否存在。本书统一使用 `g` 表示当前图，并用整数 `0`、`1` 保存状态：

```cpp
vector<vector<int>> g;
```

读入点数 `n` 后建立 1-based 矩阵：

```cpp
g.assign(n + 5, vector<int>(n + 5, 0));
```

加入有向边 `u -> v`：

```cpp
g[u][v] = 1;
```

此后可以在 $O(1)$ 时间判断这条边是否存在：

```cpp
if (g[u][v]) {
    // 存在有向边 u -> v
}
```

有向边区分起点和终点。设置 `g[u][v]` 不会自动设置 `g[v][u]`；反方向是否存在要由输入或程序另行决定。

## 无权无向图

无向边 `(u, v)` 可以从两端通行，所以矩阵中要填写两个对称位置：

```cpp
g[u][v] = 1;
g[v][u] = 1;
```

因此，无向图的邻接矩阵关于主对角线对称：

$$
g[u][v]=g[v][u].
$$

若只写其中一个方向，后续从另一端查询或遍历时就会把同一条无向边误认为不存在。

## 对角线与自环

`g[u][u]` 表示点 `u` 是否有一条连接自己的自环。普通无权图初始化为 `0`，表示输入尚未给出自环：

```cpp
g[u][u] = 0;
```

若输入包含自环 `(u, u)`，加入边后它会变成 `1`。

不能因为“点到自己不需要移动”就一律把无权邻接矩阵的对角线设为 `1`。邻接矩阵这一格回答的是有没有一条直接边，不是能否用长度为零的路径停在原点。

具体算法可能重新定义矩阵状态。例如最短路矩阵常把到自己的距离初始化为 `0`。那是距离状态的初值，不等于原图一定存在权为 `0` 的自环。

## 带权图

带权邻接矩阵让 `g[u][v]` 保存边权。因为权值 `0` 可能合法，不能再用 `0` 表示没有边。常用足够大的 `INF`：

```cpp
const int INF = 0x3f3f3f3f;
vector<vector<int>> g;

g.assign(n + 5, vector<int>(n + 5, INF));
```

加入有向边：

```cpp
g[u][v] = w;
```

加入无向边：

```cpp
g[u][v] = w;
g[v][u] = w;
```

如果后续算法把矩阵解释成最短距离，可以再设置：

```cpp
for (int u = 1; u <= n; u++) {
    g[u][u] = 0;
}
```

初始化顺序要符合题意。若需要保留输入中的自环权值，不能在读完边后无条件用 `0` 覆盖它。

## 重边会怎样

两个点之间可能存在多条同方向边。一个矩阵格子只能保存一个值，不能完整保留所有重边。

若题目只关心最小边权，可以合并：

```cpp
g[u][v] = min(g[u][v], w);
```

无向边还要对称更新：

```cpp
g[u][v] = min(g[u][v], w);
g[v][u] = min(g[v][u], w);
```

若算法必须区分每一条重边的编号、容量或使用状态，单个矩阵格不够，应改用边集或邻接表保存独立边记录。

无权矩阵只记录“至少存在一条边”，所以重复设置 `g[u][v] = 1` 不会保留重边数量。若题目要统计边数，可以让矩阵保存计数，但这已经是另一种明确的矩阵含义。

## 枚举一个点的出边

矩阵能快速判断指定的 `u -> v`，但枚举点 `u` 的全部出边时，仍要检查整行：

```cpp
for (int v = 1; v <= n; v++) {
    if (g[u][v]) {
        // 处理 u -> v
    }
}
```

无论 `u` 实际只有一条出边还是有 $n-1$ 条，都要检查 $n$ 个终点，时间是 $O(n)$。

若对所有点都这样枚举，时间是 $O(n^2)$。稀疏图只有 $O(n)$ 或 $O(n\log n)$ 条边时，大量矩阵格始终为空；[`vector` 邻接表](vector-adjacency-list.md) 只遍历真实存在的边，通常更合适。

## 直接连边不等于可达

无权矩阵中的 `g[u][v] = 1` 只说明存在一条从 `u` 到 `v` 的边。

若 `g[u][v] = 0`，仍可能通过其他点从 `u` 到达 `v`：

```text
u -> x -> v
```

判断路径可达性需要 DFS、BFS 或其他算法，不能只看一个邻接矩阵格子。邻接矩阵保存原图的直接关系，不会自动计算传递关系。

## 复杂度与适用范围

设图有 $n$ 个点：

| 操作 | 复杂度 |
| --- | ---: |
| 建立并初始化矩阵 | $O(n^2)$ |
| 判断指定直接边 | $O(1)$ |
| 加入或更新一条边 | $O(1)$ |
| 枚举一个点的全部出边 | $O(n)$ |
| 枚举整张矩阵 | $O(n^2)$ |
| 存储空间 | $O(n^2)$ |

邻接矩阵适合：

- 点数较小，$O(n^2)$ 空间可以接受；
- 图比较稠密，矩阵大部分格子都有意义；
- 算法频繁查询任意两点是否直接相连；
- 算法状态本身就是点对，例如后续的 Floyd 最短路。

普通大规模稀疏图的 DFS、BFS 和最短路通常使用邻接表。

## 完整代码

下面读取一张无权无向图，再回答若干次“两个点是否直接相邻”的查询。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, q;
vector<vector<int>> g;

void solve() {
    cin >> n >> m;

    g.assign(n + 5, vector<int>(n + 5, 0));

    for (int i = 1; i <= m; i++) {
        int u, v;
        cin >> u >> v;
        g[u][v] = 1;
        g[v][u] = 1;
    }

    cin >> q;

    while (q--) {
        int u, v;
        cin >> u >> v;
        cout << (g[u][v] ? "Yes" : "No") << '\n';
    }
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
4 3
1 2
2 3
3 4
3
1 2
1 3
4 3
```

输出：

```text
Yes
No
Yes
```

`1` 可以经过 `2` 到达 `3`，但查询问的是是否直接相邻，所以 `1 3` 输出 `No`。
