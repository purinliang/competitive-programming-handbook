# Hello World!

> 状态：草稿
> 直接前置：—

这一章先不拆开学习所有语法。我们会运行一份完整程序，再亲手修改其中最重要的一小块，看看程序如何发生变化。

## 第一个程序

先复制并运行下面的代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    cout << "Hello World!" << '\n';
}

int main() {
    solve();
    return 0;
}
```

程序会输出：

```text
Hello World!
```

现在只需要对这份代码建立一个整体印象。以后随题目变化的内容通常写在 `solve` 里面：

```cpp
void solve() {
    cout << "Hello World!" << '\n';
}
```

`cout` 把内容输出到屏幕上，`'\n'` 表示换到下一行。每次输出完整的一行后都主动换行，从第一份程序开始养成这个习惯。

其余内容，包括 `#include`、`using namespace std;`、`void`、`main` 和 `return 0;`，现在都先当成程序的固定格式。后面的教程会在真正需要时分别解释。

## 先让程序使用固定数值

接下来不动程序外壳，只把 `solve` 改成这样：

```cpp
void solve() {
    int a = 3;
    int b = 5;
    cout << a + b << '\n';
}
```

这里第一次用到了整数：

- `int a = 3;` 声明一个名为 `a` 的整数，同时把它的初始值定为 `3`。
- `int b = 5;` 声明一个名为 `b` 的整数，同时把它的初始值定为 `5`。
- `cout << a + b << '\n';` 输出 `a + b` 的结果，然后换行。

程序会计算 `3 + 5`，因此输出：

```text
8
```

这种写法把数值直接定在程序里。无论运行多少次，`a` 都是 `3`，`b` 都是 `5`。

## 再从输入取得数值

如果希望同一份程序计算任意两个整数，就不能提前把它们固定为 `3` 和 `5`。我们仍然声明 `a` 和 `b`，但改用 `cin` 在程序运行时取得它们的值：

```cpp
void solve() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << '\n';
}
```

- `int a;` 和 `int b;` 声明两个整数，但不再内定它们的值。
- `cin >> a >> b;` 从输入中依次取得两个整数，先放进 `a`，再放进 `b`。
- 读入完成后，`cout` 输出它们的和，并用 `'\n'` 换行。

例如，输入：

```text
3 5
```

程序会输出：

```text
8
```

换成其他两个整数，程序也会计算对应的结果。

## 修改后的完整程序

把新的 `solve` 放回原来的外壳，完整程序如下：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << '\n';
}

int main() {
    solve();
    return 0;
}
```

这一章已经完成了最基本的声明和输入输出：

- 用 `int` 声明整数，可以在程序中内定初始值，也可以稍后从输入取得值。
- 用 `cin` 输入数据。
- 用 `cout` 输出文字或计算结果。
- 每次输出完整的一行后，用 `'\n'` 换行。

你可以输入其他两个整数，重新运行程序并观察输出。现在不必深究所有符号的语法，只需知道我们通常在 `solve` 中编写随题目变化的内容。
