# 输入输出：文件重定向

> 状态：定稿

大多数在线评测系统都直接使用 [输入输出：标准输入](standard-input.md) 和标准输出。有些 OI 赛制或题目则会要求程序从指定文件读取，并将答案写入另一个指定文件。如果为此改写所有 `scanf` 和 `printf`，题目主体代码就会与输入输出方式绑在一起。

**重定向**只改变标准输入或标准输出实际连接的目标。完成重定向后，其余代码仍然照常使用 `scanf` / `printf` 或 `cin` / `cout`。

## freopen 的固定写法

C++ 竞赛中通常使用 `freopen` 完成文件重定向：

```cpp
freopen("sum.in", "r", stdin);
freopen("sum.out", "w", stdout);
```

第一条语句将标准输入 `stdin` 重定向到 `sum.in`：

- `"sum.in"` 是输入文件名；
- `"r"` 表示以读取模式（read）打开；
- `stdin` 表示要替换的标准输入。

第二条语句将标准输出 `stdout` 重定向到 `sum.out`：

- `"sum.out"` 是输出文件名；
- `"w"` 表示以写入模式（write）打开；
- `stdout` 表示要替换的标准输出。

文件名和模式都是字符串，因此使用双引号，不是表示单个字符的单引号。

## 重定向后的输入输出

上面两条语句执行成功后，普通的输入输出代码无需改写：

```cpp
int a;
int b;
scanf("%d%d", &a, &b);
printf("%d\n", a + b);
```

`scanf` 现在从 `sum.in` 读取，`printf` 将结果写入 `sum.out`。如果代码选用 `cin` 和 `cout`，常见竞赛环境中的效果也相同。

重定向必须在第一次相关输入输出之前执行。最稳定的位置是 `main` 开头、调用 `solve()` 之前：

```cpp
int main() {
    freopen("sum.in", "r", stdin);
    freopen("sum.out", "w", stdout);

    solve();
    return 0;
}
```

如果题目只要求文件输入或只要求文件输出，只保留对应的一条 `freopen`。

## 读取与写入模式

`"r"` 要求输入文件已经存在。如果程序的当前工作目录中没有该文件，或文件名拼写不同，打开会失败，后续读入不会得到预期数据。

`"w"` 会在文件不存在时创建它；如果文件已经存在，打开时会先清空原有内容。因此不要把需要保留的文件名误写到输出位置。

`freopen` 成功时返回重新打开的文件流，失败时返回空指针。正式比赛中文件名由题目保证，通常直接使用固定两行；本地排查“为什么读不到数据”时，可以临时检查返回值：

```cpp
if (freopen("sum.in", "r", stdin) == nullptr) {
    return 1;
}
```

这里的文件流和空指针只用于解释返回值，不要求在本篇理解它们的底层类型。

## 文件名与工作目录

比赛题面会给出确切文件名，例如 `sum.in` 和 `sum.out`。大小写、拼写和后缀都必须完全一致。

只写文件名时，程序会在运行时的**当前工作目录**中寻找或创建文件。这个目录不一定与源代码所在目录相同，而由编译器、IDE 或命令行的运行方式决定。本地找不到文件时，除了检查拼写，也要检查程序实际从哪个目录运行。

## 完整代码

下面的程序从 `sum.in` 读取两个整数，将它们的和写入 `sum.out`：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int a;
    int b;
    scanf("%d%d", &a, &b);
    printf("%d\n", a + b);
}

int main() {
    freopen("sum.in", "r", stdin);
    freopen("sum.out", "w", stdout);

    solve();
    return 0;
}
```

将以下内容保存为程序工作目录中的 `sum.in`：

```text
3 5
```

运行后，同一目录中的 `sum.out` 应包含：

```text
8
```

## 基础练习

1. 运行完整代码，然后分别删除 `sum.in`、改变文件名的大小写，观察读取失败时的现象。
2. 将输出重定向语句暂时注释，观察答案改从哪里输出。
3. 将输入重定向语句暂时注释，从键盘输入 `3 5`，确认题目主体的 `scanf` 和 `printf` 不需要改写。

## 需要记住什么

1. 文件重定向改变的是整份题目代码，还是标准输入与标准输出的实际目标？
2. 如何使用 `freopen` 将 `stdin` 与 `stdout` 分别重定向到题目指定的文件？
3. `"r"` 和 `"w"` 分别表示什么？目标文件不存在或已存在时，它们分别会怎样处理？
4. 为什么 `freopen` 应该放在第一次输入输出之前？
5. 文件名无误却仍然读取失败时，还应检查什么？

`freopen` 更完整的模式、文件流类型和系统级文件接口不属于竞赛中的基础用法，不要求理解或记忆。
