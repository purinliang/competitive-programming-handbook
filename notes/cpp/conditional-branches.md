# 控制流：条件分支

> 状态：定稿

目前的程序会从上到下执行每一条语句。但很多问题要求程序根据当前数据选择不同操作：分数达标时输出 `Passed`，否则输出 `Failed`；数字为正、为零或为负时，分别输出不同结果。

这种“只执行满足条件的那一条路”的结构，称为**条件分支**。程序执行顺序因此发生改变，所以它属于控制流。

## if

最基本的条件分支使用 `if`：

```cpp
if (score >= 60) {
    cout << "Passed" << '\n';
}
```

`if` 后的圆括号中是**条件**。`score >= 60` 比较 `score` 是否大于等于 $60$，产生一个布尔值：

- 条件为 `true` 时，执行花括号中的语句；
- 条件为 `false` 时，跳过整个代码块。

条件可以是布尔变量，也可以是产生布尔结果的比较或逻辑表达式。比较与逻辑运算符在前面的独立文章中详细说明；本篇关心的是布尔结果如何决定执行路径。

## else

如果条件不成立时也要执行另一种操作，就在 `if` 后面加上 `else`：

```cpp
if (score >= 60) {
    cout << "Passed" << '\n';
} else {
    cout << "Failed" << '\n';
}
```

两个代码块中恰好执行一个：

- `score >= 60` 为 `true` 时输出 `Passed`；
- 否则输出 `Failed`。

`else` 不再写条件，因为它代表的就是“前面的 `if` 不成立”。

## else if

如果有三种或更多互斥情况，可以使用 `else if` 组成一条分支链。判断一个整数的正负性：

```cpp
if (x > 0) {
    cout << "positive" << '\n';
} else if (x == 0) {
    cout << "zero" << '\n';
} else {
    cout << "negative" << '\n';
}
```

程序从上到下检查条件：

1. 如果 `x > 0` 成立，执行第一个代码块，然后跳过整条分支链。
2. 只有第一个条件不成立，才会检查 `x == 0`。
3. 只有前面所有条件都不成立，才会执行最后的 `else`。

因此，一条 `if / else if / else` 分支链最多只会执行一个代码块。已经命中前面分支的数据，不会再被后面的条件重复处理。

### 条件顺序

因为程序使用第一个成立的条件，有包含关系的条件必须正确排列。例如，将分数分为 `A`、`B`、`C` 和 `D`：

```cpp
if (score >= 90) {
    cout << 'A' << '\n';
} else if (score >= 80) {
    cout << 'B' << '\n';
} else if (score >= 60) {
    cout << 'C' << '\n';
} else {
    cout << 'D' << '\n';
}
```

条件按下界从大到小排列。当 `score` 是 $85$ 时，它不满足 `score >= 90`，但满足 `score >= 80`，因而输出 `B`。

如果把 `score >= 60` 放在最前面，$85$ 会立即命中这个过于宽泛的条件，后面更精确的 `B` 和 `A` 分支永远没有机会执行。

## 代码块与花括号

花括号把若干条语句组成一个**代码块**：

```cpp
if (x < 0) {
    x = -x;
    cout << "converted" << '\n';
}
```

即使当前分支只有一条语句，本书也始终保留花括号：

```cpp
if (x < 0) {
    x = -x;
}
```

C++ 允许省略单条语句外的花括号，但后续添加第二条语句时很容易误以为它也受条件控制。统一保留花括号，能让分支边界一目了然。

## 嵌套分支

一个分支的代码块中还可以再写 `if`。例如，只在整数非负时继续区分奇偶：

```cpp
if (x >= 0) {
    if (x % 2 == 0) {
        cout << "non-negative even" << '\n';
    } else {
        cout << "non-negative odd" << '\n';
    }
} else {
    cout << "negative" << '\n';
}
```

每个 `else` 总是与同一层级中离它最近、尚未配对的 `if` 结合。通过缩进和花括号明确层级，不要让读者或自己猜测 `else` 属于哪个 `if`。

## 整数条件

C++ 也允许将整数直接用作条件：

- `0` 转换为 `false`；
- 非零整数转换为 `true`。

所以

```cpp
if (x) {
    cout << "nonzero" << '\n';
}
```

与

```cpp
if (x != 0) {
    cout << "nonzero" << '\n';
}
```

对整数 `x` 的效果相同。初学时优先写明确的 `x != 0`；它直接说出想要检查的关系，不需要读者在心中补一次布尔转换。

## switch

当程序只需根据一个整数、字符或枚举值的不同取值选择分支时，可以使用 `switch`。例如根据运算符字符执行计算：

```cpp
switch (op) {
case '+':
    cout << a + b << '\n';
    break;
case '-':
    cout << a - b << '\n';
    break;
case '*':
    cout << a * b << '\n';
    break;
default:
    cout << "unknown operator" << '\n';
    break;
}
```

`switch` 先计算圆括号中的 `op`，然后跳到数值与它相等的 `case`。如果没有任何 `case` 匹配，就跳到可选的 `default`。

`break` 会立即结束当前 `switch`。如果省略 `break`，程序会从匹配位置继续向下执行后续 `case`，这种行为称为**贯穿**（fallthrough）。少数代码会有意使用它，但基础写法应当在每个独立分支末尾明确写出 `break`。

`case` 后必须是编译时可确定的整数、字符或枚举常量，不能写范围条件。因此，分数段判断使用 `if / else if`更自然；只按若干个离散值分支时，`switch` 才可能更清晰。竞赛中 `if` 的使用频率远高于 `switch`。

## 完整代码

下面的程序读入一个整数，判断它是正数、零还是负数。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int x;
    cin >> x;

    if (x > 0) {
        cout << "positive" << '\n';
    } else if (x == 0) {
        cout << "zero" << '\n';
    } else {
        cout << "negative" << '\n';
    }
    return 0;
}
```

## 基础练习

1. 输入一个整数，输出它是奇数还是偶数。
2. 输入三个整数，输出其中的最大值，不调用 `max`。
3. 输入一个从 $0$ 到 $100$ 的分数，按照本篇的 `A / B / C / D` 规则输出等级。
4. 输入两个整数和一个运算符字符 `+`、`-` 或 `*`，使用 `switch` 输出计算结果；其他字符输出 `unknown operator`。

## 需要记住什么

1. `if` 的条件为 `true` 和 `false` 时，代码块分别会怎样执行？
2. `if / else` 中有多少个代码块会被执行？
3. `if / else if / else` 按什么顺序检查条件？命中一个分支后还会继续吗？
4. 有包含关系的条件为什么通常要从更严格的条件开始？
5. 为什么即使分支中只有一条语句，也统一保留花括号？
6. 整数作为条件时，哪个值是 `false`，哪些值是 `true`？
7. `switch`、`case`、`default` 和 `break` 分别负责什么？
8. 什么样的条件适合 `if / else if`，什么样的离散取值适合 `switch`？

`switch` 的贯穿只需能够辨认并避免误用，不要求在基础阶段主动利用。
