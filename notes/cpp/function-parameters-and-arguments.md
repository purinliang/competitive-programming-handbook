# 函数的形参与实参

> 最近修订：2026-08-16 09:00 +10:00（未审阅）

[函数的定义与调用](function-definition-and-calls.md) 中的函数不需要外界提供数据。
如果希望同一个函数处理不同的数值，就需要在定义函数时为这些数据留下位置，
并在调用时提供实际使用的值。

## 形参

下面的函数返回两个整数之和：

```cpp
int add(int a, int b) {
    return a + b;
}
```

函数定义中的 `int a` 和 `int b` 是**形参**。形参规定调用函数时需要提供
什么数据，也给这些数据一个在函数体内使用的名称。

每个形参都包含类型和名称：

- `int a` 表示第一个数据应当能转换成 `int`，函数内称它为 `a`；
- `int b` 表示第二个数据应当能转换成 `int`，函数内称它为 `b`。

多个形参写在圆括号中并用逗号分隔。没有形参的函数仍要保留空圆括号：

```cpp
void print_separator() {
    cout << "---" << '\n';
}
```

## 实参

调用函数时，圆括号中真正提供的表达式是**实参**：

```cpp
int answer = add(3, 5);
```

这里的 `3` 和 `5` 是实参。它们按照位置分别提供给形参 `a` 和 `b`：

```text
第一个实参 3  →  形参 a
第二个实参 5  →  形参 b
```

实参不必是字面量，也可以是变量或能够算出值的表达式：

```cpp
int x = 3;
int y = 5;

int first = add(x, y);
int second = add(x + 1, y * 2);
```

第一次调用得到 `8`，第二次调用先计算两个实参 `x + 1` 和 `y * 2`，再让
函数使用得到的 `4` 和 `10`，最终返回 `14`。

## 数量、顺序与类型

调用必须符合函数规定的参数形式。`add` 需要两个 `int` 形参，因此下面的
调用缺少第二个实参：

```cpp
add(3);
```

下面的调用则提供了过多实参：

```cpp
add(3, 5, 7);
```

两种写法都不能匹配当前定义的 `add`。

实参与形参按位置对应，而不是按变量名对应：

```cpp
int subtract(int a, int b) {
    return a - b;
}

int b = 10;
int a = 3;
int answer = subtract(b, a);
```

第一个实参是调用处的 `b`，所以它的值 `10` 提供给第一个形参 `a`；第二个
实参是调用处的 `a`，所以它的值 `3` 提供给第二个形参 `b`。结果是 `7`。
调用处与函数内部的名称相同或不同，都不会改变按位置对应的规则。

实参的值还必须能够转换成对应的形参类型：

```cpp
int answer = add(3.9, 5.8);
```

两个实参都会先转换成 `int`，小数部分向 $0$ 截断，所以本次调用相当于
`add(3, 5)`。这遵循 [类型转换](type-conversions.md) 的规则。参数类型应准确
表达函数需要的数据，不应依靠意外的转换修补设计。

## 普通值参数是副本

当前使用的 `int a` 和 `int b` 都是普通的**值参数**。每次调用函数时，形参
会用实参的值初始化，成为这次调用自己的局部变量：

```cpp
void add_one(int x) {
    x++;
}

int value = 10;
add_one(value);
```

进入函数时，形参 `x` 得到 `value` 当前保存的 `10`：

```text
调用处 value：10
             │ 复制数值
             ▼
函数内     x：10 → 11
```

`x++` 修改的是函数内的副本。调用结束后，形参消失，调用处的 `value` 仍然
是 `10`。

因此，普通值参数适合函数只需要读取一个小型数值，或者本来就需要一份可以
独立修改的副本。以后学习指针和引用后，[参数传递](parameter-passing.md) 会
比较怎样让函数修改调用处对象，以及怎样避免复制较大的对象。

## 完整代码

下面的程序定义 `maximum`，通过两个形参接收本次需要比较的整数，再把返回值
交给 `solve` 输出：

```cpp
#include <bits/stdc++.h>
using namespace std;

int maximum(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

void solve() {
    int x;
    int y;
    cin >> x >> y;

    int answer = maximum(x, y);
    cout << answer << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 5
```

输出：

```text
5
```

调用处使用 `x` 和 `y`，函数内部使用 `a` 和 `b`。两组名称不同，但数值仍然
按照实参的位置传给对应形参。

## 常见错误

### 混淆形参与实参

形参写在函数定义中，描述函数需要什么；实参写在一次具体调用中，提供这次
真正使用的表达式。

### 依靠名称进行对应

实参与形参按照位置对应。调用处的变量名不会自动寻找函数内的同名形参。

### 提供错误数量的实参

当前函数形式要求几个参数，调用时就要提供能够匹配的实参数量。缺少或多出
实参都不能匹配这个函数。

### 以为值参数会修改原变量

普通 `int` 形参是用实参值初始化的局部副本。修改形参不会修改调用处变量。

## 需要记住什么

1. 形参写在哪里，它规定了什么？
2. 实参写在哪里，字面量、变量和表达式能否成为实参？
3. 多个实参与形参按照名称还是按照位置对应？
4. 实参类型与形参类型不完全相同时可能发生什么？
5. 普通 `int` 值参数与调用处变量是不是同一个对象？
6. 为什么在函数内修改值参数不会修改调用处变量？
