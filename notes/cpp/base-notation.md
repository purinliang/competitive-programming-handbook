# 进制表示

> 最近修订：2026-08-16 19:52 +10:00（未审阅）

十进制的 `42`、二进制的 `101010` 和十六进制的 `2a` 看起来不同，却可以表示同一
个数。进制规定一套数字符号，也规定每一位的权值；理解这套规则以后，才能准确阅读
二进制位串、源码中的 `0x` 前缀以及后面的位运算。

## 位权

在十进制数 $527$ 中，从右向左三位的权值依次是 $10^0$、$10^1$ 和 $10^2$：

$$
527=5\times10^2+2\times10^1+7\times10^0.
$$

一般地，$b$ 进制使用从 $0$ 到 $b-1$ 的数字。最右一位的权值是 $b^0$，向左每移动
一位，权值乘以 $b$。例如二进制的 $101101$ 表示：

$$
1\times2^5+0\times2^4+1\times2^3+1\times2^2
+0\times2^1+1\times2^0=45.
$$

“位权”回答的是某个位置上的数字贡献了多少。“进制转换”将把位权展开和除基取余
翻译成程序；本篇先学会阅读表示方法。

## 常用进制

竞赛中最常见的是二、八、十和十六进制：

| 进制 | 可用数字 | 十进制 $45$ 的表示 |
| --- | --- | --- |
| 二进制 | `0`、`1` | `101101` |
| 八进制 | `0` 到 `7` | `55` |
| 十进制 | `0` 到 `9` | `45` |
| 十六进制 | `0` 到 `9`、`a` 到 `f` | `2d` |

十六进制需要十六个数字符号，因此用 `a` 到 `f` 表示十进制的 $10$ 到 $15$。大写
`A` 到 `F` 也合法；本书源码和输出默认使用更常见的小写形式。

二进制直接展示每一个位，但数字会很长。因为

$$
8=2^3,\qquad 16=2^4,
$$

从右向左每三个二进制位可以缩写成一个八进制数字，每四个二进制位可以缩写成一个
十六进制数字：

```text
二进制： 0010 1101
十六进制：  2    d
```

八进制和十六进制不是新的机器存储方式，而是人类阅读二进制时使用的紧凑写法。

## C++ 整数字面量

直接写在源代码中的整数称为整数字面量。C++ 使用前缀说明源码采用哪一种进制：

| 进制 | 源码前缀 | 十进制 $42$ 的写法 |
| --- | --- | --- |
| 二进制 | `0b` 或 `0B` | `0b101010` |
| 八进制 | 一个前导 `0` | `052` |
| 十进制 | 无 | `42` |
| 十六进制 | `0x` 或 `0X` | `0x2a` |

下面四次初始化得到相同的值：

```cpp
int bin_value = 0b101010;
int oct_value = 052;
int dec_value = 42;
int hex_value = 0x2a;
```

前缀只告诉编译器怎样解释源码，不会保存在变量里。尤其要留意前导 `0`：`010` 是
八进制的 $10$，也就是十进制的 $8$，并不是十进制的 $10$。八进制中不能出现
`8` 或 `9`，实际代码也应避免用八进制书写普通整数，以免误读。

## 源码字面量与输入文本

源码中的 `0x10` 会在编译时被识别为一个整数字面量；输入文件中的 `0x10` 只是一串
字符，是否识别前缀由输入接口决定。

| 输入方式 | 默认规则 | 自动识别十、八、十六进制 |
| --- | --- | --- |
| `cin` | 十进制 | `cin >> setbase(0) >> x` |
| `scanf` | `%d` 读取十进制 | `%i` |

下面的程序只用于比较规则，不要求记忆这些少见的输入控制方式：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int a;
    int b;
    int c;

    cin >> dec >> a;
    cin >> setbase(0) >> b >> c;
    cout << "cin: " << a << ' ' << b << ' ' << c << '\n';

    scanf("%d %i %i", &a, &b, &c);
    printf("scanf: %d %d %d\n", a, b, c);
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
16 020 0x10
16 020 0x10
```

输出：

```text
cin: 16 16 16
scanf: 16 16 16
```

程序没有关闭 C 与 C++ 标准流之间的同步，因此这个对照实验可以依次使用两套接口；
正式解题仍应选择一套，不要混用。

`cout` 可以用 `dec`、`oct`、`hex` 输出十、八、十六进制，`printf` 分别使用 `%d`、
`%o`、`%x`。标准 C++17 没有对应的二进制输入输出格式，自动识别也不包含 `0b`；
题目给出二进制文本时，通常先按字符串读入，再自行转换。

## 完整代码

下面的程序证明四种源码字面量保存的是同一个整数，并分别用十、八、十六进制输出：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int bin_value = 0b101010;
    int oct_value = 052;
    int dec_value = 42;
    int hex_value = 0x2a;

    cout << bin_value << ' ' << oct_value << ' ' << dec_value << ' '
         << hex_value << '\n';
    cout << dec << dec_value << '\n';
    cout << oct << dec_value << '\n';
    cout << hex << dec_value << '\n';
}

int main() {
    solve();
    return 0;
}
```

输出：

```text
42 42 42 42
42
52
2a
```

## 基础练习

1. 按位权展开，计算二进制 `110101`、八进制 `75` 和十六进制 `3f` 的十进制值。
2. 把二进制 `11101010` 从右向左分组，直接写出对应的八进制和十六进制表示。
3. 运行完整代码，把 `42` 改成其他非负整数，观察三种输出形式。
