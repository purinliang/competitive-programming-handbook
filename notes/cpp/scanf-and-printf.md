# `scanf` 与 `printf`

> 最近修订：2026-08-16 21:45 +10:00（未审阅）

在线评测系统通过**标准输入**把测试数据交给程序，再从**标准输出**取得程序答案。
本地运行时，二者通常连接键盘与终端；提交以后，它们由评测系统连接到测试数据与
答案检查器。

C 标准库使用 `scanf` 读取格式化数据，使用 `printf` 输出格式化文本。本书后续的
竞赛模板默认采用这一组接口。

## `scanf` 读入数据

`scanf` 的第一个参数是格式字符串。格式控制符从左到右说明要读取的数据类型：

```cpp
int count;
ll total;
double ratio;

scanf("%d%lld%lf", &count, &total, &ratio);
```

常见格式如下：

| 变量类型 | `scanf` 格式 | 对应参数 |
| --- | --- | --- |
| `int` | `%d` | `&x` |
| `long long` | `%lld` | `&x` |
| `float` | `%f` | `&x` |
| `double` | `%lf` | `&x` |
| `char` | `%c` | `&ch` |
| C 字符串 | `%s` | `s` |

`scanf` 需要知道把结果写到哪里，因此普通变量前要写 `&`。C 字符串使用的字符
数组名已经会在这里转换成首元素地址，所以 `%s` 对应 `s`，不再写 `&s`。取地址
运算符的完整含义会在指针单元解释；当前先保证格式与参数一一对应。

格式与真实变量类型不匹配会让函数按错误方式写入内存，属于未定义行为。编译器
通常能为直接可见的格式错误给出警告，不要忽略。

## 空白与字符

格式字符串中的普通空白会跳过任意数量的输入空白。`%d`、`%lf` 和 `%s` 等转换
本身也会跳过前导空白；`%c` 是重要例外，它直接读取当前位置的下一个字符，包括
空格和换行。

若题目要读取下一个**非空白**字符，常在 `%c` 前写一个空格：

```cpp
char operation;
scanf(" %c", &operation);
```

前导空格先清除尚未读取的空白，`%c` 再取得真正的操作符。若空格本身就是数据，
则不能这样写。

`%s` 会跳过开头空白，然后读取到下一个空白为止，并在末尾补 `\0`。它只适合
读取单词；容量与字段宽度规则见 [C 字符串](c-strings.md)，整行文本见
[整行输入](whole-line-input.md)。

## 固定分隔符

格式字符串中的普通字符要求输入出现相同字符。例如输入时间 `12:35`：

```cpp
int hour;
int minute;
scanf("%d:%d", &hour, &minute);
```

冒号只负责匹配输入，不会保存到变量。这种格式不需要背诵；遇到题面中的固定
分隔符时，知道格式字符串可以直接匹配即可。

## 判断读入是否成功

`scanf` 返回成功赋值的变量数量。若要持续读取整数直到输入结束，可以写：

```cpp
int x;
while (scanf("%d", &x) == 1) {
    printf("%d\n", x);
}
```

同时读取两个整数时，应检查返回值是否为 `2`：

```cpp
int a;
int b;

while (scanf("%d%d", &a, &b) == 2) {
    printf("%d\n", a + b);
}
```

题目已经给出数据数量时，通常直接按次数读取；只有题面明确要求读到文件结束，才
需要这种循环。

## `printf` 输出数据

`printf` 也使用格式字符串，但后面的参数是要输出的值，不需要取地址：

```cpp
int count = 3;
ll total = 10000000000LL;
double average = 2.5;
char grade = 'A';

printf("%d %lld %f %c\n", count, total, average, grade);
```

常见输出格式如下：

| 值的类型 | `printf` 格式 |
| --- | --- |
| `int` | `%d` |
| `long long` | `%lld` |
| `double` | `%f` |
| `char` | `%c` |
| C 字符串 | `%s` |

`scanf` 读入 `double` 使用 `%lf`，`printf` 输出 `double` 却使用 `%f`。这是两套
接口最容易混淆的地方：`printf` 的 `float` 参数会先提升成 `double`，而 `scanf`
必须区分要写入 `float*` 还是 `double*`。

格式字符串中的普通文字会原样输出。要输出一个真正的百分号，写成 `%%`：

```cpp
printf("100%%\n");
```

空格和换行也不会自动出现，必须在格式字符串中明确写出。

## 不与 C++ 流混用

另一组接口是 [cin 与 cout](cin-and-cout.md)。一份正式程序应从开始就选定一组：

- `scanf` 配合 `printf`；
- `cin` 配合 `cout`。

混用不仅让空白、缓冲和错误状态更难推理；关闭 C++ 流同步以后再混用，两套缓冲的
先后顺序也不再可靠。

## 完整代码

输入整数 `n`，再输入 `n` 个绝对值不超过 $10^9$ 的整数，输出它们的和：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

void solve() {
    int n;
    scanf("%d", &n);

    ll sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        scanf("%d", &x);
        sum += x;
    }

    printf("%lld\n", sum);
}

int main() {
    solve();
    return 0;
}
```

## 常见错误

### 格式与变量类型不匹配

读入 `double` 使用 `%lf`，输出 `long long` 使用 `%lld`。格式错误不是普通的显示
差异，而可能造成未定义行为。

### 忘记普通变量前的取地址符

`scanf("%d", x)` 没有把变量地址交给函数。普通变量应写成 `&x`；字符数组配合
`%s` 时才直接使用数组名。

### 用 `%c` 意外读到换行

需要下一个非空白字符时写 `" %c"`。需要读取空白本身时则保留 `%c`，不要机械
添加空格。

### 自行输出提示文字

OJ 只接受题目规定的文本。不要额外输出“请输入”或“答案是”等提示。
