# 字符类型

> 最近修订：2026-08-16 06:57 +10:00（未审阅）

竞赛题经常把信息写成单个符号：棋盘中的 `.` 和 `#`、操作中的 `L` 和 `R`、十进制数字中的 `0` 到 `9`。这些符号不是拿来做普通整数运算的数值，但程序仍然需要保存、输入和比较它们。

C++ 使用 `char` 保存一个字符。它一次只保存一个很小的字符编码单元，最适合处理竞赛中常见的英文字母、数字和标点。

## 字符变量

声明一个 `char` 变量与声明 `int` 很相似，只是变量保存的是字符：

```cpp
char direction = 'L';
char wall = '#';
char digit = '7';
```

单个字符写在一对单引号中。`'L'`、`'#'` 和 `'7'` 都是**字符字面量**，可以分别赋给一个 `char`。

双引号表达的是一串字符，因此 `'A'` 和 `"A"` 不是同一种东西：

```cpp
char ch = 'A';
```

当前只需要记住：给 `char` 赋值时使用单引号。双引号会在后面的 [C 字符串](c-strings.md) 中解释。

## 字符与编号

计算机最终仍然只能保存二进制数据，所以每个字符都需要对应一个整数编号。字符与整数编号之间的约定称为**字符编码**。

主流竞赛环境使用 ASCII 兼容编码表示常见英文字符。例如：

| 字符 | 常见编号 |
| --- | ---: |
| `'0'` | 48 |
| `'1'` | 49 |
| `'9'` | 57 |
| `'A'` | 65 |
| `'Z'` | 90 |
| `'a'` | 97 |
| `'z'` | 122 |

因此 `char` 属于 C++ 的整数类型。把一个 `char` 赋给 `int`，可以看见它保存的编号：

```cpp
char ch = 'A';
int code = ch;

cout << ch << '\n';
cout << code << '\n';
```

在主流竞赛环境中输出：

```text
A
65
```

同一份数据输出为 `char` 时显示字符，转换成 `int` 后显示编号。这里的规则会在后面的 [类型转换](type-conversions.md) 中完整解释；当前只需要理解字符内部确实保存着一个整数编号。

## 数字字符

字符 `'7'` 与整数 `7` 看起来相似，却是两个不同的值：

- `'7'` 是字符，ASCII 编号是 `55`；
- `7` 是整数，数值就是 `7`。

如果题目输入的是一个数字字符，我们通常希望得到它代表的数值。十个数字字符在编码中按照顺序连续排列：

```text
'0'  '1'  '2'  ...  '9'
 0    1    2    ...   9
```

于是 `'7'` 与 `'0'` 的编号之差恰好是 $7$：

```cpp
char digit = '7';
int value = digit - '0';

cout << value << '\n';
```

输出：

```text
7
```

这里不需要记住 `'0'` 的具体编号是 `48`。减去 `'0'` 相当于把数字字符序列的起点移动到整数 `0`，因此代码在不同的标准 C++ 字符编码中仍然成立。

反过来，若 `value` 已经是 $0$ 到 $9$ 的整数，可以把它加到 `'0'` 上，再保存为 `char`：

```cpp
int value = 7;
char digit = '0' + value;

cout << digit << '\n';
```

输出仍然是字符：

```text
7
```

这两种转换只适用于**一位**十进制数字。字符串 `"42"` 不能放进一个 `char`，也不能只靠减去一次 `'0'` 得到整数 $42$。

## 转义字符

有些字符很难直接写在一对单引号之间。例如换行不是一个可见符号，单引号和反斜杠又会与字符字面量本身的写法冲突。

C++ 使用以反斜杠 `\` 开头的**转义序列**表示这些字符：

| 写法 | 表示的字符 |
| --- | --- |
| `'\n'` | 换行 |
| `'\t'` | 制表符 |
| `'\''` | 单引号 |
| `'\\'` | 反斜杠 |
| `'\0'` | 编号为 `0` 的空字符 |

虽然源码中写了两个字符 `'\n'`，它整体仍然是一个字符字面量。我们一直在输出结尾使用它：

```cpp
cout << "Hello" << '\n';
```

`'0'` 与 `'\0'` 尤其容易混淆：前者是屏幕上可见的数字字符 `0`，后者是编号为零的空字符。

## 字符输入

使用 `cin >> ch` 可以读取下一个非空白字符：

```cpp
char ch;
cin >> ch;
cout << ch << '\n';
```

若输入是：

```text
#
```

程序输出：

```text
#
```

这里的“非空白”表示 `cin >> ch` 会先跳过空格、换行和制表符，再读取一个字符。读取棋盘格、方向字母和数字字符时，这通常正是我们需要的行为。

如果题目需要把空格本身也读进 `char`，就不能继续使用这条规则。
[`cin` 与 `cout`](cin-and-cout.md) 会介绍读取空白字符的方法。

## 完整代码

现在解决一个只由两个数字字符组成的加法问题。输入保证 `a` 和 `b` 都是 `'0'` 到 `'9'` 之间的单个字符，要求输出它们代表的整数之和。

若输入：

```text
3 5
```

直接计算 `a + b` 会相加两个字符的编码，而不是得到 $3+5$。因此程序分成三步：

1. 用 `char` 读取两个数字字符；
2. 分别减去 `'0'`，得到对应整数；
3. 输出两个整数的和。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    char a;
    char b;
    cin >> a >> b;

    int x = a - '0';
    int y = b - '0';

    cout << x + y << '\n';
}

int main() {
    solve();
    return 0;
}
```

输出：

```text
8
```

这份代码中的每个变量只承担一个含义：`a,b` 保存原始字符，`x,y` 保存转换后的整数。若把输入改成 `8 9`，输出就是 `17`；结果可以超过一位，因为相加的是两个 `int`。

## 存储大小与其他字符类型

C++ 规定 `sizeof(char)` 永远等于 `1`，也就是说 `char` 恰好占用一个字节。在主流竞赛环境中一个字节是 8 位，因此一个 `char` 通常占 8 位。

`char`、`signed char` 和 `unsigned char` 是三种不同的类型。普通字符优先使用 `char`；只有题目真的把一个字节当作 $0$ 到 $255$ 的原始数值处理时，才通常考虑 `unsigned char`。普通 `char` 究竟按有符号还是无符号方式解释由编译环境决定，所以不要依赖它保存负数或进行大范围整数运算。

C++ 还提供 `wchar_t`、`char16_t` 和 `char32_t` 等字符类型，但普通算法竞赛几乎不需要直接使用它们。中文字符在 UTF-8 中通常由多个字节组成，不能可靠地放入一个 `char`；本篇的 `char` 用法只针对竞赛中常见的单字节字符。

## 常见错误

### 混淆字符与整数

```cpp
char digit = 7;
```

这保存的是编号为 `7` 的控制字符，不是可见字符 `'7'`。需要显示数字字符时必须写：

```cpp
char digit = '7';
```

### 混淆单引号与双引号

```cpp
char ch = "A";
```

右边是一串字符，不能赋给一个 `char`。单个字符应写成：

```cpp
char ch = 'A';
```

### 用一个 char 保存多个字符

一个 `char` 只能保存一个字符编码单元。姓名、单词、多位整数和整行文本都需要字符串或字符数组，不能不断往同一个 `char` 中添加编码单元。

## 需要记住什么

1. 单个字符字面量使用单引号还是双引号？
2. 为什么 `char` 属于整数类型，却通常不把它当成普通小整数使用？
3. 字符 `'7'` 与整数 `7` 有什么区别？
4. 为什么 `digit - '0'` 可以把一个数字字符转换成对应整数？
5. 怎样把 $0$ 到 $9$ 的整数转换成对应数字字符？
6. `'0'`、`'\0'` 和 `0` 分别表示什么？
7. `cin >> ch` 遇到输入开头的空格和换行会怎样处理？
8. 为什么一个普通 `char` 不适合保存单个中文字符？

ASCII 中每个字符的具体编号、其他字符类型和 Unicode 编码方式都不要求背诵。当前需要熟练掌握的是字符字面量、常用转义字符以及数字字符与整数之间的转换。
