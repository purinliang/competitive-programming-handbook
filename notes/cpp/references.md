# 内存与别名：引用

> 最近修订：2026-08-13 02:37 +10:00（未审阅）

[指针](pointers.md) 保存对象的地址，需要使用 `*p` 才能访问目标。有时程序只希望给一个已经存在的对象增加另一个名称，不需要空状态、改变指向或指针运算。

C++ 的**引用**是对象的别名。通过引用读写，就是在读写它绑定的原对象，不需要显式解引用。

## 声明引用

在声明中把 `&` 放在类型后，表示变量名是引用：

```cpp
int x = 10;
int& r = x;
```

- `int&` 表示“`int` 的引用”；
- `r` 是引用名称；
- `x` 是 `r` 绑定的对象。

现在 `x` 和 `r` 是同一个整数对象的两个名称：

```text
x ──┐
    ├──> 同一个 int 对象：10
r ──┘
```

读取 `r` 得到 `x` 的值：

```cpp
printf("%d\n", r); // 10
```

给 `r` 赋值会修改 `x`：

```cpp
r = 25;
printf("%d\n", x); // 25
```

引用不像指针那样使用 `*r`。一旦绑定，普通表达式中的 `r` 就直接代表原对象。

## & 的不同含义

符号 `&` 已经出现过多种用法：

```cpp
int bits = a & b; // 两个整数之间：按位与
int* p = &x;      // 表达式开头：取得 x 的地址
int& r = x;       // 声明的类型中：r 是 int 引用
```

它们由语法位置区分：

- `a & b` 有左右两个操作数，是按位运算；
- `&x` 是产生地址的表达式；
- `int& r` 是声明的一部分，表示引用类型。

不要只看到一个符号就猜含义，要连同它所在的完整表达式或声明一起阅读。

## 必须立即绑定

普通引用声明时必须指定原对象：

```cpp
int& r = x;
```

不能先留下一个“以后再决定”的引用：

```cpp
int& r;
```

这段代码不能编译。指针可以用 `nullptr` 表示暂时没有目标，引用没有对应的正常空状态。

如果一个关系可能没有对象，或者以后需要改为指向别处，就应使用指针。引用适合“从创建开始就始终代表这个对象”的关系。

## 不能重新绑定

引用初始化后，不能改为绑定另一个对象：

```cpp
int x = 10;
int y = 20;
int& r = x;

r = y;
```

最后一行不是让 `r` 改为引用 `y`，而是普通赋值。它读取 `y` 的值 `20`，再通过 `r` 写进原对象 `x`。

执行后：

```text
x == 20
y == 20
r 仍然是 x 的别名
```

指针的 `p = &y` 会改变指向；引用的 `r = y` 会修改原对象。这是两者最容易混淆的区别之一。

## 引用对象的一部分

引用不只能绑定独立变量，也能绑定数组元素或结构体成员：

```cpp
int a[3] = {10, 20, 30};
int& middle = a[1];

middle += 5;
```

执行后 `a[1]` 是 `25`。名称 `middle` 可以直接表达当前代码关心的是中间元素。

结构体成员同样可以建立别名：

```cpp
Contestant contestant = {7, 95};
int& score = contestant.score;

score = 100;
```

这会把 `contestant.score` 改成 `100`。引用没有复制成员，只是给原成员增加了一个名称。

引用名称应当真的提高可读性。如果只是把 `a[i]` 随意改名为含义不明的 `x`，代码并不会因此更清楚。

## 引用与地址

对引用使用取地址运算符，得到的是原对象的地址：

```cpp
int x = 10;
int& r = x;

cout << &x << '\n';
cout << &r << '\n';
```

两行会显示同一个地址。这再次说明 `r` 不是另一个整数副本；表达式中的 `r` 就代表 `x`。

编译器可能在底层用地址实现某些引用，也可能直接优化掉这层关系。C++ 语义只要求它表现为别名，不要求把引用理解成“自动解引用的指针”。

## const 引用

在引用的目标类型前加入 `const`，表示不能通过这个引用修改对象：

```cpp
int x = 10;
const int& r = x;

printf("%d\n", r);
```

读取仍然允许，但下面的赋值不能编译：

```cpp
r = 20;
```

`const int&` 只限制通过 `r` 进行的操作。如果原对象 `x` 本身不是 `const`，仍可直接修改 `x`：

```cpp
x = 20;
printf("%d\n", r); // 20
```

引用仍然绑定同一个对象，所以能观察到新值。

`const` 引用还能绑定某些临时计算结果：

```cpp
const int& r = 2 + 3;
```

C++ 会让这个临时整数持续到引用离开作用域。这个规则在只读函数参数中很有用，但不需要在本篇展开所有生命周期细节。

## 引用与指针的选择

| 问题 | 引用 | 指针 |
| --- | --- | --- |
| 声明时必须有目标 | 是 | 否，可以是 `nullptr` |
| 以后能否改为其他目标 | 否 | 能 |
| 访问目标是否写 `*` | 否 | 是 |
| 能否进行数组内位置移动 | 否 | 能 |
| 适合表达 | 始终存在的别名 | 可选或可变化的位置关系 |

若语义是“这个名称永远代表某个现有对象”，引用更直接；若需要“可能没有目标”“以后换目标”或遍历地址，使用指针。

## 完整代码

输入三个整数和一个 1-based 位置 `pos`，再输入增量 `delta`。程序把引用 `value` 绑定到 `a[pos]`，通过引用修改该元素，最后输出整个数组。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[4];
    for (int i = 1; i <= 3; i++) {
        scanf("%d", &a[i]);
    }

    int pos;
    int delta;
    scanf("%d%d", &pos, &delta);

    int& value = a[pos];
    value += delta;

    for (int i = 1; i <= 3; i++) {
        printf("%d", a[i]);
        if (i == 3) {
            printf("\n");
        } else {
            printf(" ");
        }
    }
    return 0;
}
```

输入：

```text
10 20 30
2 5
```

输出：

```text
10 25 30
```

`value` 没有保存 `20` 的副本，而是 `a[2]` 的别名，所以 `value += delta` 直接改变数组元素。

## 常见错误

### 声明没有目标的引用

普通引用必须立即绑定。需要暂时没有对象时使用初始化为 `nullptr` 的指针。

### 以为给引用赋值会重新绑定

`r = y` 通过引用修改原对象，不改变 `r` 的绑定关系。只有指针变量能够通过保存新地址改变指向。

### 对引用再次解引用

引用名称已经直接代表原对象，使用时不写 `*r`。星号属于指针解引用。

### 通过 const 引用修改对象

`const int&` 允许读取，不允许通过该引用写入。它是否能观察到其他名称造成的修改，取决于原对象本身是否还能被修改。

### 为简单表达式制造无意义别名

引用应该表达稳定关系或避免重复书写长成员路径。别名过多也会增加理解成本。

## 需要记住什么

1. 引用保存对象副本，还是作为原对象的别名？
2. `int& r = x;` 中的 `int&`、`r` 和 `x` 分别表示什么？
3. 修改 `r` 为什么会修改 `x`？
4. 引用能否不初始化？能否在以后重新绑定？
5. `r = y` 是改变绑定，还是把 `y` 的值写入原对象？
6. `&r` 与 `&x` 的关系是什么？
7. `const int&` 允许哪些操作，不允许哪些操作？
8. 哪些关系适合引用，哪些需要指针？

右值引用、移动语义、引用折叠和复杂生命周期规则不属于基础竞赛用法，不要求理解或记忆。[函数：参数传递](parameter-passing.md) 只会把普通引用和 `const` 引用用于函数参数。
