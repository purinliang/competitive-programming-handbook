# 函数的定义与调用

> 最近修订：2026-08-16 08:40 +10:00（未审阅）

当一段操作会被多次使用，或者它本身已经是一个可以准确命名的子任务时，把所有语句重复复制到每个位置会让代码变长，修改时还可能漏掉其中一份。

**函数**把一段操作放进一个有名称的代码块。后续代码只需调用这个名称，就能执行整段操作。

## 定义函数

先定义一个输出分隔线的函数：

```cpp
void print_separator() {
    cout << "---" << '\n';
}
```

这个定义包含四个当前需要认识的部分：

- `void` 是返回类型，暂时理解为函数不送回一个计算结果；
- `print_separator` 是函数名，说明这段操作的用途；
- 空圆括号 `()` 表示调用时不需要提供数据；
- 花括号中的语句组成函数体，每次调用时都会执行。

函数定义只说明“调用时做什么”，程序不会因为看见定义就自动执行函数体。

## 调用函数

在函数名后写一对圆括号，就是一次函数调用：

```cpp
print_separator();
```

程序执行到这一行时会进入 `print_separator` 的函数体，输出一行分隔线；函数体结束后，再回到调用位置继续向下执行。

可以调用同一个函数许多次：

```cpp
cout << "first" << '\n';
print_separator();
cout << "second" << '\n';
print_separator();
```

输出：

```text
first
---
second
---
```

若以后要改变分隔线，只需修改函数定义，不必寻找每一处重复代码。

调用时的圆括号不能省略：

```cpp
print_separator(); // 调用函数
print_separator;   // 没有调用函数
```

## solve 函数

从 [Hello World!](hello-world.md) 开始，本书就把一道题的主要流程放在 `solve()` 中：

```cpp
void solve() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << '\n';
}
```

现在可以读懂它的定义：

- `void` 表示 `solve` 不向调用处送回计算结果；
- `solve` 是函数名；
- 空圆括号表示调用处不提供数据；
- 输入、计算和输出都位于函数体中。

`solve` 不是 C++ 强制规定的名字，而是竞赛代码中的稳定习惯。它把题目逻辑与程序入口分开，也方便以后在 `main` 中按照测试用例次数重复调用。

## main 函数

`main` 是程序入口。程序开始运行后执行 `main` 的函数体，再由它调用 `solve()`：

```cpp
int main() {
    solve();
    return 0;
}
```

这里的 `int` 和 `return 0;` 表示 `main` 最后向运行环境送回整数 `0`，报告程序正常结束。函数怎样返回结果会在 [函数的返回值](function-return-values.md) 中独立解释。

普通 C++ 程序只能定义一个 `main`。`solve` 和其他辅助函数则可以按照题目需要定义多个，只要名称和参数形式能够正确区分。

## 定义位置

C++ 从上到下处理源文件。在调用函数以前，编译器至少必须已经知道函数的名称、返回类型和参数形式。

最直接的做法是把完整定义放在第一次调用以前：

```cpp
void print_separator() {
    cout << "---" << '\n';
}

int main() {
    print_separator();
    return 0;
}
```

如果希望把定义放在调用位置之后，就要先写一条**函数声明**：

```cpp
void print_separator();

int main() {
    print_separator();
    return 0;
}

void print_separator() {
    cout << "---" << '\n';
}
```

声明写出调用所需的接口信息，并用分号结束；定义则额外提供函数体。编译器先看见声明，就能检查 `main` 中的调用，稍后再找到真正的定义。

在单文件竞赛代码中，优先按依赖顺序排列完整定义，能不写额外声明就不写；确实需要把定义放到调用位置以后时，再补声明。

## 完整代码

下面的程序定义并重复调用 `print_separator`，再由 `solve` 组织一整次输入与输出：

```cpp
#include <bits/stdc++.h>
using namespace std;

void print_separator() {
    cout << "---" << '\n';
}

void solve() {
    int a;
    int b;
    cin >> a >> b;

    print_separator();
    cout << a + b << '\n';
    print_separator();
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 5
```

输出：

```text
---
8
---
```

## 常见错误

### 只写函数名

一对圆括号是调用语法的一部分。单独写 `print_separator;` 不会执行函数体。

### 在编译器认识函数以前调用

若完整定义位于调用位置以后，前面必须先有匹配的函数声明。最简单的竞赛写法是直接把辅助函数定义放在 `solve` 和 `main` 以前。

### 把定义当成自动执行

定义只建立函数。每一次实际执行都来自某个调用；没有调用的普通函数不会自行运行。

1. 函数怎样减少重复代码，并给子任务准确命名？
2. 一个最小函数定义中的返回类型、函数名、圆括号和函数体分别在哪里？
3. 怎样调用一个无参数函数？圆括号能否省略？
4. 调用结束后，程序从哪里继续执行？
5. `solve()` 在竞赛代码中负责什么？它是 C++ 强制规定的名字吗？
6. `main` 在程序中有什么特殊作用？
7. 函数声明和函数定义有什么区别？什么时候需要先声明？

本篇故意只使用无参数、无返回结果的辅助函数。函数怎样返回值，以及调用处怎样向形参提供实参，会在后面各自成篇。
