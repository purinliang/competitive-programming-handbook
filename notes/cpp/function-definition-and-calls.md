# 函数：定义与调用

> 状态：定稿

当一段计算会被多次使用，或者它本身已经是一个可以准确命名的子问题时，把所有语句重复复制到每个位置会让代码变长，修改时还可能漏掉其中一份。

**函数**把一段操作起一个名字，并明确它需要哪些输入、会产生什么结果。后续代码只需使用这个名字，就可以执行整段操作。

## 定义函数

先定义一个计算两个整数之和的函数：

```cpp
int add(int a, int b) {
    return a + b;
}
```

这个定义包含五个部分：

```text
int add(int a, int b) {
    return a + b;
}
```

- 第一个 `int` 是**返回类型**，表示函数会返回一个整数。
- `add` 是**函数名**，说明这个函数负责加法。
- 圆括号中的 `int a, int b` 是**形参列表**，表示函数需要接收两个整数。
- 花括号包围的部分是**函数体**，保存每次调用时要执行的语句。
- `return a + b;` 结束当前调用，并把计算结果送回调用处。

从返回类型到参数列表的第一行可以被称为函数的**头部**；加上函数体后，才是一个完整的函数定义。

## 调用函数

函数定义只说明“调用时应该做什么”，不会自动执行。在函数名后写一对圆括号，并提供它需要的数据，才是**调用函数**：

```cpp
int result = add(2, 3);
```

调用过程可以拆成：

1. 整数 `2` 提供给形参 `a`，整数 `3` 提供给形参 `b`。
2. 程序进入 `add` 的函数体。
3. `a + b` 得到 `5`。
4. `return` 将 `5` 送回调用处。
5. 整个表达式 `add(2, 3)` 因此产生整数 `5`，用于初始化 `result`。

调用时圆括号中的 `2` 和 `3` 称为**实参**，定义中的 `a` 和 `b` 称为**形参**。实参负责提供具体数据，形参则是函数体内部用来表示这些数据的名字。

实参不必是直接写出的数值，也可以是变量或更完整的表达式：

```cpp
int x = 2;
int y = 3;

int first = add(x, y);
int second = add(x + 1, y * 2);
```

实参名与形参名没有必要相同。上面调用中的 `x` 仍然按位置对应到第一个形参 `a`，`y` 对应到第二个形参 `b`。

## 返回值

返回类型不是 `void` 的函数需要通过 `return` 提供结果。例如，判断整数是否为偶数：

```cpp
bool is_even(int x) {
    return x % 2 == 0;
}
```

这个函数的返回类型是 `bool`，所以调用表达式会产生 `true` 或 `false`，可以直接用作条件：

```cpp
if (is_even(n)) {
    cout << "even" << '\n';
}
```

`return` 不只提供结果，也会立即结束当前函数调用。所以一个函数可以在不同分支中返回：

```cpp
int maximum(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

当 `a > b` 成立时，`return a;` 结束调用，后面的 `return b;` 不会再执行。条件不成立时，程序跳过第一个 `return`，最后返回 `b`。

对一个需要返回值的函数，每一条可能的执行路径都必须在到达函数体末尾前执行合法的 `return`。不要只检查某一个分支是否返回。

## void 函数

有些函数只负责执行操作，不需要把数值送回调用处。它们的返回类型写作 `void`：

```cpp
void print_answer(int answer) {
    cout << answer << '\n';
}
```

调用 `void` 函数时，只执行它的操作，不能把调用结果保存到变量：

```cpp
print_answer(5);
```

`void` 函数可以不写 `return`，直接执行到函数体末尾。如果想在中途结束，可以只写 `return;`，不在后面提供数值：

```cpp
void print_non_negative(int x) {
    if (x < 0) {
        return;
    }
    cout << x << '\n';
}
```

## 无参数函数

函数不需要从调用处接收信息时，将形参列表留空：

```cpp
void print_separator() {
    cout << "---" << '\n';
}
```

调用时圆括号也留空，但不能省略：

```cpp
print_separator();
```

写成 `print_separator;` 不会调用函数。圆括号是“现在执行这个函数”的一部分。

## solve 函数

从 [入门：Hello World!](hello-world.md) 开始，本书就把题目的主要逻辑放在 `solve()` 中。现在可以准确解释它的头部：

```cpp
void solve() {}
```

- `void` 表示 `solve` 不向调用处返回数值；
- 空圆括号表示它不从调用处接收实参；
- 题目输入、计算和输出都放在函数体中。

`main` 是程序的入口函数。程序开始后，`main` 调用 `solve()`：

```cpp
int main() {
    solve();
    return 0;
}
```

`main` 的返回类型是 `int`；`return 0;` 结束 `main`，并向运行环境表示程序正常结束。

`solve` 不是 C++ 强制规定的名字，而是竞赛代码中的稳定习惯。它将题目逻辑与程序入口分开，也方便后续在 `main` 中按测试用例次数重复调用。具体的多组测试循环属于循环与题面输入格式，不在本篇展开。

## 声明与定义

C++ 从上到下处理源文件。调用一个函数之前，编译器至少必须已经知道它的名字、返回类型和参数类型。

最直接的做法是把完整定义放在第一次调用之前：

```cpp
int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(2, 3) << '\n';
    return 0;
}
```

如果希望把定义放在调用位置之后，就要先写一条**函数声明**：

```cpp
int add(int a, int b);

int main() {
    cout << add(2, 3) << '\n';
    return 0;
}

int add(int a, int b) {
    return a + b;
}
```

声明只保留函数头部所提供的接口信息，将原来的函数体替换为分号。编译器因此能够检查后面的调用；真正的操作仍由唯一的函数定义提供。

在目前的单文件竞赛代码中，优先按依赖顺序排列函数定义，能不写额外声明就不写；当两个函数的组织顺序无法满足调用需求时，再使用声明。

## 完整代码

下面的程序使用 `add` 完成计算，使用 `solve` 负责一整个题目流程：

```cpp
#include <bits/stdc++.h>
using namespace std;

int add(int a, int b) {
    return a + b;
}

void solve() {
    int a;
    int b;
    cin >> a >> b;
    cout << add(a, b) << '\n';
}

int main() {
    solve();
    return 0;
}
```

## 基础练习

1. 定义 `int square(int x)`，返回 `x * x`；在 `solve()` 中读入一个整数并输出调用结果。
2. 定义 `int minimum(int a, int b)`，使用条件分支返回两个整数中较小的一个。
3. 定义 `bool is_positive(int x)`，返回 `x` 是否大于 $0$，并把调用表达式直接用作 `if` 条件。
4. 将 `add` 的定义移到 `main` 后面，观察未声明时的编译错误，再通过在 `main` 前增加函数声明修复它。
