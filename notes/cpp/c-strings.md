# 字符串：C 字符串

> 最近修订：2026-08-13 02:27 +10:00（未审阅）

单个 `char` 只能保存一个字符，但名字、单词和数字文本都由许多字符按顺序组成。把每个字符放进一个 [一维数组](one-dimensional-arrays.md)，就能按照下标访问整段文本。

C 语言及 C++ 继承的基础接口使用一种约定：字符序列末尾放一个特殊的空字符，表示文本在这里结束。满足这条约定的字符数组称为 **C 字符串**。

## 空字符

空字符写作 `'\0'`，它的字符编号是 $0$。它不是字符 `'0'`：

- `'0'` 是可以显示的十进制数字字符；
- `'\0'` 是编号为 $0$ 的控制字符，用于标记 C 字符串结束。

文本 `cat` 在字符数组中实际需要四个位置：

| 下标 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 内容 | `'c'` | `'a'` | `'t'` | `'\0'` |

可以逐个写出：

```cpp
char s[4] = {'c', 'a', 't', '\0'};
```

也可以使用字符串字面量初始化：

```cpp
char s[4] = "cat";
```

双引号中的 `"cat"` 会自动包含末尾的 `'\0'`。因此，长度为 $3$ 的文本至少需要容量 $4$。让编译器根据初始化内容推断容量也可以：

```cpp
char s[] = "cat";
```

这里 `sizeof(s)` 是 $4$，不是 $3$。

## 字符数组与 C 字符串

字符数组只说明元素类型是 `char`；只有从某个起点开始、能在合法范围内找到 `'\0'` 时，它才表示一个有效的 C 字符串。

下面只是三个字符，不是合法的 C 字符串：

```cpp
char s[3] = {'c', 'a', 't'};
```

若把它交给期待 C 字符串的输出或长度函数，程序会继续越过数组寻找不存在的结尾，产生未定义行为。

空字符后面即使还有数组元素，C 字符串接口也不会把它们视为当前文本的一部分：

```cpp
char s[6] = {'c', 'a', 't', '\0', 'x', 'y'};
```

这里 `s` 的数组容量是 $6$，C 字符串长度却是 $3$。容量、文本长度与是否存在结尾必须分开理解。

## 字符串长度

C 字符串的长度是第一个 `'\0'` 之前的字符数量，不包括空字符本身。可以用循环手动计算：

```cpp
int length = 0;

while (s[length] != '\0') {
    length++;
}
```

每轮检查一个字符，遇到空字符停止。若文本长度为 $n$，这个过程需要 $O(n)$ 时间。

标准库函数 `strlen` 完成同样工作：

```cpp
int length = strlen(s);
```

题目已经保证字符串长度不超过 `int` 范围，所以竞赛代码直接把结果保存为 `int`，方便后续使用普通下标。

`strlen(s)` 每次都会从开头重新扫描到空字符，不是 $O(1)$。下面的循环会反复计算长度，最坏达到 $O(n^2)$：

```cpp
for (int i = 0; i < strlen(s); i++) {
    // 使用 s[i]
}
```

先计算一次长度：

```cpp
int n = strlen(s);

for (int i = 0; i < n; i++) {
    // 使用 s[i]
}
```

## 容量与长度

声明容量时要为末尾空字符多留一个位置。若题目保证文本长度不超过 $100000$：

```cpp
const int MAXL = 100000 + 5;
char s[MAXL];
```

有效文本可以占用 `s[0]` 到 `s[99999]`，后面还必须有 `'\0'`。

对当前仍是完整数组的名称，`sizeof(s)` 给出数组占用的总字节数。因为 `char` 恰好占一个字节，这里也等于数组容量 `MAXL`。`strlen(s)` 则给出当前文本长度：

```cpp
printf("%zu\n", sizeof(s));
printf("%zu\n", strlen(s));
```

两者不能互换。`sizeof` 在这里由声明决定，不会寻找空字符；`strlen` 由当前内容决定，必须扫描到有效的空字符。

## 读入一个单词

`scanf` 使用 `%s` 读取 C 字符串：

```cpp
scanf("%s", s);
```

它会跳过开头的空白字符，随后读取连续的非空白字符，并自动在末尾写入 `'\0'`。因此它适合读取不含空格的单词、只由数字组成的文本或竞赛中的普通字符串。

数组名 `s` 前面不写 `&`。数组传给函数时会提供首元素位置，具体规则属于数组与指针的关系；当前记住这条固定形式即可。

只写 `%s` 没有告诉 `scanf` 数组容量。若输入比数组可容纳的文本更长，就会越界。题目上限为 $100000$ 时，可以限制最多读取 $100000$ 个字符：

```cpp
scanf("%100000s", s);
```

`scanf` 随后还会写入一个空字符，所以数组容量至少要有 $100001$。本书额外预留几个位置，声明 `MAXL = 100000 + 5`。

`%s` 遇到空格、换行或制表符就停止，不能读取包含空格的一整行。

## 读入一整行

继续使用字符数组时，C++ 输入流提供 `cin.getline`：

```cpp
cin.getline(s, MAXL);
```

它读取当前行，在换行处停止，丢弃换行，再在字符数组末尾写入 `'\0'`。第二个参数是数组容量，所以最多只能保存 `MAXL - 1` 个正文字符。

C 标准输入接口提供 `fgets`：

```cpp
fgets(s, MAXL, stdin);
```

它同样最多保存 `MAXL - 1` 个输入字符并补上 `'\0'`，但如果成功读到行末，通常会把 `\n` 一起保存在字符串中。需要把整行内容处理为不含换行的文本时，可以检查并删除它：

```cpp
int n = strlen(s);

if (n > 0 && s[n - 1] == '\n') {
    s[n - 1] = '\0';
}
```

最后一行不一定以换行结束，所以只有确认末尾是 `\n` 时才能删除。

`cin.getline` 适合已经选择 `cin` / `cout` 的程序，`fgets` 适合已经选择 C 标准
输入输出的程序；不要只为读一行而混用两套接口。若前面刚用 `cin >> n` 或
`scanf` 读过数值，还要先处理留在输入中的行末换行，具体写法见
[整行输入](whole-line-input.md)。

后续学习 `string` 后，更常用的整行接口是 `getline(cin, s)`。这里的 `cin.getline(s, MAXL)` 接收字符数组，两者不要混写。

## 输出 C 字符串

`printf` 使用 `%s`，从给定起点输出字符，直到遇到第一个 `'\0'`：

```cpp
printf("%s\n", s);
```

`cout` 也识别以空字符结尾的字符数组：

```cpp
cout << s << '\n';
```

两种写法都依赖有效的 `'\0'`。若数组没有合法结尾，输出会越界读取。

单个字符仍然使用 `%c` 或直接输出 `s[i]`：

```cpp
printf("%c\n", s[i]);
cout << s[i] << '\n';
```

## 修改字符串

每个非结尾字符都能通过下标修改：

```cpp
s[0] = 'C';
```

如果原来是 `cat`，修改后变成 `Cat`。只要不破坏末尾空字符，数组仍然是有效 C 字符串。

也可以提前写入空字符，主动截短文本：

```cpp
s[2] = '\0';
```

此后 C 字符串只包含 `s[0]`、`s[1]`。原数组后面的位置仍然存在，但 `%s` 和 `strlen` 在 `s[2]` 就停止。

向末尾追加一个字符时，必须把原来的空字符向后移动：

```cpp
int n = strlen(s);

s[n] = '!';
s[n + 1] = '\0';
```

执行前要保证容量至少为 `n + 2`：一个位置保存新字符，另一个位置保存新的结尾。

## 常用 cstring 函数

头文件 `<cstring>` 提供一组按空字符处理文本的函数；`bits/stdc++.h` 已经包含它。最常见的接口是：

| 函数 | 作用 | 复杂度 |
| --- | --- | --- |
| `strlen(s)` | 计算长度 | $O(n)$ |
| `strcmp(a, b)` | 按字典序比较两个字符串 | $O(\min(n,m))$ |
| `strcpy(target, source)` | 将 `source` 连同空字符复制到 `target` | $O(n)$ |
| `strcat(target, source)` | 将 `source` 追加到 `target` 末尾 | $O(n+m)$ |

`strcmp(a, b)` 的返回值：

- 小于 $0$ 表示 `a` 的字典序在 `b` 前；
- 等于 $0$ 表示内容相同；
- 大于 $0$ 表示 `a` 的字典序在 `b` 后。

不要假设它只返回 `-1`、`0`、`1`。判断相等应写：

```cpp
bool same = strcmp(a, b) == 0;
```

不能用 `a == b` 比较两个字符数组的文本内容；数组参与这种表达式时比较的不是逐字符内容。

`strcpy` 和 `strcat` 不知道目标数组容量。调用前必须保证目标空间足够，否则会越界。竞赛中更常直接使用 `string` 完成可变文本的复制与拼接；这里需要会读懂 C 字符串接口，而不是到处主动使用无边界检查的复制函数。

## 完整代码

输入一个长度不超过 $100000$、不含空白字符的字符串。第一行输出长度，第二行倒序输出所有字符。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXL = 100000 + 5;

char s[MAXL];

int main() {
    scanf("%100000s", s);

    int n = strlen(s);
    printf("%d\n", n);

    for (int i = n - 1; i >= 0; i--) {
        printf("%c", s[i]);
    }
    printf("\n");
    return 0;
}
```

输入：

```text
algorithm
```

输出：

```text
9
mhtirogla
```

`strlen` 先找到末尾空字符并得到长度 $9$。有效字符下标是 $0$ 到 $8$，所以倒序循环从 `n - 1` 开始，到 `0` 结束。

## 常见错误

### 忘记为空字符预留位置

长度为 $n$ 的 C 字符串至少需要 `n + 1` 个 `char`。末尾空字符也占一个数组元素。

### 把 '0' 当成 '\0'

`'0'` 是可显示的数字字符，`'\0'` 才是字符串结束标记。两者编号和用途都不同。

### 使用 %s 读入带空格文本

`%s` 只读取连续的非空白字符。字符数组整行输入使用 `cin.getline` 或 `fgets`；`fgets` 还要处理可能保留的行末换行。

### 在循环条件中反复调用 strlen

`strlen` 每次都从头扫描。字符串没有变化时先保存长度，避免把线性遍历变成平方复杂度。

### 使用 == 比较字符数组内容

比较 C 字符串内容使用 `strcmp(a, b) == 0`。`a == b` 不会逐字符判断文本是否相同。

### 复制或追加时忽略目标容量

`strcpy`、`strcat` 和手动追加都不会自动扩容。目标数组必须容纳全部字符和最后的空字符。

## 需要记住什么

1. C 字符串使用哪个字符表示结尾？它与字符 `'0'` 有什么区别？
2. 保存长度为 $n$ 的文本，字符数组至少需要多大容量？
3. 字符数组满足什么条件时才是有效的 C 字符串？
4. `sizeof(s)` 与 `strlen(s)` 分别得到什么？
5. `%s` 读取什么范围的文本？为什么要写最大字段宽度？
6. `cin.getline` 与 `fgets` 都能读取整行，它们怎样处理行末换行？
7. 怎样遍历 C 字符串中的每个有效字符？`strlen` 的复杂度是多少？
8. 为什么不能用 `==` 比较两个字符数组的文本内容？
9. 修改、复制和追加 C 字符串时，为什么必须保护末尾空字符和数组容量？

字符数组到指针的调整、字符串字面量的底层类型和各类有界 C 接口不要求在本篇理解或记忆。当前重点是：容量包含结尾、空字符决定长度、任何接口都不能越过数组边界。
