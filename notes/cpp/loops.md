# `for`

> 最近修订：2026-08-16 08:24 +10:00（未审阅）

如果要输入 $n$ 个数，或者依次处理从 $1$ 到 $n$ 的每个整数，把同一段代码复制 $n$ 遍既不能适应变化的 `n`，也很容易漏改。

重复次数由一个计数变量清楚控制时，C++ 的 `for` 循环可以把初值、继续条件和每轮更新集中写在同一处。

## 三个组成部分

从 $1$ 输出到 $n$ 可以写成：

```cpp
for (int i = 1; i <= n; i++) {
    cout << i << '\n';
}
```

圆括号内由两个分号分成三部分：

```text
初始化; 继续条件; 每轮结束后的更新
```

这段循环中：

- `int i = 1` 创建计数变量，并给出第一个值；
- `i <= n` 判断当前值是否仍要处理；
- `i++` 在一轮结束后把计数变量移动到下一个值。

`i++` 和其他更新写法已经在 [自增与自减运算符](increment-decrement-operators.md) 与 [复合赋值运算符](compound-assignment-operators.md) 中解释。本篇关心它们在 `for` 的第三部分何时执行。

## 执行顺序

`for` 的实际执行顺序是：

1. 只执行一次初始化 `int i = 1`；
2. 检查条件 `i <= n`，不成立就结束循环；
3. 执行循环体；
4. 执行更新 `i++`；
5. 回到第 2 步。

因此，更新发生在循环体之后、下一次条件检查之前。初始化不会在每轮重新执行。

它与下面的 [while](while.md) 表达同一个过程：

```cpp
int i = 1;
while (i <= n) {
    cout << i << '\n';
    i++;
}
```

固定次数或连续计数时，`for` 把三处控制信息集中在一起，更容易检查。退出时间由输入或计算结果决定时，`while` 通常更自然。

## 常见计数区间

遍历整数 $1,2,\ldots,n$：

```cpp
for (int i = 1; i <= n; i++) {
    // 使用 i
}
```

它使用闭区间 `[1, n]`，正好执行 `n` 次。若 `n == 0`，第一次条件检查就是 `1 <= 0`，循环一次也不执行。

直接配合 C++ 与 STL 的 0-based 对象时，经常遍历 $0,1,\ldots,n-1$：

```cpp
for (int i = 0; i < n; i++) {
    // 使用 i
}
```

它使用左闭右开区间 `[0, n)`，也正好执行 `n` 次。不要只背 `<=` 或 `<`；先说清楚第一个值和最后一个值，再写继续条件。

倒序遍历 $n,n-1,\ldots,1$：

```cpp
for (int i = n; i >= 1; i--) {
    // 使用 i
}
```

每次前进的距离也不一定是 $1$。例如只处理不超过 `n` 的正奇数：

```cpp
for (int i = 1; i <= n; i += 2) {
    // i 依次为 1, 3, 5, ...
}
```

初始化、条件和更新必须描述同一个方向。若从 `1` 开始、条件要求 `i <= n`，却不断执行 `i--`，通常永远不会靠近结束边界。

## 嵌套循环

一个循环体中还可以出现另一个循环：

```cpp
for (int row = 1; row <= n; row++) {
    for (int column = 1; column <= m; column++) {
        cout << row << ' ' << column << '\n';
    }
}
```

外层每固定一个 `row`，内层都会从 `column = 1` 开始完整执行到 `m`。因此上面的输出共有 `n * m` 行。

这里只需要理解执行顺序。怎样从嵌套结构计算时间复杂度，会在“从代码分析复杂度”中系统推导。

## break

`break` 立即结束当前循环。判断整数 `n` 是否存在从 $2$ 开始的小因数时，一旦找到一个因数就没有必要继续：

```cpp
bool found = false;

for (int i = 2; i < n; i++) {
    if (n % i == 0) {
        found = true;
        break;
    }
}
```

`break` 会跳到这个 `for` 之后。循环嵌套时，它只结束直接包围自己的最内层循环，不会自动结束所有外层循环。

## continue

`continue` 跳过本轮循环体剩余语句，直接进入下一轮。只把输入中的正数加入总和：

```cpp
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;

    if (x <= 0) {
        continue;
    }

    sum += x;
}
```

当 `x <= 0` 时，本轮不会执行 `sum += x`。对于 `for`，`continue` 之后仍会先执行圆括号中的更新 `i++`，再检查下一轮条件。

`break` 结束整个当前循环；`continue` 只放弃当前这一轮。先用普通语言确认需要“停止所有后续轮次”还是“忽略当前数据”。

## 完整代码

输入正整数 `n`，再输入 `n` 个整数，输出它们的总和。代码用 `ll` 保存可能超过 32 位整数范围的累计结果：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

void solve() {
    int n;
    cin >> n;

    ll sum = 0;

    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum += x;
    }

    cout << sum << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
5
3 -1 7 0 2
```

输出：

```text
11
```

循环开始前 `sum` 是 $0$，五轮之后依次变为 $3,2,9,9,11$。变量 `x` 每轮保存当前读入值，`sum` 保存此前所有已读数的总和。

## 常见错误

### 边界多一次或少一次

遍历 $1$ 到 $n$ 使用 `i <= n`，遍历从 $0$ 开始的 `n` 个位置使用 `i < n`。用最小输入和最后一个值手动走一遍，比只看循环次数更可靠。

### 更新方向错误

继续条件要求计数变量向右接近上界时，更新也必须让它增大。条件、起点和步长应当共同描述一个能够停止的过程。

### 累计变量没有初始化

`sum += x` 会读取 `sum` 的旧值。第一次读取前必须给它有意义的初值，普通求和从 $0$ 开始。

### 混淆 break 与 continue

`break` 不再执行任何后续轮次；`continue` 只是跳过本轮余下部分，并且仍会执行 `for` 的更新部分。

## 需要记住什么

1. `for` 圆括号中的三部分分别是什么？
2. 初始化、条件检查、循环体和更新按照什么顺序执行？
3. 怎样遍历闭区间 `[1, n]`？怎样遍历左闭右开区间 `[0, n)`？
4. 如何倒序遍历 $n,n-1,\ldots,1$？如何让步长变成 $2$？
5. 嵌套循环中，外层固定一个值时，内层会怎样执行？
6. `break` 与 `continue` 分别跳到哪里？
7. `for` 中执行 `continue` 后，第三部分的更新还会不会执行？
8. 为什么累计变量必须在进入循环以前初始化？
