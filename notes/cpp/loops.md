# 控制流：循环

> 最近修订：2026-08-13 02:10 +10:00（未审阅）

如果要输入 $n$ 个数、检查从 $1$ 到 $n$ 的每个整数，或者在一个条件持续成立时重复操作，把同一段代码复制许多遍既不能适应变化的 $n$，也很容易漏改。程序需要表达的是“重复这段操作”，而不是手写若干份相同语句。

**循环**让一个代码块反复执行。每轮执行称为一次**迭代**。一个能够停止的循环通常需要三部分：

1. 当前状态，例如已经处理到第几个数；
2. 继续条件，例如还有数据没有处理；
3. 状态更新，例如处理完一个数后移动到下一个。

遗漏任何一部分，都可能造成少执行一次、多执行一次或永远不能停止。

## while 循环

`while` 适合“只知道继续条件，不一定预先知道要重复多少次”的过程：

```cpp
while (condition) {
    statement;
}
```

每轮开始前，程序先检查 `condition`：

- 条件为 `true` 时执行循环体，然后回到开头重新检查；
- 条件为 `false` 时跳过循环体，继续执行循环之后的代码。

因此，若条件从一开始就是 `false`，循环体一次也不会执行。

### 从 1 输出到 n

先定义当前要输出的整数：

```cpp
int i = 1;
```

只要 `i` 仍然不超过 `n`，就应该继续：

```cpp
while (i <= n) {
    cout << i << '\n';
}
```

但这段循环会永远输出 `1`，因为 `i` 从未改变。每轮处理完当前值后，还要移动到下一个整数：

```cpp
while (i <= n) {
    cout << i << '\n';
    i = i + 1;
}
```

现在状态变化为 $1,2,3,\ldots,n,n+1$。当 `i` 变成 `n + 1` 时，`i <= n` 首次为 `false`，循环停止。

这个过程清楚展示了循环的四个位置：初始化写在循环前，条件写在 `while` 后，实际操作与状态更新写在循环体中。

## 自增与复合赋值

把整数增加 $1$ 有几种常见写法：

```cpp
i = i + 1;
i += 1;
i++;
++i;
```

当它们各自单独作为一条语句时，效果相同。本书在普通计数循环中统一使用 `i++`。

`i++` 与 `++i` 若嵌入更大的表达式，产生值的时机不同。基础循环不需要利用这种差别；不要在一个复杂表达式中多次修改同一变量。

复合赋值可以把“用旧值计算，再写回同一变量”写得更直接：

```cpp
sum += x;
product *= x;
```

它们分别对应 `sum = sum + x` 和 `product = product * x`。

## for 循环

若循环围绕一个计数变量展开，初始化、继续条件和更新可以集中写在 `for` 的圆括号中：

```cpp
for (int i = 1; i <= n; i++) {
    cout << i << '\n';
}
```

圆括号内由两个分号分成三部分：

```text
初始化; 继续条件; 每轮结束后的更新
```

执行顺序是：

1. 只执行一次 `int i = 1`；
2. 检查 `i <= n`，不成立就结束循环；
3. 执行循环体；
4. 执行 `i++`；
5. 回到第 2 步。

它与下面的 `while` 循环表达同一个过程：

```cpp
int i = 1;
while (i <= n) {
    cout << i << '\n';
    i++;
}
```

固定次数或按连续下标遍历时，`for` 把控制循环的三部分放在一起，更容易检查是否遗漏更新。退出时间由数据决定、更新位置不固定时，`while` 往往更自然。

### 常见区间写法

遍历整数 $1,2,\ldots,n$：

```cpp
for (int i = 1; i <= n; i++) {
    // 使用 i
}
```

遍历从 $0$ 开始的 `n` 个下标 $0,1,\ldots,n-1$：

```cpp
for (int i = 0; i < n; i++) {
    // 使用 i
}
```

两种写法都正好执行 `n` 次。不要只背 `<=` 或 `<`；先说清楚第一个值和最后一个值，再选择条件。

倒序遍历 $n,n-1,\ldots,1$：

```cpp
for (int i = n; i >= 1; i--) {
    // 使用 i
}
```

这里 `i--` 让 `i` 每轮减少 $1$。

## do while 循环

`do while` 先执行循环体，再检查条件：

```cpp
do {
    statement;
} while (condition);
```

因此循环体至少执行一次。注意最后的 `while (condition)` 后面有分号。

例如，持续读入整数，直到读到 `0`：

```cpp
int x;
do {
    cin >> x;
} while (x != 0);
```

程序必须先读到第一个数，才能知道它是不是 `0`，所以“先执行、后判断”能够直接表达过程。

竞赛代码中 `for` 和 `while` 更常见；`do while` 需要会读、会在“至少执行一次”时使用，不必为了使用它而改写自然的循环。

## break

有时循环的总体条件仍然成立，但当前数据已经给出明确答案，此时可以用 `break` 立即结束当前循环。

判断整数 `n` 是否存在从 $2$ 开始的小因数：

```cpp
bool found = false;

for (int i = 2; i < n; i++) {
    if (n % i == 0) {
        found = true;
        break;
    }
}
```

一旦发现整除关系，继续检查更大的 `i` 已经没有意义。`break` 跳到这个 `for` 循环之后；若循环发生嵌套，它只结束最内层的那个循环。

`break` 也可以与 `while (true)` 组合，让退出条件写在循环体中：

```cpp
while (true) {
    int x;
    cin >> x;

    if (x == 0) {
        break;
    }
}
```

这种写法适合必须先读取或计算，才能判断是否结束的过程。需要确认每条可能执行的路径最终都有机会到达 `break`。

## continue

`continue` 跳过本轮循环体剩余的语句，直接进入下一轮。

只把输入中的正数加入总和：

```cpp
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;

    if (x <= 0) {
        continue;
    }

    sum += x;
}
```

当 `x <= 0` 时，本轮不会执行 `sum += x`。在 `for` 循环中，`continue` 之后仍会执行圆括号里的更新 `i++`，然后检查下一轮条件。

在 `while` 中，更新通常写在循环体里。如果 `continue` 跳过了更新，循环可能永远停在同一个状态：

```cpp
int i = 1;
while (i <= n) {
    if (i % 2 == 0) {
        continue;
    }

    cout << i << '\n';
    i++;
}
```

上面的示意代码运行到 `i == 2` 时不会执行 `i++`，因而会永远停在 `2`。这也是计数遍历优先使用 `for` 的原因之一。实际写代码时，可以把必要更新放到 `continue` 之前，或改写条件避免这次跳转。

`break` 结束整个循环；`continue` 只结束当前这一轮。两者都属于循环执行过程的一部分，不需要拆成独立知识点。

## 完整代码

输入正整数 `n`，再输入 `n` 个整数，输出它们的总和。因为总和可能超过 32 位整数范围，代码用 `ll` 保存累计结果。

先把总和初始化为加法单位元 $0$。每轮读入一个数并加入总和，共执行 `n` 轮：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int main() {
    int n;
    cin >> n;

    ll sum = 0;

    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum += x;
    }

    cout << sum << '\n';
    return 0;
}
```

输入：

```text
5
3 -1 7 0 2
```

输出：

```text
11
```

循环开始前 `sum` 是 $0$，五轮之后依次变为 $3,2,9,9,11$。变量 `x` 每轮保存当前读入值，`sum` 保存此前所有已读数的总和。

## 常见错误

### 忘记更新循环状态

若 `while` 条件依赖 `i`，循环体却从不改变 `i`，条件就可能永远为真。写循环时同时检查初始化、条件和更新。

### 边界多一次或少一次

遍历 $1$ 到 $n$ 使用 `i <= n`，遍历 `n` 个从 $0$ 开始的下标使用 `i < n`。用最小输入和最后一个值手动走一遍，比只看循环次数更可靠。

### 累计变量没有初始化

`sum += x` 会读取 `sum` 的旧值。第一次读取前必须给它有意义的初值，求和通常从 $0$ 开始，求积通常从 $1$ 开始。

### 在 while 中跳过必要更新

`continue` 会直接进入下一次条件检查。若状态更新写在它后面，这次更新不会发生，可能造成死循环。

### 混淆 break 与 continue

`break` 不再执行任何后续轮次；`continue` 只是跳过本轮余下部分。先用普通语言确定需要“停止全部重复”还是“忽略当前数据”。
