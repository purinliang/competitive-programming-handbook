# 数学函数

> 最近修订：2026-08-16 19:21 +10:00（未审阅）

[算术表达式](arithmetic-expressions.md) 能够完成加、减、乘、除和取余，但不能直接
表示绝对值、开方、乘方、取整、三角函数、对数和指数。C++ 在 `<cmath>` 中提供了
这些常用数学函数。本篇覆盖竞赛入门范围需要认识的函数，但不把整份标准库列表当成
需要背诵的 API。

## 函数调用

函数接收圆括号中的参数，并产生一个结果。例如：

```cpp
double root = sqrt(9.0);
double power = pow(2.0, 10.0);
```

`sqrt(9.0)` 的结果是 `3.0`，`pow(2.0, 10.0)` 的结果是 `1024.0`。结果可以直接
参与后续计算，也可以保存进变量。

竞赛代码通常使用 `#include <bits/stdc++.h>`，它已经包含这些函数。只包含真正需要
的标准头文件时，应写：

```cpp
#include <cmath>
```

## 绝对值

`abs(x)` 返回 $x$ 的绝对值。C++ 为常用整数和浮点类型都提供了对应重载：

```cpp
int integer_distance = abs(-7);
double real_distance = abs(-2.5);
```

结果分别是 `7` 和 `2.5`。绝对值常用于距离、误差和“两个量相差多少”。

有符号整数的最小值没有同类型的正数与之对应。例如 64 位整数最小值的绝对值超过
64 位整数最大值；不能认为对任意 `long long x` 调用 `abs(x)` 都一定安全。

## 平方根

`sqrt(x)` 计算 $x$ 的非负平方根：

```cpp
double x = sqrt(2.0);
```

在本篇讨论的实数范围内，`x` 必须满足 $x\geq0$。传入负数通常会得到 NaN，而不是
某个可以继续当作普通实数使用的答案。

`sqrt` 返回浮点结果。即使数学答案恰好是整数，也不要仅凭一次浮点转换判断一个
大整数是不是完全平方数：

```cpp
ll root = sqrt(n);
bool perfect_square = root * root == n;
```

这段检查还需要保证 `root * root` 不溢出。数值很大时，可以在 `sqrt` 得到候选值
以后检查相邻整数，或者使用纯整数算法。

## 乘方

`pow(a, b)` 计算 $a^b$：

```cpp
double value = pow(2.0, 10.0);
```

C++ 的 `^` 不是乘方，而是后面“位运算”单元中的按位异或：

```cpp
cout << (2 ^ 10) << '\n'; // 不会输出 1024
```

`pow` 按浮点语义工作，结果可能含有舍入误差。需要精确整数幂，而且指数是非负整数
时，基础做法是直接连乘：

```cpp
ll power = 1;
for (int i = 1; i <= exponent; ++i) {
    power *= base;
}
```

这仍然需要事先确认结果能放入 `long long`。指数很大时再学习快速幂；不能为了省下
循环就把浮点 `pow` 的结果强制转换成整数模板。

## 四种取整方向

下列函数都返回浮点类型的整数值，但取整方向不同：

| 函数 | 含义 | `2.7` 的结果 | `-2.7` 的结果 |
| --- | --- | ---: | ---: |
| `floor(x)` | 向下取整 | `2.0` | `-3.0` |
| `ceil(x)` | 向上取整 | `3.0` | `-2.0` |
| `trunc(x)` | 向 $0$ 取整 | `2.0` | `-2.0` |
| `round(x)` | 四舍五入，正好一半时远离 $0$ | `3.0` | `-3.0` |

“向下”指向数轴负方向，不是“去掉小数”。因此 `floor(-2.7)` 是 `-3.0`；直接把
`double` 转成整数使用的是向 $0$ 截断，对应 `trunc` 的方向。

需要把取整结果保存成整数时，可以明确转换：

```cpp
ll answer = (ll)round(x);
```

转换前仍要保证结果处在 `long long` 的范围内。取整函数不能让一个过大的浮点数
自动变成安全整数。

## 正整数的向上整除

有时输入本来就是整数，只需要计算“至少分成多少组”。若 $a\geq0$ 且 $b>0$，可以
写成：

```cpp
ll groups = a / b + (a % b != 0);
```

`a / b` 先计算完整组数；只要还有余数，就再增加一组。常见的
`(a + b - 1) / b` 在相同符号前提下也成立，但 `a + b - 1` 可能先溢出，因此本书
在通用模板中优先使用前一种写法。

这两个公式都不能不加说明地套用到负数。出现负数时，应先根据题意确定需要向上、
向下还是向 $0$ 取整，再推导相应公式。

## 三角函数

`sin`、`cos` 和 `tan` 分别计算正弦、余弦和正切：

```cpp
double sine = sin(angle);
double cosine = cos(angle);
double tangent = tan(angle);
```

参数 `angle` 使用弧度，不是角度。圆周率可以写成：

```cpp
const double pi = acos(-1.0);
double angle = 60.0 * pi / 180.0;
```

反三角函数 `asin(x)`、`acos(x)` 和 `atan(x)` 返回的也是弧度。`asin` 与 `acos`
的实数参数必须位于 `[-1,1]`。根据坐标求方向时，通常使用：

```cpp
double direction = atan2(y, x);
```

`atan2(y,x)` 同时查看纵坐标和横坐标，能够区分象限，也能处理 `x == 0` 的方向；
不要用 `atan(y / x)` 机械替代。浮点三角函数会有舍入误差，例如数学上应为 `0` 的
结果可能显示成一个绝对值很小的数。

## 对数函数

`log(x)` 计算自然对数 $\ln x$，`log2(x)` 和 `log10(x)` 分别以 `2` 和 `10` 为底：

```cpp
double natural = log(x);
double binary = log2(x);
double decimal = log10(x);
```

在实数范围内必须满足 $x>0$。对数结果也是浮点数，不能直接把 `log2(n)` 强制转换
成整数并假设它总能精确判断 $n$ 是否为 `2` 的幂；整数问题优先使用整数运算复核。

## 指数函数

`exp(x)` 计算 $e^x$：

```cpp
double value = exp(x);
```

它与自然对数互为反函数，但两次浮点计算仍可能留下舍入误差。`x` 很大时结果可能
超过 `double` 范围得到正无穷；`x` 很小时结果可能下溢到 `0`。

## 完整代码

下面的程序读入实数 `x`、非负实数 `y`、角度 `degree`、整数底数 `base` 和非负
整数指数 `exponent`，展示绝对值、四种取整、平方根、乘方、三角函数、对数和指数：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    double x;
    double y;
    double degree;
    int base;
    int exponent;
    cin >> x >> y >> degree >> base >> exponent;

    cout << abs(x) << '\n';
    cout << floor(x) << '\n';
    cout << ceil(x) << '\n';
    cout << trunc(x) << '\n';
    cout << round(x) << '\n';
    cout << sqrt(y) << '\n';
    cout << pow(base, exponent) << '\n';

    const double pi = acos(-1.0);
    double angle = degree * pi / 180.0;
    cout << sin(angle) << '\n';
    cout << cos(angle) << '\n';

    if (y > 0) {
        cout << log(y) << '\n';
        cout << log2(y) << '\n';
        cout << log10(y) << '\n';
    }
    cout << exp(x) << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
-2 1 0 2 10
```

输出：

```text
2
-2
-2
-2
-2
1
1024
0
1
0
0
0
0.135335
```

这个例子刻意选择容易辨认的参数；一般浮点输入的输出可能带有小数或舍入误差。

## 基础练习

1. 输入一个实数，分别输出它向下取整、向上取整和向 $0$ 取整的结果。
2. 输入非负整数 `a` 和正整数 `b`，计算把 `a` 个物品装入容量为 `b` 的盒子至少
   需要多少个盒子。
3. 输入一个非负整数 `n`，使用 `sqrt` 得到候选平方根，再判断它是不是完全平方数。
4. 不使用 `pow`，用循环计算能够放入 64 位整数的 $a^b$，其中 $b\geq0$。
5. 输入角度值，转换成弧度后输出它的正弦和余弦。
6. 输入平面向量 `(x,y)`，使用 `atan2(y,x)` 输出其方向。
7. 对若干个正数比较 `log(x)`、`log2(x)` 和 `log10(x)`。

## 需要记住什么

1. `abs` 常用于表达哪两类量？有符号整数最小值有什么边界？
2. C++ 中为什么不能用 `^` 表示乘方？
3. `sqrt` 的实数参数应满足什么范围？
4. `floor`、`ceil`、`trunc` 和 `round` 对负数的结果有什么区别？
5. 为什么浮点 `pow` 不适合作为精确整数幂模板？
6. 三角函数的参数和返回值使用角度还是弧度？
7. `atan2(y,x)` 为什么比 `atan(y/x)` 更适合从坐标求方向？
8. `log`、`log2` 和 `log10` 的底数分别是什么？参数必须满足什么条件？
9. `exp(x)` 计算什么？过大或过小的参数可能发生什么？
10. 当 $a\geq0$、$b>0$ 时，怎样在不计算 `a + b - 1` 的情况下完成向上整除？
