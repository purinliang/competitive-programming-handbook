# 数学函数

> 最近修订：2026-08-16 19:21 +10:00（未审阅）

[算术运算符](arithmetic-operators.md) 能够完成加、减、乘、除和取余，但不能直接
表示开方、乘方或不同方向的取整。C++ 在 `<cmath>` 中提供了这些常用数学函数。
本篇只学习竞赛入门阶段最常用的一小组，不把整份函数列表当成需要背诵的 API。

## 函数调用

函数接收圆括号中的参数，并产生一个结果。例如：

```cpp
double root = sqrt(9.0);
double power = pow(2.0, 10.0);
```

`sqrt(9.0)` 的结果是 `3.0`，`pow(2.0, 10.0)` 的结果是 `1024.0`。结果可以直接
参与后续计算，也可以保存进变量。

竞赛代码通常使用 `#include <bits/stdc++.h>`，它已经包含这些函数。只包含真正需要
的标准头文件时，应写：

```cpp
#include <cmath>
```

## 平方根

`sqrt(x)` 计算 $x$ 的非负平方根：

```cpp
double x = sqrt(2.0);
```

在本篇讨论的实数范围内，`x` 必须满足 $x\geq0$。传入负数通常会得到 NaN，而不是
某个可以继续当作普通实数使用的答案。

`sqrt` 返回浮点结果。即使数学答案恰好是整数，也不要仅凭一次浮点转换判断一个
大整数是不是完全平方数：

```cpp
ll root = sqrt(n);
bool perfect_square = root * root == n;
```

这段检查还需要保证 `root * root` 不溢出。数值很大时，可以在 `sqrt` 得到候选值
以后检查相邻整数，或者使用纯整数算法。

## 乘方

`pow(a, b)` 计算 $a^b$：

```cpp
double value = pow(2.0, 10.0);
```

C++ 的 `^` 不是乘方，而是后面“位运算”单元中的按位异或：

```cpp
cout << (2 ^ 10) << '\n'; // 不会输出 1024
```

`pow` 按浮点语义工作，结果可能含有舍入误差。需要精确整数幂，而且指数是非负整数
时，基础做法是直接连乘：

```cpp
ll power = 1;
for (int i = 1; i <= exponent; ++i) {
    power *= base;
}
```

这仍然需要事先确认结果能放入 `long long`。指数很大时再学习快速幂；不能为了省下
循环就把浮点 `pow` 的结果强制转换成整数模板。

## 四种取整方向

下列函数都返回浮点类型的整数值，但取整方向不同：

| 函数 | 含义 | `2.7` 的结果 | `-2.7` 的结果 |
| --- | --- | ---: | ---: |
| `floor(x)` | 向下取整 | `2.0` | `-3.0` |
| `ceil(x)` | 向上取整 | `3.0` | `-2.0` |
| `trunc(x)` | 向 $0$ 取整 | `2.0` | `-2.0` |
| `round(x)` | 四舍五入，正好一半时远离 $0$ | `3.0` | `-3.0` |

“向下”指向数轴负方向，不是“去掉小数”。因此 `floor(-2.7)` 是 `-3.0`；直接把
`double` 转成整数使用的是向 $0$ 截断，对应 `trunc` 的方向。

需要把取整结果保存成整数时，可以明确转换：

```cpp
ll answer = (ll)round(x);
```

转换前仍要保证结果处在 `long long` 的范围内。取整函数不能让一个过大的浮点数
自动变成安全整数。

## 正整数的向上整除

有时输入本来就是整数，只需要计算“至少分成多少组”。若 $a\geq0$ 且 $b>0$，可以
写成：

```cpp
ll groups = a / b + (a % b != 0);
```

`a / b` 先计算完整组数；只要还有余数，就再增加一组。常见的
`(a + b - 1) / b` 在相同符号前提下也成立，但 `a + b - 1` 可能先溢出，因此本书
在通用模板中优先使用前一种写法。

这两个公式都不能不加说明地套用到负数。出现负数时，应先根据题意确定需要向上、
向下还是向 $0$ 取整，再推导相应公式。

## 完整代码

下面的程序读入实数 `x`、非负实数 `y`、整数底数 `base` 和非负整数指数
`exponent`，依次展示四种取整、平方根和乘方：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    double x;
    double y;
    int base;
    int exponent;
    cin >> x >> y >> base >> exponent;

    cout << floor(x) << '\n';
    cout << ceil(x) << '\n';
    cout << trunc(x) << '\n';
    cout << round(x) << '\n';
    cout << sqrt(y) << '\n';
    cout << pow(base, exponent) << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
-2.7 9 2 10
```

输出：

```text
-3
-2
-2
-3
3
1024
```

这个例子中的平方根和乘方都恰好能显示成整数；一般浮点输入的输出可能带有小数或
舍入误差。

## 基础练习

1. 输入一个实数，分别输出它向下取整、向上取整和向 $0$ 取整的结果。
2. 输入非负整数 `a` 和正整数 `b`，计算把 `a` 个物品装入容量为 `b` 的盒子至少
   需要多少个盒子。
3. 输入一个非负整数 `n`，使用 `sqrt` 得到候选平方根，再判断它是不是完全平方数。
4. 不使用 `pow`，用循环计算能够放入 64 位整数的 $a^b$，其中 $b\geq0$。

## 需要记住什么

1. C++ 中为什么不能用 `^` 表示乘方？
2. `sqrt` 的实数参数应满足什么范围？
3. `floor`、`ceil`、`trunc` 和 `round` 对负数的结果有什么区别？
4. 为什么浮点 `pow` 不适合作为精确整数幂模板？
5. 当 $a\geq0$、$b>0$ 时，怎样在不计算 `a + b - 1` 的情况下完成向上整除？
