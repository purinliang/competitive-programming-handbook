# 常量

> 最近修订：2026-08-16 07:12 +10:00（未审阅）

程序中的有些数值一旦确定就不应再被修改，例如题目规定的固定奖励、取模使用的模数和数组预留的容量。如果只靠注释写“请勿修改”，后续代码仍然可能误赋值，编译器也无法帮助发现。

C++ 使用 `const` 把对象标记为只读。竞赛和日常教学中，我们通常把 `const int MOD` 直接称为**常量**。

## 常量也是变量

按照 C++ 的标准术语，`const int MOD` 仍然声明了一个**变量**，同时也是一个 **`const` 对象**：

- “变量”说明声明引入了一个对象和名称；
- “`const` 对象”准确说明这个对象不能再被修改；
- “常量”是本篇和日常交流采用的自然称呼。

C++ 中的对象也不只包括类的实例。一个普通 `int`、一个数组和一个结构体实例都可以是对象；类的实例只是对象的一种。

`42` 这样的源码值是**字面量**，不是变量。下面的声明同时出现了常量和字面量：

```cpp
const int ANSWER = 42;
```

`ANSWER` 是常量的名称，`42` 是用来初始化它的整数字面量。[字面量](literals.md) 会统一整理这一区别。

## 声明常量

在类型前写 `const`，可以声明一个初始化后不能再赋值的普通常量：

```cpp
const int MOD = 1000000007;
```

`MOD` 的类型是 `const int`。基本类型的 `const` 对象必须在声明时得到初值，因为后面不能再向它赋值：

```cpp
const int MOD;    // 错误：没有初始化
MOD = 1000000007; // 错误：不能等到下一行再赋值
MOD = 998244353;  // 错误：不能修改 const 对象
```

`const int` 也可以写成 `int const`，两者表示相同类型。本书在普通对象上统一使用更直观的 `const int`。

## 用名称表达固定含义

假设题目规定每位选手固定获得 $5$ 分奖励。直接在计算中写 `5` 虽然能运行，却没有说明这个数为什么出现：

```cpp
int final_score = score + 5;
```

给固定规则一个名称后，代码会直接表达它的含义：

```cpp
const int BONUS = 5;
int final_score = score + BONUS;
```

如果规则以后调整，只需要修改常量的初值。编译器还会阻止后面的代码意外改变 `BONUS`。

本书习惯把模板级别的固定常量写成大写名称：

```cpp
const int MAXN = 2e5 + 5;
const int MOD = 1000000007;
```

局部常量仍然优先使用能说明含义的名称，不为了大写而制造难懂缩写。

## 只读不等于编译期已知

`const` 的核心含义是“初始化以后不能再修改”，并不保证初值一定能在编译程序时得到。

下面的 `MAXN` 由固定表达式初始化，编译器能够提前算出它的值：

```cpp
const int MAXN = 2e5 + 5;
```

下面的 `size` 则来自运行时输入：

```cpp
int n;
cin >> n;

const int size = n;
```

`size` 初始化以后同样不能修改，但编译器在程序运行以前不知道它是多少。因此在标准 C++17 中，它不能用作内置数组 `int a[size];` 的容量。

遇到 `const` 时应当分开两个问题：

1. 这个对象初始化后是否允许修改？
2. 它的值是否能在编译时得到？

`const` 只直接回答第一个问题。编译期常量表达式的完整规则不是本篇的记忆目标。

## 完整代码

输入一名选手原本的分数，给它加上固定的 $5$ 分奖励，再输出最终分数：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int BONUS = 5;

void solve() {
    int score;
    cin >> score;

    int final_score = score + BONUS;
    cout << final_score << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
12
```

输出：

```text
17
```

`score` 和 `final_score` 是本次输入与计算产生的状态，`BONUS` 则表达题目固定不变的规则。

## 常见错误

### 声明后再赋初值

```cpp
const int MOD;
MOD = 1000000007;
```

基本类型的常量必须在声明时初始化。应写成：

```cpp
const int MOD = 1000000007;
```

### 把 const 等同于编译期常量

由输入初始化的 `const int size = n;` 只保证后面不能修改 `size`，不保证编译器提前知道它的值。

### 用 const 修饰所有变量

`const` 应当表达“初始化后不再改变”这一真实含义。计数器、当前答案和需要反复更新的状态仍然应该使用普通变量。

## 需要记住什么

1. 为什么日常所说的常量在 C++ 标准术语中仍然属于变量？
2. `const int x = 10;` 对后续代码增加了什么限制？
3. 为什么基本类型的 `const` 对象必须在声明时初始化？
4. 常量名称和字面量有什么区别？
5. `const` 对象为什么不一定是编译期已知的常量？
6. 哪些状态不适合使用 `const`？

指针和引用中的 `const` 会在学过两种别名机制后单独解释。编译期常量表达式的完整形式化规则、`constexpr`、类的 `const` 成员函数、`mutable` 和 `const_cast` 都不是本篇的基础学习目标。
