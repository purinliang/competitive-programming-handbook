# 算术运算符

> 最近修订：2026-08-16 07:25 +10:00（未审阅）

[A+B Problem](a-plus-b-problem.md) 已经使用 `a + b` 计算两个整数的和。这样由数值、变量和运算符组成并产生一个结果的代码，称为**表达式**。本篇只讨论用来做基本计算的算术运算符。

## 二元算术运算符

下列运算符需要左右两个操作数，因此称为**二元运算符**：

| 运算符 | 名称 | 例子 | 结果 |
| --- | --- | --- | ---: |
| `+` | 加法 | `7 + 3` | `10` |
| `-` | 减法 | `7 - 3` | `4` |
| `*` | 乘法 | `7 * 3` | `21` |
| `/` | 除法 | `7 / 3` | 由操作数类型决定 |
| `%` | 取余 | `7 % 3` | `1` |

“二元”只表示它有两个操作数，与二进制无关。

```cpp
int a = 7;
int b = 3;

cout << a + b << '\n';
cout << a - b << '\n';
cout << a * b << '\n';
```

这些表达式只计算并产生结果，不会自动修改 `a` 或 `b`。若想保存结果，需要将它用于初始化或赋值：

```cpp
int sum = a + b;
int difference = a - b;
int product = a * b;
```

## 整数除法

当 `/` 两边都是整数时，C++ 执行**整数除法**。如果数学结果带有小数部分，小数部分会被直接截去，结果向 $0$ 取整：

```cpp
cout << 7 / 3 << '\n';  // 2
cout << -7 / 3 << '\n'; // -2
```

$-7/3$ 的数学结果约为 $-2.333$，向 $0$ 截断后是 $-2$，不是向下取整得到的 $-3$。

若至少有一个操作数是浮点数，就不使用整数除法：

```cpp
cout << 7.0 / 3.0 << '\n'; // 约为 2.33333
```

整数与浮点数混合计算时如何决定结果类型，将在 [类型转换](type-conversions.md) 中单独说明。当前只需区分上面两种明确情况。

## 余数

`%` 是**取余运算符**，只能用于整数。对于非零的 `b`，只要 `a / b` 的数学结果能用当前类型表示，C++ 就保证

```text
a == (a / b) * b + a % b
```

例如，

```cpp
cout << 17 / 5 << '\n'; // 3
cout << 17 % 5 << '\n'; // 2
```

对应

$$
17=3\times5+2.
$$

取余最常见的用途是把一个数拆成“完整的若干组”和“剩余部分”。例如 $367$ 秒可以拆成：

```cpp
int seconds = 367;
int minutes = seconds / 60;
int remaining_seconds = seconds % 60;
```

结果是 $6$ 分 $7$ 秒。

### 负数的余数

由于整数除法向 $0$ 截断，非零余数的正负号与被除数 `a` 相同：

```cpp
cout << -7 / 3 << '\n'; // -2
cout << -7 % 3 << '\n'; // -1
```

因为

$$
-7=(-2)\times3+(-1).
$$

所以 C++ 的 `%` 在有负数时不一定得到数学中常用的非负剩余。如果 $m>0$，并且题目需要 $[0,m)$ 内的结果，可以先求 `a % m`，只在结果为负时再加上 `m`。这个写法需要比较与条件分支，会在后续教程中翻译成代码；当前先记住 `%` 可能返回负数。

## 除数不能为零

对整数使用 `/` 或 `%` 时，右边的除数不能为 $0$：

```cpp
int quotient = a / 0;  // 错误
int remainder = a % 0; // 错误
```

整数除以 $0$ 或对 $0$ 取余都是未定义行为。题目若不保证除数非零，必须先判断；具体写法会在 [条件分支](if-and-else.md) 中讲解。

> 除数非零也不能代替范围检查。在常见的补码类型中，最小负数除以 $-1$ 的数学结果比该类型的最大值还大 $1$，因而不能表示；这种整数除法同样是未定义行为。这个极端边界只需理解，不要求背诵。

## 一元正号与负号

`+` 和 `-` 也可以只放在一个操作数前，此时它们是**一元运算符**：

```cpp
int a = 7;
int positive = +a; // 7
int negative = -a; // -7
```

一元 `+` 不改变数值，实际代码中很少主动使用；一元 `-` 将数值取反。同一个符号具体是一元还是二元运算符，由它所在的表达式决定：

```cpp
int difference = a - b; // 二元减法
int opposite = -a;      // 一元取负
```

## 计算顺序

算术表达式的基本优先级与通常的数学书写一致：

1. 先计算括号内部；
2. 再计算一元正号和负号；
3. `*`、`/`、`%` 高于 `+`、`-`；
4. 同一优先级的二元算术运算符从左到右结合。

因此，

```cpp
int x = 2 + 3 * 4;   // 14
int y = (2 + 3) * 4; // 20
int z = 20 / 5 * 2;  // 8，从左到右计算
```

优先级决定运算符与哪些操作数结合，却不应当被用来编写难以阅读的长表达式。有疑问时主动加括号，让预期结构直接出现在代码中。

## 完整代码

下面的程序读入两个整数 `a` 和 `b`，并假设 $|a|,|b|\le10^9$ 且 `b` 不为 $0$，依次输出加、减、乘、整数除法和取余的结果。这组范围保证下面所有结果都能放入 `long long`。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

void solve() {
    ll a;
    ll b;
    cin >> a >> b;

    cout << a + b << '\n';
    cout << a - b << '\n';
    cout << a * b << '\n';
    cout << a / b << '\n';
    cout << a % b << '\n';
}

int main() {
    solve();
    return 0;
}
```

代码中的 `ll` 是 `long long` 的别名，在主流竞赛环境中用于表示 64 位整数。它仍然可能溢出，正确类型必须根据题目给出的数值范围选择。

## 基础练习

1. 输入一个非负整数 `seconds`，输出它包含的完整分钟数和剩余秒数。
2. 输入一个三位非负整数，只使用 `/` 和 `%` 分别取出百位、十位和个位。
3. 先手算，再运行程序检查 `-17 / 5`、`-17 % 5`、`17 / -5` 和 `17 % -5` 的结果是否仍满足除法与余数恒等式。
