# 标识符

> 最近修订：2026-08-16 15:54 +10:00（未审阅）

程序需要给变量、函数和类型起名字，但并不是任意字符组合都能成为名称。C++ 使用标识符表示程序中的许多名称；本篇先学会判断一个标识符能否成立，再讨论怎样让名称准确表达含义。

## 标识符的作用

变量名、函数名和类型名通常都由**标识符**表示：

```cpp
int score;
void solve();
struct Student;
```

这里的 `score`、`solve` 和 `Student` 都是标识符。`int`、`void` 和 `struct` 则是 C++ 语言预留的 [关键字](keywords.md)，不能改作自己的标识符。

## 书写规则

初学阶段创建标识符时遵守以下规则即可：

- 使用英文字母、数字和下划线 `_`；
- 第一个字符不能是数字；
- 不能使用 C++ 关键字；
- 大小写不同，例如 `score` 和 `Score` 是两个标识符。

下面的标识符合法：

```cpp
score player_1 maximum_value
```

下面的写法不合法：

```cpp
1st_player // 以数字开头
    return // C++ 关键字
    player -
    id // 减号是运算符，不是名称的一部分
```

标准还为编译器和标准库实现保留了一些名称，例如包含连续两个下划线的名称，
以及以下划线后接大写字母开头的名称。竞赛代码没有必要使用这些形式；自己命名
时从小写英文字母开始最简单。

## 名称与含义

语法合法不代表名称清楚。变量名应该描述它保存的内容，而不是它暂时参加的某一步计算：

```cpp
int total_score;
int remaining_time;
```

局部含义非常明确时，可以使用竞赛中稳定的短名称，例如 `n` 表示数量、`i`
表示顺序下标。容易混淆的状态则使用更完整的英文名称。一个名称长期只承担一种
含义，阅读和调试时才容易判断数值是否合理。

## 完整代码

下面的程序使用 `first_score`、`second_score`、`total_score` 和 `solve` 等
合法标识符。它们的名称分别说明两轮分数、总分和一道题的主要流程：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int first_score;
    int second_score;
    cin >> first_score >> second_score;

    int total_score = first_score + second_score;
    cout << total_score << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 5
```

输出：

```text
8
```

## 常见错误

### 使用关键字作为名称

关键字已经参与 C++ 语法，不能重新用作变量名或函数名。看到名称附近难以理解的编译错误时，先检查它是否恰好是 [关键字](keywords.md)。

### 让标识符以数字开头

数字可以出现在标识符中，但不能成为第一个字符。可以把 `2nd_answer` 改成
`second_answer`。

### 把减号写进名称

`player-id` 会被解释成 `player` 减去 `id`，不是一个标识符。多个单词通常使用
下划线连接，例如 `player_id`。

### 只追求名称短

短名称适合含义已经由局部语境固定的对象。若同一段程序里有多个不同分数，统一
写成 `x`、`y` 和 `z` 会隐藏区别；`first_score` 等名称更容易检查。
