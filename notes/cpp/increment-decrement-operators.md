# 自增与自减运算符

> 最近修订：2026-08-16 07:44 +10:00（未审阅）

计数器和下标经常需要在原值基础上增加或减少 $1$。下面的赋值已经能够完成更新：

```cpp
count = count + 1;
count = count - 1;
```

C++ 为这两种高频操作提供了更短的自增 `++` 和自减 `--` 运算符。

## 增加或减少一

把运算符写在变量后面，可以让变量增加或减少 $1$：

```cpp
count++;
count--;
```

单独作为一条语句时，它们分别相当于：

```cpp
count = count + 1;
count = count - 1;
```

自增和自减会直接修改变量。它们不能用在字面量或普通计算结果上：

```cpp
5 ++;      // 错误：字面量不是可以修改的变量
(a + b)++; // 错误：计算结果不是这里可以修改的变量
```

## 前缀与后缀

`++` 和 `--` 都可以写在变量前面或后面：

```cpp
i++;
++i;
i--;
--i;
```

当整行只做这一次更新时，前缀和后缀的最终效果相同：

```cpp
int a = 5;
int b = 5;

a++;
++b;
```

执行后，`a` 和 `b` 都是 `6`。

区别只会在更大的表达式使用这次运算产生的值时出现：

- 后缀 `i++` 先产生旧值，再让 `i` 增加 $1$；
- 前缀 `++i` 先让 `i` 增加 $1$，再产生新值。

```cpp
int a = 5;
int old_value = a++;

int b = 5;
int new_value = ++b;
```

执行后：

- `old_value` 是 `5`，`a` 是 `6`；
- `b` 是 `6`，`new_value` 也是 `6`。

自减的前缀与后缀遵循同一规则。

## 单独成句

基础竞赛代码通常只把自增、自减当作独立更新语句：

```cpp
i++;
remaining--;
```

这样不需要关心表达式产生的是旧值还是新值。本书的普通计数循环统一写 `i++`，它与常见题解保持一致，也能直接读成“处理完当前位置后前进一步”。

不要为了缩短代码，把多次修改和其他运算塞进同一表达式：

```cpp
int answer = i++ + ++i;
```

这类写法难以判断执行过程，而且可能触及表达式求值顺序的复杂规则。把每次更新拆成独立语句，含义最清楚。

## 类型范围

自增和自减仍然执行对应类型的算术。对 32 位 `int` 的最大值继续执行 `++`，会发生有符号整数溢出；这与写 `x = x + 1` 没有区别，正确程序不能依赖成环结果。

如果变量代表计数或下标，应先根据题目范围选择能够容纳全部合法值的整数类型。运算符只是缩短写法，不会扩大类型范围。

## 完整代码

输入一个整数，依次输出它的原值、自增一次后的值和再自减一次后的值：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int x;
    cin >> x;

    cout << x << '\n';

    x++;
    cout << x << '\n';

    x--;
    cout << x << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
7
```

输出：

```text
7
8
7
```

## 常见错误

### 忘记运算会修改变量

`i++` 不只是产生 `i + 1` 的结果，它还会把新值写回 `i`。如果只想计算而不修改原变量，应写 `int next = i + 1;`。

### 在复杂表达式中依赖前后缀差别

前缀和后缀确实会产生不同的值，但基础代码很少需要利用它。把更新单独写一行，通常比记忆一条紧凑表达式更安全。

### 忽略溢出

`++` 和 `--` 没有额外的范围保护。更新后的数学结果超出类型范围时，问题仍然存在。

4. 前缀 `++i` 会先更新还是先产生值？
