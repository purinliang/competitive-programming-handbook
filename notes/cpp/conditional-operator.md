# 条件运算符

> 最近修订：2026-08-17 10:24 +10:00（未审阅）

有时程序只需要根据一个条件，在两个值之间选择一个。例如，读入两个整数后，选择其中较大的数。

使用 [`if` 与 `else`](if-and-else.md) 可以完成这种选择，但 C++ 还提供了更短的**条件运算符**：

```cpp
condition ? value_if_true : value_if_false
```

条件运算符由 `?` 和 `:` 两个符号共同组成，需要三个操作数，因此也常被称为“三目运算符”。它不是一条特殊的分支语句，而是一个会产生值的表达式。

## 在两个值之间选择

假设 `a` 和 `b` 是两个整数：

```cpp
int maximum = a > b ? a : b;
```

程序按照下面的顺序计算：

1. 先判断条件 `a > b`；
2. 条件为 `true` 时，整个表达式的结果是 `a`；
3. 条件为 `false` 时，整个表达式的结果是 `b`；
4. 最后把选出的值赋给 `maximum`。

当 `a` 和 `b` 相等时，条件 `a > b` 为 `false`，程序选择 `b`。因为两者的值相等，最终结果仍然是正确的最大值。

条件部分不一定是一次比较，也可以是任何能够转换成 [`bool`](boolean-type.md) 的表达式：

```cpp
int absolute_value = x >= 0 ? x : -x;
```

这个表达式在 `x` 非负时选择 `x`，在 `x` 为负数时选择 `-x`，因而得到 `x` 的绝对值。

## 它与 if、else 的关系

条件运算符把“根据条件选一个值”整体放进一个表达式：

```cpp
int maximum = a > b ? a : b;
```

前面学过的 [`if` 与 `else`](if-and-else.md) 可以用两个分支完成同样的选择，而且
每个分支可以执行多条语句。二者适合不同任务：

- 只需要根据条件产生一个值时，可以使用条件运算符；
- 每种情况都需要执行一段过程时，使用条件语句更清楚。

如果每个分支需要输出、修改多个变量或执行循环，就应该使用 `if` 与 `else`，不要为了缩短代码而把复杂过程塞进条件运算符。

## 只计算被选择的一边

条件运算符不会先把冒号两边都计算出来。条件为真时只计算 `?` 后面的表达式；条件为假时只计算 `:` 后面的表达式。

例如：

```cpp
int result = divisor != 0 ? value / divisor : 0;
```

当 `divisor` 是 `0` 时，条件为假，程序只选择并计算右侧的 `0`，不会执行 `value / divisor`。

这个行为与 [逻辑运算符](logical-operators.md) 的短路求值相似。不过，代码不应该依赖条件运算符悄悄修改多个变量；涉及明显副作用时，使用 `if` 与 `else` 会更容易理解。

## 两个结果应当能够相容

冒号两边的表达式共同决定整个条件表达式的类型。最简单的情况是两边本来就是同一种类型：

```cpp
int selected = use_first ? first : second;
```

如果两边类型不同，C++ 可能进行 [类型转换](type-conversions.md)：

```cpp
double selected = use_integer ? 3 : 2.5;
```

这里一边是 `int`，另一边是 `double`，整数 `3` 会转换成浮点数，整个表达式得到 `double`。初学时优先让两边表达同一种含义并使用自然相容的类型，不要依赖复杂的隐式转换。

## 不要嵌套条件运算符

条件运算符可以嵌套，但很快会变得难以阅读：

```cpp
int maximum = a > b ? (a > c ? a : c) : (b > c ? b : c);
```

即使这段代码能够找出三个数的最大值，也需要反复判断每个 `?` 与哪个 `:` 配对。使用清楚的分支或后续学习的 `max` 更合适。

本书只在一次简单选择能够完整表达意图时使用条件运算符；出现嵌套或多条操作时改用 `if` 与 `else`。

## 完整代码

下面的程序读入两个整数并输出较大的一个。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int a;
    int b;
    cin >> a >> b;

    int maximum = a > b ? a : b;
    cout << maximum << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 5
```

输出：

```text
5
```

## 基础练习

1. 输入一个整数，使用条件运算符输出它的绝对值。
2. 输入两个整数，使用条件运算符输出较小值。
3. 输入一个整数。如果它是偶数，输出 `0`；否则输出 `1`。
