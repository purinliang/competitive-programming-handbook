# `swap`

> 最近修订：2026-08-16 23:57 +10:00（未审阅）

交换两个变量，指的是让左边得到右边原来的值，同时让右边得到左边原来的值。

例如：

```text
a = 3, b = 5
```

交换以后：

```text
a = 5, b = 3
```

标准库的 `swap` 直接表达这个操作：

```cpp
swap(a, b);
```

它会修改两个参数，与只返回选择结果的 [`min` 与 `max`](min-and-max.md) 不同。

## 为什么不能连续赋值

下面的写法不能完成交换：

```cpp
a = b;
b = a;
```

第一行执行后，`a` 原来的值已经丢失。假设最初 `a = 3`、`b = 5`：

1. `a = b` 以后，两者都是 `5`；
2. `b = a` 只是再次把 `5` 写入 `b`；
3. 原来的 `3` 再也找不到。

手工交换需要先保存一个旧值：

```cpp
int temporary = a;
a = b;
b = temporary;
```

这三行正好解释了交换需要保留什么信息。实际代码通常直接使用 `swap(a, b)`，意图更明确，也能处理许多不适合手工复制成 `int` 的类型。

## 交换数组元素

排序算法经常需要交换两个位置的元素：

```cpp
swap(a[i], a[j]);
```

调用以后，其他数组元素保持不变，只有 `a[i]` 与 `a[j]` 互换。

例如，冒泡排序发现相邻元素顺序错误时，可以写：

```cpp
if (a[i] > a[i + 1]) {
    swap(a[i], a[i + 1]);
}
```

交换的是两个元素本身，不是下标 `i` 和 `i + 1`。如果误写成 `swap(i, j)`，改变的是循环或位置变量，数组内容不会按预期互换。

## 交换其他对象

只要两个参数的类型支持交换，就可以使用相同接口：

```cpp
string first = "left";
string second = "right";
swap(first, second);
```

也可以交换两个相同类型的 `vector`：

```cpp
vector<int> first = {1, 2};
vector<int> second = {3, 4, 5};
swap(first, second);
```

交换后，`first` 保存 `{3, 4, 5}`，`second` 保存 `{1, 2}`。标准容器会交换各自维护的状态；对 `vector` 来说，这通常不需要逐个复制所有元素。

两个参数通常应当是相同类型的可修改对象。下面这种写法没有意义：

```cpp
swap(a, 5);
```

字面量 `5` 不是一个可以保存交换结果的变量。

## 不要使用算术或异或技巧

有些代码试图不使用临时变量，通过加减法交换整数：

```cpp
a = a + b;
b = a - b;
a = a - b;
```

中间的 `a + b` 可能超出整数范围，而且这套写法只适用于某些数值类型。异或交换同样更难阅读，还会在两个参数实际引用同一个对象时产生问题。

标准库 `swap` 清楚地表达意图，编译器也能够优化正常交换代码。竞赛代码没有必要用难读且容易出错的技巧代替它。

## 完整代码

下面的程序读入两个整数，交换后按相反顺序输出。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int a;
    int b;
    cin >> a >> b;

    swap(a, b);
    cout << a << ' ' << b << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 5
```

输出：

```text
5 3
```
