# A+B Problem

> 状态：草稿
> 直接前置：[0101 Hello World!](hello-world.md)

上一章的程序只会输出固定文字。这一次，我们让它计算两个整数的和，并把完成的代码第一次提交给在线评测系统。

## 问题描述

输入两个整数 `a` 和 `b`，输出它们的和。

例如，输入：

```text
3 5
```

输出：

```text
8
```

## 解题过程

先不接收输入，直接在程序中内定两个数：

```cpp
void solve() {
    int a = 3;
    int b = 5;
    cout << a + b << '\n';
}
```

- `int a = 3;` 声明一个名为 `a` 的整数，同时把它的初始值定为 `3`。
- `int b = 5;` 声明一个名为 `b` 的整数，同时把它的初始值定为 `5`。
- `cout << a + b << '\n';` 计算 `a + b`，输出结果后换行。

这份程序总是计算 `3 + 5`。如果想让同一份程序处理任意两个整数，就不能提前决定 `a` 和 `b` 的值。我们保留整数声明，再用 `cin` 从输入中取得数值：

```cpp
void solve() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << '\n';
}
```

- `int a;` 和 `int b;` 声明两个整数，但不内定它们的值。
- `cin >> a >> b;` 从输入中依次取得两个整数，先放进 `a`，再放进 `b`。
- 读入完成后，`cout` 输出它们的和，并用 `'\n'` 换行。

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << '\n';
}

int main() {
    solve();
    return 0;
}
```

## 练习题

将完整代码提交到 [洛谷 P1001 A+B Problem](https://www.luogu.com.cn/problem/P1001)。这一节默认已经完成洛谷账户的注册和登录，不讲解账户操作。

在线评测系统通常简称 **OJ**。它会准备输入数据，运行提交的程序，再比较程序输出和标准答案。因此，提交时只能输出答案，不能输出 `请输入 a 和 b`、`答案是` 或 `Hello World!` 等提示文字。

提交步骤如下：

1. 打开题目，确认输入两个整数、输出一个整数。
2. 进入提交页面，选择支持 C++17 的 C++ 语言。
3. 只粘贴完整 C++ 代码，不要把 Markdown 的三个反引号、样例输入或样例输出一起粘贴进去。
4. 提交并等待评测结果。`Accepted`，通常简称 `AC`，表示代码通过了全部测试。

如果没有通过，先看评测状态：

- `Compilation Error`（`CE`）：代码没有成功编译，先检查是否漏写符号或复制了代码块之外的内容。
- `Wrong Answer`（`WA`）：程序成功运行，但输出不正确，先检查是否输出了提示文字、是否真的计算了 `a + b`，以及每个名称的拼写是否一致。

在本地先尝试几组不同的整数，再以洛谷 P1001 获得 `AC` 作为这一篇的完成标志。整数范围、变量规则、运算符和输入输出的更多细节，会在后续教程中分别展开。
