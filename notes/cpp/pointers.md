# 指针

> 最近修订：2026-08-16 11:08 +10:00（未审阅）

每个存在于内存中的对象都有自己的地址。普通整数变量保存整数，而**指针**保存另一个对象的地址。程序因此可以先得到一个位置，再通过该位置间接读写原对象。

本篇只解释指针自身。将指针作为函数参数、将引用作为对象别名，分别属于后续的
[参数传递](parameter-passing.md) 与 [引用](references.md)。

## 取得地址

已经声明一个整数 `x` 后，表达式 `&x` 得到 `x` 的地址：

```cpp
int x = 10;
&x;
```

这里的 `&` 是**取地址运算符**。`x` 的类型是 `int`，`&x` 的类型是“指向 `int` 的指针”，写作 `int*`。

地址在真实运行时通常显示成类似 `0x7ffd...` 的值，但具体数字由每次运行的内存布局决定。解题时关心“这是哪个对象的地址”，不会背诵或猜测具体数值。

## 声明指针

下面的语句声明指针 `p`，并让它保存 `x` 的地址：

```cpp
int x = 10;
int* p = &x;
```

- `int*` 是 `p` 的类型，表示它可以指向 `int` 对象；
- `p` 是指针变量的名字；
- `&x` 是 `x` 的地址，用来初始化 `p`。

可以把当前关系理解为：

```text
p  ──指向──>  x
              10
```

`p` 自己也是变量，它在内存中有自己的位置；只是它保存的内容恰好是 `x` 的地址。

一条声明中的 `*` 只修饰紧跟它的名字：

```cpp
int* p;
int q;
```

不要将它缩成 `int* p, q;` 后误以为两者都是指针；其中只有 `p` 是指针，`q` 仍然是 `int`。本书在需要多个指针时每行声明一个，让类型一目了然。

## 解引用

只拥有地址 `p` 时，表达式 `*p` 访问 `p` 所指向的对象。这个操作称为**解引用**：

```cpp
int x = 10;
int* p = &x;

printf("%d\n", *p); // 10
```

这里表达式中的 `*` 是解引用运算符，不是乘法，也不是声明指针时类型中的星号。同一个符号在不同位置的意义由语法上下文区分。

`*p` 表示的就是原对象 `x`，因此它不只能读取，也能被赋值：

```cpp
*p = 25;
printf("%d\n", x); // 25
```

修改 `*p` 就是修改 `x`，并不会创建一个整数副本。

## 改变指向

一个普通指针变量可以先指向一个对象，后来再保存另一个同类型对象的地址：

```cpp
int a = 10;
int b = 20;
int* p = &a;

*p = 11; // 修改 a
p = &b;
*p = 21; // 修改 b
```

`p = &b;` 改变的是指针中保存的地址，不是把 `a` 和 `b` 互相赋值。执行完后，`a` 是 `11`，`b` 是 `21`，`p` 最终指向 `b`。

## 空指针

当一个指针暂时不指向任何对象时，使用 `nullptr`：

```cpp
int* p = nullptr;
```

`nullptr` 是 C++ 的空指针值。可以检查指针是否为空：

```cpp
if (p == nullptr) {
    printf("no object\n");
}
```

空指针不指向对象，因此不能解引用：

```cpp
*p = 10; // 未定义行为
```

同样不要声明一个未初始化的局部指针后立即解引用：

```cpp
int* p;
*p = 10; // p 保存不确定内容
```

解引用之前，必须能确定指针正在指向一个仍然存在的合法对象。`nullptr` 可以明确表示“目前没有对象”，比留下未初始化的地址安全。

## 数组与指针运算

在大多数表达式中，一维数组名会转换为指向首元素的指针。因此，学过
[一维数组](one-dimensional-arrays.md) 后，可以写：

```cpp
int a[5] = {10, 20, 30, 40, 50};
int* p = a;
```

此时 `p` 指向 `a[0]`，所以 `*p` 是 `10`。对指针加上整数 `k`，表示向后移动 `k` 个元素，不是移动 `k` 个字节：

```cpp
printf("%d\n", *(p + 2)); // 30
```

下标运算本身就可以用指针加法和解引用表示：

```text
a[i] 等价于 *(a + i)
```

因此，`p++` 使指针改为指向下一个元素，而 `(*p)++` 使当前指向的元素自增：

```cpp
p++;    // 现在指向 a[1]
(*p)++; // a[1] 从 20 变成 21
```

指针加减只能在同一数组的元素范围内，以及数组末尾后紧邻的一个位置之间进行。可以计算指向“末尾后一位”的指针作为循环边界，但那个位置不是数组元素，不能解引用。

## scanf 中的地址

[`scanf` 与 `printf`](scanf-and-printf.md) 中的代码已经多次使用：

```cpp
int x;
scanf("%d", &x);
```

现在可以完整解释 `&x`：`scanf` 必须修改调用处的 `x`，所以调用时不是只向它提供 `x` 当前保存的整数，而是提供 `x` 的地址。`scanf` 根据 `%d` 知道这是一个 `int` 的地址，然后将读到的整数写入该地址指向的对象。

将地址传给函数的完整参数规则属于后续的函数参数传递。本篇只需要识别 `&x` 的类型是 `int*`，并理解函数拥有这个地址后就能找到原对象。

## 完整代码

下面的程序读入一个整数，使用指针读取它，再通过同一个指针修改原变量：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int x;
    scanf("%d", &x);

    int* p = &x;
    printf("%d\n", *p);

    *p = *p + 1;
    printf("%d\n", x);
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
41
```

输出：

```text
41
42
```

第一行通过 `*p` 读取 `x`，第二行通过 `x` 观察 `*p = *p + 1` 对原对象的修改。两个名称或表达式最终访问的是同一个整数对象。

## 常见错误

### 解引用空指针或未初始化指针

解引用以前必须明确知道指针指向一个仍然存在的合法对象。`nullptr` 表示没有
目标，只能比较，不能解引用。

### 混淆 p++ 与 (*p)++

`p++` 改变指针，使它指向下一个数组元素；`(*p)++` 修改当前指向的整数。括号
直接写明自增操作的对象。

### 让指针越过同一数组

指针运算只在同一数组及其末尾后一位的边界内有规定。末尾后一位可以比较，不能
解引用；继续走得更远也不是合法的数组遍历。

### 继续使用已经失效的地址

指针保存地址不代表目标会永远存在。目标对象生命周期结束后，原指针成为悬空
指针，不能继续解引用。

## 需要记住什么

1. `x`、`&x`、`p` 和 `*p` 分别表示什么？
2. `int* p = &x;` 中的 `int*`、`p` 和 `&x` 分别负责什么？
3. 为什么修改 `*p` 会改变 `p` 指向的原对象？
4. `nullptr` 表示什么？为什么不能解引用空指针或未初始化指针？
5. 对数组元素指针加 `1` 时，移动的是一个字节还是一个元素？
6. `p++` 与 `(*p)++` 分别改变什么？
7. `scanf("%d", &x)` 为什么需要 `x` 的地址？
8. 为什么保存过地址的指针也可能在目标对象销毁后失效？

指针自身的字节数、多级指针、`void*`、动态内存和指针底层的机器表示都不是本篇的基础学习目标，不要求理解或记忆。
