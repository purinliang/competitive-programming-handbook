# 字面量

> 最近修订：2026-08-16 07:18 +10:00（未审阅）

在源码中直接写出的固定值称为**字面量**（literal）。例如，下面的声明中 `score` 是标识符，`60` 是整数字面量：

```cpp
int score = 60;
```

字面量不是变量。它没有供后续代码反复赋值的名称，而是直接把一个值写进表达式。

## 常见字面量

不同写法会产生不同类型的值：

```cpp
42       // 整数字面量
3.14     // 浮点字面量
'A'      // 字符字面量
true     // 布尔字面量
"hello"  // 字符串字面量
```

单引号和双引号不能交换：`'A'` 表示一个字符，`"A"` 表示包含一个可见字符的字符串字面量。字符串的具体类型和末尾的空字符会在 C 字符串文章中解释。

整数和浮点字面量还有后缀、进制和科学计数法等写法。它们已经分别在 [整数类型](integer-types.md) 和 [浮点类型](floating-point-types.md) 中按用途说明；本篇只统一“字面量”这个名称。

## 字面量与表达式

一个字面量直接写出一个值；多个字面量还可以组成更大的表达式：

```cpp
42          // 一个字面量
2e5 + 5     // 一个表达式，其中有两个字面量
```

严格按照 C++ 语法，`-7` 也不是一个带负号的整数字面量，而是一元负号 `-` 作用于整数字面量 `7` 得到的表达式。日常交流中偶尔会笼统地说“负数字面量”，但分析类型、范围或运算顺序时应知道它的真实结构。

## 字面量与常量

下面两行都包含不会在运行期间自行改变的值，但只有第二行声明了名称：

```cpp
cout << 1000000007 << '\n';
const int MOD = 1000000007;
```

第一行的 `1000000007` 是整数字面量。第二行用同一个字面量初始化了名为 `MOD` 的常量；按照 C++ 标准术语，`MOD` 仍然是变量，同时也是 `const` 对象。日常语言有时会把两者都笼统称作常量，因此精确讨论代码时应区分“字面量”和“由 `const` 声明的常量”。

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int answer = 42;
    double pi = 3.14;
    char grade = 'A';
    bool accepted = true;

    cout << answer << '\n';
    cout << pi << '\n';
    cout << grade << '\n';
    cout << accepted << '\n';
}

int main() {
    solve();
    return 0;
}
```
