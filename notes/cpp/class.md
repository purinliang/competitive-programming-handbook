# 类与对象

> 最近修订：2026-08-16 12:57 +10:00（未审阅）

[结构体](struct.md) 已经能把若干相关数据组合成一种类型。随着类型拥有更多操作，
我们还可能希望把数据与操作放在一起，并限制外部代码能够直接接触哪些细节。
类（`class`）提供了这种类类型的另一种声明形式。

本篇只建立类、对象以及 `class` 与 `struct` 的关系。成员函数、访问控制、构造与
析构、继承和多态会在后续扩展文章中分别讨论。

## 声明 class

使用 `class` 声明一种类类型：

```cpp
class Contestant {
  public:
    int id;
    int score;
};
```

类定义末尾的分号不能省略。`Contestant` 是类型名称，花括号内部列出它的成员。
这里的 `public:` 暂时理解为“后面的成员允许从类外直接访问”；访问权限会另文
展开。

有了类型以后，可以声明这种类型的对象：

```cpp
Contestant alice;
Contestant bob;
```

`alice` 和 `bob` 是两个独立对象，各自拥有自己的 `id` 与 `score`：

```cpp
alice.id = 1;
alice.score = 95;

bob.id = 2;
bob.score = 88;
```

点运算符左侧是对象，右侧是成员名称，与访问结构体成员时完全相同。

## 类与对象

类是一种类型，描述这类值包含哪些成员、支持哪些操作以及外部能够访问哪些部分；
对象则是程序中实际存在的一个这种类型的实例。

可以把它与基本类型对照：

```cpp
int x;
Contestant alice;
```

`int` 与 `Contestant` 都是类型，`x` 与 `alice` 都是对象。日常面向对象讨论常把
“对象”专门用于类的实例，但 C++ 标准中的 object 范围更广，普通整数和数组
同样是对象。函数和引用则不是对象。

因此，“类经过实例化得到对象”是有用的入门说法，但不能据此断言只有类类型的值
才叫对象。

## class 与 struct

C++ 中的 `class` 与 `struct` 都能声明**类类型**。二者都可以拥有：

- 数据成员与成员函数；
- 构造函数与析构函数；
- 访问权限；
- 继承与虚函数；
- 运算符重载。

所以，“`struct` 只能保存数据，`class` 才能拥有函数”是错误的。

二者关键的语言默认值不同：

| 声明形式 | 成员的默认访问权限 | 继承时的默认方式 |
| --- | --- | --- |
| `struct` | `public` | `public` |
| `class` | `private` | `private` |

下面的两个字段因此不能直接从类外访问：

```cpp
class Contestant {
    int id;
    int score;
};
```

写出 `public:` 后才得到本篇开头的行为。继承方式等真正学习继承时再解释；现在只
需要知道这也是两种声明形式的默认差别。

## 选择 struct 还是 class

语言没有强迫一种唯一风格。竞赛代码中常用以下约定表达意图：

- 只是把几个公开字段组织在一起时，使用 `struct`；
- 希望通过成员函数维护内部状态，并隐藏部分实现细节时，使用 `class`。

这只是代码风格，不是功能边界。树状数组、线段树等竞赛数据结构即使带有成员
函数，也可以为了默认公开和书写简洁使用 `struct`。判断代码是否合法时要依据
C++ 规则，不能依据名字带来的印象。

## 对象彼此独立

每个普通对象都拥有自己的非静态数据成员：

```cpp
Contestant alice;
Contestant bob;

alice.score = 95;
bob.score = 88;
```

修改 `alice.score` 不会修改 `bob.score`。类描述共同结构，对象保存各自状态。

对象赋值通常会按成员复制状态：

```cpp
bob = alice;
```

执行后两个对象的字段值相同，但它们仍然是两个对象；之后再修改其中一个的普通
成员，不会自动同步另一个。拥有指针、资源管理或自定义复制操作的类会更复杂，
不属于本篇的基础目标。

## 完整代码

下面使用 `class` 声明参赛者类型，建立两个对象并分别保存输入的数据：

```cpp
#include <bits/stdc++.h>
using namespace std;

class Contestant {
  public:
    int id;
    int score;
};

void solve() {
    Contestant alice;
    Contestant bob;

    cin >> alice.id >> alice.score;
    cin >> bob.id >> bob.score;

    cout << alice.id << ' ' << alice.score << '\n';
    cout << bob.id << ' ' << bob.score << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
1 95
2 88
```

输出：

```text
1 95
2 88
```

把 `class` 改为 `struct` 并删除 `public:`，这份程序仍然成立，因为结构体成员
默认公开。

## 常见错误

### 忘记类定义末尾的分号

类定义与结构体定义一样，闭花括号以后仍需写 `;`。

### 认为 class 中什么都不能直接访问

`class` 的成员默认是 `private`，但 `public:` 后的成员可以从类外访问。它不是
“所有成员永远私有”的语法。

### 把 struct 当成没有函数的低级 class

两者都声明类类型并支持同一套主要语言功能；默认访问权限和默认继承方式才是
关键差异。

### 认为同类对象共享普通字段

每个对象拥有自己的非静态数据成员。属于整个类的共享成员需要使用 `static`，
后续“类的成员”会单独说明。
