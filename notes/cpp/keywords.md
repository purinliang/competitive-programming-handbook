# 关键字

> 最近修订：2026-08-16 15:54 +10:00（未审阅）

[标识符](keywords-and-identifiers.md) 让我们可以为变量、函数和类型创建名称，但有些单词已经承担 C++ 语法规定的作用，不能再拿来命名其他对象。这些由语言预留的单词称为**关键字**。

## 语言预留的单词

我们已经在不同主题中见过一些关键字：

| 关键字 | 已经见过的作用 |
| --- | --- |
| `int`、`double`、`char`、`bool` | 写出基本类型 |
| `const` | 限制对象不能通过这个名称修改 |
| `if`、`else`、`switch` | 选择要执行的分支 |
| `while`、`for` | 重复执行语句 |
| `return` | 结束函数并返回结果 |
| `struct` | 声明结构体类型 |

同一个关键字可能参与不止一种语法，具体作用在对应文章中学习。本篇只关注它们共有的性质：这些拼写已经由语言保留。

## 不能作为标识符

下面的声明试图把 `return` 用作变量名：

```cpp
int return = 0;
```

编译器会把 `return` 当作关键字，而不是普通标识符，因此无法按照变量声明解析这行代码。变量、函数和自定义类型都不能使用关键字作为名称。

遇到名称附近难以理解的语法错误时，可以检查这个单词是否恰好是关键字；不要靠改变大小写绕开问题。虽然 `Return` 不是关键字，但它容易与 `return` 混淆，通常也不是清楚的名称。

## 常见名称不一定是关键字

代码中经常出现的单词不一定属于 C++ 语法：

- `main` 是程序入口函数的名称；
- `cout` 是标准库提供的对象名称；
- `vector` 是标准库提供的类型模板名称；
- `solve` 是本书经常自行定义的函数名。

它们都是标识符，不是关键字。关键区别不在于出现频率，而在于这个单词是否由 C++ 语言本身保留并赋予语法作用。

## 不需要背诵完整列表

C++ 的关键字数量很多，主线不要求一次背完。遇到新关键字时，在它所解决的问题中学习具体行为；编辑器的语法高亮和编译器错误也能帮助辨认。

真正需要记住的是分类方法：语言预留的关键字不能自行改作名称，标准库名称和普通函数名则不是关键字。初赛若直接考查某个单词是否为关键字，再回到完整关键字表集中复习即可。

## 需要记住什么

1. 什么是关键字？
2. 为什么关键字不能作为变量名、函数名或类型名？
3. `main`、`cout` 和 `vector` 是不是关键字？
4. 为什么学习程序设计时不需要一开始背诵完整关键字表？
