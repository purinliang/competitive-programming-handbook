# 表达式：位运算符

> 最近修订：2026-08-13 02:08 +10:00（未审阅）

一个整数由许多二进制位组成。有时每一位不再共同表示一个普通数值，而是分别记录一种真假状态：第 $0$ 位表示开关 $0$ 是否开启，第 $1$ 位表示开关 $1$ 是否开启，依此类推。这样，一个整数就能同时保存许多独立状态。

C++ 的**位运算符**直接处理整数的每一位。它们也用于子集枚举、状态压缩和许多底层算法。本篇只讨论整数运算；标准库类型 `bitset` 是另一种工具，不与位运算符混在一起。

## 二进制位的编号

二进制位从右向左以 $0$ 为起点编号。以八位形式展示十进制的 $45$：

$$
45=(00101101)_2.
$$

| 位编号 | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 位值 | 0 | 0 | 1 | 0 | 1 | 1 | 0 | 1 |
| 权值 | $2^7$ | $2^6$ | $2^5$ | $2^4$ | $2^3$ | $2^2$ | $2^1$ | $2^0$ |

为 `1` 的第 $0$、$2$、$3$、$5$ 位贡献 $1+4+8+32=45$。

源码中可以用 `0b` 直接书写二进制整数字面量：

```cpp
int x = 0b00101101;
```

前导的 `0` 只帮助人对齐，不会固定变量只有八位。[基本类型：整数](integer-types.md) 已经介绍了二、八、十六进制字面量；无论源码采用哪种进制，整数进入运算后都是同一个值。

## 按位与

按位与使用一个 `&`。它把两个整数同一位置上的位分别相与，只有两个位都是 `1`，结果位才是 `1`：

```text
  00101101
& 00110110
  --------
  00100100
```

因此 `0b00101101 & 0b00110110` 等于 `0b00100100`，也就是十进制的 $36$。

按位与最常用于**保留指定位置、清除其他位置**。掩码中为 `1` 的位置允许原数通过，为 `0` 的位置会被清成 `0`。

它与逻辑与 `&&` 不同：`&` 逐位处理整数，而且不会短路；`&&` 把两边当作完整的真假条件。

## 按位或

按位或使用一个 `|`。同一位置只要至少一个位是 `1`，结果位就是 `1`：

```text
  00101101
| 00110110
  --------
  00111111
```

按位或适合把某些位置设为 `1`。掩码为 `1` 的位置会被打开，其他位置保持原样。

它与逻辑或 `||` 也不同：`|` 处理每一位且不会短路，`||` 组合两个真假条件。

## 按位异或

按位异或使用 `^`。同一位置的两个位不同时结果为 `1`，相同时结果为 `0`：

```text
  00101101
^ 00110110
  --------
  00011011
```

异或可以理解为“这一位是否不同”。它有几条常用性质：`x ^ 0` 等于 `x`，`x ^ x` 等于 `0`，并且异或满足交换律与结合律。这里的 `^` 是 C++ 运算符，不表示乘方；C++ 没有用单个运算符表示幂。

用一个只有第 $k$ 位为 `1` 的掩码与整数异或，可以翻转第 $k$ 位：原来为 `0` 就变成 `1`，原来为 `1` 就变成 `0`。

## 按位取反

按位取反使用 `~`，它把每一位的 `0` 与 `1` 互换：

```text
~ 00101101
  --------
  11010010
```

实际整数类型通常不只有图中展示的八位。`~x` 会翻转该类型参与运算的**全部位**，包括没有画出来的高位。因此，直接输出 `~x` 往往不会得到只对八位取反后的正数。

若只关心低四位，可以再用低四位全为 `1` 的掩码保留它们：

```cpp
unsigned int low_four_bits = (~x) & 0b1111u;
```

`u` 后缀表示这个整数字面量是 `unsigned int`。位模式本身正是无符号整数擅长表达的语义。

## 左移与右移

左移使用 `<<`，右移使用 `>>`：

```cpp
unsigned int left = x << k;
unsigned int right = x >> k;
```

对没有溢出的非负数，左移 $k$ 位相当于乘以 $2^k$，右移 $k$ 位相当于向下取整地除以 $2^k$。更重要的用途是把一个 `1` 移到指定位置：

```cpp
unsigned int bit = 1u << k;
```

`bit` 只有第 $k$ 位是 `1`，因而可以选中这一位。

移位有明确边界：移动位数必须大于等于 $0$，并且严格小于左操作数类型的位数。在主流竞赛环境中，`unsigned int` 有 $32$ 位，所以 `1u << k` 要求 $0\le k<32$。

> 有符号整数左移到不能表示的范围可能产生未定义行为；负数右移在 C++17 中还涉及实现规定的结果。本篇统一用无符号整数解释位模式，避免把这些平台边界混入基本操作。

需要在常见 64 位整数中生成第 $k$ 位掩码时，可以写：

```cpp
unsigned long long bit = 1ULL << k;
```

这里 `ULL` 让左边的 `1` 在移位前就成为 `unsigned long long`。只把结果保存在 64 位变量里是不够的：`1 << k` 的左操作数仍然是 `int`，移位已经先按 `int` 执行。

## 位掩码的四个基本操作

现在用整数 `mask` 记录许多开关。先生成只选中第 $k$ 位的掩码：

```cpp
unsigned int bit = 1u << k;
```

### 查询第 k 位

用按位与只保留第 $k$ 位，再判断结果是否非零：

```cpp
bool enabled = (mask & bit) != 0;
```

括号很重要。直接写 `mask & bit != 0` 会受到运算符优先级影响，不能清楚表达预期分组。本书统一为位运算主动添加括号。

### 把第 k 位设为 1

按位或会打开掩码中为 `1` 的位置：

```cpp
mask = mask | bit;
```

也可以使用复合赋值：

```cpp
mask |= bit;
```

### 把第 k 位清为 0

`~bit` 只有第 $k$ 位是 `0`，其他位都是 `1`。与它按位与，就只清除第 $k$ 位：

```cpp
mask &= ~bit;
```

### 翻转第 k 位

与 `bit` 异或会翻转第 $k$ 位，其他位保持不变：

```cpp
mask ^= bit;
```

这四种操作的核心都不是需要背诵的魔法。先构造“只有目标位为 `1`”的 `bit`，再根据希望保留、打开、清除还是翻转选择 `&`、`|` 或 `^`。

## 完整代码

输入一个非负整数 `mask` 和位编号 `k`，保证 $0\le k<32$。依次输出：原数第 $k$ 位是否为 `1`、将该位置为 `1` 后的数、将该位清为 `0` 后的数、翻转该位后的数。

四个结果都从原始 `mask` 出发，互不影响：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    unsigned int mask;
    int k;
    cin >> mask >> k;

    unsigned int bit = 1u << k;

    bool enabled = (mask & bit) != 0;
    unsigned int set_mask = mask | bit;
    unsigned int cleared_mask = mask & ~bit;
    unsigned int toggled_mask = mask ^ bit;

    cout << enabled << '\n';
    cout << set_mask << '\n';
    cout << cleared_mask << '\n';
    cout << toggled_mask << '\n';
    return 0;
}
```

输入：

```text
10 2
```

$10=(1010)_2$，第 $2$ 位原来是 `0`。输出：

```text
0
14
10
14
```

把第 $2$ 位设为 `1` 或翻转后，结果都是 $(1110)_2=14$；清除一个原本就是 `0` 的位不会改变 `mask`。

## 常见错误

### 混淆位运算与逻辑运算

`&`、`|`、`^` 逐位处理整数；`&&`、`||`、`!` 组合真假条件。它们表达的不是同一件事，是否短路也不同。

### 用 ^ 表示乘方

`2 ^ 3` 的结果是按位异或后的 `1`，不是 $2^3=8$。小整数幂可以直接相乘，通用整数幂会在快速幂算法中推导。

### 先用 int 移位，再保存进更大的类型

`long long bit = 1 << k` 仍然先按 `int` 计算左移。需要 64 位掩码时，应从 `1LL` 或 `1ULL` 开始；处理位模式时优先使用 `1ULL`。

### 移动超过类型宽度

移动位数为负数，或大于等于左操作数的位数，都会产生未定义行为。位编号必须先满足范围约束。

### 忘记 ~ 会翻转所有位

图中只画低若干位不代表变量只有这些位。需要限制结果宽度时，使用额外掩码保留目标区间。

## 需要记住什么

1. 二进制位从哪一侧开始以 $0$ 编号？第 $k$ 位的权值是多少？
2. `&`、`|`、`^`、`~` 分别怎样计算每一位？
3. `&&` 与 `&`、`||` 与 `|` 有什么本质区别？
4. 怎样构造只有第 $k$ 位为 `1` 的掩码？
5. 怎样查询、置位、清位和翻转第 $k$ 位？
6. 为什么 64 位掩码应从 `1ULL` 开始移位，而不是先计算 `1 << k`？
7. 移位位数必须满足什么范围？
8. 为什么 `~x` 不能只翻转示意图中画出的几位？

位运算符的基础是准确理解单个位如何变化。状态压缩、子集枚举、lowbit 和 `bitset` 都会在各自需要这些操作的文章中继续推导，不在本篇一次塞入。
