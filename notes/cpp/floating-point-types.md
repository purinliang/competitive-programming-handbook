# 浮点类型

> 最近修订：2026-08-16 21:28 +10:00（未审阅）

[整数类型](integer-types.md) 只能保存整数。程序需要表示平均值、距离或几何坐标等
带小数部分的数时，通常使用浮点类型。

## 浮点数

日常所说的“小数”描述了数的写法，例如 `123.45`。**浮点数**描述的则是一种保存数的方法。

先看十进制科学计数法：

$$
123.45 = 1.2345 \times 10^2,
$$

$$
0.0012345 = 1.2345 \times 10^{-3}.
$$

两边都保存 `1.2345`，再用指数决定小数点应该移动到哪里。小数点的位置可以随指数“浮动”，所以这种表示方法称为浮点表示。

计算机中的浮点数也把有效数字与数量级分开保存，因此能同时表示很小和很大的数。
但存储空间有限，绝大多数实数只能舍入到附近某个可以表示的值。具体二进制编码
属于配套扩展；当前先从代码中能够观察到的精度和舍入行为理解浮点数。

## float 与 double

C++ 提供 `float`、`double` 和 `long double` 三种浮点类型，其中竞赛中最常用的是 `double`。

主流竞赛环境中，两种类型的十进制精度大致如下：

| 类型 | 大约相当于十进制 | 保证可靠的十进制位数 | 竞赛中的选择 |
| --- | ---: | ---: | --- |
| `float` | 约 7 位 | 6 位 | 通常不用 |
| `double` | 约 16 位 | 15 位 | 默认选择 |

“约 7 位”和“约 16 位”只描述精度规模，不能保证任意这么长的十进制数都原样
保留。对做题更稳妥的结论是：`float` 可靠保留 6 位十进制有效数字，`double`
可靠保留 15 位。这里说的是从第一个非零数字开始计算的有效数字总数，不是小数点
后的位数。例如 `12345.67` 有 7 位有效数字。

> 上述精度是主流竞赛环境采用 IEEE 754 时的结果。C++17 本身只保证 `double`
> 的精度不低于 `float`，没有强制具体位宽和编码格式。

`long double` 的大小和精度存在明显的平台差异。竞赛中没有特殊精度需求时直接使用 `double`；`long double` 的具体格式不要求理解或记忆。

有限精度会留下可观察的舍入误差：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    double x = 0.1 + 0.2;
    cout << fixed << setprecision(17) << x << '\n';
}

int main() {
    solve();
    return 0;
}
```

输出为：

```text
0.30000000000000004
```

这不是计算机“算错了”，而是 `0.1` 和 `0.2` 都不能用有限位二进制浮点数精确表示。它们先被保存成附近的值，相加后再发生一次舍入。

## 科学计数法

C++ 的浮点字面量可以直接使用十进制科学计数法。字母 `e` 后面的整数表示 10 的指数：

```cpp
double large = 1.25e6; // 1.25 × 10^6，也就是 1250000
double small = 3.5e-4; // 3.5 × 10^-4，也就是 0.00035
float single = 1.0e3f; // 末尾的 f 表示 float
```

没有后缀的浮点字面量默认为 `double`；末尾增加 `f` 或 `F` 后才是 `float`。

`cout` 的默认格式会根据数值大小选择普通小数或科学计数法。使用 `scientific` 可以强制采用科学计数法，使用 `fixed` 可以强制小数点保持在固定位置，使用 `defaultfloat` 可以恢复默认选择。

## 输出精度

`setprecision(n)` 与当前输出格式共同决定显示多少位：

- 在 `defaultfloat` 中，`n` 表示有效数字总数。
- 在 `fixed` 中，`n` 表示小数点后的位数。
- 在 `scientific` 中，`n` 表示有效数字第一位之后的位数，也就是小数点后的位数。

下面的程序展示三种格式：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    double x = 12345.6789;

    cout << defaultfloat << x << '\n';
    cout << scientific << x << '\n';
    cout << fixed << setprecision(2) << x << '\n';
    cout << scientific << setprecision(3) << x << '\n';
}

int main() {
    solve();
    return 0;
}
```

输出为：

```text
12345.7
1.234568e+04
12345.68
1.235e+04
```

`fixed`、`scientific` 和 `setprecision` 的设置会继续影响后面的输出，直到再次修改。竞赛题要求输出固定小数位数时，最常见的写法是：

```cpp
cout << fixed << setprecision(2) << answer << '\n';
```

这里的 `2` 表示保留两位小数；输出时会按照当前舍入规则得到最接近的显示结果。

## 配套篇

[IEEE 754 浮点数表示](ieee-754.md) 解释符号位、阶码、尾数、隐藏位、非正规数、正负零、无穷、$\mathrm{NaN}$ 以及三种精度口径。这些内容不要求任何读者理解或记忆。

## 需要记住什么

1. “浮点”这个名称中的小数点为什么会浮动？
2. `float` 和 `double` 分别大约相当于多少位十进制有效数字，又分别保证可靠保存多少位？
3. 没有特殊理由时，竞赛中应该优先选择 `float` 还是 `double`？
4. 为什么 `0.1 + 0.2` 不一定得到内部精确等于 `0.3` 的结果？
5. C++ 中怎样写 $1.25 \times 10^6$？怎样声明一个 `float` 字面量？
6. 怎样固定输出两位小数？`fixed` 下的 `setprecision(2)` 表示什么？

`long double` 的平台差异、完整往返输出位数和 IEEE 754 编码不要求在本篇理解或记忆。
