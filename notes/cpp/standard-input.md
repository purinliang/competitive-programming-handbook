# 输入输出：标准输入

> 状态：定稿

同一份程序需要处理评测系统准备的不同数据，不能把所有数值预先写在代码中。C++ 将程序通常接收数据的来源称为**标准输入**。

在本地直接运行程序时，标准输入通常来自键盘；提交到在线评测系统（OJ）后，它来自评测系统预先准备的文本。程序只按约定读取标准输入，不必知道数据的真正来源。

## cin 读入

[A+B Problem](a-plus-b-problem.md) 已经使用过 `cin`：

```cpp
int a;
int b;
cin >> a >> b;
```

`cin` 是 C++ 标准库提供的标准输入流。运算符 `>>` 从左向右处理读入：

1. `cin >> a` 读取一个符合 `int` 规则的整数，将其保存到 `a`。
2. 第一次读入完成后，`>> b` 继续读取下一个整数，将其保存到 `b`。

被读入变量的类型决定了程序如何解释接下来的文本：

```cpp
int count;
long long total;
double ratio;

cin >> count >> total >> ratio;
```

这里依次需要一个 `int`、一个 `long long` 和一个 `double`。题目会保证正常测试数据符合输入格式。

## 空白字符

对整数和浮点数等常见数值，`cin >> variable` 会先跳过空格、换行和制表符等**空白字符**，再读取下一个值。因此，以下三份输入对 `cin >> a >> b;` 没有区别：

```text
3 5
```

```text
3
5
```

```text
    3       5
```

题面中的换行常常只是为了展示数据结构。当使用普通的 `>>` 读取数值时，通常不需要为“这个数在同一行还是下一行”分别写代码。

## scanf 读入

本书后续的竞赛代码默认使用 `scanf` 和 `printf`。`scanf` 同样从标准输入读取数据，但要用**格式控制符**明确写出数据类型：

```cpp
int a;
int b;
scanf("%d%d", &a, &b);
```

- `"%d%d"` 是格式字符串，两个 `%d` 表示依次读取两个 `int`。
- `&a` 和 `&b` 把两个变量所在的位置交给 `scanf`，使它能将读到的值写回变量。
- 格式控制符与后面的变量按位置一一对应。

`&` 在这里的完整含义属于指针与地址。当前只需要记住：使用 `scanf` 读入这些普通变量时，变量名前要写 `&`。

`%d`、`%lld` 和 `%lf` 等数值格式也会自动跳过前面的空白字符，所以 `scanf("%d%d", &a, &b);` 同样不在乎两个数之间使用空格还是换行。

## 常用格式控制符

`scanf` 中的格式控制符必须与变量的真实类型对应：

| 变量类型 | `scanf` 格式 |
| --- | --- |
| `int` | `%d` |
| `long long` | `%lld` |
| `float` | `%f` |
| `double` | `%lf` |
| `long double` | `%Lf` |
| `char` | `%c` |

例如：

```cpp
int count;
long long total;
double ratio;

scanf("%d%lld%lf", &count, &total, &ratio);
```

`double` 在 `scanf` 中使用 `%lf`，不是 `%f`。如果格式控制符与变量类型不对应，`scanf` 就可能按错误的大小和规则写入内存；这是未定义行为，不能依赖某一次运行看似正常。

> `printf` 输出 `double` 时反而使用 `%f`。输入与输出的这个区别会在下一篇“输入输出：标准输出”再对照。

## 字符输入

`%c` 与数值格式有一个重要区别：它不会自动跳过空白字符。

```cpp
int n;
char operation;

scanf("%d", &n);
scanf("%c", &operation);
```

如果输入是 `3` 后换行，第二条 `scanf` 很可能把这个换行符读入 `operation`。希望读取下一个非空白字符时，在 `%c` 前写一个空格：

```cpp
scanf(" %c", &operation);
```

格式字符串中的这个空格会匹配并跳过任意数量的空白字符，然后 `%c` 才读取真正的操作符。

## 匹配固定符号

`scanf` 的格式字符串不只能包含 `%d` 等格式控制符。普通字符要求输入中的对应位置出现同样的字符。

例如，输入以 `HH:MM` 形式给出时间：

```text
08:35
```

可以直接匹配中间的冒号：

```cpp
int hour;
int minute;
scanf("%d:%d", &hour, &minute);
```

格式中的 `:` 本身不会保存到变量；它只要求输入在两个整数之间出现冒号。这类写法并不需要背诵，遇到固定分隔符时知道可以查阅即可。

## 读入是否成功

`cin >> x` 不仅尝试读入，还能作为条件表示“这次读入是否成功”。当题目要求读到输入结束，而不是预先给出数量时，可以写：

```cpp
int x;
while (cin >> x) {
    cout << x << '\n';
}
```

`scanf` 会返回成功赋值的变量数量。只读取一个整数时，返回值等于 `1` 就表示读入成功：

```cpp
int x;
while (scanf("%d", &x) == 1) {
    printf("%d\n", x);
}
```

读取两个值时，可以检查返回值是否为 `2`：

```cpp
int a;
int b;
while (scanf("%d%d", &a, &b) == 2) {
    printf("%d\n", a + b);
}
```

在规范的竞赛输入中，题面通常直接给出数据数量，因而普通的 `for` 循环更常见。只有题面明确说“读到文件结束”时，才需要这种条件读入。

## 不混用两套接口

`cin` 和 `scanf` 都能完成竞赛中的标准输入。一份正式解题代码应选择其中一套，并与对应的输出接口一起使用：

- `cin` 与 `cout`；
- `scanf` 与 `printf`。

后续的竞赛模板默认使用 `scanf` 和 `printf`。使用 `cin` 和 `cout` 时可以进一步设置流同步与绑定，但这同时涉及输出流，放在“输入输出：标准输出”中说明。

## 完整代码

下面的程序先读取整数数量 `n`，再读取 `n` 个整数并输出它们的和：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

void solve() {
    int n;
    scanf("%d", &n);

    ll sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        scanf("%d", &x);
        sum += x;
    }

    printf("%lld\n", sum);
}

int main() {
    solve();
    return 0;
}
```

例如，输入：

```text
5
1 2 3 4 5
```

输出：

```text
15
```

## 基础练习

1. 读入三个 `int`，输出它们的和。分别使用 `cin` 和 `scanf` 完成一次。
2. 先读取整数 `n`，再使用循环读取 `n` 个 `long long`，输出它们的和。
3. 将输入 `12:34` 分别读入整数 `hour` 和 `minute`，输出 `hour + minute`。
4. 不预先读取数量，一直读取 `int` 到输入结束，统计成功读取了多少个整数。
