# 指针与引用中的 `const`

> 最近修订：2026-08-16 11:27 +10:00（未审阅）

[常量](const.md) 已经说明，`const int value` 不能通过名称 `value` 修改。指针和
引用引入了两个不同的问题：不能修改的是指针自己保存的地址，还是地址指向的
对象？只有把 `const` 与它限制的部分对应起来，声明才不会靠背诵。

## 指向 const 对象的指针

在目标类型前写 `const`：

```cpp
int x = 10;
const int* p = &x;
```

`p` 是“指向 `const int` 的指针”。可以通过它读取目标：

```cpp
cout << *p << '\n';
```

但不能通过 `p` 修改目标：

```cpp
*p = 20;
```

这段赋值不能编译。限制的是通过 `p` 进行的访问，不一定表示原对象本身不可修改：

```cpp
x = 20;
cout << *p << '\n'; // 20
```

原对象 `x` 不是 `const`，所以可以直接修改；`p` 仍指向同一个对象，并能读到
新值。

指向只读目标的普通指针本身仍然可以改变指向：

```cpp
int y = 30;
p = &y;
```

`const int*` 也可以写成 `int const*`，两种写法含义相同。本书统一把 `const`
写在基础类型前面。

## const 指针

把 `const` 写在星号和指针名之间，限制的是指针变量本身：

```cpp
int x = 10;
int* const p = &x;
```

`p` 是“指向 `int` 的 `const` 指针”。声明时必须给出地址，以后不能改为保存
另一个地址：

```cpp
int y = 30;
p = &y;
```

这段代码不能编译。但目标类型仍然是可修改的 `int`，所以可以写：

```cpp
*p = 20;
```

执行后 `x` 变成 `20`。

可以用一个稳定问题判断限制落在哪里：

- `const` 在星号左边，限制通过指针修改目标；
- `const` 在星号右边，限制指针自己改为其他地址。

## 两边都是 const

两个限制可以同时出现：

```cpp
int x = 10;
const int* const p = &x;
```

这里既不能写 `*p = 20;`，也不能写 `p = &y;`。`p` 从初始化开始固定指向
`x`，并且只允许通过它读取。

三种声明可以对照为：

| 声明 | 能否通过指针修改目标 | 能否改变指向 |
| --- | --- | --- |
| `const int* p` | 否 | 是 |
| `int* const p` | 是 | 否 |
| `const int* const p` | 否 | 否 |

## 指向真正的 const 对象

若原对象本身声明为 `const`，就只能取得允许只读访问的指针：

```cpp
const int LIMIT = 100;
const int* p = &LIMIT;
```

不能把它的地址交给普通 `int*`：

```cpp
int* p = &LIMIT;
```

否则普通指针的类型会承诺能够修改目标，与原对象的 `const` 限制冲突。

从可修改对象得到只读视角是安全的，因为它只减少操作权限；反方向去掉 `const`
则可能允许原本禁止的写入。

## const 引用

引用没有“以后改变绑定”的普通操作，所以只需要讨论能否通过引用修改目标：

```cpp
int x = 10;
const int& r = x;
```

`r` 可以读取 `x`，但不能执行 `r = 20;`。与 `const int*` 相同，这不一定
使原对象变成常量：

```cpp
x = 20;
cout << r << '\n'; // 20
```

`const` 引用还可以绑定字面量或计算产生的临时值：

```cpp
const int& r = 2 + 3;
```

普通 `int&` 不能绑定这种临时结果。函数只读取一个较大对象时，后续会使用
`const T&` 表示“不复制，也不允许函数通过这个参数修改对象”。

## 完整代码

输入两个整数。程序先用指向 `const int` 的指针依次读取两个对象，再用
`const` 指针修改它固定指向的第一个对象：

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int x;
    int y;
    cin >> x >> y;

    const int* reader = &x;
    cout << *reader << '\n';

    reader = &y;
    cout << *reader << '\n';

    int* const writer = &x;
    *writer += 1;
    cout << x << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
10 20
```

输出：

```text
10
20
11
```

`reader` 能改变指向但不能通过它写入目标；`writer` 不能改变指向，却能修改
它固定指向的 `x`。

## 常见错误

### 只看声明中有没有 const

关键不只是出现了 `const`，而是它位于星号左侧还是右侧。分别检查目标和指针
自己的修改权限。

### 以为 const int* 会让原对象永久只读

它只禁止通过这个指针修改。若原对象本来不是 `const`，仍可通过其他可写名称
修改，并从指针观察新值。

### 把 const 对象交给普通指针

普通 `int*` 允许通过解引用写入，不能指向 `const int`。需要使用
`const int*` 保留只读限制。

### 把 const 引用理解成值副本

`const int&` 仍然是原对象的别名，只是不能通过这个别名写入。其他名称修改原
对象后，引用会观察到变化。

## 需要记住什么

1. `const int* p` 限制的是目标还是指针自己？
2. `int* const p` 限制的是目标还是指针自己？
3. 哪种声明同时禁止修改目标和改变指向？
4. 为什么 `const int*` 仍可以改为指向另一个整数？
5. 为什么 `int*` 不能保存 `const int` 对象的地址？
6. `const int&` 是副本还是只读别名？
7. 原对象不是 `const` 时，其他名称能否修改它并让只读指针或引用观察到新值？
