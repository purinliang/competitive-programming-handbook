# bitset

> 最近修订：2026-08-15 20:56 +10:00（未审阅）

假设题目有 $1000$ 名学生，我们只需要记录每名学生是否到场。使用 `bool` 数组当然可以完成，但求两个班都到场、至少一个班到场等集合关系时，仍要逐个位置扫描。

`bitset<N>` 保存固定数量的二进制位，并支持整组按位运算。它适合以下条件同时成立的场景：

- 每个位置只需要保存 `0` 或 `1`；
- 位数在编译时已经确定；
- 经常需要对整组状态做交、并、翻转、计数或移位。

整数的 `&`、`|`、`^` 和移位规则见 [位运算符](bitwise-operators.md)。本篇只解释标准库类型 `bitset` 如何保存和操作比普通整数更多的位。

## 固定长度

下面声明一个恰好包含 $1000$ 位的对象：

```cpp
const int MAX_STUDENTS = 1000;
bitset<MAX_STUDENTS> present;
```

没有显式初值时，所有位默认是 `0`。尖括号中的长度是类型的一部分，并且必须是编译期常量：

```cpp
bitset<8> a;
bitset<16> b;
```

`a` 和 `b` 是不同类型，不能直接进行按位运算。下面的写法也不合法：

```cpp
int n;
scanf("%d", &n);
bitset<n> bits; // 错误：n 不是编译期常量
```

题目在运行时给出实际长度 `n` 时，可以根据题目上限声明一个足够大的 `bitset<MAXN>`，只使用其中需要的部分。真正需要运行时改变位数时，`bitset` 就不是合适的工具。

## 位的位置

`bitset` 是标准库类型，位置从 `0` 开始。`bitset<8>` 的有效位置是 `0..7`：

```cpp
bitset<8> bits;
bits[0] = 1;
bits[7] = 1;
```

输出时，位置较大的位写在左边，位置 `0` 写在最右边。上面的 `bits` 显示为：

```text
10000001
```

这与整数二进制表示中“最低位在最右边”的习惯一致。不要把输出字符串最左边的字符误认为位置 `0`。

本书自定义的学生编号仍使用 `1..n`。若学生 `u` 对应 `bitset` 中的一位，只在接口边界转换一次：

```cpp
present[u - 1] = 1;
```

后续始终使用同一对应关系，不在算法中交替混用两套下标。

## 创建初始状态

可以从无符号整数的低位创建 `bitset`：

```cpp
bitset<8> bits(13);
```

$13$ 的二进制表示是 `1101`，因此固定为八位以后输出：

```text
00001101
```

也可以直接使用只包含 `0` 和 `1` 的字符串：

```cpp
bitset<8> bits("00101101");
```

字符串按照人类书写二进制数的顺序排列：最右边的字符对应位置 `0`。从字符串创建时若字符数量少于长度，高位补 `0`。

## 单个位的操作

下标运算符可以读取或修改一位：

```cpp
if (bits[3]) {
    printf("position 3 is set\n");
}

bits[3] = 1;
bits[3] = 0;
```

`test(pos)` 也用于读取指定位置：

```cpp
bool value = bits.test(3);
```

两者的常见区别是：`test(pos)` 会检查位置并在越界时抛出 `out_of_range`，`bits[pos]` 不负责提供这种边界检查。竞赛代码通常在已经证明位置合法后使用更短的下标写法。

三个成员函数分别把一位设为 `1`、设为 `0` 和翻转：

```cpp
bits.set(3);   // 位置 3 变成 1
bits.reset(3); // 位置 3 变成 0
bits.flip(3);  // 0 变成 1，1 变成 0
```

不提供位置时，它们操作全部位：

```cpp
bits.set();   // 全部变成 1
bits.reset(); // 全部变成 0
bits.flip();  // 每一位分别翻转
```

## 整体查询

`count()` 返回值为 `1` 的位数：

```cpp
int selected = bits.count();
```

返回类型实际是标准库的无符号长度类型；题目上限保证结果能放进 `int` 时，竞赛代码中可以直接保存为 `int`。

另外几个查询回答整组状态的问题：

```cpp
bits.any();  // 是否至少有一位是 1
bits.none(); // 是否所有位都是 0
bits.all();  // 是否所有位都是 1
bits.size(); // 总位数 N
```

`size()` 返回声明中的固定长度，不是当前值为 `1` 的位数。

## 整组按位运算

长度相同的两个 `bitset` 可以直接使用整数中熟悉的按位运算符：

```cpp
bitset<1000> a;
bitset<1000> b;

bitset<1000> intersection = a & b;
bitset<1000> union_set = a | b;
bitset<1000> symmetric_difference = a ^ b;
bitset<1000> complement = ~a;
```

- `a & b` 只保留两边都是 `1` 的位置，可以表示集合交集；
- `a | b` 保留至少一边是 `1` 的位置，可以表示集合并集；
- `a ^ b` 保留恰好一边是 `1` 的位置；
- `~a` 翻转固定长度内的每一位。

也可以使用 `&=`、`|=` 和 `^=` 直接修改左侧对象。

`bitset` 还支持固定宽度的左右移位：

```cpp
bits <<= 2;
bits >>= 1;
```

空出的位置补 `0`，越过固定长度边界的位直接丢弃。它不会像动态序列一样因为移位而增长。

这些整体操作通常按机器字成块处理，而不是为每一位执行一次完整的 C++ 循环。对 $N$ 位状态，可以把工作量理解为大约 $O(N / W)$，其中 $W$ 是实现一次能够处理的机器字位数。具体分块方式由标准库实现决定，不应把任意长度 `bitset` 的整体运算误写成严格的 $O(1)$。

## 转换为其他表示

`to_string()` 把全部位转成由 `0` 和 `1` 组成的 `string`：

```cpp
string text = bits.to_string();
```

字符串长度等于 `bitset` 的固定长度，最右边仍对应位置 `0`。

当数值能够放入对应的无符号整数时，可以使用：

```cpp
unsigned long long value = bits.to_ullong();
```

若高位使结果超出 `unsigned long long` 的范围，`to_ullong()` 会抛出 `overflow_error`。它不是把任意长度二进制数转成高精度整数的通用方法。

## 完整代码

下面的程序统计两个活动小组中“同时参加”“至少参加一个”和“两个都没有参加”的学生人数。学生编号为 `1..n`，而 `bitset` 的位置为 `0..n-1`，所以读入时统一使用 `u - 1` 完成转换。

输入第一行给出学生总数 `n`、第一个小组人数 `a` 和第二个小组人数 `b`，随后两行分别给出两个小组的学生编号。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAX_STUDENTS = 1000;

int main() {
    int n, a, b;
    scanf("%d%d%d", &n, &a, &b);

    bitset<MAX_STUDENTS> first;
    bitset<MAX_STUDENTS> second;

    for (int i = 1; i <= a; i++) {
        int u;
        scanf("%d", &u);
        first[u - 1] = 1;
    }

    for (int i = 1; i <= b; i++) {
        int u;
        scanf("%d", &u);
        second[u - 1] = 1;
    }

    int both = (first & second).count();
    int at_least_one = (first | second).count();
    int neither = n - at_least_one;

    printf("%d %d %d\n", both, at_least_one, neither);
    return 0;
}
```

输入：

```text
8 4 5
1 2 5 8
2 3 5 6 8
```

输出：

```text
3 6 2
```

学生 `2`、`5`、`8` 同时参加两个小组，共 $3$ 人；至少参加一个小组的学生是 `1`、`2`、`3`、`5`、`6`、`8`，共 $6$ 人；其余 $2$ 人两个小组都没有参加。

程序声明的位数由上限 `MAX_STUDENTS` 决定，而不是输入的实际 `n`。本题只对已经读入的学生位置设为 `1`，因此未使用的高位始终为 `0`，不会影响交集、并集和计数结果。

## 常见错误

### 把最左边当成位置 0

`bitset<8>(1)` 输出为 `00000001`。位置 `0` 在最右边，和整数最低位一致。

### 使用运行时长度

`bitset<n>` 中的 `n` 必须在编译时确定。运行时读入的规模只能决定使用哪些位，不能改变这个对象的类型。

### 混用题目编号与位位置

题目对象按 `1..n` 编号时，集中使用 `u - 1` 映射到 `bitset`。不要有些操作减 `1`、另一些操作直接使用 `u`。

### 忘记固定宽度

`~bits` 会翻转声明长度内的所有位，包括实际题目没有使用的高位。若随后调用 `count()`，这些高位也会被计入。需要只处理前 `n` 位时，应构造相应掩码，或避免对未使用区域直接整体取反。

### 把转换函数当成高精度

较长的 `bitset` 可以保存超过 64 位的状态，但不代表它能通过 `to_ullong()` 无损转换成 64 位整数。

## 基础练习

1. 声明 `bitset<8>`，分别设置位置 `0` 和位置 `7`，观察输出顺序。
2. 对同一个位置依次调用 `set`、`flip` 和 `reset`，记录每一步结果。
3. 使用 `count()`、`any()`、`none()` 和 `all()` 检查全零、全一以及只设置一位的状态。
4. 使用两个 `bitset<100>` 表示两个集合，计算交集、并集和只属于其中一边的位置数量。
5. 题目编号使用 `1..n` 时，只在读入处转换成 `bitset` 的位置，并检查编号 `1` 与编号 `n` 分别落在哪一位。
6. 对只使用前 `n` 位的 `bitset<MAXN>` 整体取反，观察为什么未使用的高位会影响 `count()`。

## 需要记住什么

1. `bitset<N>` 中的 `N` 何时必须确定？它能否在运行时改变？
2. `bitset` 的位置从几开始？输出字符串中的位置 `0` 在哪一边？
3. `set`、`reset` 和 `flip` 分别怎样修改一位？不传位置时会怎样？
4. `count`、`any`、`none`、`all` 和 `size` 分别回答什么问题？
5. 如何用 `&` 和 `|` 表示两个集合的交集与并集？
6. 为什么较大的 `bitset` 整体运算不能简单视为严格的 $O(1)$？
7. 为什么只使用前 `n` 位时，直接对整个 `bitset<MAXN>` 取反可能得到错误的计数？
8. `to_ullong()` 为什么不是任意长度二进制数的高精度转换方法？

标准库如何选择内部机器字、不同实现的常数差异，以及使用 `bitset` 优化动态规划转移等内容不属于本篇的基础接口，不要求记忆。
