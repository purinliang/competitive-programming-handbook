# 二分答案

> 最近修订：2026-08-16 14:15 +10:00（未审阅）

[二分查找](binary-search.md) 在有序数组中寻找目标位置。许多问题没有一份已经排好
的候选数组，却要求最大化或最小化一个整数答案。只要能够判断“某个候选答案是否
可行”，并且可行性随候选值单调变化，就可以直接二分答案的数值范围。

二分答案把优化问题改写成若干次判断问题：不直接问“最优答案是多少”，而是反复问“答案至少达到 `x` 可不可以”或“答案至多限制为 `x` 能不能完成”。

## 切绳问题

有 $n$ 根长度为正整数的绳子，第 $i$ 根长度为 $a[i]$。每次可以把绳子切成若干段，剩余不足一段的部分可以丢弃。要求得到至少 $k$ 段长度相同的整数绳段，最大化每段长度。

例如，绳长为：

```text
8 7 5
```

要求至少 $5$ 段：

- 每段长 $3$ 时，可以切出 `2 + 2 + 1 = 5` 段，可行；
- 每段长 $4$ 时，可以切出 `2 + 1 + 1 = 4` 段，不可行。

最优答案因此是 $3$。

## 直接枚举答案

答案至少为 $1$，至多为最长绳子的长度 `maximum`。最直接的方法是从 $1$ 到 `maximum` 逐个尝试：

```cpp
ll answer = 0;
for (ll length = 1; length <= maximum; length++) {
    if (feasible(length)) {
        answer = length;
    }
}
```

若绳长可以达到 $10^{18}$，即使每次判断很快，也不可能枚举所有整数长度。需要利用可行性的顺序一次排除大量候选值。

## 可行性判定

候选段长为 `length` 时，一根长度为 `a[i]` 的绳子最多切出：

$$
\left\lfloor\frac{a[i]}{length}\right\rfloor
$$

段。把所有绳子的贡献相加，只要达到 `required` 就可行：

```cpp
bool feasible(const vector<ll>& a, int n, ll required, ll length) {
    ll pieces = 0;
    for (int i = 1; i <= n; i++) {
        pieces += a[i] / length;
        if (pieces >= required) {
            return true;
        }
    }
    return false;
}
```

变量 `pieces` 只关心是否达到要求，不需要计算超过 `required` 后的精确总数，因此可以提前返回。这既减少无意义运算，也避免在绳子很多、商很大时继续累加而溢出。

函数只能在 `length >= 1` 时调用，因为除数不能为 $0$。答案为 $0$ 只作为“连长度 $1$ 都无法满足”的返回哨兵，不进入判定函数。

## 可行性的单调性

若段长 `length` 可行，那么任何更短的正整数段长也可行：缩短每段不会减少任意绳子能切出的段数。

反过来，若某个段长不可行，那么任何更长的段长也不可能可行。

把候选长度从小到大排列，可行性一定形如：

```text
true true true ... true false false ... false
```

我们要找的正是最后一个 `true`。

二分答案前必须证明这条单调性。仅仅能够写出一个 `feasible(x)` 函数，不代表它的真假结果一定只有一次分界；如果结果会反复变化，排除一侧就没有依据。

## 候选范围

正整数段长的搜索范围是闭区间 `[1,maximum]`：

```cpp
ll l = 1;
ll r = maximum;
```

答案变量先设为 $0$：

```cpp
ll answer = 0;
```

若没有任何正长度可行，循环结束后仍返回 $0$。若题目保证至少能切出 $k$ 段长度为 $1$ 的绳子，那么 $0$ 不会成为最终答案，但保留这个哨兵让函数边界完整。

## 寻找最后一个可行值

每轮检查中点：

```cpp
ll mid = l + (r - l) / 2;
```

若 `mid` 可行，它是当前答案候选，但右边可能还有更大的可行值：

```cpp
answer = mid;
l = mid + 1;
```

若 `mid` 不可行，根据单调性，`mid` 及其右边都不可能成为答案：

```cpp
r = mid - 1;
```

完整搜索是：

```cpp
ll maximum_piece_length(const vector<ll>& a, int n, ll required) {
    ll maximum = 0;
    for (int i = 1; i <= n; i++) {
        maximum = max(maximum, a[i]);
    }

    ll l = 1;
    ll r = maximum;
    ll answer = 0;

    while (l <= r) {
        ll mid = l + (r - l) / 2;
        if (feasible(a, n, required, mid)) {
            answer = mid;
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }

    return answer;
}
```

循环过程中：

- `answer` 是已经检查过的最大可行值；
- `[l,r]` 是尚未判断、仍可能包含更大可行值的候选区间；
- `r` 右边尚未成为 `answer` 的值都已经被证明不可行。

循环结束时未知区间为空，已经不存在比 `answer` 更大的可行候选，因此它就是最优答案。

## 为什么边界会终止

闭区间搜索的非空条件是 `l <= r`。每轮无论可行与否，都会排除 `mid`：

- 可行时令 `l = mid + 1`；
- 不可行时令 `r = mid - 1`。

候选区间严格缩小，因此不会无限循环。使用显式 `answer` 后，不需要为了让上下取整配合而背诵多套 `l < r` 模板。

## 最小可行值

有些问题的真假方向相反：较小候选不可行，达到某个值后全部可行：

```text
false false ... false true true ... true
```

例如“把所有任务放进容量为 `capacity` 的容器中，最小需要多大容量”。这时寻找第一个 `true`：

```cpp
ll answer = impossible_sentinel;

while (l <= r) {
    ll mid = l + (r - l) / 2;
    if (feasible(mid)) {
        answer = mid;
        r = mid - 1;
    } else {
        l = mid + 1;
    }
}
```

与 [下界查找](binary-search.md#第一个不小于目标的位置) 完全相同：遇到可行值先保存，再继续向左寻找更小答案。

因此不应先背“最大值用哪一个中点公式”。先画出候选值从左到右的真假分布，确认要找第一个 `true` 还是最后一个 `true`，再决定可行时向哪一边继续。

## 判定函数与答案函数

二分答案的代码应把两个职责分开：

- `feasible(candidate)` 只回答一个候选值能否满足题目；
- 二分循环只利用真假单调性寻找分界。

这样可以分别检查：

1. 判定函数对一个固定候选是否正确；
2. 单调性方向是否正确；
3. 搜索范围是否覆盖全部可能答案；
4. 二分更新是否在寻找正确边界。

把复杂题意全部塞进二分循环，会让这四类错误混在一起，很难调试。

## 搜索范围的上下界

二分只能在已经证明包含答案的范围内工作。切绳问题中：

- 正长度最小为 $1$；
- 任一绳段不能长于最长原绳，因此上界是 `maximum`；
- $0$ 只作为没有正答案时的哨兵。

其他问题的上下界必须从题意推导。上界过小会直接漏掉答案；上界虽然正确但过于巨大，只会增加对数级的少量轮数，不过还可能让中间计算溢出。

使用 64 位整数保存候选范围时，中点写作 `l + (r-l)/2`。若判定中还会计算乘法、平方或总和，需要根据题目范围单独防止这些表达式溢出；二分本身不会自动解决数值安全问题。

## 时间复杂度

设答案候选范围宽度为 $M$。每轮把候选数量减半，二分进行 $O(\log M)$ 轮。

切绳判定扫描 $n$ 根绳子，最坏是 $O(n)$，因此总时间复杂度是：

$$
O(n\log M)
$$

输入数组使用 $O(n)$ 空间；判定函数和二分循环只使用固定数量的变量，额外空间是 $O(1)$。

这里的对数取决于答案范围 $M$，不是元素数量 $n$。这也是二分答案与在长度为 $n$ 的数组上二分位置的区别。

## 完整代码

输入 $n$ 根正整数长度的绳子和需要的段数 `required`，输出能够切出的最大整数段长。
绳长和 `required` 不超过 $10^{18}$。每次加法前都有 `pieces < required`，单根
贡献也不超过 $10^{18}$，所以本轮和小于 $2\times10^{18}$，能放入 64 位整数；
达到要求后立即结束，不再累加无关的大数。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

bool feasible(const vector<ll>& a, int n, ll required, ll length) {
    ll pieces = 0;
    for (int i = 1; i <= n; i++) {
        pieces += a[i] / length;
        if (pieces >= required) {
            return true;
        }
    }
    return false;
}

ll maximum_piece_length(const vector<ll>& a, int n, ll required) {
    ll maximum = 0;
    for (int i = 1; i <= n; i++) {
        maximum = max(maximum, a[i]);
    }

    ll l = 1;
    ll r = maximum;
    ll answer = 0;

    while (l <= r) {
        ll mid = l + (r - l) / 2;
        if (feasible(a, n, required, mid)) {
            answer = mid;
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }

    return answer;
}

void solve() {
    int n;
    ll required;
    cin >> n >> required;

    vector<ll> a(n + 5);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    cout << maximum_piece_length(a, n, required) << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 5
8 7 5
```

输出：

```text
3
```

完整代码允许 `n = 0`，此时最长绳长和答案都是 $0$；通常题目会保证至少有一根绳子。它假设 `required >= 1`，因为“至少切出零段”没有有限的最大段长，需要由题目另行定义。

## 常见错误

### 没有证明单调性

能够判断一个候选值不代表可以二分。必须证明某个值可行后，哪一侧全部可行；某个值不可行后，哪一侧全部不可行。

### 把真假方向写反

切绳长度越大越难，可行性是 `true...false`，要找最后一个 `true`。最小容量等问题是 `false...true`，要找第一个 `true`。

### 候选范围包含零

切绳判定需要除以 `length`，因此二分范围从 $1$ 开始。答案变量可以用 $0$ 表示没有正长度可行，但不能调用 `feasible(0)`。

### 可行后向错误方向搜索

最大化可行值时，`mid` 可行说明它可以成为答案，还要令 `l = mid + 1` 尝试更大值。最小化可行值则应继续向左。

### 只分析二分轮数

总复杂度还要乘上一次判定的成本。切绳每次判定是 $O(n)$，所以不是单纯的 $O(\log M)$，而是 $O(n\log M)$。

### 判定函数累加溢出

只需要知道段数是否达到 `required`，达到后立即返回，不继续累加可能很大的无用总数。

## 需要记住什么

1. 二分答案怎样把优化问题改写为判定问题？
2. 什么样的可行性序列才能二分？为什么必须先证明单调性？
3. 切绳问题的 `feasible(length)` 怎样计算？段长增大时可行性怎样变化？
4. 搜索最大可行值时，`answer`、`[l,r]` 分别保存什么？
5. 找最后一个 `true` 与找第一个 `true` 时，可行分支分别向哪边继续？
6. 为什么使用显式 `answer` 能让闭区间模板不依赖特殊的中点取整口诀？
7. 搜索范围上下界和不存在答案的哨兵怎样从题意推导？
8. 为什么切绳候选不能包含 $0$？
9. 若一次判定是 $O(T)$、答案范围宽度是 $M$，总时间复杂度是多少？
10. 二分使用 64 位整数时，还需要检查判定函数中的哪些数值运算？

浮点二分、实数误差控制、指数扩展上界和嵌套判定不属于本篇整数二分答案基础。不同题目的主要难点通常在判定函数与单调性证明，而不是复制二分循环。
