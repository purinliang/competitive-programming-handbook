# 离散化

> 最近修订：2026-08-13 20:51 +10:00（未审阅）

有些题目的数值范围极大，但实际只出现很少的不同值。若后续操作只关心两个值是否相等、谁更小以及它们的相对顺序，就可以把这些稀疏数值替换成从 `1` 开始的连续排名。这种映射称为离散化。

本篇会复用 [STL 算法：排序](../cpp/sorting.md)、[STL 算法：去重](../cpp/deduplication.md) 和 [查找：二分查找](binary-search.md)。

## 巨大而稀疏的数值

假设数组是：

```text
a = 100 -5 100 20 -5 1000000000000
```

若想按数值建立计数数组，直接访问 `count[a[i]]` 会遇到两个问题：

- `-5` 不能直接作为普通数组下标；
- 最大值达到 $10^{12}$，即使只出现六个数，也不可能为中间所有位置分配数组。

真正出现的不同值只有四个：

```text
-5 20 100 1000000000000
```

把它们从小到大编号：

| 原值 | `-5` | `20` | `100` | `1000000000000` |
| ---: | ---: | ---: | ---: | ---: |
| 编号 | 1 | 2 | 3 | 4 |

原数组就能替换成：

```text
3 1 3 2 1 4
```

这些编号只占用 `1..4`，可以安全地作为计数数组、树状数组或线段树的下标。

## 映射需要保留的关系

设 `id(x)` 表示原值 `x` 的离散编号。离散化必须保持：

- 若 $x = y$，则 `id(x) == id(y)`；
- 若 $x < y$，则 `id(x) < id(y)`；
- 每个实际出现的不同值恰好使用 `1..m` 中的一个编号，其中 `m` 是不同值的数量。

因此，比较原值与比较编号得到相同的大小顺序，重复值也一定得到同一个编号。

离散化不保持数值距离。`20` 与 `100` 的编号相差 $1$，但原值相差 $80$；`100` 与 $10^{12}$ 的编号也只相差 $1$。若题目需要真实坐标差、区间长度或算术运算，必须继续使用原值，不能拿编号差代替。

## 保留原数组

排序能建立大小顺序，却会改变元素原来的位置。后续还要按照原顺序输出每个 `a[i]` 的编号，因此不能直接排序 `a`。

建立副本 `values`：

```cpp
vector<ll> values(n + 5);
for (int i = 1; i <= n; i++) {
    values[i] = a[i];
}
```

`a[1..n]` 保持输入顺序，`values[1..n]` 专门用于建立原值与编号之间的映射。

## 排序不同值

先排列副本：

```cpp
sort(values.begin() + 1, values.begin() + n + 1);
```

本书自定义数组使用闭区间 `values[1..n]`。`sort` 接收 STL 的左闭右开范围，所以调用边界写成 `[values.begin() + 1, values.begin() + n + 1)`；右端的 `+1` 表示最后一个元素之后的位置。

示例排序后是：

```text
-5 -5 20 100 100 1000000000000
```

相同值现在彼此相邻，但还不能直接把位置当作排名：若不删除重复项，`20` 会得到编号 `3`，中间的编号 `2` 却仍然对应另一个 `-5`。

## 去除重复值

对已经排序的范围调用 `unique`：

```cpp
auto new_end = unique(values.begin() + 1, values.begin() + n + 1);
int m = new_end - values.begin() - 1;
```

`unique` 把每个不同值的一份移动到范围前部，并返回逻辑末尾。它从下标 `1` 开始保存，所以逻辑范围 `[values.begin() + 1, new_end)` 的元素数量是：

```text
new_end - (values.begin() + 1)
```

代码中的 `new_end - values.begin() - 1` 是同一个结果，保存为不同值数量 `m`。去重后的有效数据位于 `values[1..m]`：

```text
下标：       1   2    3               4
values[i]： -5  20  100  1000000000000
```

这里不调用 `erase`。`values` 是自定义算法的 1-based 工作数组，逻辑长度由 `m` 单独记录，尾部继续保留统一的 `+5` 容量余量。`values[m + 1]` 以后的旧内容不再属于去重结果，不能读取。

## 二分寻找编号

`values[1..m]` 已经严格递增。对每个原值 `a[i]`，在其中寻找第一个不小于它的位置：

```cpp
int lower_bound_index(const vector<ll>& values, int m, ll target) {
    int l = 1;
    int r = m;
    int answer = m + 1;

    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (values[mid] >= target) {
            answer = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }

    return answer;
}
```

每个 `a[i]` 都来自建立 `values` 时复制的原数组，所以它一定存在于去重结果中。`lower_bound_index` 不会返回失败哨兵 `m + 1`，返回位置就是从 `1` 开始的离散编号：

```cpp
compressed[i] = lower_bound_index(values, m, a[i]);
```

不需要再加一，也不需要保存额外映射表。排序后的第一个不同值自然位于 `values[1]`，它的编号就是 `1`。

## 从编号恢复原值

`values` 同时是反向映射：

```cpp
ll original_value = values[compressed[i]];
```

例如 `compressed[i] == 3` 时，对应原值是 `values[3] == 100`。

这只能恢复某个编号代表的原值，不能恢复“这个值原来出现在哪个位置”。原位置仍由 `a[i]` 或其他与输入下标绑定的数组保存。

## 完整过程

离散化依次完成四件事：

1. 复制原数组，避免排序破坏原顺序；
2. 排序副本，让大小关系变成位置顺序；
3. 去重，保证每个不同值只占一个连续编号；
4. 对每个原值二分查找其排名。

完整核心代码是：

```cpp
vector<ll> values(n + 5);
for (int i = 1; i <= n; i++) {
    values[i] = a[i];
}

sort(values.begin() + 1, values.begin() + n + 1);
auto new_end = unique(values.begin() + 1, values.begin() + n + 1);
int m = new_end - values.begin() - 1;

vector<int> compressed(n + 5);
for (int i = 1; i <= n; i++) {
    compressed[i] = lower_bound_index(values, m, a[i]);
}
```

## 正确性

排序去重后，`values[1..m]` 严格递增，并且每个输入值恰好出现一次。

若两个原值相等，二分查找会返回同一个唯一位置，所以它们得到相同编号。若 $x < y$，严格递增数组中的 `x` 必然位于 `y` 左边，所以 `id(x) < id(y)`。每个位置 `1..m` 又分别存放一个实际出现的值，因此编号连续且没有空缺。

这三点分别保证了相等关系、大小关系和紧凑编号，正好满足离散化的定义。

## 时间与空间复杂度

复制数组需要 $O(n)$ 时间，排序需要 $O(n\log n)$ 时间，去重需要 $O(n)$ 时间。对 $n$ 个原值分别在 $m$ 个不同值中二分查找，需要 $O(n\log m)$ 时间。

因为 $m\le n$，总时间复杂度是 $O(n\log n)$。`values` 与 `compressed` 各保存 $O(n)$ 个元素，额外空间复杂度是 $O(n)$。

一次离散化后，后续算法可以反复使用 `compressed[i]`，不需要每次重新二分。

## 离线条件

编号取决于全部不同值的排序结果。若建立映射后又出现一个介于已有值之间的新值，后面的编号可能整体变化。

例如原来只有 `10, 30`，编号分别是 `1, 2`；后来插入 `20` 后，`30` 应改为编号 `3`。因此普通离散化需要在处理主要操作前，先收集所有将会参与映射的值，这称为离线处理。

若题目提前给出修改值、询问端点或事件坐标，并且它们以后会作为离散下标使用，就要在排序去重前一并收集。动态到达且无法提前获得的值不能直接套用这份固定映射，应根据题目改用有序容器或其他动态结构。

## 完整代码

下面的程序读入一组 64 位整数，输出不同值数量以及每个输入位置对应的 1-based 离散编号。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int lower_bound_index(const vector<ll>& values, int m, ll target) {
    int l = 1;
    int r = m;
    int answer = m + 1;

    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (values[mid] >= target) {
            answer = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }

    return answer;
}

int main() {
    int n;
    scanf("%d", &n);

    vector<ll> a(n + 5);
    vector<ll> values(n + 5);
    for (int i = 1; i <= n; i++) {
        scanf("%lld", &a[i]);
        values[i] = a[i];
    }

    sort(values.begin() + 1, values.begin() + n + 1);
    auto new_end = unique(values.begin() + 1, values.begin() + n + 1);
    int m = new_end - values.begin() - 1;

    vector<int> compressed(n + 5);
    for (int i = 1; i <= n; i++) {
        compressed[i] = lower_bound_index(values, m, a[i]);
    }

    printf("%d\n", m);
    for (int i = 1; i <= n; i++) {
        if (i > 1) {
            printf(" ");
        }
        printf("%d", compressed[i]);
    }
    printf("\n");
    return 0;
}
```

输入：

```text
6
100 -5 100 20 -5 1000000000000
```

输出：

```text
4
3 1 3 2 1 4
```

## 常见错误

### 直接排序原数组

若后续仍要按照输入位置使用数据，直接排序 `a` 会丢失原顺序。应当排序副本 `values`。

### 排序后没有去重

重复值会占据多个位置，使编号出现空缺。必须让每个不同值只保留一份。

### 继续读取逻辑末尾之后

`unique` 不会改变 `vector::size()`。本篇只允许读取 `values[1..m]`，不能把尾部旧内容当作去重结果。

### 忘记 STL 范围的右端加一

自定义闭区间 `values[1..n]` 传给 `sort` 或 `unique` 时，右端必须写成 `values.begin() + n + 1`。

### 用编号计算原值距离

编号只保存相等和顺序关系，不保存差值、比例与几何距离。需要这些量时，应当通过 `values[id]` 取回原值再计算。

### 遗漏以后出现的值

普通离散化是离线过程。所有以后会作为映射对象的值都要在排序去重前收集。

## 基础练习

1. 对示例手动执行复制、排序、去重和二分映射，写出每一步的有效数组。
2. 测试所有值相同、已经递增、严格递减、包含负数和包含 64 位大数的输入。
3. 用排序后的不同值作为真值，随机检查相同原值的编号相同、较小原值的编号较小。
4. 根据 `values[compressed[i]]` 恢复原数组，验证与输入完全相同。
5. 统计每个不同值出现的次数，使用离散编号访问长度为 `m` 的计数数组。
6. 构造一组数，说明离散编号的差不能代替原值的差。
7. 一次性读入全部修改操作，将初始值和未来修改值共同离散化。

## 需要记住什么

1. 离散化解决的是“数值范围很大”还是“实际不同值很多”？
2. 离散编号必须保留原值的哪些关系？哪些数值关系不会保留？
3. 为什么要排序副本而不是直接排序原数组？
4. 为什么排序以后还必须去重？
5. `values[1..m]` 怎样同时提供正向排名和反向恢复？
6. 为什么二分查找返回的位置可以直接作为 1-based 编号？
7. 普通离散化的总时间和额外空间复杂度分别是多少？
8. 为什么必须提前收集以后会出现的值？
9. 自定义闭区间传给 `sort` 和 `unique` 时，怎样转换为 STL 的左闭右开范围？
