# 倍增

> 最近修订：2026-08-17 10:25 +10:00（未审阅）

有 $n$ 个房间，每个房间都有一扇门，并且这扇门只会通向一个确定的房间。站在房间 `u`，穿过一次门就到达 `to[u]`。现在需要多次回答：从房间 `u` 出发，连续穿过 $k$ 扇门后位于哪个房间？

一次查询可以按照 `to` 逐步移动：

```cpp
while (k > 0) {
    u = to[u];
    k--;
}
```

这需要 $O(k)$ 时间。当 $k$ 可以达到 $10^{18}$ 时，即使只有一次查询也无法完成。倍增的目标是预先保存长度为 $1,2,4,8,\ldots$ 的跳跃，再用少量大步拼出任意 $k$。

## 从一步到两步

数组 `to[u]` 已经回答了一个最小问题：从 `u` 出发走 $1$ 步到哪里。

若还想知道走 $2$ 步的位置，可以先走到 `to[u]`，再从那里走一步：

```cpp
to[to[u]]
```

走 $4$ 步可以拆成两个 $2$ 步，走 $8$ 步又可以拆成两个 $4$ 步。每次把已经知道的跳跃长度翻倍，就能很快覆盖巨大的步数。

## 倍增表

定义：

$$
jump[u][j]=\text{从房间 }u\text{ 出发走 }2^j\text{ 步后到达的房间}.
$$

这里 `u` 是从 `1` 开始的房间编号；`j` 是 $2$ 的指数，所以从数学上自然使用 `0,1,2,...`：

```text
jump[u][0]：走 1 步
jump[u][1]：走 2 步
jump[u][2]：走 4 步
jump[u][3]：走 8 步
```

指数 `0` 表示 $2^0=1$，不是把房间或普通数组改成 0-based。

第一列就是题目给出的单步跳转：

```cpp
jump[u][0] = to[u];
```

## 从较短跳跃得到较长跳跃

从 `u` 出发走 $2^j$ 步，可以分成两段长度都是 $2^{j-1}$ 的跳跃：

1. 第一段到达 `jump[u][j - 1]`；
2. 再从这个中间房间走 $2^{j-1}$ 步。

因此：

$$
jump[u][j]=jump[jump[u][j-1]][j-1].
$$

代码按照指数从小到大建立整张表：

```cpp
for (int u = 1; u <= n; u++) {
    jump[u][0] = to[u];
}

for (int j = 1; j < LOG; j++) {
    for (int u = 1; u <= n; u++) {
        jump[u][j] = jump[jump[u][j - 1]][j - 1];
    }
}
```

计算第 `j` 列时只读取已经完成的第 `j - 1` 列，所以这个顺序不会访问未计算的数据。房间的处理顺序没有依赖关系，同一列内按照 `u = 1..n` 枚举即可。

## 用二进制拆分步数

任意非负整数都能写成若干个不同的 $2$ 的幂之和。例如：

$$
13=8+4+1=2^3+2^2+2^0.
$$

因此走 $13$ 步，可以依次完成一次 $8$ 步、一次 $4$ 步和一次 $1$ 步的跳跃。检查 `k` 二进制表示中的每一位：

```cpp
for (int j = 0; j < LOG; j++) {
    if ((k >> j) & 1) {
        u = jump[u][j];
    }
}
```

若第 `j` 位为 `1`，就使用长度为 $2^j$ 的跳跃；若为 `0`，这一长度不属于 `k` 的二进制分解，直接跳过。

跳跃的执行顺序不会改变最终步数，因为每次都从当前房间继续沿同一个 `to` 关系前进。程序总共执行的步数恰好是所有已选 $2^j$ 之和，也就是 `k`。

## 表的列数

题目保证 `0 <= k <= 1e18`。因为：

$$
10^{18}<2^{60},
$$

`k` 的最高有效位不会超过第 `59` 位。取：

```cpp
const int LOG = 60;
```

并枚举 `j = 0..59` 就能覆盖所有查询。

`LOG` 表示需要保存的有效指数数量。内部 `vector` 仍按仓库约定额外保留 `+5` 个位置，但算法只访问前 `LOG` 列。

## 封装跳转关系

倍增表和“走若干步”的操作共同维护同一份跳转关系，适合放进一个 `struct`：

```cpp
const int LOG = 60;

struct doubling {
    vector<vector<int>> jump;

    doubling(const vector<int>& to, int n) {
        jump.assign(n + 5, vector<int>(LOG + 5, 0));

        for (int u = 1; u <= n; u++) {
            jump[u][0] = to[u];
        }

        for (int j = 1; j < LOG; j++) {
            for (int u = 1; u <= n; u++) {
                jump[u][j] = jump[jump[u][j - 1]][j - 1];
            }
        }
    }

    int move(int u, ll k) const {
        for (int j = 0; j < LOG; j++) {
            if ((k >> j) & 1) {
                u = jump[u][j];
            }
        }
        return u;
    }
};
```

构造函数接收完整的单步跳转数组，建立倍增表。`move(u, k)` 不修改表，只沿表查询，因此声明为 `const` 成员函数。

## 正确性

先证明倍增表的含义正确。第 `0` 列直接保存 `to[u]`，确实是从 `u` 走 $2^0=1$ 步的位置。

假设第 `j - 1` 列能够正确完成 $2^{j-1}$ 步。递推式先从 `u` 走 $2^{j-1}$ 步，再从到达的位置继续走 $2^{j-1}$ 步，总步数为：

$$
2^{j-1}+2^{j-1}=2^j.
$$

所以第 `j` 列也正确。按照指数归纳，整张表都符合定义。

查询时，程序只对 `k` 中为 `1` 的二进制位执行对应跳跃。不同位代表的步数互不重复，它们的总和恰好为 `k`；每一次跳跃又都沿真实的 `to` 关系前进。因此查询结束时所在位置就是从起点连续走 $k$ 步后的房间。

## 复杂度

倍增表有 $n$ 行和 `LOG` 个有效列，建立时间复杂度为 $O(n\log K)$，空间复杂度为 $O(n\log K)$，其中 $K$ 是允许的最大步数。

一次查询最多检查 `LOG` 个二进制位，时间复杂度为 $O(\log K)$。这把逐步跳转的 $O(k)$ 降到了对数级。

## 完整代码

第一行输入房间数 `n` 和查询数 `q`；第二行输入 `to[1..n]`。每个查询给出起点 `u` 和步数 `k`，输出最终房间。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int LOG = 60;

struct doubling {
    vector<vector<int>> jump;

    doubling(const vector<int>& to, int n) {
        jump.assign(n + 5, vector<int>(LOG + 5, 0));

        for (int u = 1; u <= n; u++) {
            jump[u][0] = to[u];
        }

        for (int j = 1; j < LOG; j++) {
            for (int u = 1; u <= n; u++) {
                jump[u][j] = jump[jump[u][j - 1]][j - 1];
            }
        }
    }

    int move(int u, ll k) const {
        for (int j = 0; j < LOG; j++) {
            if ((k >> j) & 1) {
                u = jump[u][j];
            }
        }
        return u;
    }
};

int main() {
    int n;
    int q;
    scanf("%d%d", &n, &q);

    vector<int> to(n + 5);
    for (int u = 1; u <= n; u++) {
        scanf("%d", &to[u]);
    }

    doubling table(to, n);

    while (q--) {
        int u;
        ll k;
        scanf("%d%lld", &u, &k);
        printf("%d\n", table.move(u, k));
    }

    return 0;
}
```

输入：

```text
5 3
2 3 4 5 3
1 0
1 4
1 10
```

输出：

```text
1
5
5
```

当 `k = 0` 时没有任何二进制位需要跳跃，起点保持不变。这也是查询必须支持的边界情况。
