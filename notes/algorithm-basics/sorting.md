# 冒泡排序

> 最近修订：2026-08-16 10:15 +10:00（未审阅）

[sort](../cpp/sorting.md) 已经能在实际解题中高效排列元素。亲自推导基础排序的意义
不是替代标准库，而是练习怎样从局部操作建立不变量、证明结果并计算操作次数。

冒泡排序只比较相邻元素：发现前大后小时就交换。一次从左到右的扫描会把当前最大
值送到最右端；重复这个过程，未确定范围不断缩小，最终整个数组有序。

## 排序目标与相邻逆序

给定 1-based 数组 `a[1..n]`，升序排序要求：

$$
a[1]\le a[2]\le\cdots\le a[n].
$$

排序只能改变元素的排列顺序，不能增加、丢失或修改原来的值。

若相邻两个位置满足 `a[j] > a[j + 1]`，它们的顺序与升序目标相反。交换后，
较小值来到左边，较大值来到右边：

```cpp
if (a[j] > a[j + 1]) {
    swap(a[j], a[j + 1]);
}
```

`swap(x, y)` 交换两个变量的值。不断消除相邻逆序，最终每一对相邻元素都满足
前者不大于后者，整个数组也就非递减有序。

## 一轮扫描

从左向右比较 `a[j]` 与 `a[j + 1]`。当前较大的值会在交换后继续向右参加下一次
比较。

以 `4 2 5 1 3` 为例，第一轮状态依次变为：

```text
4 2 5 1 3
2 4 5 1 3
2 4 5 1 3
2 4 1 5 3
2 4 1 3 5
```

扫描到末尾时，当前范围的最大值 `5` 已经与沿途所有元素比较，并到达最右端。
一轮扫描的作用不是让整个数组立即有序，而是确定当前最右边的一个位置。

## 不断缩小未确定范围

第一轮结束后，`a[n]` 已经正确，不需要再次参与。第二轮只扫描到 `n - 1`，
再下一轮只扫描到 `n - 2`。

令 `end` 表示当前未确定范围的最右位置：

```cpp
for (int end = n; end >= 2; end--) {
    for (int j = 1; j < end; j++) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
        }
    }
}
```

每轮开始前，后缀 `a[end + 1..n]` 已经有序，并且包含整个数组中最大的那些值；
本轮把剩余范围最大值送到 `a[end]`，于是正确后缀向左扩大一格。

这个“正确后缀不断扩大”就是冒泡排序的不变量。当 `end = 2` 的最后一轮完成，
只剩的 `a[1]` 也自然位于正确位置，整个数组有序。

## 提前结束

若一整轮没有发生交换，说明当前未确定前缀中不存在相邻逆序，因此它已经有序。
可以用布尔变量记录本轮是否交换：

```cpp
void bubble_sort(vector<int>& a, int n) {
    for (int end = n; end >= 2; end--) {
        bool swapped = false;

        for (int j = 1; j < end; j++) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }

        if (!swapped) {
            break;
        }
    }
}
```

`swapped` 必须在每一轮开始时重新设为 `false`。若沿用上一轮的 `true`，即使当前
范围已经有序也无法提前结束。

## 正确性

可以按轮数证明不变量。

开始以前，正确后缀为空，不变量自然成立。假设某轮开始前
`a[end + 1..n]` 已经位于最终位置；内层从左到右扫描 `a[1..end]`，较大值不断
向右，因此这个范围的最大值最终到达 `a[end]`。原有后缀没有被修改，于是
`a[end..n]` 成为新的正确后缀。

若某轮没有交换，未确定前缀的所有相邻对都已非递减，可以安全结束。否则循环最终
完成到 `end = 2`，不变量保证全部位置正确。

交换只改变两个原有元素的位置，所以算法不会增加或丢失元素。

## 复杂度

逆序数组需要进行：

$$
(n-1)+(n-2)+\cdots+1=\frac{n(n-1)}2
$$

次相邻比较，并发生同数量级的交换。因此最坏时间复杂度是 $O(n^2)$。

已经有序时，第一轮完成 $n-1$ 次比较后发现没有交换并结束，最好时间复杂度是
$O(n)$。不能据此把冒泡排序整体称为线性算法；未特别说明时仍关注最坏情况。

算法只使用循环变量和一个布尔变量，额外空间复杂度是 $O(1)$，属于原地排序。

## 稳定性

稳定排序会保持关键字相等元素原来的相对顺序。可以把两个相等值暂时标成
`2a`、`2b`：虽然排序只比较数值 `2`，仍希望先出现的 `2a` 排在 `2b` 前。

本篇只在 `a[j] > a[j + 1]` 时交换。相等元素不会互相跨越，因此这份冒泡排序
稳定。若错误地把条件改成 `>=`，相等元素也会交换，稳定性就被破坏。

稳定性属于具体实现，不能只看“冒泡排序”四个字猜测；应检查相等元素是否可能在
操作中改变相对顺序。

## 完整代码

下面的程序使用 1-based 下标和 `+5` 余量排列整数数组：

```cpp
#include <bits/stdc++.h>
using namespace std;

void bubble_sort(vector<int>& a, int n) {
    for (int end = n; end >= 2; end--) {
        bool swapped = false;

        for (int j = 1; j < end; j++) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }

        if (!swapped) {
            break;
        }
    }
}

void solve() {
    int n;
    cin >> n;

    vector<int> a(n + 5);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    bubble_sort(a, n);

    for (int i = 1; i <= n; i++) {
        if (i > 1) {
            cout << ' ';
        }
        cout << a[i];
    }
    cout << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
5
4 2 5 1 3
```

输出：

```text
1 2 3 4 5
```

空数组和单元素数组不会进入外层循环，可以直接得到正确结果。

## 常见错误

### 访问 j + 1 越界

本轮最后一次比较是 `a[end - 1]` 与 `a[end]`，所以条件必须是 `j < end`，
不能写 `j <= end`。

### 每轮仍扫描到 n

已经确定的后缀无需再次参与。虽然一直扫描到 `n` 仍可能排对，但丢失了不变量
表达，也进行了多余比较。

### swapped 没有逐轮清零

它表示“当前这一轮是否交换”，不是整个算法是否曾经交换；必须放在外层循环内部
初始化。

### 把最好情况当成统一复杂度

提前结束让有序输入达到 $O(n)$，但逆序等输入仍需 $O(n^2)$。

### 为稳定实现使用大于等于

使用 `>=` 会让相等元素交换。升序只需修复严格的前大后小关系。
