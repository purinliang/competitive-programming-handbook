# 用归并排序统计逆序对

> 最近修订：2026-08-17 02:18 +10:00（未审阅）

给定数组 `a[1..n]`，若两个位置满足：

$$
i<j\quad\text{并且}\quad a[i]>a[j],
$$

就称 `(i,j)` 是一个逆序对。直接枚举所有位置对需要 $O(n^2)$ 时间；归并排序在
合并两个有序区间时，可以一次统计整批跨越中点的逆序对，把时间降到
$O(n\log n)$。

## 三类位置对

把闭区间 `[l,r]` 分成 `[l,mid]` 与 `[mid+1,r]`。区间内的逆序对只有三类：

1. 两个位置都在左半区；
2. 两个位置都在右半区；
3. 第一个位置在左半区，第二个位置在右半区。

两个递归调用分别统计前两类。合并阶段只需统计跨越中点的第三类。

## 合并时出现了什么信息

递归返回后，两侧已经分别升序。用 `i` 指向左侧当前元素，`j` 指向右侧当前元素。

若：

```cpp
a[i] <= a[j]
```

当前左侧元素不大于右侧最小剩余元素，因此它不会与右侧剩余部分形成逆序对，按普通
归并取走 `a[i]`。

若：

```cpp
a[i] > a[j]
```

左半区已经有序，所以：

```text
a[i], a[i+1], ..., a[mid]
```

全部大于 `a[j]`。这些左侧位置原本都位于 `j` 以前，因此一次形成：

$$
mid-i+1
$$

个新的逆序对。

代码在取走右侧元素时累加：

```cpp
inversion_count += mid - i + 1;
temporary[position++] = a[j++];
```

这就是归并排序能比逐对检查更快的原因：利用两侧有序性，一次确认整段左侧后缀。

## 为什么相等时不计数

逆序对要求严格 `a[i]>a[j]`。当两个值相等时，不构成逆序对，合并条件必须写成：

```cpp
if (a[i] <= a[j])
```

优先取左侧元素既避免把相等值误计为逆序，也继续保持归并排序的稳定性。

## 一个例子

考虑：

```text
3 1 2
```

逆序对是：

```text
(1,2): 3 > 1
(1,3): 3 > 2
```

共两个。

归并最外层合并 `[3]` 与 `[1,2]` 时，右侧先取 `1`，左侧剩余一个元素，增加
`1`；随后右侧取 `2`，再次增加 `1`，得到总数 `2`。

## 完整代码

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

int n;
vector<int> a;
vector<int> temporary;
ll inversion_count;

void merge(int l, int mid, int r) {
    int i = l;
    int j = mid + 1;
    int position = l;

    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            temporary[position++] = a[i++];
        } else {
            inversion_count += mid - i + 1;
            temporary[position++] = a[j++];
        }
    }

    while (i <= mid) {
        temporary[position++] = a[i++];
    }
    while (j <= r) {
        temporary[position++] = a[j++];
    }

    for (int k = l; k <= r; k++) {
        a[k] = temporary[k];
    }
}

void merge_sort(int l, int r) {
    if (l >= r) {
        return;
    }

    int mid = l + (r - l) / 2;
    merge_sort(l, mid);
    merge_sort(mid + 1, r);
    merge(l, mid, r);
}

int main() {
    scanf("%d", &n);

    a.assign(n + 5, 0);
    temporary.assign(n + 5, 0);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }

    inversion_count = 0;
    merge_sort(1, n);
    printf("%lld\n", inversion_count);
    return 0;
}
```

输入：

```text
3
3 1 2
```

输出：

```text
2
```

## 正确性

按照区间长度归纳。长度不超过 `1` 时没有位置对，逆序对数为零。

对更长区间，两个递归调用根据归纳假设准确统计完全位于左右半区的逆序对。合并时：

- 若 `a[i]<=a[j]`，右侧最小剩余值都不小于 `a[i]`，当前左值没有跨区逆序对；
- 若 `a[i]>a[j]`，左侧有序保证 `a[i..mid]` 全部大于 `a[j]`，恰好新增
  `mid-i+1` 对。

每个跨区逆序对会在它的右侧元素被取走时唯一计数，不会重复或遗漏。三类位置对
互斥并覆盖整个区间，所以最终计数正确。

## 复杂度

算法只在普通归并排序的合并分支中增加一次常数时间累加，时间复杂度仍为
$O(n\log n)$，临时数组使用 $O(n)$ 额外空间。

逆序对最多有：

$$
\frac{n(n-1)}2,
$$

即使数组元素使用 `int`，计数也常常需要 `long long`。

## 常见错误

### 增加 `j-i+1`

形成逆序的是左半区尚未取出的 `i..mid`，数量是 `mid-i+1`，与右指针 `j`
没有直接关系。

### 相等时选择右侧并计数

逆序对要求严格大于。相等时必须进入左侧分支，不增加答案。

### 只统计最外层合并

完全位于左半或右半的逆序对不会跨越当前中点，必须由递归调用统计。

### 使用 `int` 保存答案

逆序数组会达到最大逆序对数，平方数量级很容易超过 32 位整数。
