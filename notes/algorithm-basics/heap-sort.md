# 堆排序

> 最近修订：2026-08-16 14:43 +10:00（未审阅）

[二叉堆](binary-heap.md) 能在 $O(1)$ 时间找到当前最大值，并在
$O(\log n)$ 时间删除它。如果不断取出最大值，就能按照从大到小的顺序得到全部
元素。

直接把取出的值放进另一个数组可以完成排序，但需要 $O(n)$ 额外空间。堆排序进一步
利用原数组已经空出来的位置：每次把堆顶最大值交换到当前堆的末尾，再把这个位置
排除在堆外。重复以后，数组右侧会逐渐形成升序排列。

## 两段共用一个数组

设当前仍属于大根堆的闭区间是 `a[1..heap_size]`，它右侧的
`a[heap_size+1..n]` 已经排好序。

初始时还没有元素排好：

```text
堆：a[1..n]    已排序部分：空
```

大根堆的最大值位于 `a[1]`。把它与 `a[heap_size]` 交换：

```cpp
swap(a[1], a[heap_size]);
```

最大值现在位于当前堆的最后一个位置。它不小于堆中任何其他值，因此也不小于已经
排在右侧的值以前取出的下一个最大值。把堆的逻辑长度减一后，这个位置就成为有序
后缀最左边的新元素。

```text
堆：a[1..heap_size - 1]    已排序部分：a[heap_size..n]
```

这里必须区分数组长度 `n` 与堆的逻辑长度 `heap_size`。数组元素没有被删除，只是
边界左移；右侧元素已经确定最终位置，后续下沉不能再访问它们。

## 恢复堆性质

交换前，根以外的父子关系都满足大根堆性质。交换后，原来的末尾元素来到根，它
可能比自己的孩子小；其余节点之间的关系没有改变。

因此只需从根 `u = 1` 开始下沉。与普通二叉堆不同，边界不再使用整个数组长度，
而是使用当前的 `heap_size`：

```cpp
void sift_down(int u, int heap_size) {
    while (u * 2 <= heap_size) {
        int v = u * 2;
        if (v + 1 <= heap_size && a[v + 1] > a[v]) {
            v++;
        }
        if (a[u] >= a[v]) {
            break;
        }
        swap(a[u], a[v]);
        u = v;
    }
}
```

每次选择两个孩子中较大的一个。若 `a[u]` 已经不小于较大孩子，它也不会小于另
一个孩子；否则交换以后，只有被换下去的节点还可能违反堆性质。

下沉最多经过完全二叉树的一条根到叶路径，因此需要 $O(\log n)$ 时间。

## 从底向上建堆

排序开始前，输入数组通常还不是大根堆。叶节点单独看已经满足堆性质，因此从最后
一个非叶节点 `n / 2` 开始倒序下沉：

```cpp
void build_heap() {
    for (int u = n / 2; u >= 1; u--) {
        sift_down(u, n);
    }
}
```

处理节点 `u` 时，它的两个子树已经分别是大根堆；一次下沉就能让以 `u` 为根的
整棵子树成为大根堆。所有节点可下沉层数之和是 $O(n)$，所以建堆总时间是
$O(n)$。

不要把“有 $n$ 个节点，每次下沉最坏 $O(\log n)$”直接乘成建堆复杂度。大部分
节点靠近叶层，只能下沉很少层；$O(n\log n)$ 是逐个调用堆的 `push` 建堆时的
上界，不是这里从底向上建堆的紧确结果。

## 排序过程

建成大根堆后，让 `heap_size` 从 `n` 递减到 `2`：

```cpp
void heap_sort() {
    build_heap();

    for (int heap_size = n; heap_size >= 2; heap_size--) {
        swap(a[1], a[heap_size]);
        sift_down(1, heap_size - 1);
    }
}
```

一次循环结束后：

1. `a[heap_size]` 已经位于最终位置；
2. `a[heap_size..n]` 保持升序；
3. `a[1..heap_size-1]` 重新成为大根堆。

当 `heap_size == 2` 的循环完成后，右侧位置 `2..n` 已经确定，位置 `1` 只剩最小
元素，整个数组升序排列。

## 正确性

可以用有序后缀作为循环不变量。每轮开始时假设：

- `a[1..heap_size]` 是大根堆；
- `a[heap_size+1..n]` 已经升序排列；
- 堆中任意元素都不大于有序后缀中的任意元素。

根节点是堆中最大值。把它交换到 `a[heap_size]` 后，它成为剩余堆与旧后缀之间
正确的分界元素。缩小边界不会改变旧后缀，下沉又恢复剩余部分的大根堆性质，因此
三条条件在下一轮仍成立。

初始建堆时后缀为空，条件成立；循环结束时堆只剩一个元素，后缀覆盖其余位置，
所以整个数组升序排列。

## 复杂度与性质

从底向上建堆需要 $O(n)$ 时间。随后进行 $n-1$ 轮，每轮交换为 $O(1)$，下沉为
$O(\log n)$，总时间为：

$$
O(n)+O(n\log n)=O(n\log n)
$$

这个上界不依赖输入原有顺序，最好、平均和最坏时间都是 $O(n\log n)$。

算法只在原数组内交换元素，并保存少量下标，不建立与 $n$ 同阶的辅助数组，所以
主要额外空间是 $O(1)$。这里不把输入数组本身算作额外空间。

堆排序不稳定。根与末尾的远距离交换可能让两个相等关键字跨越。例如只看关键字的
记录 `2a, 2b, 1`，一次堆顶与末尾交换就可能改变 `2a` 与 `2b` 的相对顺序。需要
稳定排序时不能直接使用这个实现。

堆排序还依赖数组的随机访问：父子节点由下标计算，并且每轮要交换根与当前末尾。
单向链表不能高效完成这些操作，因此并不适合照搬数组堆排序。

## 完整代码

下面的程序对 1-based 数组 `a[1..n]` 升序排序。`a` 与 `n` 是题目级共享状态；
`u`、`v` 和 `heap_size` 只描述当前下沉或当前堆边界，因此保留为局部状态。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> a;

void sift_down(int u, int heap_size) {
    while (u * 2 <= heap_size) {
        int v = u * 2;
        if (v + 1 <= heap_size && a[v + 1] > a[v]) {
            v++;
        }
        if (a[u] >= a[v]) {
            break;
        }
        swap(a[u], a[v]);
        u = v;
    }
}

void build_heap() {
    for (int u = n / 2; u >= 1; u--) {
        sift_down(u, n);
    }
}

void heap_sort() {
    build_heap();

    for (int heap_size = n; heap_size >= 2; heap_size--) {
        swap(a[1], a[heap_size]);
        sift_down(1, heap_size - 1);
    }
}

void solve() {
    cin >> n;

    a.assign(n + 5, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    heap_sort();

    for (int i = 1; i <= n; i++) {
        if (i > 1) {
            cout << ' ';
        }
        cout << a[i];
    }
    cout << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
7
4 10 3 5 1 8 2
```

输出：

```text
1 2 3 4 5 8 10
```

空数组和只有一个元素的数组都不进入排序循环；重复值可以正确排序，但不保证原
相对顺序。

## 实际比赛中的选择

只需要给数组排序时，优先使用标准库的 `sort`。它经过充分优化，接口更短，也不
需要自己维护堆边界。

堆排序值得学习的原因是：它把二叉堆的局部不变量转化成完整排序，提供确定的
$O(n\log n)$ 最坏时间和 $O(1)$ 主要额外空间。题目要求手写堆排序、需要分析排序
性质，或者某个算法本身要维护动态最值时，这些推导才会直接发挥作用。
