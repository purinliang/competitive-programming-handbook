# 递推

> 最近修订：2026-08-15 20:49 +10:00（未审阅）

一个培养皿在第 $1$ 天有 $1$ 个细菌。此后每天开始时，每个细菌都会分裂成两个，实验员再放入 $3$ 个新细菌。给定天数 $n$，求第 $n$ 天结束时培养皿中的细菌数量。

题目描述的是一个从前一天产生后一天的过程。若逐个模拟每个细菌，数量增长后需要处理大量完全相同的个体；我们真正关心的只有每天结束时的总数。

## 每天的细菌数量

为了准确描述“前一天”和“后一天”，定义：

$$
a[i]=\text{第 }i\text{ 天结束时的细菌数量}.
$$

题目给出的第一天数量直接成为初始值：

$$
a[1]=1.
$$

到了第 $i$ 天，原有的 `a[i - 1]` 个细菌分别分裂成两个，然后又加入 $3$ 个，因此：

$$
a[i]=2a[i-1]+3 \qquad (i\ge 2).
$$

这个用较早项表示较晚项的等式称为递推关系。`a[1]` 决定从哪里开始，递推关系决定怎样得到后续每一项；缺少任何一部分，都不能唯一确定整个数列。

## 按依赖顺序计算

计算 `a[i]` 时必须先知道 `a[i - 1]`。因此从已经确定的 `a[1]` 出发，按照 `2, 3, ..., n` 的顺序计算：

```cpp
vector<ll> a(n + 5, 0);
a[1] = 1;

for (int i = 2; i <= n; i++) {
    a[i] = 2 * a[i - 1] + 3;
}
```

本书自定义的数列使用 1-based 下标，所以第 $i$ 天直接对应 `a[i]`。位置 `0` 没有参与本题递推，保持为初始化后的 `0`。

不能在同一个循环中从大到小计算。第一次计算 `a[n]` 时，`a[n - 1]` 还没有产生，读到的只会是初始化值，而不是前一天的真实数量。

## 手动递推

当 $n=5$ 时，计算过程为：

| `i` | 已知的 `a[i - 1]` | `a[i] = 2 * a[i - 1] + 3` |
| ---: | ---: | ---: |
| 1 | — | 1 |
| 2 | 1 | 5 |
| 3 | 5 | 13 |
| 4 | 13 | 29 |
| 5 | 29 | 61 |

每一行只依赖上一行已经得到的结果。手算前几项可以同时检查初始值、循环起点和递推式是否写对。

## 为什么不模拟每个细菌

若真的为每个细菌保存一个对象，第 $i$ 天需要遍历当天已有的全部细菌。细菌数量本身呈指数增长，程序所做的工作也会迅速增加。

但同一天的细菌对后续过程没有区别：每个都会分裂一次。只保存总数后，一天的全部变化可以用一次乘法和一次加法完成。程序计算 $n$ 天只需进行 $n-1$ 次相同更新。

递推经常利用这种信息压缩：不保存产生当前状态的全部细节，只保存足以得到下一步的汇总量。

## 正确性

可以按照天数归纳证明数组中的结果正确。

第 $1$ 天结束时题目明确有 $1$ 个细菌，所以 `a[1] = 1` 正确。

假设 `a[i - 1]` 已经等于第 $i-1$ 天结束时的真实数量。第 $i$ 天每个原有细菌分裂成两个，共有 `2 * a[i - 1]` 个，再加入 $3$ 个，得到 `2 * a[i - 1] + 3` 个。因此递推式计算出的 `a[i]` 也正确。

循环从第 $2$ 天依次计算到第 $n$ 天，所以最终 `a[n]` 就是题目要求的答案。

## 完整代码

输入保证 `1 <= n <= 61`，所有中间结果和答案都能用 64 位整数保存。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int main() {
    int n;
    scanf("%d", &n);

    vector<ll> a(n + 5, 0);
    a[1] = 1;

    for (int i = 2; i <= n; i++) {
        a[i] = 2 * a[i - 1] + 3;
    }

    printf("%lld\n", a[n]);
    return 0;
}
```

输入：

```text
5
```

输出：

```text
61
```

## 复杂度与空间

循环计算 `a[2..n]`，每一项只进行固定次数的整数运算，所以时间复杂度是 $O(n)$。数组保存 `a[1..n]`，空间复杂度是 $O(n)$。

本题的下一项只依赖上一项，也可以只保存一个变量，把额外空间降为 $O(1)$。这里保留完整数组，是为了让 `a[i]` 与“第 $i$ 天的答案”始终一一对应，并能直接查看任意一天的中间结果。

## 递推、递归与动态规划

递推关系是不同项之间的数学依赖，例如 `a[i] = 2 * a[i - 1] + 3`；递归是函数直接或间接调用自身的程序结构。一个递推关系既可以用循环计算，也可能被写成递归函数，两者不是同一个概念。

[动态规划：状态与转移](../dynamic-programming/dp-state-transition.md) 还需要从问题中设计状态、推导转移，并合并重复子问题。本题已经直接给出了唯一的递推过程，不需要在多个选择中寻找状态，因此先把它看作普通递推即可。
