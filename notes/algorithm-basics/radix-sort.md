# 基数排序

> 最近修订：2026-08-17 00:34 +10:00（未审阅）

比较排序通过比较完整数值决定先后。[计数排序](counting-sort.md) 则为值域中的每个整数准备位置；当最大值很大时，频次数组可能无法承受。

如果整数可以拆成少量数位，我们还能每次只处理一个数位。例如十进制整数可以依次按照个位、十位、百位整理。只要每一趟保持前面已经建立的顺序，处理完所有数位后就能得到完整排序。

这种方法称为**基数排序**。本篇推导从最低位到最高位的 LSD（Least Significant Digit first）基数排序，并把输入限制为非负整数。

## 为什么从最低位开始

考虑：

```text
21 13 12
```

先按个位排序：

```text
21 12 13
```

再按十位排序时，`12` 与 `13` 的十位相同。若这一趟保持它们原来的相对顺序，就得到：

```text
12 13 21
```

十位决定更高层的分组；十位相同时，上一趟建立的个位顺序继续有效。因此，从低位到高位处理时，每一趟必须使用**稳定排序**。

若十位排序把相同十位的 `12` 和 `13` 随意交换，个位的工作就会被破坏，最终结果不一定有序。

## 取出一个十进制数位

令 `place` 表示当前位权：

- 个位是 `1`；
- 十位是 `10`；
- 百位是 `100`。

非负整数 `value` 在这一位的数字是：

```cpp
int digit = value / place % 10;
```

例如 `value = 347`：

| `place` | 表达式 | 数位 |
| ---: | --- | ---: |
| `1` | `347 / 1 % 10` | `7` |
| `10` | `347 / 10 % 10` | `4` |
| `100` | `347 / 100 % 10` | `3` |

高于最高有效位时，整数除法得到 `0`。例如 `47` 的百位视为 `0`，所以短数会自然排在同高位的长数以前。

## 用计数排序处理一位

一位十进制数字只有 `0..9` 共十种可能，可以使用稳定计数排序完成一趟。

本书自定义数组预留第 `0` 格，所以把数字 `digit` 映射到：

```cpp
int index = digit + 1;
```

`count[1..10]` 分别对应数字 `0..9`。

先统计每个数位出现次数：

```cpp
for (int i = 1; i <= n; i++) {
    int digit = a[i] / place % 10;
    count[digit + 1]++;
}
```

再求前缀和。此后 `count[index]` 表示数位不大于当前数字的元素数量，也就是这一组最后可以写到的位置：

```cpp
for (int index = 2; index <= 10; index++) {
    count[index] += count[index - 1];
}
```

## 为什么要从右向左放入

为了保持稳定性，恢复输出数组时从原数组右端向左处理：

```cpp
for (int i = n; i >= 1; i--) {
    int digit = a[i] / place % 10;
    int index = digit + 1;
    output[count[index]] = a[i];
    count[index]--;
}
```

同一数位的一组位置从右端向左分配。原数组中靠后的元素先占据这一组靠后的位置，原来靠前的元素随后占据更前的位置，因此相同数位元素的相对顺序不变。

如果从左向右读取，却仍然从组尾递减写入，就会把相同数位元素的顺序反转，破坏上一趟已经排好的低位。

一趟结束后，把 `output[1..n]` 复制回 `a[1..n]`。

## 逐位处理

先求数组最大值 `max_value`。只要当前位权没有超过它的最高有效位，就执行一趟：

```cpp
for (ll place = 1; max_value / place > 0; place *= 10) {
    counting_sort_by_digit(place);
}
```

当所有值都是 `0` 时，循环不会执行，原数组本来就已经有序。

`place` 使用 64 位整数。即使输入元素是 32 位非负整数，处理十亿位后再乘以 `10` 也不会立刻超出 64 位范围。

## 正确性

处理完个位后，数组按照最低一位有序。

假设处理完前 $k$ 位后，数组已经按照这 $k$ 位组成的低位部分有序。第 $k+1$ 趟按更高一位稳定排序：

- 更高位不同的数按照这一位确定先后；
- 更高位相同的数保持上一趟相对顺序，所以仍按低 $k$ 位有序。

因此处理完第 $k+1$ 位后，数组按照低 $k+1$ 位有序。处理完最大值的全部数位后，这些数位已经覆盖完整数值，数组整体有序。

## 复杂度

设：

- $n$ 是元素数量；
- $d$ 是最大值的十进制位数；
- $b=10$ 是每一位可能的数字数量。

每一趟统计、前缀和、稳定放置与复制需要 $O(n+b)$ 时间，共 $d$ 趟：

$$
O\bigl(d(n+b)\bigr).
$$

十进制下 $b=10$ 是常数，常写成 $O(dn)$。额外输出数组需要 $O(n)$ 空间，计数数组需要 $O(b)$ 空间。

这不是“不考虑数值大小的严格 $O(n)$”。数位数量 $d$ 仍由最大值和选择的基数决定。改用更大的基数可以减少趟数，却会增加每一趟计数数组大小。

## 为什么只处理非负整数

普通十进制取位公式直接适用于非负整数。负数的符号与 C++ 负数除法、取余行为会让简单的 `0..9` 桶顺序失去预期含义。

可以把负数和非负数分开处理，再按照绝对值和符号规则合并；也可以对固定位宽的无符号表示设计专门顺序。但这会增加另一层转换，不属于本篇基础模板。

题目含负数且没有明确需要基数排序时，优先使用可靠的 `sort`。

## 完整代码

下面对 1-based 非负 `int` 数组进行十进制 LSD 基数排序。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int n;
vector<int> a;
vector<int> output;

void counting_sort_by_digit(ll place) {
    int count[15] = {};

    for (int i = 1; i <= n; i++) {
        int digit = a[i] / place % 10;
        count[digit + 1]++;
    }

    for (int index = 2; index <= 10; index++) {
        count[index] += count[index - 1];
    }

    for (int i = n; i >= 1; i--) {
        int digit = a[i] / place % 10;
        int index = digit + 1;
        output[count[index]] = a[i];
        count[index]--;
    }

    for (int i = 1; i <= n; i++) {
        a[i] = output[i];
    }
}

void radix_sort() {
    int max_value = 0;

    for (int i = 1; i <= n; i++) {
        max_value = max(max_value, a[i]);
    }

    for (ll place = 1; max_value / place > 0; place *= 10) {
        counting_sort_by_digit(place);
    }
}

void solve() {
    cin >> n;

    a.assign(n + 5, 0);
    output.assign(n + 5, 0);

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    radix_sort();

    for (int i = 1; i <= n; i++) {
        if (i > 1) {
            cout << ' ';
        }
        cout << a[i];
    }
    cout << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
8
170 45 75 90 802 24 2 66
```

输出：

```text
2 24 45 66 75 90 170 802
```
