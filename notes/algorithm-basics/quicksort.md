# 快速排序

> 最近修订：2026-08-16 18:04 +10:00（未审阅）

[冒泡排序](bubble-sort.md)、[选择排序](selection-sort.md) 和
[插入排序](insertion-sort.md) 的最坏时间复杂度都是 $O(n^2)$。要得到更快的
一般排序，可以不再每次只确定一个位置，而是把整个区间分成两部分，再分别解决
规模更小的同类问题。

快速排序选择一个基准值，把不大于基准的元素放到左侧、不小于基准的元素放到右侧，然后递归排序左右两个子区间。

## 分治结构

对闭区间 `a[l..r]` 排序，可以分成三步：

1. 选择一个基准值 `pivot`；
2. 重新排列区间，并找到分界 `j`，使 `a[l..j]` 中的值都不大于 `pivot`，`a[j+1..r]` 中的值都不小于 `pivot`；
3. 分别排序 `a[l..j]` 和 `a[j+1..r]`。

当区间只有零个或一个元素，也就是 `l >= r` 时，它本来就有序，递归立即停止：

```cpp
if (l >= r) {
    return;
}
```

这种“把问题划分成若干更小的同类问题，分别解决后得到整体答案”的方法称为分治。

## 选择基准值

本篇选取区间中间位置的元素值：

```cpp
int pivot = a[l + (r - l) / 2];
```

写成 `l + (r - l) / 2` 避免直接计算 `l + r`。`pivot` 保存的是一个数值，不是固定不动的下标；分区交换可能让原来的中间元素移动，但后续比较仍然使用已经保存的值。

从区间内部选择基准还有一个重要作用：左指针向右寻找时，至少会在某个等于 `pivot` 的元素处停下；右指针同理，不会越过整个合法区间。

选择中间位置不代表每次都能把数值均匀分半。某些输入中，中间元素仍可能是极大值或极小值；基准选择会直接影响快速排序的性能。

## 两端寻找放错的元素

令指针 `i` 从左边界外 `l-1` 开始，`j` 从右边界外 `r+1` 开始：

```cpp
int i = l - 1;
int j = r + 1;
```

每轮先让 `i` 至少向右移动一次，再跳过所有严格小于 `pivot` 的值：

```cpp
do {
    i++;
} while (a[i] < pivot);
```

停止时，`a[i] >= pivot`。它不能继续留在希望“不大于基准”的左侧，可能需要与右边交换。

同理，让 `j` 至少向左移动一次，再跳过所有严格大于 `pivot` 的值：

```cpp
do {
    j--;
} while (a[j] > pivot);
```

停止时，`a[j] <= pivot`。如果 `i < j`，左右各找到了一个位于错误一侧的元素，交换它们：

```cpp
if (i < j) {
    swap(a[i], a[j]);
}
```

然后继续下一轮，从交换位置的内侧再次寻找。

## 为什么使用严格比较

扫描条件必须是 `< pivot` 和 `> pivot`，不能跳过所有等于基准的元素。大量元素都等于 `pivot` 时，两个指针仍要在每轮至少移动一次，才能互相靠近并结束。

例如数组全部是 `5`：

- `i` 每轮向右移动一格后立即停下；
- `j` 每轮向左移动一格后立即停下；
- 若二者尚未相遇，就交换两个相等值；
- 下一轮继续向内移动。

交换相等值看起来没有改变数组，却保证了分区过程取得进展。若指针在等于基准处停住后既不交换也不移动，循环会永远停在同一位置。

## 一次分区

完整分区循环是：

```cpp
while (i < j) {
    do {
        i++;
    } while (a[i] < pivot);

    do {
        j--;
    } while (a[j] > pivot);

    if (i < j) {
        swap(a[i], a[j]);
    }
}
```

以 `5 1 4 2 3` 为例，`pivot = 4`：

| 状态 | `i` 停在 | `j` 停在 | 操作 | 数组 |
| --- | ---: | ---: | --- | --- |
| 初始 |  |  |  | `5 1 4 2 3` |
| 第一轮 | 1 | 5 | 交换 | `3 1 4 2 5` |
| 第二轮 | 3 | 4 | 交换 | `3 1 2 4 5` |
| 第三轮 | 4 | 3 | 停止 | `3 1 2 4 5` |

退出时 `j = 3`。左区间 `a[1..3]` 的值都不大于 `4`，右区间 `a[4..5]` 的值都不小于 `4`。

## 分区不变量

每轮扫描开始前，可以确认：

- `a[l..i]` 中已经处理的值都不大于 `pivot`；
- `a[j..r]` 中已经处理的值都不小于 `pivot`；
- 尚未确定的元素位于两个指针之间。

扫描会跳过已经位于正确一侧的值；交换后，两个停止位置也分别满足左侧不大于、
右侧不小于。下一轮先移动指针，因此已经处理的范围不断向中间扩大。

退出时两个指针相遇或交错，可以得到需要的左右分区：

$$
a[l..j]\le\text{pivot},\qquad a[j+1..r]\ge\text{pivot}
$$

这并不表示左区间内部已经有序，也不表示基准值最终停在 `j`。分区只建立“左边不大于、右边不小于”的关系，内部顺序交给递归继续处理。

## 递归两个子区间

分区结束后，递归调用必须与分界定义完全一致：

```cpp
quick_sort(l, j);
quick_sort(j + 1, r);
```

不能把同一套分区循环随意改成 `[l,i-1]` 与 `[i,r]`，也不能漏掉或重复中间元素。分区方式、退出条件和递归边界是一整套约定。

数组 `a` 是整道题共享的状态，放在全局；`l`、`r` 只描述当前递归调用负责的
区间，因此继续作为参数。完整函数是：

```cpp
vector<int> a;

void quick_sort(int l, int r) {
    if (l >= r) {
        return;
    }

    int pivot = a[l + (r - l) / 2];
    int i = l - 1;
    int j = r + 1;

    while (i < j) {
        do {
            i++;
        } while (a[i] < pivot);

        do {
            j--;
        } while (a[j] > pivot);

        if (i < j) {
            swap(a[i], a[j]);
        }
    }

    quick_sort(l, j);
    quick_sort(j + 1, r);
}
```

因为 `pivot` 来自当前非空区间，两侧扫描都有停止位置；当 `l < r` 时，得到的两个递归区间都严格小于原区间，递归最终会到达 `l >= r`。

## 正确性

可以按照区间长度理解正确性：

- 长度不超过 $1$ 的区间已经有序；
- 对更长区间，一次分区保证左侧所有值不大于基准、右侧所有值不小于基准；
- 假设两个更短子区间经过递归后各自有序；
- 左区间的任意值都不大于 `pivot`，右区间的任意值都不小于 `pivot`，因此左区间
  任意值都不大于右区间任意值；连接两个有序子区间后，整个区间有序。

分区只交换原有元素，递归也只在原数组中继续交换，所以不会增加或丢失元素。

## 时间复杂度

一次分区中，`i` 只向右、`j` 只向左，总共扫描 $O(r-l+1)$ 个位置。

如果每次分区都大致均衡，递归层数是 $O(\log n)$。同一层的所有区间总长度是 $O(n)$，因此平均时间复杂度是：

$$
O(n\log n)
$$

如果每次都极不均衡，只分出长度 $1$ 和长度 $n-1$ 的部分，递归会有 $O(n)$ 层，每层仍可能扫描线性区间，最坏时间退化为 $O(n^2)$。

选择中间位置只能避免某些简单输入直接导致坏分区，不能消除最坏情况。实际比赛中的一般排序优先使用经过充分实现和保护的 `std::sort`，不应仅为了“快速排序名字很快”就替换标准库。

## 空间复杂度

分区直接交换原数组元素，只使用 `pivot,i,j` 等固定变量，单次调用的额外空间是 $O(1)$。

递归调用栈仍然要计入空间。分区均衡时递归深度是 $O(\log n)$；极端不均衡时深度可能达到 $O(n)$，既增加空间，也可能超过竞赛环境的调用栈限制。

因此本篇实现的平均额外空间是 $O(\log n)$，最坏额外空间是 $O(n)$。这里的空间来自递归层数，不是另建了一个长度为 $n$ 的辅助数组。

## 稳定性

分区会交换相距很远的元素。两个相等关键字的记录可能在交换中改变相对顺序，因此快速排序通常不稳定。

可以设计额外存储来维持稳定分区，但那会改变本篇原地快速排序的结构和成本。需要稳定性时，应根据题目直接选择稳定排序方法，而不是强行改造这份基础实现。

## 完整代码

下面的程序读入 $n$ 个整数并使用 1-based 闭区间快速排序。空数组调用
`quick_sort(1, 0)` 时会立即返回。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> a;

void quick_sort(int l, int r) {
    if (l >= r) {
        return;
    }

    int pivot = a[l + (r - l) / 2];
    int i = l - 1;
    int j = r + 1;

    while (i < j) {
        do {
            i++;
        } while (a[i] < pivot);

        do {
            j--;
        } while (a[j] > pivot);

        if (i < j) {
            swap(a[i], a[j]);
        }
    }

    quick_sort(l, j);
    quick_sort(j + 1, r);
}

void solve() {
    scanf("%d", &n);

    a.assign(n + 5, 0);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }

    quick_sort(1, n);

    for (int i = 1; i <= n; i++) {
        if (i > 1) {
            printf(" ");
        }
        printf("%d", a[i]);
    }
    printf("\n");
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
8
5 1 4 2 3 3 -1 8
```

输出：

```text
-1 1 2 3 3 4 5 8
```

## 常见错误

### 只交换但不推进指针

本篇使用 `do...while`，每轮扫描都会先让 `i`、`j` 至少移动一次。大量元素等于基准时也能继续前进。

### 扫描条件包含等号

使用 `a[i] <= pivot` 或 `a[j] >= pivot` 可能让指针越过用于保证停止的基准值，访问区间外位置。等于基准时应当停止扫描，由交换和下一轮推进指针。

### 把 pivot 当成最终下标

`pivot` 是保存下来的数值，分区过程中对应元素可能移动。分区后不能假设它位于 `j` 或 `j+1`。

### 混用另一套递归边界

本篇分区退出后递归 `[l,j]` 与 `[j+1,r]`。复制另一份代码中的 `i-1`、`i` 边界而不同时更换分区规则，可能漏排、重复或无限递归。

### 忘记最坏情况

快速排序平均很快，但最坏仍是 $O(n^2)$，递归深度也可能达到 $O(n)$。提交普通排序题时优先使用 `sort`。
