# 二分查找

> 最近修订：2026-08-16 13:00 +10:00（未审阅）

在无序数组中寻找目标值，最直接的方法是从左到右逐个检查，最坏需要 $O(n)$
时间。若数组已经按升序排列，一次比较不仅能判断中间元素是否等于目标，还能证明
中点某一侧的全部位置都不可能是答案。

二分查找反复检查候选区间中点，并在每轮排除至少一半位置，把查找时间降低到
$O(\log n)$。本篇只解决“找到任意一个等于目标的位置”；重复值的左右边界留到
下一篇单独推导。

## 有序是前提

考虑升序数组：

```text
1 3 4 7 9 12 15
```

寻找 `9` 时，先检查中间的 `7`。因为 `7 < 9`，中点及其左边的所有值都不可能
等于 `9`，可以一次排除前四个位置。

若数组无序，例如：

```text
1 12 4 7 3 9 15
```

中点 `7 < 9` 并不能说明目标只在右边，左侧仍可能存在 `9`。没有顺序关系，就
无法从一次比较推出整段位置都能排除。

如果只查找一次而数据原本无序，先排序需要 $O(n\log n)$，通常还不如一次
$O(n)$ 顺序查找。排序后二分的价值在于同一组数据需要处理许多次查询，或数据本来
就已经有序。

## 候选闭区间

本篇使用 1-based 数组和闭区间 `[l,r]` 表示仍可能包含目标的位置。开始时所有
逻辑元素都是候选：

```cpp
int l = 1;
int r = n;
```

循环保持以下不变量：如果目标存在且尚未返回，那么至少一个目标位置仍在
`a[l..r]` 中。

闭区间在 `l <= r` 时非空，所以循环条件是：

```cpp
while (l <= r) {
```

只剩一个位置，即 `l == r` 时，仍然必须检查它。

## 计算中点

中点写作：

```cpp
int mid = l + (r - l) / 2;
```

这里 `r - l` 非负，整数除以 `2` 相当于向下取整，因此 `mid` 落在 `[l,r]` 中。
写成 `l + (r - l) / 2` 还避免了 `(l + r) / 2` 先计算 `l + r` 可能产生的整数
溢出。

竞赛中常见的 `l + r >> 1` 会按 `(l + r) >> 1` 解析，但它仍可能先让 `l + r`
溢出，而且读者还要额外记住移位优先级。本书统一使用更清晰的安全写法。

## 排除中点与一侧

比较 `a[mid]` 与 `target`，只有三种情况。

若相等，已经找到一个合法位置：

```cpp
if (a[mid] == target) {
    return mid;
}
```

若 `a[mid] < target`，升序保证 `a[l..mid]` 都小于目标，可以全部排除：

```cpp
l = mid + 1;
```

若 `a[mid] > target`，升序保证 `a[mid..r]` 都大于目标：

```cpp
r = mid - 1;
```

更新必须排除已经检查过的 `mid`。若写成 `l = mid`，当候选只剩两个位置且
`mid == l` 时，左边界不会改变，循环可能永远重复。

## 完整查找函数

```cpp
int binary_search_index(const vector<int>& a, int n, int target) {
    int l = 1;
    int r = n;

    while (l <= r) {
        int mid = l + (r - l) / 2;

        if (a[mid] == target) {
            return mid;
        }
        if (a[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }

    return -1;
}
```

每轮只删除已由有序性证明不可能包含目标的位置，所以候选不变量继续成立。循环
结束时 `l > r`，候选区间为空；若目标存在就会违背不变量，因此返回 `-1` 正确。

`-1` 不可能是 1-based 合法下标，适合表示没有找到。它只是本函数的接口约定，
调用者应先判断结果，再访问数组。

## 重复值

对数组：

```text
1 3 3 3 7
```

查找 `3` 可能返回下标 `2`、`3` 或 `4`，取决于每轮中点。本篇只承诺找到任意一个
相等位置，不承诺第一次或最后一次出现位置。

若题目需要第一个不小于目标、第一个大于目标、最后一个不大于目标，或者统计重复
次数，就不能在第一次相等时返回。它们共享“继续向某一侧寻找边界”的结构，但循环
不变量与本篇的任意位置查找不同，因此单独学习。

## 复杂度

长度为 $n$ 的候选区间每轮最多保留约一半：

$$
n,\frac n2,\frac n4,\ldots,1.
$$

经过 $O(\log n)$ 轮后候选为空或已经找到目标。每轮只做常数次比较与赋值，所以
时间复杂度是 $O(\log n)$，额外空间复杂度是 $O(1)$。

若需要先排序，排序成本是 $O(n\log n)$；之后每次查询是 $O(\log n)$。对 $q$ 次
查询，总时间为：

$$
O(n\log n+q\log n).
$$

是否值得先排序还要考虑排序会改变原位置。若题目最终需要返回输入时的下标，就要
同时保存原编号，不能把排序后的位置误当成原位置。

## 完整代码

下面的程序读入一个已经非递减排列的 1-based 数组和目标值，输出任意一个目标
下标；不存在时输出 `-1`：

```cpp
#include <bits/stdc++.h>
using namespace std;

int binary_search_index(const vector<int>& a, int n, int target) {
    int l = 1;
    int r = n;

    while (l <= r) {
        int mid = l + (r - l) / 2;

        if (a[mid] == target) {
            return mid;
        }
        if (a[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }

    return -1;
}

void solve() {
    int n, target;
    cin >> n >> target;

    vector<int> a(n + 5);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    cout << binary_search_index(a, n, target) << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
7 9
1 3 4 7 9 12 15
```

输出：

```text
5
```

空数组会以 `l = 1,r = 0` 开始，循环不执行并返回 `-1`。

## 常见错误

### 在无序数组上二分

没有顺序或单调性质时，中点比较不能排除整侧。先确认前置条件，而不是看到“查找”
就套二分。

### 把闭区间循环写成 l < r

`[l,r]` 的两个端点都属于候选，只剩一个位置时仍要检查，因此非空条件是
`l <= r`。

### 更新后仍保留 mid

已经证明中点不等于目标后，必须使用 `mid + 1` 或 `mid - 1` 把它排除。否则候选
区间可能不再缩小。

### 期待返回重复值的固定位置

相等时立即返回只能保证任意一个位置。边界问题需要另一套继续搜索的循环不变量。

### 忘记检查 -1

返回值为 `-1` 时目标不存在，不能继续访问 `a[-1]`。

### 混淆排序后位置与原位置

二分返回的是当前有序数组下标。若数组是排序副本，还需通过保存的原编号恢复输入
位置。
