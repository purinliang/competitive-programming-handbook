# Notes

这里保存算法竞赛教程正文及其长期图示。模块目录适合独立查阅，学习路线适合连续教学；两者可以复用正文，也可以在教学目标不同时使用独立版本：

- [按模块浏览](catalog.md)：完整知识注册表，同时收录核心教程与可选扩展。
- [按学习路线浏览](learning-path.md)：从 C++ 基础到高中进阶的七章主线，并在文末索引全部扩展阅读。

教程自己定义的数组、数据结构、图和树默认使用 1-based 下标；原生 `string` 的字符位置保留 0-based。完整规则见学习路线中的 [下标约定](learning-path.md#下标约定) 和 [区间约定](learning-path.md#区间约定)。

## 编号与目录

学习路线使用六位 `CCUUPP` 文章 ID，分别表示两位章号、单元号和篇序。例如 `030405` 表示第 03 章第 04 单元的第 05 篇。文件名另行使用不带 ID 的英文语义路径；完整规则见 [文章编号与语义路径](../docs/article-identity.md)。

模块目录包括 `cpp/`、`algorithm-basics/`、`data-structures/`、`graph-theory/`、`math/`、`computational-geometry/`、`dynamic-programming/` 和 `strings/`。计划节点只登记在模块目录中；开始起草时再创建文件。

## 写作与检查

新增或修订教程前先阅读 [写作与协作规范](AGENTS.md)。规范定义了核心与扩展的边界、文章完成标准、待审阅与已审阅的协作流程，以及 SVG/YAML 资产位置。

修改知识目录、学习路线、文章状态或长期图片后运行：

```bash
make notes-check
```

该检查会验证目录字段、七章核心覆盖、扩展索引顺序、正文状态、内部资源链接和 SVG 来源。模块目录是唯一注册表，不在本页重复维护文章清单。
