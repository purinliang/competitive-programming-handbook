# Notes

这里保存算法竞赛教程正文及其长期图示。模块目录适合独立查阅，学习路线适合连续教学；两者可以复用正文，也可以在教学目标不同时使用独立版本：

- [按模块浏览](catalog.md)：完整知识注册表，同时收录核心教程与可选扩展。
- [按学习路线浏览](learning-path.md)：从 C++ 基础到高中进阶的六阶段主线，并在文末索引全部扩展阅读。

教程自己定义的数据默认使用 1-based 下标、闭区间和 `+5` 容量余量；直接对接 C++ / STL 时保留其原生约定。完整规则见学习路线中的 [下标与区间约定](learning-path.md#下标与区间约定)。

## 编号与目录

正文文件使用四位 ID：前两位表示模块，后两位表示篇。例如 `0304` 是数据结构模块的第 4 篇。大纲首次审核通过后 ID 保持稳定；ID 不代表学习先后，调整路线时不重命名正文。

模块目录包括 `cpp/`、`algorithm-basics/`、`data-structures/`、`graph-theory/`、`math/`、`computational-geometry/`、`dynamic-programming/` 和 `strings/`。计划节点只登记在模块目录中；开始起草时再创建文件。

## 写作与检查

新增或修订教程前先阅读 [写作与协作规范](AGENTS.md)。规范定义了核心与扩展的边界、文章完成标准、待审阅与已审阅的协作流程，以及 SVG/YAML 资产位置。

修改知识目录、学习路线、文章状态或长期图片后运行：

```bash
make notes-check
```

该检查会验证目录字段、六阶段核心覆盖、扩展索引顺序、正文状态、内部资源链接和 SVG 来源。模块目录是唯一注册表，不在本页重复维护文章清单。
