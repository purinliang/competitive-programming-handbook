# Notes

这里保存算法竞赛教程正文及其长期图示。每个知识点只有一份正文，两个入口从不同角度指向同一批文件：

- [按模块浏览](CATALOG.md)：完整知识注册表，同时收录核心教程与可选扩展。
- [按学习路线浏览](LEARNING-PATH.md)：从 C++ 基础到约 Codeforces 2100 的分阶段主线，只收录核心教程。

## 编号与目录

正文文件使用四位 ID：前两位表示模块，后两位表示篇。例如 `0304` 是数据结构模块的第 4 篇。大纲首次审核通过后 ID 保持稳定；ID 不代表学习先后，调整路线时不重命名正文。

模块目录包括 `cpp/`、`algorithm-basics/`、`data-structures/`、`graph-theory/`、`math/`、`computational-geometry/`、`dynamic-programming/` 和 `strings/`。计划节点只登记在模块目录中；开始起草时再创建文件。

## 写作与检查

新增或修订教程前先阅读 [写作与协作规范](AGENTS.md)。规范定义了核心与扩展的边界、文章完成标准、草稿到固化的协作流程，以及 SVG/YAML 资产位置。

修改知识目录、学习路线、文章状态或长期图片后运行：

```bash
make notes-check
```

该检查会验证目录字段、文件级依赖 DAG、主线拓扑顺序、正文元数据、内部资源链接和 SVG 来源。模块目录是唯一注册表，不在本页重复维护文章清单。
