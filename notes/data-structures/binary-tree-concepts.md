# 二叉树的基本概念

> 最近修订：2026-08-16 16:20 +10:00（未审阅）

[有根树](../graph-theory/rooted-trees.md) 可以让一个节点拥有任意多个孩子。很多数据
结构却需要在每个节点固定保留两个不同的位置：左边的位置和右边的位置。二叉树正是
把这种顺序写进结构本身的树。

## 二叉树

二叉树（binary tree）可以递归地定义为：一棵二叉树要么为空，要么由一个根节点、
一棵左子树和一棵右子树组成；左、右子树本身也都是二叉树。

因此每个节点最多有两个子节点，分别称为左子节点（left child）和右子节点
（right child）。这两个位置并不等价：

- 只有左子节点；
- 只有右子节点；
- 同时具有左、右子节点。

前两种情况是两棵不同的二叉树。交换一个节点的左、右子树，通常也会得到另一棵
二叉树。普通有根树只记录孩子关系；二叉树还记录孩子所在的左、右位置，所以它是
一种有顺序的树形结构。

> 二叉树限制的是子节点数量，不是把它看作无向图时的度数。非根节点还与父节点
> 相连，因此在对应的无向图中最多可以连接三条边。

## 叶节点与内部节点

没有左、右子节点的节点称为叶节点（leaf node）。至少有一个子节点的节点称为内部
节点（internal node）。节点在有根树中的深度、树的高度等概念沿用
[有根树](../graph-theory/rooted-trees.md) 的约定。

二叉树节点的孩子数量只能是 `0`、`1` 或 `2`。后面的几类特殊二叉树，正是对这些
数量以及各层排列方式继续增加限制。

## 完整二叉树

完整二叉树（full binary tree，也称 proper binary tree）要求每个节点的孩子数量
只能是 `0` 或 `2`。换句话说，每个内部节点必须同时具有左、右两个子节点。

它不要求所有叶节点位于同一层。例如根的左孩子可以是叶节点，右子树仍然可以继续
向下生长；只要不存在恰好只有一个孩子的节点，它仍然是完整二叉树。

## 完全二叉树

完全二叉树（complete binary tree）要求：

1. 除最后一层以外，其余每一层都已经填满；
2. 最后一层的节点全部连续排列在最左侧，中间不能留下空位。

这个定义关心的是按层排列后的空缺位置，不要求每个内部节点都有两个孩子。倒数第二
层右侧的节点可以只有左孩子，也可以没有孩子。

完全二叉树从上到下、从左到右编号以后，实际节点恰好占据连续的 `1..n`。这个重要
性质将在 [完全二叉树](complete-binary-tree.md) 中单独推导，并用于数组存储和二叉堆。

## 完美二叉树

完美二叉树（perfect binary tree）要求所有内部节点都有两个孩子，并且所有叶节点
位于同一层。它的每一层都被完全填满，所以它既是完整二叉树，也是完全二叉树。

若把根所在层记作第 `1` 层，共有 `h` 层，那么第 `i` 层有 $2^{i-1}$ 个节点，整棵树
共有：

$$
1+2+4+\cdots+2^{h-1}=2^h-1
$$

个节点。

## 三种定义的区别

| 名称 | 核心限制 | 叶节点必须同层 | 最后一层必须靠左 |
| --- | --- | --- | --- |
| 完整二叉树 | 每个节点有 `0` 或 `2` 个孩子 | 否 | 否 |
| 完全二叉树 | 逐层填充，最后一层从左连续排列 | 否 | 是 |
| 完美二叉树 | 每个内部节点有两个孩子，叶节点同层 | 是 | 是 |

三者不能根据中文名称互相猜测。判断时应回到结构限制：是在限制孩子数量、空缺位置，
还是叶节点层数。

> “满二叉树”在中文资料中存在歧义。有些资料用它表示完美二叉树，也有资料受英文
> `full binary tree` 影响，用它描述完整二叉树。本书正文统一使用“完整二叉树”、
> “完全二叉树”和“完美二叉树”，不单独用“满二叉树”代替其中任何一种。

## 它们都不等于二叉搜索树

完整、完全和完美只描述树的形状，不限制节点值。二叉搜索树则要求左、右子树中的值
满足特定次序，它可能是完全二叉树，也可能是一条很长的斜链。不要因为图形规整就
推断节点值已经有序。

## 基础练习

1. 分别画出只有左孩子和只有右孩子的两个节点二叉树，说明它们为什么不同。
2. 画一棵完整但不完全的二叉树。
3. 画一棵完全但不完整的二叉树。
4. 证明每棵完美二叉树同时是完整二叉树和完全二叉树。
5. 给出一棵形状完全相同但节点值不满足二叉搜索顺序的二叉树。

## 需要记住什么

1. 二叉树为什么必须区分左子节点和右子节点？
2. 只有一个孩子时，左孩子和右孩子是否表示同一种结构？
3. 完整二叉树限制什么？
4. 完全二叉树最后一层怎样排列？
5. 完美二叉树还比完整二叉树多出什么限制？
6. 为什么本书不单独使用“满二叉树”这个名称？
7. 这些形状限制是否会自动保证节点值满足二叉搜索顺序？
