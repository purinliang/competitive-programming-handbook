# 稀疏表（ST 表）

> 最近修订：2026-08-15 21:16 +10:00（未审阅）

给定一个不会再修改的数组，需要多次查询闭区间 `[l,r]` 的最大值。

每次扫描整个区间需要 $O(r-l+1)$ 时间。线段树能在 $O(\log n)$ 内查询并支持修改，但如果数组始终不变，我们可以预处理所有长度为 $2$ 的幂的区间，再用两个区间完成任意查询。

稀疏表（Sparse Table，常简称 ST 表）正是为这类**静态、可重复覆盖**的区间查询设计的数据结构。基础版本的复杂度是：

- 预处理 $O(n\log n)$；
- 单次查询 $O(1)$；
- 空间 $O(n\log n)$。

本篇只维护区间最大值。区间最小值的结构完全相同，只需把 `max` 改成 `min`。

## 长度为 2 的幂的区间

定义：

$$
table[j][i]=\max(a[i],a[i+1],\ldots,a[i+2^j-1]).
$$

也就是说，`table[j][i]` 保存从位置 `i` 开始、长度为 $2^j$ 的闭区间最大值。

```text
table[0][i]：区间 [i, i]，长度 1
table[1][i]：区间 [i, i + 1]，长度 2
table[2][i]：区间 [i, i + 3]，长度 4
table[3][i]：区间 [i, i + 7]，长度 8
```

位置 `i` 使用本书自定义数组的 1-based 下标；指数 `j` 从 `0` 开始，因为最短区间长度是 $2^0=1$。

第 `0` 层直接等于原数组：

```cpp
for (int i = 1; i <= n; i++) {
    table[0][i] = a[i];
}
```

## 合并两个一半区间

长度为 $2^j$ 的区间可以从中点分成两个长度为 $2^{j-1}$ 的区间：

```text
[i, i + 2^j - 1]
= [i, i + 2^(j-1) - 1]
  + [i + 2^(j-1), i + 2^j - 1]
```

因此：

$$
table[j][i]
=\max\left(table[j-1][i],table[j-1][i+2^{j-1}]\right).
$$

代码按照区间长度从小到大建立：

```cpp
for (int j = 1; j < max_log; j++) {
    int length = 1 << j;
    int half = length / 2;
    for (int i = 1; i + length - 1 <= n; i++) {
        table[j][i] = max(table[j - 1][i], table[j - 1][i + half]);
    }
}
```

内层条件保证整个区间 `[i,i+length-1]` 没有超过 `n`。每个状态只读取上一层已经算好的两个状态。

## 查询需要多长的区间

查询 `[l,r]`，长度是：

```cpp
int length = r - l + 1;
```

选择满足 $2^j\le length$ 的最大 `j`，也就是：

$$
j=\lfloor\log_2(length)\rfloor.
$$

不必在每次查询中调用浮点对数。预处理：

```cpp
log_table[1] = 0;
for (int length = 2; length <= n; length++) {
    log_table[length] = log_table[length / 2] + 1;
}
```

整数除以 `2` 会删除二进制最低位，因此长度减半以后，向下取整的二进制对数恰好少 `1`。

例如：

```text
length = 1：j = 0，使用长度 1
length = 6：j = 2，使用长度 4
length = 8：j = 3，使用长度 8
```

## 用两个区间覆盖查询

取一个长度为 $2^j$ 的区间贴住查询左端点：

```text
[l, l + 2^j - 1]
```

再取一个同样长的区间贴住右端点：

```text
[r - 2^j + 1, r]
```

根据 `j` 的选择，$2^j\le length<2^{j+1}=2\times2^j$。两个区间的总长度至少覆盖整个 `[l,r]`，中间可能重叠，但不会留下空隙。

最大值允许重复计算。同一个元素即使同时出现在两个区间中，仍有：

$$
\max(x,x)=x.
$$

因此查询可以直接写成：

```cpp
int query(int l, int r) const {
    int length = r - l + 1;
    int j = log_table[length];
    return max(table[j][l], table[j][r - (1 << j) + 1]);
}
```

只读取两个预处理值并取一次最大值，所以查询是 $O(1)$。

## 为什么不能直接查询区间和

两个查询区间可能重叠。例如长度为 $6$ 时选择两个长度为 $4$ 的区间，中间两个位置会出现两次。

最大值、最小值和最大公约数满足重复计算不改变结果：

```text
max(x, x) = x
min(x, x) = x
gcd(x, x) = x
```

这种性质称为幂等性。区间和不满足：

```text
x + x != x
```

所以不能把基础 ST 表的两个重叠区间直接相加。静态区间和应当使用前缀和；需要修改时再考虑树状数组或线段树。

稀疏表也能用若干个长度为 2 的幂且互不重叠的区间，在 $O(\log n)$ 内组合某些其他运算，但那不再是本篇 $O(1)$ 的基础查询方式。

## 完整代码

`SparseTable` 保存实际长度、对数表和所有长度为 2 的幂的区间。每个自定义下标维度都保留 `+5` 余量：位置使用 `1..n`，指数使用 `0..max_log-1`。

程序读入静态数组，再回答若干区间最大值查询。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct SparseTable {
    int n;
    int max_log;
    vector<int> log_table;
    vector<vector<int>> table;

    SparseTable(int n, const vector<int>& a) : n(n), log_table(n + 5) {
        max_log = 1;
        while ((1LL << max_log) <= n) {
            max_log++;
        }

        table.assign(max_log + 5, vector<int>(n + 5));

        for (int i = 1; i <= n; i++) {
            table[0][i] = a[i];
        }

        for (int j = 1; j < max_log; j++) {
            int length = 1 << j;
            int half = length / 2;
            for (int i = 1; i + length - 1 <= n; i++) {
                table[j][i] = max(table[j - 1][i], table[j - 1][i + half]);
            }
        }

        for (int length = 2; length <= n; length++) {
            log_table[length] = log_table[length / 2] + 1;
        }
    }

    int query(int l, int r) const {
        int length = r - l + 1;
        int j = log_table[length];
        return max(table[j][l], table[j][r - (1 << j) + 1]);
    }
};

int main() {
    int n, q;
    scanf("%d%d", &n, &q);

    vector<int> a(n + 5);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }

    SparseTable sparse(n, a);

    while (q--) {
        int l, r;
        scanf("%d%d", &l, &r);
        printf("%d\n", sparse.query(l, r));
    }
    return 0;
}
```

输入：

```text
8 4
3 1 7 4 6 2 9 5
1 1
2 5
4 8
1 8
```

输出：

```text
3
7
9
9
```

单点区间 `[1,1]` 使用第 `0` 层；`[2,5]` 的最大值是 `7`；包含位置 `7` 的后两个查询最大值都是 `9`。

## 正确性

先按 `j` 归纳预处理表。第 `0` 层的区间只有一个元素，显然正确。若第 `j-1` 层正确，长度 $2^j$ 的区间被完整分成两个长度 $2^{j-1}$ 的区间；取两个正确最大值的较大者，正是整个区间最大值。因此所有 `table[j][i]` 都符合定义。

查询时，左右两个长度 $2^j$ 的区间都位于 `[l,r]` 内，并且它们的并集覆盖 `[l,r]`。每个查询元素至少出现一次，重叠元素可能出现两次；最大值的幂等性保证重复不会改变结果。所以两个预处理最大值的较大者就是整个查询区间最大值。

## 复杂度

表共有 $O(\log n)$ 层，每层最多保存 $n$ 个区间，预处理时间和空间都是 $O(n\log n)$。对数表需要额外 $O(n)$ 时间和空间，不改变总复杂度。

单次查询只查表两次并计算一次 `max`，时间复杂度为 $O(1)$。

数组发生一次修改后，许多跨过该位置的预处理区间都会失效。基础 ST 表不支持高效修改；若题目同时要求修改和区间最值，使用线段树等动态结构。

## 常见错误

### 忘记闭区间长度加 1

查询 `[l,r]` 的长度是 `r-l+1`。少写 `+1` 会让单点查询长度变成 `0`，并使对数下标失效。

### 第二个区间起点少加 1

右端对齐的长度 $2^j$ 区间起点是 `r-(1<<j)+1`。它必须恰好包含 `r` 在内的 $2^j$ 个位置。

### 预处理越过数组末尾

只有 `i+length-1<=n` 时，`table[j][i]` 对应的完整区间才存在。

### 使用浮点 log2

浮点对数在 2 的幂边界附近可能受精度影响，也没有必要重复计算。预处理整数 `log_table` 更直接稳定。

### 把 ST 表用于动态修改

ST 表的查询快来自提前保存大量重叠区间。修改一个元素后，基础结构没有只更新少量状态的方法。

### 对非幂等运算使用重叠覆盖

区间和会把重叠部分计算两次。使用两个重叠区间以前，必须确认重复元素不会改变答案。

## 基础练习

1. 对数组 `3 1 7 4 6 2 9 5` 手算 `table[0]`、`table[1]` 和 `table[2]`。
2. 查询长度分别为 `1,2,3,6,8` 时，写出 `log_table[length]`。
3. 画出查询 `[2,7]` 使用的两个长度为 $4$ 的区间，标出重叠位置。
4. 把完整代码改成区间最小值，并与逐个扫描的朴素程序随机对拍。
5. 把合并操作改成 `gcd`，验证重叠覆盖仍然正确。
6. 构造一个区间和反例，说明两个重叠区间为什么会重复计数。

## 需要记住什么

1. `table[j][i]` 表示哪个闭区间的信息？长度是多少？
2. 为什么一个长度 $2^j$ 的状态能由两个第 `j-1` 层状态得到？
3. `log_table[length]` 保存什么？为什么可以由 `length/2` 递推？
4. 查询 `[l,r]` 时左右两个区间的起点分别是什么？
5. 为什么这两个区间一定覆盖完整查询？它们是否可能重叠？
6. 为什么最大值允许重叠，而区间和不允许？
7. ST 表的预处理、查询和空间复杂度分别是什么？
8. 为什么基础 ST 表只适合静态数组？

二维 ST 表、Disjoint Sparse Table、RMQ 与 LCA 的其他转换，以及针对非幂等运算的稀疏表变体不属于基础静态区间最值，不要求理解或记忆。
