# 完全二叉树

> 最近修订：2026-08-16 16:20 +10:00（未审阅）

[二叉树的基本概念](binary-tree-concepts.md) 已经给出完全二叉树的形状定义。它最重要
的程序性质不是“看起来比较整齐”，而是按层编号以后没有空洞，可以直接存入连续数组。

## 从上到下、从左到右编号

完全二叉树除最后一层外全部填满，最后一层又从左向右连续排列。因此按照层序，也就是
从上到下、同层从左到右，把根编号为 `1`，其余节点会恰好得到连续编号 `1..n`。

```text
              1
          /       \
         2         3
       /   \     /   \
      4     5   6     7
     / \
    8   9
```

这里不存在“编号 `6` 为空但编号 `7` 存在”的情况；那会违反最后一层从左连续排列的
要求。

## 父子下标

每一层的节点数是上一层的两倍。使用上述从 `1` 开始的编号时，节点 `u` 的位置关系为：

```text
父节点：u / 2
左子节点：2 * u
右子节点：2 * u + 1
```

根节点 `1` 没有父节点。对其他节点做整数除法：`2 * p` 和 `2 * p + 1` 都会得到父亲
`p`，所以节点 `u` 的父亲统一是 `u / 2`。

## 孩子是否存在

公式给出的是孩子应该占据的位置，不保证这个位置已经有真实节点。完全二叉树只有
`1..n` 是有效编号，因此：

```cpp
bool has_left_child(int u) {
    return 2 * u <= n;
}

bool has_right_child(int u) {
    return 2 * u + 1 <= n;
}
```

如果 `2 * u > n`，那么左右孩子都不存在，`u` 是叶节点。由此还可得到叶节点编号为：

```text
n / 2 + 1, n / 2 + 2, ..., n
```

编号不超过 `n / 2` 的节点至少有一个孩子。

## 为什么能够直接用数组存储

普通二叉树需要为每个节点保存 `left_child[u]` 和 `right_child[u]`。完全二叉树的形状
已经由节点总数 `n` 和层序编号唯一确定，父子关系可以通过下标计算，因此只需保存节点
值：

```cpp
int n;
vector<int> value;

value.assign(n + 5, 0);
```

`value[u]` 就是位置 `u` 的节点值。额外的 `+5` 只提供统一的安全余量；编号 `0` 仍然
留空。

这种表示没有删除左右孩子数组后再“猜”树形，而是利用完全二叉树的定义证明树形已经
包含在下标中。

## 普通二叉树为什么不能照搬

考虑一棵不断只有右孩子的普通二叉树。若仍强行使用完全二叉树的下标公式，节点位置会
依次成为：

```text
1, 3, 7, 15, 31, ...
```

只有 `k` 个节点时，最后下标已经接近 $2^k$，中间绝大多数数组位置为空。更重要的是，
普通二叉树的实际编号通常由输入给出，并不自动满足父子下标公式。因此普通二叉树应当
显式保存左右孩子，只有完全二叉树才自然适合这套连续数组表示。

## 树的层数

若根是第 `1` 层，编号 `u` 所在层数是：

$$
\lfloor\log_2 u\rfloor+1
$$

含 `n` 个节点的完全二叉树共有：

$$
\lfloor\log_2 n\rfloor+1
$$

层。每进入下一层，最小编号都会翻倍；所以从节点不断走向父亲时，编号每次除以 `2`，
最多经过 $O(\log n)$ 层到达根。

## 与二叉堆的关系

完全二叉树只规定形状，不规定节点值。二叉堆在这个形状上再增加父子值的大小关系。
因此二叉堆既能用连续数组保存，又能通过父子下标在 $O(\log n)$ 层内向上或向下调整。

## 完整程序

下面的程序读入一棵按层序给值的完全二叉树，输出每个节点的父亲和存在的孩子：

```cpp
#include <bits/stdc++.h>

using namespace std;

int n;
vector<int> value;

void solve() {
    scanf("%d", &n);

    value.assign(n + 5, 0);
    for (int u = 1; u <= n; u++) {
        scanf("%d", &value[u]);
    }

    for (int u = 1; u <= n; u++) {
        int parent = u / 2;
        int left_child = 2 * u;
        int right_child = 2 * u + 1;

        printf("u=%d value=%d", u, value[u]);
        if (u != 1) {
            printf(" parent=%d", parent);
        }
        if (left_child <= n) {
            printf(" left=%d", left_child);
        }
        if (right_child <= n) {
            printf(" right=%d", right_child);
        }
        printf("\n");
    }
}

int main() {
    solve();
    return 0;
}
```

## 基础练习

1. 写出含 `10` 个节点的完全二叉树中每个节点的父亲与孩子。
2. 证明编号大于 `n / 2` 的节点恰好都是叶节点。
3. 只用数组下标，从任意节点不断走到根并输出路径。
4. 给出一个不是完全二叉树的形状，说明它按相同公式存储时会留下哪些空位。
5. 比较显式孩子数组与完全二叉树数组各自需要保存的信息。

5. 哪些编号一定对应叶节点？
