# 莫比乌斯函数

> 最近修订：2026-08-16 01:15 +10:00（未审阅）

有些计数问题要求两个整数互质。直接逐对计算最大公约数通常太慢，我们希望把条件：

$$
\gcd(a,b)=1
$$

改写成可以按约数求和的形式。

莫比乌斯函数提供了一组只取 `-1`、`0`、`1` 的权值。它让同一个整数的约数彼此抵消，最后只留下“最大公约数是否为 `1`”这一条信息。

本篇先解释这些权值怎样由质因数分解得到，再学习一次求出 `1..n` 中全部函数值的方法。更一般的莫比乌斯反演属于配套扩展，不是理解本篇定义和代码的前提。

## 定义

莫比乌斯函数记作 $\mu(n)$，只讨论正整数 `n`。

首先规定：

$$
\mu(1)=1.
$$

对 `n>1`，查看 `n` 的质因数分解：

- 如果某个质因数的指数至少为 `2`，即存在质数 `p` 使 $p^2\mid n$，那么 $\mu(n)=0$；
- 否则所有质因数都只出现一次。若一共有 `k` 个不同质因数，那么 $\mu(n)=(-1)^k$。

因此，莫比乌斯函数的值只有三种：

$$
\mu(n)=
\begin{cases}
1,&n=1,\\
0,&n\text{ 含有某个质因数的平方},\\
(-1)^k,&n\text{ 是 }k\text{ 个不同质数的乘积}.
\end{cases}
$$

不含任何质因数平方的正整数称为无平方因子数。这个名称只是在描述定义，不需要另外记一套算法。

## 从质因数分解计算

先看几个例子：

| `n` | 质因数分解 | `mu(n)` | 原因 |
| --- | --- | --- | --- |
| `1` | 空乘积 | `1` | 单独规定 |
| `2` | `2` | `-1` | 一个不同质因数 |
| `6` | `2*3` | `1` | 两个不同质因数 |
| `12` | `2^2*3` | `0` | 含有 `2^2` |
| `30` | `2*3*5` | `-1` | 三个不同质因数 |

对单个 `n` 试除时，每发现一个新的质因数，就把答案变号：

```cpp
value = -value;
```

随后检查这个质因数能否再除一次。若能，原数含有它的平方，可以立刻返回 `0`：

```cpp
x /= p;
if (x % p == 0) {
    return 0;
}
```

合起来得到：

```cpp
int mobius(ll n) {
    int value = 1;
    ll x = n;

    for (ll p = 2; p <= x / p; p++) {
        if (x % p != 0) {
            continue;
        }

        x /= p;
        value = -value;
        if (x % p == 0) {
            return 0;
        }
    }

    if (x > 1) {
        value = -value;
    }
    return value;
}
```

循环结束后若 `x>1`，剩下的 `x` 是一个尚未处理的质因数，因此还要变号一次。这个函数计算单个值需要 $O(\sqrt n)$ 时间。

## 约数和为什么会抵消

莫比乌斯函数最重要的基础性质是：

$$
\sum_{d\mid n}\mu(d)=
\begin{cases}
1,&n=1,\\
0,&n>1.
\end{cases}
$$

先取 `n=6`。它的约数是 `1,2,3,6`：

$$
\mu(1)+\mu(2)+\mu(3)+\mu(6)
=1-1-1+1
=0.
$$

再取 `n=12`。含有平方因子的约数 `4` 和 `12` 的函数值都是 `0`，其余部分仍然抵消：

$$
\mu(1)+\mu(2)+\mu(3)+\mu(4)+\mu(6)+\mu(12)
=1-1-1+0+1+0
=0.
$$

一般地，设 `n>1` 有 `k` 个不同质因数。只有从这 `k` 个质因数中各选零次或一次得到的约数，莫比乌斯函数值才不为 `0`。

选择偶数个质因数的约数贡献 `1`，选择奇数个质因数的约数贡献 `-1`。按选择个数求和：

$$
\sum_{d\mid n}\mu(d)
=\sum_{j=0}^{k}\binom{k}{j}(-1)^j
=(1-1)^k
=0.
$$

当 `n=1` 时只有约数 `1`，所以和为 $\mu(1)=1$。这就是完整结论。

## 把互质条件改写成约数和

令：

$$
g=\gcd(a,b).
$$

把上面的性质应用到 `g`：

$$
[\gcd(a,b)=1]=\sum_{d\mid\gcd(a,b)}\mu(d).
$$

方括号表示条件成立时取 `1`，不成立时取 `0`。

- 若 `a,b` 互质，那么 `g=1`，右侧只有 $\mu(1)=1$；
- 若 `a,b` 不互质，那么 `g>1`，右侧全部抵消为 `0`。

而：

$$
d\mid\gcd(a,b)
$$

等价于 `d` 同时整除 `a` 和 `b`。这样，原本逐对检查最大公约数的条件就能改写成按公约数 `d` 分类的求和。这是莫比乌斯函数在计数题中的核心作用。

本篇只要求理解这一步改写。如何系统地从一种约数和恢复另一种函数，会在莫比乌斯反演中讨论。

## 用欧拉筛预处理

竞赛中通常需要 `1..n` 的全部莫比乌斯函数值。对每个整数分别试除会需要大约 $O(n\sqrt n)$ 时间；可以沿用 [欧拉筛](euler-sieve.md)“每个合数只由最小质因数生成一次”的框架。

先设置：

```cpp
mu[1] = 1;
```

当 `i` 是质数时，它只含一个不同质因数：

```cpp
primes.push_back(i);
mu[i] = -1;
```

接着用质数 `p` 生成 `i*p`，分成两种情况。

如果 `p` 已经整除 `i`，那么 `i*p` 含有 $p^2$：

```cpp
if (i % p == 0) {
    mu[i * p] = 0;
    break;
}
```

如果 `p` 不整除 `i`，`i*p` 比 `i` 多了一个不同质因数，所以函数值变号：

```cpp
mu[i * p] = -mu[i];
```

`break` 的原因与普通欧拉筛相同：当前乘积已经由它的最小质因数生成，继续枚举会破坏“每个合数只生成一次”的规则。

## 完整代码

下面的程序输出 `mu(1)..mu(n)`：

```cpp
#include <bits/stdc++.h>

using namespace std;

vector<int> mobius_sieve(int n) {
    vector<int> mu(n + 5);
    vector<int> primes;
    vector<bool> is_composite(n + 5);

    mu[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!is_composite[i]) {
            primes.push_back(i);
            mu[i] = -1;
        }

        for (int p : primes) {
            if (p > n / i) {
                break;
            }

            int value = i * p;
            is_composite[value] = true;
            if (i % p == 0) {
                mu[value] = 0;
                break;
            }
            mu[value] = -mu[i];
        }
    }
    return mu;
}

int main() {
    int n;
    scanf("%d", &n);

    vector<int> mu = mobius_sieve(n);
    for (int i = 1; i <= n; i++) {
        printf("%d%c", mu[i], " \n"[i == n]);
    }
    return 0;
}
```

输入：

```text
12
```

输出：

```text
1 -1 -1 0 -1 1 -1 0 0 1 -1 0
```

## 正确性

欧拉筛保证每个合数 `i*p` 恰好在 `p` 是其最小质因数时被生成。

- 若 `p` 整除 `i`，那么 `i*p` 含有平方因子 $p^2$，代码令 `mu[i*p]=0`；
- 若 `p` 不整除 `i`，那么 `p` 是新增加的不同质因数，代码令 `mu[i*p]=-mu[i]`；
- 每个质数只含一个不同质因数，代码令它的函数值为 `-1`；
- `mu[1]` 按定义初始化为 `1`。

这些情况覆盖 `1..n` 中所有正整数，并且每次赋值都符合莫比乌斯函数的定义，因此程序计算正确。

## 复杂度

欧拉筛让每个合数只被生成一次，时间复杂度为 $O(n)$。

三个数组合计使用 $O(n)$ 空间。`mu` 的每个元素只可能是 `-1`、`0` 或 `1`，但使用 `int` 可以让代码更直接。

## 常见错误

### 忘记 mu(1)=1

`1` 没有质因数，必须单独初始化。若保持默认值 `0`，约数和恒等式会从最小输入开始失效。

### 只按不同质因数个数变号

含有平方因子的数必须取 `0`。例如 `12` 有两个不同质因数，但不能写成 `1`，因为它含有 $2^2$。

### 把 mu(n) 当作普通正计数

`mu(n)` 是抵消权值，可以为负数。它通常出现在求和式中，不表示某一类对象的数量。

### 在线性筛中漏掉 break

当 `i%p==0` 时必须停止。继续枚举会让同一个合数经由不同质因数重复生成，失去线性复杂度保证。

### 把莫比乌斯函数和反演混成一个概念

莫比乌斯函数是本篇定义的数论函数；莫比乌斯反演是利用它恢复约数和关系的一条定理。先掌握函数值和抵消性质，再学习反演。
