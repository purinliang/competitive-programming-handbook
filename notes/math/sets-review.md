# 集合：基本概念与交、并、补

> 最近修订：2026-08-17 01:22 +10:00（未审阅）

集合用来描述“一批满足条件且彼此不重复的对象”。题目中的可选点、已经访问的状态、质数范围和答案候选都可能被看成集合。

本篇只复习有限集合最常用的记号，以及交集、并集、差集和补集。C++ 标准库 `set` 是实现集合操作的一种容器，不等于数学集合概念本身。

## 元素与集合

使用花括号列出集合元素：

$$
A=\{1,3,5\}.
$$

`3` 属于 $A$，记作：

$$
3\in A.
$$

`2` 不属于 $A$，记作：

$$
2\notin A.
$$

集合不记录重复次数，也不依赖列出顺序：

$$
\{1,3,5\}=\{5,3,1\}=\{1,1,3,5\}.
$$

若题目关心顺序，应使用序列；若关心同一个值出现多少次，应使用多重集合或频次数组，而不是普通集合。

## 空集与集合大小

不含任何元素的集合称为空集，记作：

$$
\varnothing.
$$

集合 $A$ 的元素数量记作 $|A|$。例如：

$$
|\{1,3,5\}|=3,
\qquad
|\varnothing|=0.
$$

空集不是“包含一个空东西的集合”。集合 `{0}` 包含元素 `0`，大小为 `1`；空集没有元素，大小为 `0`。

## 子集

若集合 $A$ 的每个元素都属于集合 $B$，就称 $A$ 是 $B$ 的子集：

$$
A\subseteq B.
$$

例如：

$$
\{1,3\}\subseteq\{1,2,3\}.
$$

每个集合都是自己的子集，空集也是任意集合的子集。

若 $A\subseteq B$ 且 $A\ne B$，则 $A$ 是 $B$ 的真子集。不同资料可能使用 `⊂` 或 `⊊` 表示真子集；为避免符号约定差异，本书在需要时会同时写出“子集且不相等”的条件。

两个集合相等，当且仅当它们互为子集：

$$
A=B
\iff
A\subseteq B\text{ 且 }B\subseteq A.
$$

## 交集

$A$ 与 $B$ 的交集包含同时属于两者的元素：

$$
A\cap B=\{x\mid x\in A\text{ 且 }x\in B\}.
$$

例如：

$$
\{1,2,3\}\cap\{2,3,4\}=\{2,3\}.
$$

交集对应逻辑“并且”。程序中用布尔数组表示成员关系时：

```cpp
in_intersection[x] = in_a[x] && in_b[x];
```

若 $A\cap B=\varnothing$，称两个集合不相交。

## 并集

$A$ 与 $B$ 的并集包含至少属于其中一个集合的元素：

$$
A\cup B=\{x\mid x\in A\text{ 或 }x\in B\}.
$$

例如：

$$
\{1,2,3\}\cup\{2,3,4\}=\{1,2,3,4\}.
$$

公共元素 `2` 和 `3` 仍只出现一次。并集对应包含式逻辑“或者”：同时属于两者的元素当然也属于并集。

```cpp
in_union[x] = in_a[x] || in_b[x];
```

## 差集

$A$ 相对 $B$ 的差集包含属于 $A$ 但不属于 $B$ 的元素：

$$
A\setminus B=\{x\mid x\in A\text{ 且 }x\notin B\}.
$$

例如：

$$
\{1,2,3\}\setminus\{2,3,4\}=\{1\}.
$$

差集有方向，通常：

$$
A\setminus B\ne B\setminus A.
$$

程序中的条件是：

```cpp
in_difference[x] = in_a[x] && !in_b[x];
```

## 全集与补集

补集必须先明确讨论范围。设全集 $U$ 包含当前问题允许的所有元素，$A$ 相对 $U$ 的补集是：

$$
\overline A=U\setminus A.
$$

例如全集是：

$$
U=\{1,2,3,4,5\},
$$

并且：

$$
A=\{1,3,5\},
$$

那么：

$$
\overline A=\{2,4\}.
$$

不说明全集时，“不属于 $A$ 的所有对象”没有确定边界。例如整数 `6` 是否属于补集，取决于全集是否包含它。

使用成员布尔值时，在全集范围内：

```cpp
in_complement[x] = !in_a[x];
```

## 德摩根律

补集与交、并满足：

$$
\overline{A\cap B}
=
\overline A\cup\overline B,
$$

$$
\overline{A\cup B}
=
\overline A\cap\overline B.
$$

第一条表示“不同时属于 $A$ 和 $B$”，等价于“不属于 $A$，或者不属于 $B$”。第二条表示“不属于两者中任何一个”，等价于“既不属于 $A$，也不属于 $B$”。

它们与逻辑运算中的德摩根律是同一结构。

## 两个集合大小的容斥

直接把 $|A|$ 与 $|B|$ 相加时，交集中的每个元素被计算两次。因此：

$$
|A\cup B|
=
|A|+|B|-|A\cap B|.
$$

这是一阶容斥原理，也是后续组合计数的基础。若两集合不相交，交集大小为 `0`，并集大小才直接等于两者大小之和。

## 完整代码

下面把全集固定为 `1..n`，用两个布尔数组保存集合 $A$、$B$，再输出交集、并集与 $A\setminus B$ 的大小。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> in_a;
vector<int> in_b;

void solve() {
    int a_size;
    int b_size;
    cin >> n >> a_size >> b_size;

    in_a.assign(n + 5, 0);
    in_b.assign(n + 5, 0);

    for (int i = 1; i <= a_size; i++) {
        int x;
        cin >> x;
        in_a[x] = 1;
    }

    for (int i = 1; i <= b_size; i++) {
        int x;
        cin >> x;
        in_b[x] = 1;
    }

    int intersection_size = 0;
    int union_size = 0;
    int difference_size = 0;

    for (int x = 1; x <= n; x++) {
        intersection_size += in_a[x] && in_b[x];
        union_size += in_a[x] || in_b[x];
        difference_size += in_a[x] && !in_b[x];
    }

    cout << intersection_size << ' '
         << union_size << ' '
         << difference_size << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
5 3 3
1 2 3
2 3 4
```

输出：

```text
2 4 1
```
