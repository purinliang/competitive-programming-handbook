# 排列数

> 最近修订：2026-08-15 22:30 +10:00（未审阅）

有 `n` 个互不相同的元素，从中选出 `k` 个并依次放入 `k` 个位置，一共有多少种不同结果？

例如从 `A,B,C,D,E` 中选出 `3` 个组成长度为 `3` 的序列：

```text
ABC
ACB
BAC
...
```

`ABC` 与 `ACB` 选择了相同元素，但顺序不同，所以是两个不同结果。这类“有顺序、不重复”的选择由排列数计算。

## 逐个填入位置

第一个位置可以放任意元素，有 `n` 种选择。

选走一个元素后，第二个位置不能重复使用它，只剩 `n-1` 种选择。继续填入：

```text
第 1 个位置：n 种
第 2 个位置：n-1 种
第 3 个位置：n-2 种
...
第 k 个位置：n-k+1 种
```

一个完整结果由这 `k` 步共同组成。根据 [乘法原理](multiplication-principle.md)：

$$
P(n,k)=n(n-1)(n-2)\cdots(n-k+1).
$$

中文教材也常把排列数记作 $A_n^k$。本书正文优先使用参数顺序更直观的 $P(n,k)$：先写可选元素总数 `n`，再写选出的数量 `k`。

示例中：

$$
P(5,3)=5\times4\times3=60.
$$

## 为什么顺序已经被计算

每一步对应一个确定位置。选择：

```text
第 1 位 A，第 2 位 B，第 3 位 C
```

与：

```text
第 1 位 A，第 2 位 C，第 3 位 B
```

在第二步就做出了不同选择，因此乘法原理会把它们统计为两个有序组。

不需要算完“选择哪些元素”后再额外乘一个含义不清的顺序数；递减乘积本身已经同时完成选择与排序。

## 阶乘写法

正整数 `n` 的阶乘定义为：

$$
n!=1\times2\times3\times\cdots\times n.
$$

排列数的递减乘积是 `n!` 的前 `k` 个大因数。把没有使用的部分 $(n-k)!$ 约掉：

$$
P(n,k)=\frac{n!}{(n-k)!}.
$$

例如：

$$
P(5,3)=\frac{5!}{2!}
=\frac{5\times4\times3\times2\times1}{2\times1}
=5\times4\times3.
$$

阶乘公式是递减乘积的简写，不是另一套计数方法。精确计算单个排列数时，直接乘 `k` 个因数通常更简单，也不会先产生更大的 `n!`。

## 全排列

当 `k=n` 时，所有元素都要使用一次：

$$
P(n,n)=n!.
$$

这称为 `n` 个不同元素的全排列。

例如三个元素 `A,B,C` 的全排列有：

```text
ABC ACB BAC BCA CAB CBA
```

一共：

$$
3!=6
$$

种。

## 边界条件

本篇约定 `n>=0`。

### 选择 0 个元素

从 `n` 个元素中选择 `0` 个并排列，只有一个空序列：

$$
P(n,0)=1.
$$

这与空积为 `1` 一致。阶乘公式也要求定义：

$$
0!=1.
$$

### 选择数量超过元素数量

若 `k>n`，在不允许重复的前提下无法填满所有位置：

$$
P(n,k)=0.
$$

代码应在进入乘法循环以前处理这个边界，不能让递减因数经过 `0` 后继续变成负数。

## 翻译成代码

按照位置 `1..k` 逐个乘入当前可选数量：

```cpp
ll answer = 1;
for (int position = 1; position <= k; position++) {
    answer *= n - position + 1;
}
```

第 `position` 个位置以前已经使用 `position-1` 个元素，所以还剩：

$$
n-(position-1)=n-position+1
$$

种选择。

## 完整代码

下面的函数计算精确排列数，并假设答案能够放入 64 位整数。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

ll permutation_count(int n, int k) {
    if (k < 0 || k > n) {
        return 0;
    }

    ll answer = 1;
    for (int position = 1; position <= k; position++) {
        answer *= n - position + 1;
    }
    return answer;
}

int main() {
    int n, k;
    scanf("%d%d", &n, &k);
    printf("%lld\n", permutation_count(n, k));
    return 0;
}
```

输入：

```text
5 3
```

输出：

```text
60
```

若题目要求模 `MOD`，可以在每次乘法后取模。乘法中间类型仍要根据 `MOD` 的范围选择。

## 正确性

第 `position` 个位置填写以前，已经使用了 `position-1` 个不同元素，所以恰好有 `n-position+1` 个元素仍可选择。

任意一串循环选择都会得到一个长度为 `k`、元素互不相同的有序序列；反过来，每个合法序列在每个位置都确定了唯一选择过程。二者一一对应。

因此根据乘法原理，把每个位置的选择数相乘，得到的恰好是全部排列数量。

## 与组合数的区别

排列数区分顺序。若只关心选中了哪些元素，不关心它们的排列顺序，则 `ABC` 与 `ACB` 属于同一种选择，应使用下一篇组合数。

| 问题 | 是否区分顺序 | 示例 |
| --- | --- | --- |
| 排列 | 是 | 选出金、银、铜牌获得者 |
| 组合 | 否 | 选出三名队员组成小组 |

判断顺序是否重要，要看题目怎样定义两个方案是否相同，而不是看解题代码是否使用数组保存结果。

## 复杂度

函数执行 `k` 次乘法，时间复杂度为 $O(k)$，额外空间为 $O(1)$。

排列数增长非常快。即使 `n` 不大，答案也可能超过 64 位整数。模板只适用于题目范围保证答案能放入 `ll` 的情况；取模题在乘法过程中取模，精确大数题需要其他表示。

## 常见错误

### 把排列数写成 n 的 k 次方

$n^k$ 允许每个位置独立选择全部 `n` 个元素，因此允许重复。排列数不允许重复，选择数应依次减少。

### 忽略顺序

若顺序不同算不同方案，就不能只计算选中元素集合。反过来，顺序无关时使用排列数会把同一集合重复统计。

### 额外再乘 k 的阶乘

$P(n,k)$ 的逐位置选择已经区分所有顺序。再乘 `k!` 会重复计算。

### 先计算完整阶乘

直接计算 `n!/(n-k)!` 可能让中间的 `n!` 溢出，即使最终排列数仍能表示。精确单次计算直接乘 `k` 个所需因数。

### 错误处理 k 等于 0

选择零个元素的空序列有一种，答案是 `1`，不是 `0`。

### 忘记 k 大于 n

不重复选择时元素不够，答案应直接返回 `0`。

## 基础练习

1. 手算 `P(6,2)` 和 `P(6,6)`。
2. 列出三个不同元素的全部全排列，验证数量是 `3!`。
3. 比较长度为 `3` 的可重复字符串数量 `5^3` 与不重复排列数 `P(5,3)`。
4. 说明为什么 `P(n,0)=1`。
5. 举出一个顺序重要的题目和一个顺序不重要的题目。
6. 修改代码，在固定模数下计算排列数。

## 需要记住什么

1. 排列数描述的是哪一种选择？
2. 第 `position` 个位置为什么有 `n-position+1` 种选择？
3. $P(n,k)$ 的递减乘积和阶乘形式分别是什么？
4. 全排列与一般排列数是什么关系？
5. `k=0` 与 `k>n` 时答案分别是什么？
6. 排列数与组合数最核心的区别是什么？
7. 为什么直接乘 `k` 个因数通常比先算两个阶乘更适合精确计算？
