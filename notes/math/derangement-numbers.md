# 错位排列

> 最近修订：2026-08-17 11:22 +10:00（未审阅）

$n$ 个人各有一顶不同的帽子。把所有帽子随机发回去，要求没有任何人拿到自己的
帽子，一共有多少种发法？

这类排列称为**错位排列**。记答案为 $D_n$。直接枚举 $n!$ 个排列再检查固定点
很快就不可行；观察一个人的帽子怎样参与排列环，可以得到只依赖前两个状态的
递推。

## 最小状态

没有人时，空排列视为一种合法方案：

$$
D_0=1.
$$

只有一个人时，他只能拿到自己的帽子，不合法：

$$
D_1=0.
$$

两个人只能交换帽子，所以 $D_2=1$。

$D_0=1$ 不是现实中“发帽子”的数量，而是组合递推中的空结构单位元；它使
$D_2=(2-1)(D_1+D_0)=1$ 自然成立。

## 固定第 n 个人拿到谁的帽子

第 $n$ 个人不能拿自己的帽子，可以拿其余任意一人的帽子。设他拿了第 `j` 个人
的帽子，`j` 有 $n-1$ 种选择。

接下来按照第 `j` 个人是否拿到第 $n$ 个人的帽子分成两类。

### 两人互换

若第 `j` 个人恰好拿到第 $n$ 个人的帽子，两人形成一个长度为 2 的排列环：

```text
n -> j -> n
```

删除这两个人与两顶帽子，剩余 $n-2$ 个人仍然必须全部错位，共有
$D_{n-2}$ 种方案。

### 没有两人互换

若第 `j` 个人没有拿到第 $n$ 个人的帽子，那么某个其他人 `k` 会拿到第 $n$
个人的帽子。排列环中会出现：

```text
k -> n -> j
```

删除第 $n$ 个人，并让 `k` 改拿第 `j` 个人的帽子：

```text
k -> j
```

就得到剩余 $n-1$ 个人的一份错位排列。反过来，从任意 $n-1$ 人错位排列中找到
拿第 `j` 顶帽子的人，把第 $n$ 个人插在中间，也能唯一恢复原方案。

因此，这一类与 $D_{n-1}$ 一一对应。

## 得到递推式

对固定的 `j`，两类方案数为：

$$
D_{n-2}+D_{n-1}.
$$

第 $n$ 个人拿谁的帽子有 $n-1$ 种选择，所以：

$$
D_n=(n-1)(D_{n-1}+D_{n-2}).
$$

这两类按照“是否形成二元环”互不重叠，又覆盖了全部可能，因此没有重复或遗漏。

## 完整代码

错位排列增长很快。输入 `n` 和正整数 `mod`，输出 $D_n\bmod mod$。递推只有
加法和乘法，对模数是否为质数没有要求。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

ll derangement(int n, ll mod) {
    if (n == 0) {
        return 1 % mod;
    }
    if (n == 1) {
        return 0;
    }

    ll previous_two = 1 % mod;
    ll previous_one = 0;

    for (int i = 2; i <= n; i++) {
        ll current = (i - 1LL) * (previous_one + previous_two) % mod;
        previous_two = previous_one;
        previous_one = current;
    }

    return previous_one;
}

void solve() {
    int n;
    ll mod;
    cin >> n >> mod;
    cout << derangement(n, mod) << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```

时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。代码只保留 $D_{i-1}$ 与
$D_{i-2}$，因为更早状态不会参与下一次转移。

若 `mod` 接近 64 位整数上限，乘法可能溢出，应按题目范围替换为安全模乘；常见
竞赛模数下普通 64 位乘法足够。这个问题与错位排列递推本身分开处理。

## 容斥公式

错位排列也可以从全部 $n!$ 个排列中，用容斥原理排除“至少一个人拿到自己的
帽子”：

$$
D_n=n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}.
$$

选择 $k$ 个人固定自己的帽子有 $\binom nk$ 种，剩余帽子任意排列有
$(n-k)!$ 种，两者乘积为 $n!/k!$，按照容斥符号交替相加。

这个公式揭示 $D_n$ 大约等于 $n!/e$，但在任意模数下包含除法，不如递推稳定。
只需求单个或连续的错位排列数时，优先使用无需逆元的递推。

## 怎样识别错位排列

核心条件是一个排列中禁止固定点：每个对象都不能被映射到自己。帽子、信件、
座位和礼物只是同一个模型的不同表述。

若某些人允许拿回自己的物品，或每个人还有其他禁配关系，就不再是纯错位排列；
可能需要容斥、二分图匹配或其他计数方法。不要因为题目出现“不能相同”就直接
套用 $D_n$。

## 常见错误

- 把 $D_0$ 写成 0，导致整个递推从 $D_2$ 开始错误；
- 固定第 $n$ 个人的去向后，忘记还有 $n-1$ 种 `j` 的选择；
- 只统计两人互换的 $D_{n-2}$，漏掉第 $n$ 个人插入更长排列环的情况；
- 把递推误写成 `n * (D[n-1] + D[n-2])`；
- 使用容斥公式取模，却没有处理除法需要逆元的条件；
- 题目还有额外禁配关系时仍当作标准错位排列；
- 模数很大时忽略乘法溢出风险。
