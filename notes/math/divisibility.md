# 整除

> 最近修订：2026-08-16 11:21 +10:00（未审阅）

除法通常会产生余数，但数论中经常只关心“能否恰好除尽”。整除把这个问题写成一种可以推理的关系，后续的质数、最大公约数和模运算都会反复使用它。

## 定义

给定整数 $a$ 和 $b$。如果存在某个整数 $k$，使得

$$
a=bk,
$$

就说 $b$ **整除** $a$，记作

$$
b\mid a.
$$

例如，$12=3\times4$，所以 $3\mid12$；不存在整数 $k$ 使 $12=5k$，所以 $5\nmid12$。

在 $b\mid a$ 中，`b` 是除数，`a` 是被除数。不要因为口语中的“`a` 能被 `b` 整除”而把顺序写反。

## 约数与倍数

若 $b\mid a$，就称 $b$ 是 $a$ 的约数，$a$ 是 $b$ 的倍数。“因数”也常用于相近语境，本书讨论整除关系时统一使用“约数”。

例如，$1,2,3,4,6,12$ 是 $12$ 的全部正约数，$12,24,36,\ldots$ 都是 $12$ 的正倍数。讨论“全部约数”时必须看题目是否只取正数；整除关系本身允许负整数。

## 余数判定

当 $b\ne0$ 时，$b\mid a$ 等价于 $a$ 除以 $b$ 的余数为 $0$：

```cpp
typedef long long ll;

bool divides(ll b, ll a) {
    return b != 0 && a % b == 0;
}
```

函数参数仍按照数学记号 `b | a` 的顺序排列。这个函数主动排除 `b == 0`，因为 C++ 中整数对 $0$ 取余是未定义行为。

## 零的边界

对任意非零整数 $b$，都有

$$
b\mid0,
$$

因为 $0=b\times0$。相反，$0$ 不能整除任何非零整数，因为不可能有 $a=0\times k\ne0$。

> 若完全按照“存在整数 $k$ 使 $a=bk$”的定义，$0\mid0$ 成立；也有教材事先要求除数非零，因而不讨论这个式子。竞赛代码不需依赖这个边界约定；看到零时，直接回到题面定义。

## 基本性质

整除的下列性质可以直接把定义中的乘积代入验证。

- 对任意非零整数 $a$，都有 $a\mid a$；若采用允许 $0\mid0$ 的定义，这一条也覆盖 $a=0$。
- 若 $a\mid b$ 且 $b\mid c$，则 $a\mid c$。
- 若 $d\mid a$ 且 $d\mid b$，则对任意整数 $x,y$，都有 $d\mid(ax+by)$。
- $a\mid b$ 当且仅当 $-a\mid b$；在只关心整除性时，正负号不会改变结果。

第三条尤其重要。例如，若 $d$ 同时整除 $a$ 和 $b$，那么它也一定整除

$$
a-qb.
$$

欧几里得算法正是通过这种线性组合，把原问题换成更小的问题。

## 基础练习

1. 分别判断 $3\mid12$、$12\mid3$、$-3\mid12$、$5\mid0$ 是否成立，并写出对应的整数 $k$。
2. 已知 $4\mid a$ 且 $4\mid b$，证明 $4\mid(3a-2b)$。
3. 写一个 `divides` 函数，依次测试正数、负数和零；保证程序不会计算对 $0$ 取余。

## 需要记住什么

1. $b\mid a$ 的定义是什么？符号两边分别是除数还是被除数？
2. 当 $b\ne0$ 时，如何用 `%` 判断 $b\mid a$？
3. 为什么任意非零整数都整除 $0$？
4. 若 $d\mid a$ 且 $d\mid b$，为什么 $d$ 也整除 $ax+by$？

`0 | 0` 在不同教材中的约定差异只需了解，不需要记忆。[质数](prime-numbers.md) 会继续研究正整数的约数结构。
