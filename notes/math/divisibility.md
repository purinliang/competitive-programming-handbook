# 因数、倍数与整除

> 最近修订：2026-08-16 20:57 +10:00（未审阅）

除法通常会产生商和余数，数论则经常先问一个更简单的问题：“能不能恰好除尽？”
整除把这个问题写成一种可以推理的关系，因数与倍数描述这个关系两端的整数。

质数、最大公约数、质因数分解和模运算都会反复使用这些概念。

## 整除

给定整数 $a,b$。如果存在整数 $k$，使得：

$$
a=bk,
$$

就说 $b$ **整除** $a$，记作：

$$
b\mid a.
$$

例如 $12=3\times4$，所以 $3\mid12$；不存在整数 $k$ 使 $12=5k$，所以
$5\nmid12$。

符号左侧 `b` 是用来除的数，右侧 `a` 是被除的数。口语通常说“`a` 能被 `b`
整除”，书写时不要因此把两边颠倒。

## 因数与倍数

若 $b\mid a$，就称 $b$ 是 $a$ 的**因数**，$a$ 是 $b$ 的**倍数**。“约数”是
“因数”的另一个常见名称；本书后文统一使用“因数”。

例如：

```text
1, 2, 3, 4, 6, 12
```

是 $12$ 的全部正因数，而：

```text
12, 24, 36, 48, ...
```

都是 $12$ 的正倍数。

说“全部因数”时要看题目是否只讨论正因数。整除关系允许负整数，所以 $-3$ 也是
$12$ 的因数，$-12$ 也是 $3$ 的倍数。竞赛数论若没有特别说明，列举因数通常指
正因数。

## 用余数判断

当 `b != 0` 时，$b\mid a$ 等价于 `a` 除以 `b` 的余数为 $0$：

```cpp
bool is_divisible(ll a, ll b) {
    return b != 0 && a % b == 0;
}
```

函数名按英语语序表示“`a` 能否被 `b` 整除”，所以被除数 `a` 在前、除数 `b`
在后。先检查 `b != 0` 很重要：C++ 的整数除法和取余都不允许除数为 $0$，否则
行为未定义。

函数返回假只表示本程序不接受 `b == 0` 作为除数，不是在替所有数学教材规定
$0\mid0$ 应怎样解释。

## 数字 0

对任意非零整数 $b$，都有：

$$
b\mid0,
$$

因为可以取 $k=0$，得到 $0=b\times0$。换句话说，$0$ 是每个非零整数的倍数。

相反，$0$ 不能整除任何非零整数，因为：

$$
0\times k=0
$$

不可能等于一个非零的 $a$。

“C++ 中不能除以 $0$”和“$0$ 是不是某个整数的倍数”是两个问题：前者约束 `/`、
`%` 的除数，后者使用 $a=bk$ 的数学定义。不能从“不能除以零”错误推出“零不是
任何数的倍数”。

若完全按照“存在整数 $k$ 使 $a=bk$”的定义，$0\mid0$ 成立；也有教材预先要求
整除符号左侧非零，因此不讨论这个式子。竞赛代码通常不依赖这项边界约定；遇到它
时按题面定义处理。

## 数字 1 与正负号

对任意整数 $a$，都有：

$$
1\mid a,
$$

因为 $a=1\times a$。所以 $1$ 是每个整数的因数，每个整数都是 $1$ 的倍数。

正负号不会改变“能否整除”：

$$
b\mid a\iff -b\mid a\iff b\mid -a.
$$

例如 $3\mid12$、$-3\mid12$、$3\mid-12$ 都成立。它们对应的整数倍 `k` 符号
不同，但存在性不变。

## 基本性质

整除的性质可以直接把定义中的乘积代入验证。

### 传递性

若 $a\mid b$ 且 $b\mid c$，则 $a\mid c$。

因为存在整数 $x,y$ 使 $b=ax$、$c=by$，代入得到：

$$
c=a(xy),
$$

而 $xy$ 仍是整数。

### 整数线性组合

若 $d\mid a$ 且 $d\mid b$，则对任意整数 $x,y$，都有：

$$
d\mid(ax+by).
$$

设 $a=dm$、$b=dn$，那么：

$$
ax+by=d(mx+ny).
$$

其中 $mx+ny$ 仍是整数。特别地，`d` 也整除 $a-b$、$a+b$ 和 $a-qb$。
[欧几里得算法](euclidean-algorithm.md) 正是利用 $a-qb$，把最大公约数问题换成
数值更小但公因数不变的问题。

## 完整代码

程序读入若干组 `a,b`，逐组判断 $b\mid a$。输入允许 `b == 0`，此时程序按照
函数接口统一输出 `No`，并且不会执行对零取余。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

bool is_divisible(ll a, ll b) {
    return b != 0 && a % b == 0;
}

void solve() {
    int q;
    scanf("%d", &q);

    while (q--) {
        ll a;
        ll b;
        scanf("%lld%lld", &a, &b);
        printf(is_divisible(a, b) ? "Yes\n" : "No\n");
    }
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
4
12 3
12 5
12 -3
12 0
```

输出：

```text
Yes
No
Yes
No
```

每组判断只进行固定次数的整数运算，时间复杂度是 $O(1)$，额外空间复杂度是
$O(1)$；处理 `q` 组询问的总时间是 $O(q)$。

## 常见错误

### 写反整除符号

$b\mid a$ 表示 `a` 是 `b` 的整数倍。它不表示 `a` 整除 `b`。

### 先计算对零取余

应让 `b != 0` 位于 `&&` 左侧，利用短路求值避免执行 `a % b`。不能先保存
`a % b`，再检查 `b`。

### 混淆因数与倍数

若 $3\mid12$，$3$ 是 $12$ 的因数，$12$ 是 $3$ 的倍数。两个术语的方向相反。

### 认为 0 不是任何数的倍数

对非零整数 $b$，$0=b\times0$，所以 $0$ 是 `b` 的倍数；这不会允许 C++ 把 $0$
用作 `/` 或 `%` 的除数。

## 基础练习

1. 分别判断 $3\mid12$、$12\mid3$、$-3\mid12$、$5\mid0$ 是否成立，并写出整数 $k$。
2. 列出 $18$ 的全部正因数和前五个正倍数。
3. 已知 $4\mid a$ 且 $4\mid b$，证明 $4\mid(3a-2b)$。
4. 解释为什么 $0$ 是 $7$ 的倍数，却不能在 C++ 中计算 `12 % 0`。
5. 修改完整程序，按题目给出的明确约定单独处理 `0 | 0`。

## 需要记住什么

1. $b\mid a$ 的定义是什么？符号左右两边的顺序怎样理解？
2. 若 $b\mid a$，谁是谁的因数，谁是谁的倍数？
3. 当 `b != 0` 时，怎样用 `%` 判断 $b\mid a$？
4. 为什么任意非零整数都整除 $0$？
5. “不能除以零”为什么不等于“零不是任何数的倍数”？
6. 正负号是否改变整除关系？
7. 为什么公因数也一定整除整数线性组合 $ax+by$？

`0 | 0` 的教材约定差异只需了解，不需要脱离题面背诵一种答案。
