# Prufer 序列

> 最近修订：2026-08-23 06:30 +10:00（未审阅）

$n$ 个有标号节点能组成多少棵不同的无根树？直接选择 $n-1$ 条边会枚举大量不连通图
和含环图，很难只保留树。

Prufer 序列把每棵节点编号为 `1..n` 的树唯一编码成一个长度为 `n-2` 的序列，序列
中的每个位置都可以任取 `1..n`。树的计数因此立即变成：

$$
n^{n-2}.
$$

本文建立树与序列之间的双向转换，并解释序列中一个编号出现的次数为什么恰好比对应
节点的度数少 `1`。

## 每次删除编号最小的叶子

树中度数为 `1` 的节点称为叶子。对一棵有 `n` 个节点的树，重复执行：

1. 找出当前编号最小的叶子 `leaf`；
2. 记录它唯一相邻的节点 `neighbor`；
3. 删除 `leaf` 及其相连的边。

删除 `n-2` 次后只剩两个节点。依次记录的 `neighbor` 构成 Prufer 序列。

例如，对边集：

```text
1-4
2-4
3-4
4-5
5-6
```

最初叶子为 `1,2,3,6`：

- 删除 `1`，记录 `4`；
- 删除 `2`，记录 `4`；
- 删除 `3`，记录 `4`，此时 `4` 成为叶子；
- 删除 `4`，记录 `5`。

所以序列为：

```text
4 4 4 5
```

长度确实是 $6-2=4$。

> 必须固定删除“编号最小”的叶子。若每次任意挑选叶子，同一棵树可能得到不同序列，
> 就不再是唯一编码。

## 从序列恢复每个节点的初始度数

编码过程中，节点 `u` 每次作为被删除叶子的邻居出现，都会失去一条相连边。它最终
还要保留最后一条边，才能自己成为叶子，或成为最后剩下的两个节点之一。

因此：

$$
degree(u)=1+\mathrm{count}(u),
$$

其中 $\mathrm{count}(u)$ 是编号 `u` 在 Prufer 序列中的出现次数。

特别地：

- 序列中从未出现的节点度数为 `1`，恰好是原树叶子；
- 出现 `k` 次的节点度数为 `k+1`。

这个性质让我们在还没有恢复任何边以前，就能从序列算出所有度数。

## 解码：把删除过程倒放

已知长度为 `n-2` 的序列 `code`：

1. 把所有节点度数初始化为 `1`；
2. 每读到一个编号 `u`，令 `degree[u]` 增加 `1`；
3. 把当前所有度数为 `1` 的节点放进最小堆；
4. 依次处理序列值 `u`，取出最小叶子 `leaf`，加入边 `(leaf,u)`；
5. 删除这条边后令 `degree[u]` 减少 `1`，若它变成叶子就放入最小堆；
6. 序列处理完后，连接最后两个叶子。

处理 `code[i]` 时，堆顶正是编码过程第 `i` 次删除的最小叶子。因此解码会逐步恢复
原来的每一条边。

## 为什么树与序列一一对应

编码规则没有选择余地：当前树和“最小叶子”共同确定下一项，因此每棵树只产生一个
序列。

反过来，任意长度为 `n-2`、元素位于 `1..n` 的序列都能按上述度数和最小堆规则完成
解码：

- 初始度数之和为 $n+(n-2)=2n-2$，正好对应 $n-1$ 条边；
- 每处理一个序列值都会连接并删除一个叶子；
- 最后恰好剩两个度数为 `1` 的节点，再连接最后一条边；
- 每次新节点都通过一条边接入尚未删除的部分，不会形成环，最终又含 $n-1$ 条边，
  所以结果是一棵树。

对解码所得树重新编码时，每一步都会选回同一个最小叶子，得到原序列。于是编码和
解码互为逆过程，树与序列构成一一对应。

## Cayley 公式

长度为 `n-2` 的序列共有 `n-2` 个位置，每个位置都能独立选择 `1..n` 中任意编号：

$$
n\times n\times\cdots\times n=n^{n-2}.
$$

由于每个序列唯一对应一棵有标号树，所以 $n$ 个有标号节点的无根树数量为：

$$
\boxed{n^{n-2}}.
$$

这就是 Cayley 公式。这里统计的是节点编号不同就视为不同的有标号树，不是把同构形状
合并后的无标号树数量。

## 给定度数时的树数量

若要求节点 `i` 的度数为 $d_i$，它在序列中必须恰好出现 $d_i-1$ 次。

当所有 $d_i\ge1$ 且：

$$
\sum_{i=1}^{n}d_i=2n-2
$$

时，这些出现次数之和为 `n-2`。满足指定度数的有标号树数量就是对应多重集合的排列
数量：

$$
\frac{(n-2)!}{\prod_{i=1}^{n}(d_i-1)!}.
$$

若度数和不等于 $2n-2$，或某个 $d_i<1$，则不存在这样的树。

## 完整代码

输入节点数 `n` 和长度为 `n-2` 的 Prufer 序列，输出唯一对应的树边。保证
`2 <= n`，序列中所有编号位于 `1..n`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> code;
vector<int> degree;

vector<pair<int, int>> decode_prufer() {
    degree.assign(n + 5, 1);
    for (int u : code) {
        ++degree[u];
    }

    priority_queue<int, vector<int>, greater<int>> leaves;
    for (int u = 1; u <= n; ++u) {
        if (degree[u] == 1) {
            leaves.push(u);
        }
    }

    vector<pair<int, int>> edges;
    edges.reserve(n - 1);

    for (int u : code) {
        int leaf = leaves.top();
        leaves.pop();

        edges.push_back({leaf, u});
        --degree[leaf];
        --degree[u];
        if (degree[u] == 1) {
            leaves.push(u);
        }
    }

    int u = leaves.top();
    leaves.pop();
    int v = leaves.top();
    leaves.pop();
    edges.push_back({u, v});

    return edges;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    code.resize(n - 2);
    for (int& u : code) {
        cin >> u;
    }

    vector<pair<int, int>> edges = decode_prufer();
    for (auto [u, v] : edges) {
        cout << u << ' ' << v << '\n';
    }
    return 0;
}
```

## 编码怎样实现

从一棵已有树编码时，同样先计算度数并把所有叶子加入最小堆。每次取出最小叶子，在
它的邻接表中找到仍未删除的邻居，将该邻居加入序列，再更新度数。

每个节点只会作为叶子删除一次，扫描它原来的邻接表一次；全部邻接表长度之和为
$2(n-1)$。配合最小堆后，编码与解码都能在 $O(n\log n)$ 时间完成。

若只需要线性时间，可以利用编号和“当前最小叶子只会向右移动，除非新叶子编号更小”
的性质维护指针；这种实现常数更小，但分支更绕，不改变 Prufer 序列本身的原理。

## 复杂度

完整解码程序中：

- 统计度数需要 $O(n)$；
- 每个节点至多进入、离开最小堆一次，时间复杂度为 $O(n\log n)$；
- 度数、序列、堆与答案共使用 $O(n)$ 空间。

## 常见错误

- 把序列长度写成 `n-1`；
- 编码时任意选择叶子，没有固定选择编号最小者；
- 把节点度数直接设成序列出现次数，漏掉最后保留的一条边；
- 解码时连接一条边后只减少叶子度数，没有减少序列值对应节点的度数；
- 节点刚变成叶子时没有加入最小堆；
- 处理完序列后忘记连接最后两个节点；
- 把 Cayley 公式用于无标号树计数；
- 给定度数时忘记检查度数和必须等于 $2n-2$。
