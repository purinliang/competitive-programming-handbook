# 快速幂

> 最近修订：2026-08-16 21:18 +10:00（未审阅）

计算 $base^{exponent}$ 最直接的方法，是把 `base` 连乘 `exponent` 次：

```cpp
ll result = 1;
for (ll i = 1; i <= exponent; i++) {
    result *= base;
}
```

这需要 $O(exponent)$ 次乘法。若指数接近 $10^{18}$，即使最终结果的保存问题由题目
另行解决，也不可能逐次完成这么多乘法。

快速幂把指数拆成若干个 $2$ 的幂，并用反复平方准备对应结果。它只需要
$O(\log exponent)$ 次乘法。本篇先学习普通整数版本，并假设所有乘法结果都能放入
64 位整数；模意义下控制数值范围的版本将在 [模快速幂](modular-exponentiation.md)
中学习。

## 反复平方

计算 $base^8$ 不需要连续乘八次。可以依次得到：

$$
base^2=base\times base,
$$

$$
base^4=base^2\times base^2,
$$

$$
base^8=base^4\times base^4.
$$

每次平方都会让指数翻倍。已知 $base^{2^j}$ 时，再平方一次便得到
$base^{2^{j+1}}$。

## 指数的二进制分解

任意非负整数都能唯一表示成若干个不同的 $2$ 的幂之和。例如：

$$
13=8+4+1=2^3+2^2+2^0.
$$

因此：

$$
base^{13}=base^8\times base^4\times base^1.
$$

整数的奇偶性告诉我们最低二进制位：

- `exponent % 2 == 1` 表示最低位是 `1`，需要选中当前幂；
- `exponent % 2 == 0` 表示最低位是 `0`，跳过当前幂；
- `exponent /= 2` 删除最低位，让下一位成为新的最低位。

同时把当前底数平方，它就会依次表示原始底数的
$base^1,base^2,base^4,base^8,\ldots$。

## 三个变化的量

循环维护三个量：

- `result`：已经选中的二进制位对应幂的乘积；
- `base`：当前最低位对应的原始底数幂；
- `exponent`：还没有处理的指数部分。

初始时尚未选中任何幂，乘法的空积是 `1`：

```cpp
ll result = 1;
```

每轮先判断当前最低位。若它是 `1`，就把当前 `base` 乘入答案：

```cpp
if (exponent % 2 == 1) {
    result *= base;
}
```

然后删除最低位。只要后面还有位需要处理，就把 `base` 平方，准备下一轮：

```cpp
exponent /= 2;
if (exponent > 0) {
    base *= base;
}
```

最后一次处理后不再平方，可以避免计算一个答案根本不需要的更高次幂。

## 手算 $3^{13}$

观察每轮开始时的状态：

| 剩余指数 | 当前 `base` | 是否乘入 | 本轮后的 `result` |
| ---: | ---: | --- | ---: |
| $13$ | $3^1$ | 是 | $3^1$ |
| $6$ | $3^2$ | 否 | $3^1$ |
| $3$ | $3^4$ | 是 | $3^5$ |
| $1$ | $3^8$ | 是 | $3^{13}$ |

指数依次变成 `13, 6, 3, 1, 0`，只执行四轮。

## 循环不变量

设最初要求 $B^E$。每轮开始时始终满足：

$$
result\times base^{exponent}=B^E.
$$

初始时 `result=1`、`base=B`、`exponent=E`，关系成立。

若当前指数为偶数 $2q$，不修改 `result`，随后把底数平方、指数减半：

$$
result\times(base^2)^q=result\times base^{2q}.
$$

若当前指数为奇数 $2q+1$，先把一个 `base` 乘入 `result`，再进行同样的变化：

$$
(result\times base)\times(base^2)^q
=result\times base^{2q+1}.
$$

两种情况都保持不变量。循环结束时 `exponent=0`，剩余部分等于 $1$，所以
`result=B^E`。

## 完整代码

`power` 没有跨调用状态，只根据本次参数返回结果，因此使用普通函数。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

ll power(ll base, ll exponent) {
    ll result = 1;

    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result *= base;
        }

        exponent /= 2;
        if (exponent > 0) {
            base *= base;
        }
    }

    return result;
}

void solve() {
    ll base, exponent;
    scanf("%lld%lld", &base, &exponent);
    printf("%lld\n", power(base, exponent));
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 13
```

输出：

```text
1594323
```

## 边界与数值范围

### 指数为零

循环不执行并返回 `1`，对应 $base^0=1$。这份实现把 $0^0$ 视为乘法的空积 `1`；
若题目另有定义，以题意为准。

### 指数为负

本篇只接受非负指数。整数范围内的负指数通常不是整数，不能直接交给当前循环。

### 乘法溢出

快速幂只减少乘法次数，不会扩大 64 位整数的表示范围。若某次 `result *= base` 或
`base *= base` 的数学结果超出范围，就会发生有符号整数溢出，程序行为未定义。
必须先根据题目范围证明所有乘法安全。

当前代码只在后续还有二进制位时平方，避免最后一次无用平方；这仍不能替代数据范围
分析。题目要求取模时，应改用模快速幂，而不是先算出完整幂再取模。

## 复杂度

每轮把非负指数除以 `2`，所以循环次数为 $O(\log exponent)$。把一次 64 位整数
乘法视为 $O(1)$ 时，时间复杂度是 $O(\log exponent)$，额外空间是 $O(1)$。

## 常见错误

### 把 `^` 当成乘方

C++ 中 `base ^ exponent` 是按位异或，不是乘方。

### 只反复平方

反复平方只能准备 $base^1,base^2,base^4,\ldots$。指数某一位为 `1` 时，还必须把
对应幂乘入 `result`。

### 先删除最低位

若先执行 `exponent /= 2` 再判断奇偶，原来的最低位已经丢失。每轮必须先判断当前
指数是否为奇数。

### 认为对数时间不会溢出

时间复杂度与数值容量是两件事。即使循环只有几十轮，中间乘积仍可能超出范围。

## 基础练习

1. 手动把 `13` 写成不同的 $2$ 的幂之和，并模拟 `3^13` 的四轮状态。
2. 比较指数 `0,1,2,8,15` 时循环执行多少轮、哪些轮会乘入答案。
3. 用 $O(exponent)$ 的重复乘法对拍小指数，检查快速幂结果。
4. 估算 `2^62` 与 `2^63` 是否能用 64 位整数保存，并观察边界。
5. 把乘法替换成矩阵乘法需要哪些单位元和结合律条件？

## 需要记住什么

1. 为什么反复平方能依次得到指数为 $1,2,4,8,\ldots$ 的幂？
2. 怎样通过奇偶性和除以 `2` 从低到高读取指数的二进制位？
3. `result`、`base` 和 `exponent` 分别表示什么？
4. 循环不变量怎样覆盖偶数指数与奇数指数？
5. 为什么时间复杂度是 $O(\log exponent)$？
6. 快速幂为什么不能解决整数溢出？
7. 指数为 `0` 和负数时分别怎样处理？

普通快速幂的核心是指数分解，与是否取模无关。后续的模快速幂和矩阵快速幂都会
保留同一循环，只替换乘法、单位元和结果表示方式。
