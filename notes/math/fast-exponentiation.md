# 快速幂

> 最近修订：2026-08-15 21:28 +10:00（未审阅）

需要计算：

$$
base^{exponent}\bmod MOD,
$$

其中 `exponent` 是非负 64 位整数。按照定义把 `base` 连乘 `exponent` 次，需要 $O(exponent)$ 时间；当指数接近 $10^{18}$ 时无法完成。

快速幂利用指数的二进制表示，把指数拆成 $1,2,4,8,\ldots$，并通过反复平方得到这些幂。每轮把指数减半，只需要 $O(\log exponent)$ 次乘法。

本文使用固定模数 `MOD=10^9+7`。每次乘法后立即取模的依据见 [模运算](modular-arithmetic.md)。

## 从重复乘法到平方

计算 $base^8$ 不需要连续乘八次。可以反复平方：

$$
base^2=base\times base,
$$

$$
base^4=base^2\times base^2,
$$

$$
base^8=base^4\times base^4.
$$

指数每次翻倍，只用三次乘法就得到八次方。一般地，已经知道 $base^{2^j}$ 时，平方一次就得到：

$$
base^{2^{j+1}}=base^{2^j}\times base^{2^j}.
$$

这与倍增的思想相同：用已经完成的长度为 $2^j$ 的结果，得到长度为 $2^{j+1}$ 的结果。

## 指数的二进制分解

任意非负整数都能表示为若干个不同的 2 的幂之和。例如：

$$
13=8+4+1=2^3+2^2+2^0.
$$

所以：

$$
base^{13}=base^8\times base^4\times base^1.
$$

反复检查指数是否为奇数并除以 `2`，就能从低位到高位读取二进制：

```text
13 是奇数：需要当前的 base^1
13 / 2 = 6
6 是偶数：不需要当前的 base^2
6 / 2 = 3
3 是奇数：需要当前的 base^4
3 / 2 = 1
1 是奇数：需要当前的 base^8
1 / 2 = 0，结束
```

每除一次 `2`，当前底数就平方一次，使它依次表示原始底数的 $1,2,4,8,\ldots$ 次幂。

## 三个持续变化的量

算法维护：

- `result`：已经选中的那些 2 的幂对应的乘积；
- `base`：当前二进制位代表的幂；
- `exponent`：还没有处理的指数部分。

初始时还没有选中任何幂，乘法的空积是 `1`：

```cpp
ll result = 1;
```

底数先规范到 `[0,MOD-1]`：

```cpp
base %= MOD;
if (base < 0) {
    base += MOD;
}
```

每一轮：

1. 若 `exponent` 是奇数，把当前 `base` 乘入答案；
2. 把 `base` 平方，准备下一位；
3. 把 `exponent` 除以 `2`，删除已经处理的最低位。

```cpp
while (exponent > 0) {
    if (exponent % 2 == 1) {
        result = result * base % MOD;
    }
    base = base * base % MOD;
    exponent /= 2;
}
```

`result` 和 `base` 始终位于 `[0,MOD-1]`。对本篇固定的 `MOD=10^9+7`，两者乘积能够放入 64 位整数。

## 手算 3 的 13 次方

忽略取模，观察每轮状态：

| 剩余指数 | 当前 `base` | 是否乘入 | `result` |
| ---: | ---: | --- | ---: |
| 13 | $3$ | 是 | $3$ |
| 6 | $3^2=9$ | 否 | $3$ |
| 3 | $3^4=81$ | 是 | $3^5$ |
| 1 | $3^8=6561$ | 是 | $3^{13}$ |

指数从 `13` 依次变成 `6,3,1,0`，只执行四轮。真正代码每次乘法后取模，但同余值与完整整数幂保持一致。

## 正确性不变量

设最初要求计算 $B^E$。循环过程中始终满足：

$$
result\times base^{exponent}\equiv B^E\pmod {MOD}.
$$

初始时 `result=1`、`base=B`、`exponent=E`，等式显然成立。

若当前指数是偶数 `2q`，本轮不修改 `result`，随后令底数平方、指数减半：

$$
result\times(base^2)^q=result\times base^{2q}.
$$

若当前指数是奇数 `2q+1`，先把一个 `base` 乘入 `result`，再平方底数并把指数变成 `q`：

$$
(result\times base)\times(base^2)^q
=result\times base^{2q+1}.
$$

两种情况都保持不变量。循环结束时 `exponent=0`，剩余部分是 $base^0=1$，所以：

$$
result\equiv B^E\pmod {MOD}.
$$

## 完整代码

`power` 只依赖本次参数和固定全局模数，没有持续对象状态，因此使用普通函数。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const ll MOD = 1e9 + 7;

ll power(ll base, ll exponent) {
    base %= MOD;
    if (base < 0) {
        base += MOD;
    }

    ll result = 1;
    while (exponent > 0) {
        if (exponent % 2 == 1) {
            result = result * base % MOD;
        }
        base = base * base % MOD;
        exponent /= 2;
    }
    return result;
}

int main() {
    ll base, exponent;
    scanf("%lld%lld", &base, &exponent);
    printf("%lld\n", power(base, exponent));
    return 0;
}
```

输入：

```text
3 13
```

输出：

```text
1594323
```

$3^{13}=1594323$，还没有超过 `MOD`，所以输出与完整整数幂相同。指数更大时，程序仍只保存模 `MOD` 的代表值。

## 边界条件

### 指数为 0

对任意底数，算法返回乘法单位元 `1`：

$$
base^0=1.
$$

这份快速幂实现把 `0^0` 视为乘法的空积 `1`；若具体题目为它规定了其他含义，以题意为准。

### 底数为负

函数开头把底数规范到 `[0,MOD-1]`。例如 `-2` 会被替换成同余的 `MOD-2`，后续平方和乘法都保持正确。

### 指数为负

本篇只接受非负指数。负指数需要把底数替换成模逆元，再计算正指数；逆元不一定存在，不能让当前循环直接处理负数。

### 模数为 1

若把函数改成接收一般正模数，初始值也应写成 `1%mod`，因为模 `1` 的标准代表值只有 `0`。本篇固定 `MOD=10^9+7`，所以 `result=1` 已经规范。

## 复杂度

每轮把非负指数除以 `2`，循环次数是 $O(\log exponent)$。每轮只执行固定次数的 64 位乘法、取余和除法，所以时间复杂度为 $O(\log exponent)$，额外空间为 $O(1)$。

即使指数是 $10^{18}$，循环也只有大约 $60$ 轮。

## 常见错误

### 使用异或符号表示乘方

C++ 中 `base ^ exponent` 是按位异或，不是乘方。整数快速幂必须显式实现循环。

### 忘记指数为奇数时乘入答案

反复平方只得到 $base^1,base^2,base^4,\ldots$。二进制位为 `1` 时必须把对应幂加入乘积。

### 先把 exponent 除以 2

若先删除最低位，再判断奇偶，就会错过当前位。每轮先检查当前 `exponent%2`，再除以 `2`。

### 只在最后取模

底数反复平方会极快溢出。`result*base` 和 `base*base` 都必须立即取模。

### 忽略乘法类型上限

本篇固定模数保证两个标准余数的乘积能放进 64 位整数。模数接近 64 位上限时，需要替换乘法实现，而不是照搬当前一行。

### 让负指数进入循环

负数整数除以 `2` 的行为不能实现模意义的负指数。必须先判断是否存在逆元，并把问题转换成非负指数。

## 基础练习

1. 手动把 `13` 写成不同 2 的幂之和，并模拟 `3^13` 的四轮状态。
2. 分别计算指数 `0,1,2,8,15` 时循环执行多少轮、哪些轮会乘入答案。
3. 用 $O(exponent)$ 的重复乘法作为参考，对小指数随机检查快速幂。
4. 测试负底数、底数为 `0` 和指数为 `0` 的边界。
5. 把固定 `MOD` 改为函数参数，并正确处理 `mod=1` 的初始值。
6. 用同样的指数分解思路实现不取模但保证结果不溢出的整数快速幂。

## 需要记住什么

1. 快速幂为什么只需要准备 $base^1,base^2,base^4,\ldots$？
2. 怎样从指数的奇偶性和整数除以 `2` 逐位读取二进制？
3. `result`、`base` 和 `exponent` 在循环中分别表示什么？
4. 为什么奇数指数要先把当前 `base` 乘入 `result`？
5. 循环不变量怎样覆盖偶数和奇数两种情况？
6. 为什么时间复杂度是 $O(\log exponent)$？
7. 指数为 `0`、底数为负和指数为负时分别怎样处理？
8. 为什么固定模数的范围保证仍然是代码的一部分？

矩阵快速幂会把普通乘法替换成矩阵乘法，继续使用完全相同的指数拆分。快速幂求模逆元、欧拉降幂和一般代数结构上的幂运算将在各自需要时解释，不属于本篇基础整数模幂。
