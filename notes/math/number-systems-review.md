# 数系：自然数、整数、有理数与实数

> 最近修订：2026-08-17 01:16 +10:00（未审阅）

竞赛题面经常直接写“给定一个正整数”“答案是有理数”或“在实数范围内求解”。这些名称描述的是数学对象的范围，不等于 C++ 中某一种具体类型。

本篇只统一自然数、整数、有理数、无理数和实数的定义，以及它们与程序数据类型之间的边界。

## 自然数

自然数用于计数：

```text
0, 1, 2, 3, ...
```

“自然数是否包含 `0`”在不同教材中存在约定差异。题目若只写自然数而没有进一步说明，应结合范围判断；严谨表达可以写：

- 非负整数：`0, 1, 2, ...`；
- 正整数：`1, 2, 3, ...`。

本书需要包含 `0` 时优先直接说“非负整数”，需要排除 `0` 时说“正整数”，避免依赖自然数的两种约定。

## 整数

整数集合包含负整数、零和正整数：

$$
\mathbb Z=\{\ldots,-2,-1,0,1,2,\ldots\}.
$$

整数之间进行加法、减法和乘法，结果仍然是整数。例如：

$$
3-5=-2,
\qquad
(-3)\times4=-12.
$$

整数除法的数学结果不一定是整数：

$$
1\div2=\frac12.
$$

因此整数集合对加、减、乘封闭，对普通除法不封闭。除数为 `0` 时，除法没有定义。

## 有理数

能够写成两个整数之比的数称为有理数：

$$
\frac pq,
\qquad
p,q\in\mathbb Z,
\qquad
q\ne0.
$$

例如：

$$
\frac12,
\quad
-\frac73,
\quad
5=\frac51,
\quad
0=\frac01
$$

都是有理数。每个整数都是有理数，因为整数 $z$ 总能写成 $z/1$。

同一个有理数可以有多种分数表示：

$$
\frac12=\frac24=\frac{-3}{-6}.
$$

把分子分母同时除以最大公因数，可以得到最简形式；若还统一令分母为正，就能为同一个有理数选择唯一的规范表示。

有限小数和无限循环小数都是有理数，例如：

$$
0.125=\frac18,
\qquad
0.333\ldots=\frac13.
$$

## 无理数与实数

不能写成整数比值的实数称为无理数，例如：

$$
\sqrt2,
\qquad
\pi.
$$

无理数的小数展开无限且不循环。仅仅看到很多小数位还不能判断一个数无理；有理数也可能有无限循环展开。

有理数与无理数合在一起组成实数集合 $mathbb R$。实数可以对应数轴上的位置，并且能够比较大小。

常见包含关系是：

$$
\mathbb N\subseteq\mathbb Z\subseteq\mathbb Q\subseteq\mathbb R.
$$

其中自然数是否含 `0` 不影响这条包含关系。无理数属于实数，但不属于有理数。

## 数学集合与 C++ 类型不同

数学整数集合 $mathbb Z$ 向两侧无限延伸。C++ 的 `int` 和 `long long` 只能保存有限范围内的整数：

```cpp
int x;
long long y;
```

因此：

```text
int 可表示值 ⊂ long long 常见可表示值 ⊂ 数学整数
```

`double` 也不等于“实数类型”。实数集合包含无限多需要无限信息才能精确描述的数，而 `double` 只有固定数量的二进制位，只能近似保存绝大多数实数和许多有理数。

例如数学上 $0.1$ 是有理数，但二进制浮点数通常不能精确保存它。一个数属于哪个数学集合，与程序选择什么近似表示是两件事。

## C++ 整数除法不会自动得到有理数

两个整数相除时，C++ 执行整数除法：

```cpp
int result = 1 / 2;
```

`result` 是 `0`，因为整数除法向 `0` 截断。即使把结果保存进 `double`，计算顺序也不会改变：

```cpp
double result = 1 / 2;
```

右侧仍然先进行整数除法，结果是 `0`，再转换成 `0.0`。

至少让一个操作数成为浮点数，才能进行浮点除法：

```cpp
double result = 1.0 / 2;
```

若题目要求精确保存分数，浮点近似可能仍不够。可以保存分子和分母，并用最大公因数约分；具体实现属于有理数表示或分数运算问题。

## 区间名称

题面还常用：

- 正数：大于 `0`；
- 负数：小于 `0`；
- 非负数：大于等于 `0`；
- 非正数：小于等于 `0`。

`0` 既不是正数也不是负数，但同时是非负数和非正数。写判断条件时，应把“正”和“非负”对应到 `>` 与 `>=`，不要漏掉边界。

## 完整代码

下面用同一组整数展示整数除法与浮点除法的区别。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int numerator;
    int denominator;
    cin >> numerator >> denominator;

    int integer_result = numerator / denominator;
    double real_result = 1.0 * numerator / denominator;

    cout << integer_result << '\n';
    cout << fixed << setprecision(6) << real_result << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
1 2
```

输出：

```text
0
0.500000
```

输入保证 `denominator != 0`。
