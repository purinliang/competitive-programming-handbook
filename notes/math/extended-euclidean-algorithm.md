# 数论：扩展欧几里得算法

> 状态：定稿

[数论：欧几里得算法](euclidean-algorithm.md) 只能求出 $\gcd(a,b)$ 的数值。现在考虑一个更具体的问题：允许把整数 $a$ 和 $b$ 分别增加或减少任意整数次，最终能够凑出哪些整数 $c$？

把使用次数分别记作整数 $x,y$，问题就是线性不定方程

$$
ax+by=c.
$$

例如，$252\times(-2)+105\times5=21$，所以若一次操作改变 $252$、另一次操作改变 $105$，允许正向或反向操作时就能凑出 $21$。扩展欧几里得算法不仅判断目标能否凑出，还会实际找出一组操作次数 $x,y$。

本篇围绕三个典型问题展开：求二元线性不定方程的一组整数解、求线性同余方程的最小非负解，以及在模数不是质数时求乘法逆元。它们的共同核心是：所有能够写成 $ax+by$ 的整数，恰好是 $\gcd(a,b)$ 的所有整数倍。

## 裴蜀等式

对不同时为 $0$ 的整数 $a,b$，存在整数 $x,y$，使得

$$
ax+by=\gcd(a,b).
$$

这个等式称为**裴蜀等式**（Bézout identity），$x,y$ 称为一组裴蜀系数。

扩展欧几里得算法（extended Euclidean algorithm）在计算 $\gcd(a,b)$ 的同时，返回其中一组 $x,y$。系数通常不唯一；递归回代会稳定地得到其中一组，但它不保证 $x,y$ 非负、绝对值最小或满足其他最优条件。需要特殊范围时，应当先求一组解，再利用后文的通解调整。

## 终止位置的系数

欧几里得算法最后会到达

$$
\gcd(a,0)=a
$$

的边界。在这里，等式

$$
a\times1+0\times0=a
$$

已经直接给出了系数 $x=1$、$y=0$。

所以问题不是“怎样猜出最底层的系数”，而是“怎样把它们沿着辗转相除的过程反向带回去”。

## 从子问题回代

欧几里得算法把 $(a,b)$ 变成 $(b,a\bmod b)$。假设递归已经为更小的问题找到了 $x_1,y_1$：

$$
bx_1+(a\bmod b)y_1=\gcd(b,a\bmod b).
$$

根据欧几里得算法，右边也是 $\gcd(a,b)$。再使用

$$
a\bmod b=a-\left\lfloor\frac ab\right\rfloor b,
$$

把余数替换回 $a,b$：

$$
\begin{aligned}
bx_1+(a\bmod b)y_1
&=bx_1+\left(a-\left\lfloor\frac ab\right\rfloor b\right)y_1\\
&=ay_1+b\left(x_1-\left\lfloor\frac ab\right\rfloor y_1\right).
\end{aligned}
$$

现在它已经变成 $ax+by$ 的形式。对照系数得到

$$
x=y_1,
$$

$$
y=x_1-\left\lfloor\frac ab\right\rfloor y_1.
$$

这两行不是需要凭空背诵的公式；它们只是把 $a\bmod b$ 换回 $a-qb$ 后，重新收集 $a,b$ 的系数。

## 手算回代

欧几里得算法已经得到

$$
252=2\times105+42,
$$

$$
105=2\times42+21.
$$

从最后一个非零余数开始：

$$
21=105-2\times42.
$$

再用第一个式子中的 $42=252-2\times105$ 替换 $42$：

$$
\begin{aligned}
21
&=105-2(252-2\times105)\\
&=-2\times252+5\times105.
\end{aligned}
$$

所以对 $a=252,b=105$，一组系数是 $x=-2$、$y=5$。

代回验证：

$$
252\times(-2)+105\times5=21=\gcd(252,105).
$$

## 翻译成代码

递归函数除了返回 `gcd`，还需要通过引用参数带回 `x` 和 `y`。下文沿用 `typedef long long ll;` 定义的别名 `ll`：

```cpp
ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }

    ll x1, y1;
    ll g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - a / b * y1;
    return g;
}
```

调用结束后始终满足

```text
a * x + b * y = g
```

本篇代码假设 $a,b$ 是非负整数且不同时为 $0$。负数会让 C++ 整除向零截断的细节进入推导；若题目允许负参数，应当先统一符号再调用。

参数声明中的 `&` 表示 C++ 引用。函数内给 `x,y` 赋值，会直接修改调用位置传入的两个变量。返回值已经用来带回 `gcd`，因此这里用两个引用参数同时带回裴蜀系数。

## 二元线性不定方程

因为 $g=\gcd(a,b)$ 同时整除 $a,b$，所有整数线性组合 $ax+by$ 都是 $g$ 的倍数。另一方面，扩展欧几里得算法已经找到一组系数使 $ax+by=g$；把两个系数同时乘以整数 $t$，就可以得到 $tg$。

因此，线性不定方程

$$
ax+by=c
$$

存在整数解当且仅当

$$
\gcd(a,b)\mid c.
$$

若 $g\mid c$，把 `exgcd` 求出的裴蜀系数同时乘以 $c/g$，就得到原方程的一组解：

```cpp
bool solve_equation(ll a, ll b, ll c, ll& x, ll& y) {
    ll g = exgcd(a, b, x, y);
    if (c % g != 0) {
        return false;
    }

    ll t = c / g;
    x *= t;
    y *= t;
    return true;
}
```

返回 `false` 表示无整数解；返回 `true` 时，引用参数 `x,y` 保存其中一组解。这里继续假设 $a,b$ 非负且不同时为 $0$，并且中间乘法能够放入 64 位整数。

例如，对方程

$$
252x+105y=42,
$$

`exgcd` 先求得 $252\times(-2)+105\times5=21$，再把系数乘以 $42/21=2$，得到一组解 $x=-4$、$y=10$。

## 全部整数解

设 $x_0,y_0$ 是 $ax+by=c$ 的一组解，$g=\gcd(a,b)$。对任意整数 $k$，都有

$$
x=x_0+k\frac bg,
$$

$$
y=y_0-k\frac ag.
$$

把它们代回原式，新增的两项正好相消，因此每个 $k$ 都给出一组解；反过来，原方程的全部整数解都可以这样表示。

对刚才的 $252x+105y=42$，从 $x_0=-4,y_0=10$ 出发，通解是

$$
x=-4+5k,
$$

$$
y=10-12k.
$$

取 $k=1$ 又得到 $x=1,y=-2$。这解释了为什么 `exgcd` 返回的系数不是唯一答案：它只提供一个起点，通解负责调整范围、正负或其他题目限制。若 $b>0$，总能选择恰当的 $k$，把 $x$ 归一化到 $[0,b/g)$；这一步才得到指定范围内的代表元。

## 线性同余方程

线性同余方程

$$
ax\equiv c\pmod m
$$

表示 $m\mid(ax-c)$。也就是说，存在整数 $y$ 使

$$
ax+my=c.
$$

它正是一个二元线性不定方程。因此它有解当且仅当

$$
\gcd(a,m)\mid c.
$$

求出一组解后，所有 $x$ 相差 $m/g$ 的整数倍，其中 $g=\gcd(a,m)$。下面的接口返回区间 $[0,m/g)$ 中的代表解 `x`，并通过 `period` 返回全部解的周期 $m/g$：

```cpp
bool solve_congruence(ll a, ll c, ll m, ll& x, ll& period) {
    ll y;
    ll g = exgcd(a, m, x, y);
    if (c % g != 0) {
        return false;
    }

    x *= c / g;
    period = m / g;
    x = (x % period + period) % period;
    return true;
}
```

这里假设 $m>0$，并且系数乘法不会溢出。若函数返回 `true`，全部解为

全部解可以写成 $x=x_0+k\cdot\text{period}$，其中 $k\in\mathbb Z$。

其中 $x_0$ 是函数返回的 `x`。

例如，

$$
14x\equiv30\pmod{100}
$$

中 $\gcd(14,100)=2$，而 $2\mid30$，所以有解。函数得到 $x_0=45$、`period = 50`，全部解就是 $x=45+50k$；代回可见 $14\times45\equiv30\pmod{100}$。

## 非质数模数下的逆元

当 $c=1$ 时，线性同余方程变成

$$
ax\equiv1\pmod m.
$$

此时的 $x$ 就是 $a$ 模 $m$ 的乘法逆元。模数 $m$ 不必是质数；逆元存在的准确条件是 $\gcd(a,m)=1$。

例如求 $7$ 模 $15$ 的逆元。扩展欧几里得算法给出

$$
7\times(-2)+15\times1=1.
$$

因此 $x=-2$ 是同余方程的一组解。把它归一化到 $[0,15)$，得到 $x=13$，而

$$
7\times13=91\equiv1\pmod{15}.
$$

所以 $7$ 模 $15$ 的逆元是 $13$，尽管模数 $15$ 是合数。相比之下，$\gcd(6,15)=3$，而 $3\nmid1$，所以 $6$ 模 $15$ 没有逆元。

直接复用上一节的线性同余方程接口即可：

```cpp
bool inverse(ll a, ll m, ll& result) {
    ll period;
    return solve_congruence(a, 1, m, result, period);
}
```

中国剩余定理和扩展中国剩余定理在合并同余条件时，也会使用 `exgcd` 求出的裴蜀系数。

## 复杂度

`exgcd` 与欧几里得算法进行相同次数的辗转相除，时间复杂度为 $O(\log\min(a,b))$，递归栈空间为 $O(\log\min(a,b))$。从一组裴蜀系数构造方程解、通解或同余方程代表解，都只再做常数次运算。

## 基础练习

1. 手算 `exgcd(99, 78)` 的递归与回代过程，并验证返回的 $x,y$。
2. 分别判断 $18x+30y=6$ 与 $18x+30y=7$ 是否有整数解；对有解的方程求出一组解。
3. 已知 $252x+105y=42$ 的一组解为 $x=-4,y=10$，使用通解找出另外三组解。
4. 求线性同余方程 $14x\equiv30\pmod{100}$ 的最小非负解和解的周期。
5. 分别求 $7$ 和 $6$ 模 $15$ 的逆元；若不存在，使用最大公约数说明原因。

## 需要记住什么

1. 所有形如 $ax+by$ 的整数为什么恰好是 $\gcd(a,b)$ 的倍数？
2. 当 `b == 0` 时，为什么可以返回 `x = 1, y = 0`？
3. 从 $bx_1+(a\bmod b)y_1$ 回代后，新的 $x,y$ 分别是什么？
4. `ll& x` 中的 `&` 有什么作用？为什么这里需要引用参数？
5. 方程 $ax+by=c$ 存在整数解的充要条件是什么？怎样从裴蜀系数得到一组解？
6. 已知一组解后，怎样表示全部整数解？`exgcd` 是否保证直接返回最小非负解？
7. 为什么 $ax\equiv c\pmod m$ 可以改写成二元线性不定方程？它何时有解，解的周期是什么？
8. 模数不是质数时，乘法逆元存在的准确条件是什么？怎样用 `exgcd` 求出它？
