# 数论：最大公约数与最小公倍数

> 状态：定稿

[数论：算术基本定理](fundamental-theorem-of-arithmetic.md) 把每个正整数变成了一组唯一的质因数指数。在这组坐标上，最大公约数和最小公倍数并不是两个需要分别背诵的奇怪公式：它们就是逐个质数取 `min` 和 `max`。

## 公约数与最大公约数

若正整数 $d$ 同时整除 $a$ 和 $b$，就称 $d$ 是 $a,b$ 的**公约数**。所有公约数中最大的一个称为**最大公约数**（greatest common divisor），记作

$$
\gcd(a,b).
$$

例如，$12$ 和 $18$ 的正公约数是 $1,2,3,6$，所以 $\gcd(12,18)=6$。

若 $\gcd(a,b)=1$，就称 $a,b$ **互质**。互质只表示两者没有大于 $1$ 的公约数，不表示它们各自都是质数。例如 $8$ 和 $15$ 都是合数，但它们互质。

## 公倍数与最小公倍数

若正整数 $m$ 同时是 $a$ 和 $b$ 的倍数，就称 $m$ 是 $a,b$ 的**公倍数**。所有正公倍数中最小的一个称为**最小公倍数**（least common multiple），记作

$$
\mathrm{lcm}(a,b).
$$

例如，$12$ 和 $18$ 的最小公倍数是 $36$。

## 指数的最小值

假设质数 $p$ 在 $a$ 和 $b$ 的质因数分解中分别出现 $x$ 次和 $y$ 次：

$$
a=\cdots p^x\cdots,\qquad b=\cdots p^y\cdots.
$$

若 $d$ 是两者的公约数，$d$ 中 $p$ 的指数既不能超过 $x$，也不能超过 $y$。因此它最多是

$$
\min(x,y).
$$

为了让公约数尽可能大，每个质数的指数都应当取到这个上限。所以

$$
\gcd(a,b)=\prod_p p^{\min(e_p(a),e_p(b))}.
$$

换句话说，`gcd` 就是对每个质因数指数分别取 `min`。

## 指数的最大值

若 $m$ 是 $a,b$ 的公倍数，$m$ 中 $p$ 的指数必须至少能够容纳 $a$ 中的 $x$ 次和 $b$ 中的 $y$ 次。因此它至少是

$$
\max(x,y).
$$

为了让公倍数尽可能小，不应当额外增加任何指数。所以

$$
\mathrm{lcm}(a,b)=\prod_p p^{\max(e_p(a),e_p(b))}.
$$

`lcm` 就是对每个质因数指数分别取 `max`。

## 一个完整例子

分解 $72$ 和 $120$：

$$
72=2^3\times3^2,
$$

$$
120=2^3\times3^1\times5^1.
$$

把未出现的质因数指数补成 $0$：

| 质数 | $72$ 中的指数 | $120$ 中的指数 | `min` | `max` |
| --- | ---: | ---: | ---: | ---: |
| $2$ | $3$ | $3$ | $3$ | $3$ |
| $3$ | $2$ | $1$ | $1$ | $2$ |
| $5$ | $0$ | $1$ | $0$ | $1$ |

因此

$$
\gcd(72,120)=2^3\times3=24,
$$

$$
\mathrm{lcm}(72,120)=2^3\times3^2\times5=360.
$$

## 乘积关系

对每个质数的两个指数 $x,y$，都有

$$
\min(x,y)+\max(x,y)=x+y.
$$

而两个数相乘时，质因数指数正好相加。所以对正整数 $a,b$，

$$
\gcd(a,b)\mathrm{lcm}(a,b)=ab.
$$

由此可以用 `gcd` 计算 `lcm`。下面的函数假设 `a,b` 都是非负整数：

```cpp
long long lcm(long long a, long long b) {
    if (a == 0 || b == 0) {
        return 0;
    }
    return a / gcd(a, b) * b;
}
```

先除后乘不会改变整数结果，却能比 `a * b / gcd(a, b)` 降低中间乘法溢出的风险。若 `lcm` 本身已经超出 64 位整数范围，换顺序也无法保存结果；仍然必须根据数据范围判断。

若要让自己的函数接收负数，应当先统一处理符号，使最小公倍数保持非负；也可以直接使用后文的 `std::lcm`。

## 零的约定

为了让算法和常用性质在边界上保持统一，竞赛中使用

$$
\gcd(a,0)=|a|,
$$

$$
\mathrm{lcm}(a,0)=0.
$$

特别地，$\gcd(0,0)=0$。常见数论题通常只输入正整数，但这些约定可以让聚合多个数的代码从初值 $0$ 开始。

## 常用性质

- `gcd` 和 `lcm` 都满足交换律与结合律。
- 若 $a\mid b$，则 $\gcd(a,b)=|a|$，$\mathrm{lcm}(a,b)=|b|$。
- $\gcd(a,b)$ 整除 $a,b$ 的任意线性组合 $ax+by$。
- 多个数的最大公约数可以从左到右合并：$\gcd(a,b,c)=\gcd(\gcd(a,b),c)$。

## C++17 接口

`<numeric>` 提供 `std::gcd` 和 `std::lcm`。本仓库使用 `<bits/stdc++.h>` 时也可以直接调用：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int main() {
    ll a, b;
    scanf("%lld%lld", &a, &b);

    printf("%lld\n", gcd(a, b));
    printf("%lld\n", lcm(a, b));
    return 0;
}
```

输入：

```text
72 120
```

输出：

```text
24
360
```

标准库函数会处理参数的正负号。但如果真实结果无法用返回类型表示，程序仍然不能得到正确数值。

## 基础练习

1. 用质因数指数分别求出 $\gcd(84,126)$ 和 $\mathrm{lcm}(84,126)$。
2. 证明 $\gcd(a,b)$ 一定整除 $\mathrm{lcm}(a,b)$。
3. 依次合并数组 $[18,24,30]$，求三个数的最大公约数；再把初值改成 $0$，检查结果为什么不变。
4. 构造一组 64 位整数范围内的正整数，使 `a * b` 溢出而 `a / gcd(a, b) * b` 仍可表示。

## 需要记住什么

1. 公约数、最大公约数、公倍数和最小公倍数分别如何定义？
2. 为什么 `gcd` 对每个质因数指数取 `min`？
3. 为什么 `lcm` 对每个质因数指数取 `max`？
4. 怎样由 `min(x, y) + max(x, y) = x + y` 推出 $\gcd(a,b)\mathrm{lcm}(a,b)=ab$？
5. 计算 `lcm` 时为什么应当先除以 `gcd` 再相乘？
6. $\gcd(a,0)$ 和 $\mathrm{lcm}(a,0)$ 分别约定为什么？
