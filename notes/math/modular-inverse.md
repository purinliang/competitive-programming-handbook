# 模逆元

> 最近修订：2026-08-15 21:39 +10:00（未审阅）

在普通整数中，除以 `3` 等于乘以 $1/3$。但取模以后通常只保存整数余数，$1/3$ 不是整数，C++ 的整数除法也不能表达“模意义下除以 `3`”。

例如要计算：

$$
\frac23\pmod7,
$$

直接执行整数除法会得到 `0`，再取模仍是 `0`，但这不是我们需要的模除法。真正的问题是：能否找到一个整数，承担普通算术中 $1/3$ 的作用？

## 乘法逆元

若整数 $x$ 满足：

$$
ax\equiv1\pmod m,
$$

就称 $x$ 是 $a$ 模 $m$ 的乘法逆元，简称模逆元，记作：

$$
a^{-1}\pmod m.
$$

这里的 $a^{-1}$ 不是普通实数中的 $1/a$，而是“与 $a$ 相乘后模 $m$ 等于 `1`”的整数余数。

例如：

$$
3\times5=15\equiv1\pmod7,
$$

所以 `5` 是 `3` 模 `7` 的逆元。

得到逆元以后，模除法就能改写成模乘法：

$$
\frac ab\equiv a\times b^{-1}\pmod m.
$$

因此：

$$
\frac23\equiv2\times5\equiv3\pmod7.
$$

## 存在条件

求 $a$ 模 $m$ 的逆元，就是求解 [线性同余方程](linear-congruences.md)：

$$
ax\equiv1\pmod m.
$$

线性同余方程的可解条件是：

$$
\gcd(a,m)\mid1.
$$

只有 `1` 的正因数能够整除 `1`，所以逆元存在的充要条件是：

$$
\gcd(a,m)=1.
$$

也就是说，$a$ 与 $m$ 互质时且仅当 $a$ 模 $m$ 的逆元存在。

例如 `3` 与 `7` 互质，所以逆元存在；`2` 与 `6` 的最大公约数是 `2`，所以 `2` 模 `6` 没有逆元。

## 唯一性

若 $x_1,x_2$ 都是 $a$ 模 $m$ 的逆元，那么：

$$
ax_1\equiv ax_2\equiv1\pmod m.
$$

两式相减：

$$
a(x_1-x_2)\equiv0\pmod m.
$$

逆元存在时 $\gcd(a,m)=1$，因此可以约去 $a$，得到：

$$
x_1\equiv x_2\pmod m.
$$

所以逆元的整数写法可以有无穷多个，但它们模 $m$ 的余数相同。把答案规范到 `[0,m-1]` 后，逆元唯一。

## 扩展欧几里得方法

当 $\gcd(a,m)=1$ 时，[扩展欧几里得算法](extended-euclidean-algorithm.md) 可以求出 $x,y$，使：

$$
ax+my=1.
$$

对两边模 $m$，第二项消失：

$$
ax\equiv1\pmod m.
$$

所以裴蜀系数 $x$ 正是 $a$ 模 $m$ 的逆元。若 $x$ 是负数，把它规范到 `[0,m-1]` 即可。

例如扩展欧几里得得到：

$$
7\times(-2)+15\times1=1.
$$

因此 `-2` 是 `7` 模 `15` 的一个逆元表示。规范化后：

$$
-2\equiv13\pmod {15},
$$

而且 $7\times13=91\equiv1\pmod {15}$。

代码返回最小非负逆元；不存在时返回 `-1`：

```cpp
ll inverse(ll a, ll m) {
    a %= m;
    if (a < 0) {
        a += m;
    }

    auto result = exgcd(a, m);
    ll g = get<0>(result);
    ll x = get<1>(result);
    if (g != 1) {
        return -1;
    }

    x %= m;
    if (x < 0) {
        x += m;
    }
    return x;
}
```

本篇约定 `m>1`，因此合法逆元位于 `[0,m-1]`，`-1` 可以稳定表示不存在。

## 质数模快速幂方法

若模数 $p$ 是质数且 $p\nmid a$，[费马小定理](fermat-little-theorem.md) 给出：

$$
a^{p-1}\equiv1\pmod p.
$$

拆出一个因子 $a$：

$$
a\cdot a^{p-2}\equiv1\pmod p.
$$

所以：

$$
a^{-1}\equiv a^{p-2}\pmod p.
$$

直接调用快速幂即可：

```cpp
ll inverse_prime(ll a, ll p) {
    return power(a, p - 2, p);
}
```

调用前必须已经知道 `p` 是质数，并确认 `a%p!=0`。若模数不保证是质数，不能照搬 `p-2`；改用扩展欧几里得并检查最大公约数。

两种常用方法的边界如下：

| 方法 | 模数条件 | 元素条件 | 时间复杂度 |
| --- | --- | --- | --- |
| 扩展欧几里得 | 任意 `m>1` | `gcd(a,m)=1` | $O(\log m)$ |
| 费马小定理与快速幂 | `p` 是质数 | `a%p!=0` | $O(\log p)$ |

质数模并不意味着只能使用快速幂；扩展欧几里得仍然正确。快速幂方法的优势是能够直接复用固定质数模下已有的 `power`。

## 模除法

要计算：

$$
\frac ab\pmod m,
$$

先求 `b` 的逆元，再做乘法：

```cpp
ll inv = inverse(b, m);
if (inv == -1) {
    // b 在模 m 意义下不可逆，普通模除法不存在。
}
a %= m;
if (a < 0) {
    a += m;
}
ll answer = (__int128)a * inv % m;
```

这里要求 $\gcd(b,m)=1$。如果 `b` 没有逆元，不代表每个线性同余方程 $bx\equiv a\pmod m$ 都无解；它可能无解，也可能有多个不同解。

例如：

$$
2x\equiv4\pmod6
$$

有 `x=2,5` 两个不同解，但 `2` 模 `6` 没有逆元。因此这应当作为一般线性同余方程求解，不能含糊地称作唯一的 `4/2 mod 6`。

## 完整代码

下面的程序使用扩展欧几里得求任意 `m>1` 下的逆元，不要求模数是质数。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

tuple<ll, ll, ll> exgcd(ll a, ll b) {
    if (b == 0) {
        return {a, 1, 0};
    }

    auto [g, x1, y1] = exgcd(b, a % b);
    ll x = y1;
    ll y = x1 - a / b * y1;
    return {g, x, y};
}

ll inverse(ll a, ll m) {
    a %= m;
    if (a < 0) {
        a += m;
    }

    auto result = exgcd(a, m);
    ll g = get<0>(result);
    ll x = get<1>(result);
    if (g != 1) {
        return -1;
    }

    x %= m;
    if (x < 0) {
        x += m;
    }
    return x;
}

int main() {
    ll a, m;
    scanf("%lld%lld", &a, &m);

    ll inv = inverse(a, m);
    if (inv == -1) {
        printf("No inverse\n");
        return 0;
    }

    printf("%lld\n", inv);
    return 0;
}
```

输入：

```text
7 15
```

输出：

```text
13
```

程序也接受负数 `a`。例如 `-2` 模 `7` 的标准代表是 `5`，它的逆元是 `3`，因为 $5\times3\equiv1\pmod7$。

## 复杂度

扩展欧几里得与普通欧几里得执行相同次数的辗转相除，时间复杂度为 $O(\log m)$，递归栈空间为 $O(\log m)$。

质数模快速幂方法执行 $O(\log p)$ 次模乘法，额外空间为 $O(1)$。

## 常见错误

### 直接使用整数除法

C++ 的 `/` 先完成普通整数除法，它与模除法不是同一种运算。需要模除法时，应把除数替换成它的模逆元。

### 不检查逆元是否存在

逆元存在的准确条件是 `gcd(a,m)==1`。模数是质数时，任何不被模数整除的数都有逆元；一般模数不能省略最大公约数检查。

### 对合数模使用 p-2

$a^{p-2}$ 来自费马小定理，只适用于质数模。变量恰好命名为 `MOD` 不会让一个合数自动变成质数。

### 把负系数直接当答案

扩展欧几里得返回的裴蜀系数可能为负。输出前必须对模数取余并规范到 `[0,m-1]`。

### 随意约去同余式两边的因子

只有被约去的数模 `m` 可逆时，约分才保持等价。否则约分可能丢失解或改变模数。

### 中间乘法溢出

把除法转换成 `a*inverse(b)` 后，乘法仍可能超出 64 位整数。模数范围较大时使用 `__int128` 保存中间乘积。

## 基础练习

1. 手算 `3` 模 `7` 的逆元，并用乘法验证。
2. 判断 `6` 模 `15` 是否有逆元，说明所用条件。
3. 使用扩展欧几里得求 `7` 模 `15` 的逆元，并把负系数规范化。
4. 在质数模 `13` 下用快速幂求 `5` 的逆元，再与扩展欧几里得结果比较。
5. 计算 `2/3 mod 7`，并说明为什么不能先执行 C++ 整数除法。
6. 分析 `2x≡4 (mod 6)` 的全部解，说明“方程有解”为什么不等于“除数有逆元”。
7. 对小模数枚举所有 `x`，随机验证 `inverse` 的存在性和返回值。
