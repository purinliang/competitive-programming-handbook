# 组合数：定义与递推

> 最近修订：2026-08-15 22:45 +10:00（未审阅）

有 `n` 个互不相同的元素，从中选出 `k` 个，但不关心选出元素的顺序，一共有多少种不同选择？

例如从 `A,B,C,D,E` 中选择 `3` 名队员组成小组。选择：

```text
A, B, C
```

与按照 `C,A,B` 的顺序说出同三个人没有区别，它们属于同一个小组。

这类“无顺序、不重复”的选择数量称为组合数，记作：

$$
C(n,k)
$$

或：

$$
\binom nk.
$$

中文教材也常写作 $C_n^k$。本书正文优先使用 $C(n,k)$，参数依次表示总元素数与选出元素数。

本篇约定总元素数 `n` 是非负整数。

## 从排列数去掉顺序

[排列数](permutations-count.md) $P(n,k)$ 会从 `n` 个不同元素中选出 `k` 个并排列，因此区分顺序。

固定一个已经选好的 `k` 元素集合。把其中 `k` 个不同元素重新排列，共有：

$$
k!
$$

种顺序。这些顺序在排列数中是不同结果，在组合数中却属于同一个集合。

因此每一种组合都被 $P(n,k)$ 重复统计了恰好 `k!` 次：

$$
C(n,k)=\frac{P(n,k)}{k!}.
$$

代入排列数公式：

$$
C(n,k)=\frac{n!}{k!(n-k)!}.
$$

例如：

$$
C(5,3)=\frac{5!}{3!2!}=10.
$$

这里的除法在完整整数公式中一定整除，因为它只是把每个无序集合对应的 `k!` 个排列合并成一个。

## 对称性

从 `n` 个元素中选出 `k` 个，等价于决定剩下哪 `n-k` 个不选。

每个被选集合都有唯一的补集，因此：

$$
C(n,k)=C(n,n-k).
$$

例如从 `5` 人中选 `3` 人，与决定哪 `2` 人不入选一一对应：

$$
C(5,3)=C(5,2)=10.
$$

计算时可以令：

```cpp
k = min(k, n - k);
```

减少后续需要处理的选择数量。这个优化来自组合含义，不只是公式巧合。

## 按是否选择一个元素分类

直接使用阶乘公式会遇到大整数、除法和模逆元等实现问题。组合数还拥有一个只使用加法的递推。

在 `n` 个元素中固定最后一个元素 `x`。所有选出 `k` 个元素的方案可以分成两个互斥情形。

### 不选择 x

需要从其余 `n-1` 个元素中选择 `k` 个：

$$
C(n-1,k).
$$

### 选择 x

`x` 已经占用一个名额，还需从其余 `n-1` 个元素中选择 `k-1` 个：

$$
C(n-1,k-1).
$$

每个方案恰好属于其中一种情形。根据加法原理：

$$
C(n,k)=C(n-1,k)+C(n-1,k-1).
$$

这称为 Pascal 递推。它直接来自“是否选择固定元素”的分类，不需要记成凭空出现的公式。

## 边界条件

从 `n` 个元素中一个也不选，只有空集合一种方案：

$$
C(n,0)=1.
$$

把所有元素全部选中，也只有一种方案：

$$
C(n,n)=1.
$$

若选择数量不合法：

$$
k<0\quad\text{或}\quad k>n,
$$

则：

$$
C(n,k)=0.
$$

这些边界让 Pascal 递推在两侧自然成立。例如：

$$
C(n,0)=C(n-1,0)+C(n-1,-1)=1+0.
$$

## Pascal 三角形

从 `C(0,0)=1` 开始，使用递推逐行计算：

```text
n=0:              1
n=1:            1   1
n=2:          1   2   1
n=3:        1   3   3   1
n=4:      1   4   6   4   1
n=5:    1   5  10  10   5   1
```

每个内部数字等于左上方与右上方之和。这就是 Pascal 三角形，也常称杨辉三角。

第 `n` 行第 `k` 项是 `C(n,k)`。左右对称对应：

$$
C(n,k)=C(n,n-k).
$$

## 一维递推

若只需要一个 `C(n,k)`，不必保存整个二维三角形。

令 `combination[chosen]` 表示处理完当前数量的元素后，选择 `chosen` 个的方案数。初始还没有处理任何元素：

```cpp
vector<ll> combination(k + 5);
combination[0] = 1;
```

位置 `0` 在这里不是被浪费的数组格，而是真实表示“选择零个元素”的状态。

每加入一个新元素 `total`，根据 Pascal 递推：

```cpp
combination[chosen] += combination[chosen - 1];
```

`combination[chosen]` 的旧值表示不选择新元素，`combination[chosen-1]` 的旧值表示选择新元素。

## 为什么必须倒序

同一行更新时，右侧必须从大到小：

```cpp
for (int chosen = min(total, k); chosen >= 1; chosen--) {
    combination[chosen] += combination[chosen - 1];
}
```

倒序保证读取的 `combination[chosen-1]` 仍属于上一行。

若从小到大更新，`combination[chosen-1]` 已经包含当前新元素，再用它更新更大状态，相当于同一个元素可以被重复选择。

例如处理第一个元素时，正序先得到 `combination[1]=1`，随后会错误地用这个新值更新 `combination[2]`，声称只靠一个元素就能选出两个。

## 完整代码

下面的函数用 Pascal 递推计算精确组合数，并假设答案与所有中间组合数都能放入 64 位整数。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

ll binomial(int n, int k) {
    if (k < 0 || k > n) {
        return 0;
    }

    k = min(k, n - k);
    vector<ll> combination(k + 5);
    combination[0] = 1;

    for (int total = 1; total <= n; total++) {
        for (int chosen = min(total, k); chosen >= 1; chosen--) {
            combination[chosen] += combination[chosen - 1];
        }
    }
    return combination[k];
}

int main() {
    int n, k;
    scanf("%d%d", &n, &k);
    printf("%lld\n", binomial(n, k));
    return 0;
}
```

输入：

```text
5 3
```

输出：

```text
10
```

若题目要求模 `MOD`，把递推改为：

```cpp
combination[chosen] = (combination[chosen] + combination[chosen - 1]) % MOD;
```

Pascal 递推只有加法，适用于任意正模数，不需要模数是质数，也不需要模逆元。

## 正确性

处理完 `total` 个元素后，`combination[chosen]` 表示从这些元素中选择 `chosen` 个的方案数。

初始 `total=0` 时，只有 `combination[0]=1`，其余状态为 `0`，含义正确。

加入新元素时，任意合法方案恰好分为不选择它和选择它两类：前者由旧 `combination[chosen]` 计数，后者删除新元素后与旧 `combination[chosen-1]` 一一对应。两类互斥且完整，所以相加得到新状态。

倒序更新保证两个加数都来自加入新元素以前。归纳可知循环结束后返回的 `combination[k]` 正是 `C(n,k)`。

## 复杂度

外层处理 `n` 个元素，每层最多更新 `k` 个状态，时间复杂度为：

$$
O(nk).
$$

一维数组使用 $O(k)$ 空间。利用对称性令 `k=min(k,n-k)` 后，实际复杂度是 $O(n\min(k,n-k))$ 时间与 $O(\min(k,n-k))$ 空间。

当需要大量组合数查询且模数是固定质数时，可以预处理阶乘与逆阶乘，把单次查询
降到 $O(1)$；该方法属于后续扩展。

## 常见错误

### 把排列数当作组合数

组合不区分选出元素的顺序。使用 `P(n,k)` 会把每个集合重复统计 `k!` 次。

### 组合数公式中的分母写错

准确公式是：

$$
\frac{n!}{k!(n-k)!}.
$$

两个分母分别去掉选中元素内部的顺序与未使用的阶乘部分。

### 一维递推正序更新

正序会让当前元素在同一轮被重复使用。每轮必须从 `min(total,k)` 倒序更新到 `1`。

### 忘记选择零个元素

`C(n,0)=1`，所以必须初始化 `combination[0]=1`。它是有意义的空集合状态。

### 用普通整数除法计算模组合数

先对阶乘取模后，不能直接使用 C++ `/`。Pascal 递推可以只用加法；阶乘方法需要 [模逆元](modular-inverse.md)。

### 忽略中间值容量

组合数增长很快。即使最终题目只要求取模，也要在每次加法或乘法后及时取模；精确计算需要根据范围选择表示。

## 基础练习

1. 列出从 `A,B,C,D` 中选择两个元素的全部组合，验证 `C(4,2)=6`。
2. 从 `P(n,k)` 的含义出发，说明为什么每个组合对应 `k!` 个排列。
3. 用补集建立 `C(n,k)` 与 `C(n,n-k)` 的一一对应。
4. 按是否选择固定元素，独立推出 Pascal 递推。
5. 手算 Pascal 三角形的第 `0..6` 行。
6. 用正序更新一维数组，找出它第一次产生错误的状态。
7. 分别测试 `k=0`、`k=n`、`k>n` 的边界。
