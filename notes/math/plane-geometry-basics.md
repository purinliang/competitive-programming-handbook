# 几何：平面几何基础

> 最近修订：2026-08-17 01:37 +10:00（未审阅）

竞赛题会直接使用线段、垂直、三角形的高、圆的半径等术语。理解这些对象和公式，是把题意翻译成程序的前提。

本篇只复习不依赖坐标的初等平面几何：基本对象、角、三角形、常见四边形与圆。坐标、向量、点积、叉积和直线方程属于后续计算几何，不在这里展开。

## 点、直线、射线与线段

**点**表示位置，没有长度和面积，通常用大写字母 `A`、`B`、`C` 命名。

**直线**向两个方向无限延伸，没有端点。经过不同点 $A$、$B$ 的直线可以记作直线 $AB$。

**射线**有一个端点，并向一个方向无限延伸。射线 $AB$ 的端点是 $A$，方向从 $A$ 指向 $B$；射线 $AB$ 与射线 $BA$ 通常不同。

**线段**有两个端点，只包含两端之间的有限部分。线段 $AB$ 的长度常记作：

$$
|AB|.
$$

线段 $AB$ 与线段 $BA$ 是同一条线段，长度相等。

一个点把线段分成长度相等的两部分时，这个点称为线段的中点。

## 相交、平行与垂直

平面内两条不同直线：

- 有一个公共点时相交；
- 没有公共点时平行；
- 相交并形成直角时垂直。

平行常记作：

$$
l_1\parallel l_2.
$$

垂直常记作：

$$
l_1\perp l_2.
$$

点到直线的距离，是从点向直线所作垂线段的长度，而不是随意连接到直线某点的长度。

## 角

两条具有共同端点的射线组成角。记作 $angle ABC$ 时，中间字母 $B$ 是顶点，两边是射线 $BA$ 与 $BC$。

使用角度制：

- 一周角是 $360^\circ$；
- 平角是 $180^\circ$；
- 直角是 $90^\circ$；
- 小于 $90^\circ$ 的正角是锐角；
- 大于 $90^\circ$ 且小于 $180^\circ$ 的角是钝角。

两个角之和为 $90^\circ$ 时互余，之和为 $180^\circ$ 时互补。

C++ 数学库的三角函数通常使用弧度，不直接使用角度。角度 `degree` 转弧度：

$$
\text{radian}
=
\text{degree}\times\frac{\pi}{180}.
$$

## 三角形的元素

三角形由三个不共线的点以及连接它们的三条线段组成。三角形 $ABC$ 有：

- 顶点 $A$、$B$、$C$；
- 边 $AB$、$BC$、$CA$；
- 内角 $\angle A$、$\angle B$、$\angle C$。

三角形内角和是：

$$
\angle A+\angle B+\angle C=180^\circ.
$$

选择一条边作为底，从对面顶点向底边所在直线作垂线，对应线段长度称为这条底边上的高。高可能位于三角形内部、边上或外部，但面积公式始终使用垂直距离。

从顶点连接对边中点的线段称为中线；把一个顶角分成相等两角的射线或线段称为角平分线。中线不一定垂直于对边，不能把它自动当成高。

## 三角形分类

按边长分类：

- 等边三角形：三边相等，三个内角都是 $60^\circ$；
- 等腰三角形：至少两边相等，对应两个底角相等；
- 不等边三角形：三边长度两两不同。

按最大内角分类：

- 锐角三角形：三个内角都小于 $90^\circ$；
- 直角三角形：有一个内角等于 $90^\circ$；
- 钝角三角形：有一个内角大于 $90^\circ$。

同一个三角形可以同时属于一类边长分类和一类角度分类，例如等腰直角三角形。

## 三角形是否存在

三个正长度 $a,b,c$ 能组成非退化三角形，当且仅当任意两边之和大于第三边：

$$
a+b>c,
\quad
a+c>b,
\quad
b+c>a.
$$

若先令 $a\le b\le c$，只需检查：

$$
a+b>c.
$$

等号 `a + b == c` 表示三点共线的退化情况，不是有正面积的三角形。

代码中计算 `a + b` 时要考虑整数范围；边长可能接近 32 位上限时，应先使用 64 位整数。

## 三角形周长与面积

三边长度为 $a,b,c$ 时，周长：

$$
P=a+b+c.
$$

以长度 $b$ 为底、对应高为 $h$ 时，面积：

$$
S=\frac{bh}{2}.
$$

面积单位是长度单位的平方。例如底和高用厘米，面积单位是平方厘米。

已知三边时可以使用海伦公式。令半周长：

$$
p=\frac{a+b+c}{2},
$$

则：

$$
S=\sqrt{p(p-a)(p-b)(p-c)}.
$$

使用浮点计算以前应先确认三边确实构成非退化三角形；否则根号内可能为负数。

## 勾股定理

直角三角形中，设两条直角边为 $a,b$，斜边为 $c$，则：

$$
a^2+b^2=c^2.
$$

斜边是直角对面的边，也是三边中最长的一条。

反过来，若三条正长度满足 $a\le b\le c$ 且：

$$
a^2+b^2=c^2,
$$

则它们构成直角三角形。

整数平方可能溢出 32 位范围，代码应使用 `1LL * a * a` 一类 64 位计算。

## 常见四边形

四边形有四条边，内角和为 $360^\circ$。常见特殊四边形：

- 平行四边形：两组对边分别平行；
- 矩形：四个角都是直角；
- 菱形：四条边相等；
- 正方形：四边相等且四角都是直角；
- 梯形：通常指至少有一组对边平行的四边形，具体教材对“恰有一组”存在约定差异。

常见周长和面积：

| 图形 | 周长 | 面积 |
| --- | --- | --- |
| 长方形，长 $a$、宽 $b$ | $2(a+b)$ | $ab$ |
| 正方形，边长 $a$ | $4a$ | $a^2$ |
| 平行四边形，底 $b$、高 $h$ | 各边相加 | $bh$ |
| 梯形，上下底 $a,b$、高 $h$ | 各边相加 | $(a+b)h/2$ |

平行四边形和梯形的高都是两条平行边之间的垂直距离，不一定等于斜边长度。

## 圆

平面内到固定点距离相等的所有点组成圆。固定点称为圆心，相等距离称为半径 $r$。

经过圆心、两个端点都在圆上的线段称为直径 $d$：

$$
d=2r.
$$

圆周长：

$$
C=2\pi r=\pi d.
$$

圆面积：

$$
S=\pi r^2.
$$

C++17 可以使用：

```cpp
double pi = acos(-1.0);
```

这比在代码中手写位数不足的 `3.14` 更准确。竞赛题若明确给出使用某个 $pi$ 近似值，应按题目要求，而不是自行替换。

## 完整代码

下面读入三角形的底和高，以及圆的半径，分别输出面积。

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    double base;
    double height;
    double radius;
    cin >> base >> height >> radius;

    double pi = acos(-1.0);
    double triangle_area = base * height / 2.0;
    double circle_area = pi * radius * radius;

    cout << fixed << setprecision(6);
    cout << triangle_area << '\n';
    cout << circle_area << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
3 4 2
```

输出：

```text
6.000000
12.566371
```
