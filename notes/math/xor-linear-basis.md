# 异或线性基

> 最近修订：2026-08-17 10:22 +10:00（未审阅）

给定 $n$ 个非负整数，可以任选其中若干个，求最大的异或和。

直接枚举子集有 $2^n$ 种选择。异或的每一位却只关心这一位被选中了奇数次还是
偶数次，与模 2 加法完全相同。把一个 63 位非负整数看成一个 63 维二进制向量，
任选若干数异或，就是在二元域上任选若干向量相加。

异或线性基保存一组线性无关的代表向量，并满足：

> 原来所有数字能够异或得到的结果，线性基也能得到；线性基不能产生原集合无法
> 产生的结果。

因此，不必保留所有输入，只需保留至多 63 个真正提供新方向的向量。

## 最高位作为主元

用 `basis[bit]` 保存最高有效位恰好为 `bit` 的基向量。插入数字 `x` 时，从高位
向低位检查。

若 `x` 的第 `bit` 位为 0，这一位不需要处理。若为 1：

- `basis[bit] == 0`：还没有以这一位为最高位的基向量，把当前 `x` 放入；
- 否则执行 `x ^= basis[bit]`，消去当前最高位，继续处理更低位。

```cpp
for (int bit = 62; bit >= 0; bit--) {
    if (((x >> bit) & 1) == 0) {
        continue;
    }

    if (basis[bit] == 0) {
        basis[bit] = x;
        return true;
    }

    x ^= basis[bit];
}
```

这和高斯消元选择主元并消去同一列是同一个过程，只不过一行二进制向量被压进
一个整数，向量加法写成按位异或。

## 为什么消去不会丢失答案

假设已有基向量 `b = basis[bit]`，当前数字 `x` 的最高位也为 `bit`。用
`x ^= b` 替换 `x`。

新的 `x` 可以由旧的 `x` 和 `b` 得到；旧的 `x` 也可以由新的 `x` 与 `b`
再次异或得到，因为：

$$
(x\oplus b)\oplus b=x.
$$

所以替换前后可表示结果的集合完全相同，只是当前数字的最高位被消掉，能够继续
寻找它是否在更低位提供新方向。

## 插入结果变成零意味着什么

若所有 1 都被已有基向量消去，最终 `x == 0`，说明原数字可以由当前线性基中的
若干向量异或得到。它与已有向量线性相关，不需要加入。

若在某一位找到空主元并保存，则这个向量拥有此前所有基向量都无法产生的最高位，
所以一定线性无关。每个主元位最多保存一个向量，线性基大小不超过整数位数。

## 从高位到低位构造最大异或和

初始 `result = 0`。从第 62 位向第 0 位依次检查基向量：

```cpp
if ((result ^ basis[bit]) > result) {
    result ^= basis[bit];
}
```

比较整数大小时，最高不同位决定结果。走到 `bit` 时，更高位已经达到当前可行
范围内的最优状态；`basis[bit]` 的最高位恰好是 `bit`，不会改变更高位。

若异或它能使结果变大，就应当选择；否则放弃。后续更低主元再也无法改变已经
确定的高位，因此这个局部选择同时是全局最优。

## 完整代码

输入保证每个数位于 `[0,2^63)`，因此使用 64 位整数的第 0 到第 62 位。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

struct XorBasis {
    static const int MAX_BIT = 62;
    vector<ll> basis;

    XorBasis() : basis(MAX_BIT + 1, 0) {}

    bool insert(ll x) {
        for (int bit = MAX_BIT; bit >= 0; bit--) {
            if (((x >> bit) & 1) == 0) {
                continue;
            }

            if (basis[bit] == 0) {
                basis[bit] = x;
                return true;
            }

            x ^= basis[bit];
        }

        return false;
    }

    ll maximum_xor() const {
        ll result = 0;

        for (int bit = MAX_BIT; bit >= 0; bit--) {
            if ((result ^ basis[bit]) > result) {
                result ^= basis[bit];
            }
        }

        return result;
    }

    bool can_represent(ll x) const {
        for (int bit = MAX_BIT; bit >= 0; bit--) {
            if (((x >> bit) & 1) != 0) {
                x ^= basis[bit];
            }
        }

        return x == 0;
    }
};

void solve() {
    int n;
    cin >> n;

    XorBasis linear_basis;
    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;
        linear_basis.insert(x);
    }

    cout << linear_basis.maximum_xor() << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```

## 判断一个数能否表示

要判断目标 `x` 能否由原集合的某个子集异或得到，同样从高位向低位消去。

若 `x` 当前最高位为 `bit`，只有 `basis[bit]` 能在不引入更高位的前提下消掉它。
消到最后为 0 就可以表示；某个需要的主元不存在时，异或 0 不会改变 `x`，最终
自然得到不能表示。

因此，插入、最大异或和、可表示性查询都只检查固定的 63 位，单次时间为
$O(63)$，在渐近意义上可视为 $O(\log V)$，其中 $V$ 是数值范围。

## 为什么这组基不是唯一的

输入顺序不同，某个主元位置保存的具体向量可能不同，但它们张成的结果集合相同。
基础最大异或查询只需要阶梯形主元，不要求把每个主元的低位也全部消成 0。

若要查询第 $k$ 小可表示异或值、求规范表示或处理前缀版本，通常还会把线性基
进一步化成简化阶梯形，或保存额外版本信息。这些操作有新的需求和证明，不应在
只求最大异或时提前增加模板复杂度。

## 异或线性基适合什么问题

它适合“从一组整数中任选若干个做异或”的问题，例如：

- 最大或最小的可表示异或值；
- 判断某个异或值能否由子集得到；
- 图上环异或值所张成空间的维护；
- 带版本或区间限制的异或表示问题的基础结构。

若每个数只能以某种固定顺序选择，或目标运算不是异或，线性基未必适用。最重要
的识别条件是：选择结果在模 2 加法下形成线性空间。

## 常见错误

- 从低位向高位插入，却仍使用“最高位主元”的最大值贪心；
- 遇到已有主元就停止，没有继续异或消去更低位；
- 把最终消成 0 的相关向量也强行插入；
- 计算最大异或时从低位开始，提前牺牲更重要的高位；
- 使用有符号数的第 63 位参与移位和比较，却仍按非负整数大小解释；
- 误以为基向量的具体内容唯一，依赖输入顺序以外的固定形态；
- 只需要最大异或时仍加入第 k 小、持久化等大量额外结构。
