# Catalan 数

> 最近修订：2026-08-17 11:48 +10:00（未审阅）

使用 $n$ 对圆括号组成一个合法括号序列，一共有多少种？

合法意味着从左到右任意前缀中，左括号数量都不少于右括号，最终两者数量相等。
例如 $n=3$ 时共有 5 种：

```text
((()))
(()())
(())()
()(())
()()()
```

这个数量是第 $n$ 个 Catalan 数，记为 $C_n$。它反复出现在“一个结构被根或
第一对匹配唯一拆成左右两部分”的问题中。

## 观察第一枚左括号匹配谁

任意非空合法括号序列都以左括号开始。找到与第一枚左括号匹配的右括号，整个
序列被唯一写成：

```text
( A ) B
```

其中 `A` 和 `B` 本身都是合法括号序列。

若 `A` 使用 $k$ 对括号，则 `B` 使用 $n-1-k$ 对括号。两部分可以独立选择：

$$
C_k\cdot C_{n-1-k}.
$$

$k$ 可以从 0 到 $n-1$，所以：

$$
C_n=\sum_{k=0}^{n-1}C_kC_{n-1-k}.
$$

每个合法序列的第一枚左括号只有一个匹配位置，因此这种拆分既不重复也不遗漏。

## 为什么 `C[0] = 1`

没有括号的空串是一种合法括号序列：

$$
C_0=1.
$$

它使“内部为空”或“后续为空”的拆分能够正常贡献。例如：

$$
C_1=C_0C_0=1.
$$

若把空结构计为 0，任何更大的结构都无法从递推中生成。

## 完整代码

输入非负整数 `n` 和正整数 `mod`，使用卷积递推计算 $C_n\bmod mod$。这份实现
只用加法和乘法，不要求模数为质数。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

ll catalan_number(int n, ll mod) {
    vector<ll> catalan(n + 5, 0);
    catalan[0] = 1 % mod;

    for (int size = 1; size <= n; size++) {
        for (int left_size = 0; left_size < size; left_size++) {
            int right_size = size - 1 - left_size;
            catalan[size] += catalan[left_size] * catalan[right_size] % mod;
            catalan[size] %= mod;
        }
    }

    return catalan[n];
}

void solve() {
    int n;
    ll mod;
    cin >> n >> mod;
    cout << catalan_number(n, mod) << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```

时间复杂度为 $O(n^2)$，空间复杂度为 $O(n)$。

代码假设两个模后结果相乘不会超过 64 位整数；常见竞赛模数满足这一点。模数
接近 64 位整数上限时，应按题目环境替换安全模乘，而不是改变 Catalan 递推。

## 二叉树为什么也是同一个数

考虑含 $n$ 个节点、只区分左右儿子的二叉树形态。选择根以后：

- 左子树含 $k$ 个节点，有 $C_k$ 种形态；
- 右子树含 $n-1-k$ 个节点，有 $C_{n-1-k}$ 种形态。

根占一个节点，左右子树独立，因此总数满足完全相同的递推：

$$
C_n=\sum_{k=0}^{n-1}C_kC_{n-1-k}.
$$

这不是“另一个巧合公式”，而是合法括号中的 `(A)B` 与二叉树的“根、左子树、
右子树”拥有同一种递归结构。

## 闭式公式

Catalan 数还满足：

$$
C_n=\frac{1}{n+1}\binom{2n}{n}
=\binom{2n}{n}-\binom{2n}{n-1}.
$$

第二个形式可以通过格路径理解：从 `(0,0)` 走到 `(n,n)` 的全部单调路径中，
减去越过对角线的坏路径。反射坏路径后，它们与某一类终点偏移路径一一对应。

模质数且需要单个大下标答案时，可以使用阶乘与模逆元计算闭式。模数为合数、
`n+1` 不可逆或下标越过模数时，需要更细致的组合数方法。平方递推虽然较慢，
但对任意正模数都直接成立。

## 常见 Catalan 结构

以下对象都可以与同一个递归或格路径限制建立一一对应：

- $n$ 对合法括号序列；
- $n$ 个节点的有序二叉树形态；
- 不越过对角线的单调格路径；
- 按固定入栈顺序能够产生的合法出栈序列；
- 凸多边形的不相交三角剖分。

看到列表中的名词不应立即套公式。必须先找出唯一拆分或一一对应，并确认题目
没有额外标号、权值、相同元素或高度限制；这些条件会改变计数。

## 常见错误

- 把 `C[0]` 写成 0，导致所有状态无法生成；
- 拆分时忘记根或最外层括号已经占用一个单位；
- 右侧规模误写成 `n-k`，总规模多出一个；
- 只统计 `C[k] + C[n-1-k]`，忘记左右选择应使用乘法原理；
- 使用闭式取模时，模数为合数却直接求 `n+1` 的逆元；
- 题目带有额外限制时，只因出现括号或二叉树就套 Catalan 数；
- 混淆“有序二叉树形态”与节点带不同标号后的计数。
