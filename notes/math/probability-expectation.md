# 概率与期望基础

> 最近修订：2026-08-17 03:29 +10:00（未审阅）

抛一枚硬币、掷一枚骰子或随机打乱一个序列时，我们不能在试验前确定结果，但可以
描述各种结果出现的可能性。概率回答“某件事发生的可能性有多大”，期望则把所有
可能取值按概率加权，回答“重复试验时平均会得到什么”。

本篇只建立竞赛中最常用的概念：样本空间、事件、条件概率、独立性、随机变量、
期望与期望的线性性。

## 先列出所有可能结果

一次随机试验的所有可能结果构成 **样本空间**，通常记作 $\Omega$。样本空间中的
一个具体结果称为样本点。

例如，掷一枚六面骰子：

$$
\Omega=\{1,2,3,4,5,6\}.
$$

“点数为偶数”不是一个单独结果，而是若干结果组成的 **事件**：

$$
A=\{2,4,6\}.
$$

事件发生，就是试验的实际结果落在这个集合中。

## 等可能结果下的概率

如果样本空间有限，并且每个样本点等可能出现，那么：

$$
P(A)=\frac{|A|}{|\Omega|}.
$$

掷一枚公平骰子时，偶数事件包含 `3` 个结果，全部有 `6` 个结果，因此：

$$
P(A)=\frac{3}{6}=\frac{1}{2}.
$$

> 只有各结果等可能时，才能直接用“有利结果数除以全部结果数”。一枚不均匀的
> 骰子仍有六个点数，但不能只数集合大小。

概率始终满足：

$$
0\le P(A)\le 1,
\qquad
P(\Omega)=1,
\qquad
P(\varnothing)=0.
$$

## 补集、并集与交集

事件 $A$ 不发生的事件是它的补集，记作 $\overline A$。二者恰好把样本空间分完，
所以：

$$
P(\overline A)=1-P(A).
$$

“至少有一次成功”常常不容易直接计数，但它的补事件是“每次都失败”。这时先算
补集通常更简单。

对任意两个事件 $A$ 与 $B$：

$$
P(A\cup B)=P(A)+P(B)-P(A\cap B).
$$

直接相加会把同时属于 $A$ 和 $B$ 的结果数两次，所以必须减回一次。若
$A\cap B=\varnothing$，两事件互斥，公式才简化为直接相加。

## 条件概率

已经知道 $B$ 发生后，样本空间就从 $\Omega$ 缩小成 $B$。在这个新范围内，$A$
仍然发生的部分是 $A\cap B$。当 $P(B)>0$ 时：

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)}.
$$

移项后得到乘法公式：

$$
P(A\cap B)=P(B)P(A\mid B).
$$

例如，已知骰子点数大于 `3`，剩下的等可能结果是 $\{4,5,6\}$。其中偶数有
$\{4,6\}$，因此条件概率为 $2/3$，而不是原来的 $1/2$。

## 独立不等于互斥

如果知道 $B$ 是否发生不会改变 $A$ 的概率，则称 $A$ 与 $B$ 相互独立：

$$
P(A\mid B)=P(A).
$$

与乘法公式结合，独立事件满足：

$$
P(A\cap B)=P(A)P(B).
$$

两次独立抛公平硬币时，“第一次正面”与“第二次正面”相互独立。两者同时发生的
概率是 $1/2\times1/2=1/4$。

互斥则表示两个事件不可能同时发生，即 $P(A\cap B)=0$。两个概率都大于 `0` 的
互斥事件不可能独立，因为一个发生后另一个的概率立刻变为 `0`。

## 随机变量把结果变成数字

随机变量是一个函数，它给样本空间中的每个结果分配一个数。

掷两枚骰子时，具体结果是有序对 $(a,b)$。可以定义随机变量：

$$
X(a,b)=a+b.
$$

不同样本点可以得到相同的 $X$。例如 $(1,6)$、$(2,5)$ 和 $(3,4)$ 都使
$X=7$。因此“随机变量取值为 `7`”本身也是一个事件。

## 期望是按概率加权的平均值

若离散随机变量 $X$ 可能取 $x_1,x_2,\ldots,x_k$，则它的期望为：

$$
E(X)=\sum_{i=1}^{k}x_iP(X=x_i).
$$

对公平六面骰子的点数 $X$：

$$
E(X)=1\times\frac16+2\times\frac16+\cdots+6\times\frac16
=\frac{7}{2}.
$$

期望可以不是一次试验能实际取到的值。骰子不会掷出 `3.5`，但在大量重复试验中，
平均点数会趋近 `3.5`。

期望也不是“最可能的结果”。它把每个取值的大小和概率同时纳入计算。

## 期望的线性性

对任意随机变量 $X$、$Y$ 和常数 $a,b$：

$$
E(aX+bY)=aE(X)+bE(Y).
$$

这条性质不要求 $X$ 与 $Y$ 独立。它的价值是把一个难以直接求分布的总量，拆成
许多个简单贡献。

例如，抛 `n` 次公平硬币，令 $X$ 表示正面总数。定义指示变量：

$$
I_i=
\begin{cases}
1,&\text{第 }i\text{ 次为正面},\\
0,&\text{否则}.
\end{cases}
$$

则：

$$
X=I_1+I_2+\cdots+I_n.
$$

每个 $I_i$ 的期望都是 $1/2$，所以：

$$
E(X)=E(I_1)+\cdots+E(I_n)=\frac n2.
$$

更一般地，若指示变量 $I$ 在事件 $A$ 发生时为 `1`，否则为 `0`，则：

$$
E(I)=P(A).
$$

## 用枚举校验小规模概率

对等可能且规模很小的样本空间，可以直接枚举全部结果。下面的程序计算掷两枚公平
六面骰子时，点数和至少为 `s` 的概率，并输出约分后的分数。

```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
    int s;
    cin >> s;

    int favorable = 0;
    int total = 0;
    for (int a = 1; a <= 6; a++) {
        for (int b = 1; b <= 6; b++) {
            total++;
            if (a + b >= s) {
                favorable++;
            }
        }
    }

    int divisor = gcd(favorable, total);
    cout << favorable / divisor << "/" << total / divisor << '\n';
    return 0;
}
```

输入：

```text
10
```

输出：

```text
1/6
```

有利结果是 `(4,6)`、`(5,5)`、`(5,6)`、`(6,4)`、`(6,5)` 和
`(6,6)`，共 `6` 个；全部有序结果有 $6\times6=36$ 个，所以概率为
$6/36=1/6$。

程序用于校验计数，不替代公式推导。样本空间很大时，必须利用组合计数、状态转移
或其他结构避免完整枚举。

## 常见混淆

### 把不等可能的结果当成等可能

“掷两枚骰子的点数和”可以取 `2` 到 `12`，但这 `11` 个和不等可能。应当枚举
等可能的有序对 $(a,b)$，再统计它们对应的和。

### 把互斥当成独立

互斥说的是“不能同时发生”，独立说的是“知道一个是否发生，不改变另一个的
概率”。它们是两种不同关系。

### 把期望当成必然结果

期望是加权平均，不保证单次试验接近它，也不保证期望本身是可能取值。

## 需要记住什么

1. 什么是样本空间和事件？等可能时怎样计算概率？
2. 补集概率和两个事件并集的概率怎样计算？
3. 条件概率的分母为什么是 $P(B)$？
4. 独立与互斥有什么区别？
5. 什么是随机变量？期望的定义是什么？
6. 期望的线性性是什么？使用时是否要求随机变量独立？

## 基础练习

1. 掷两枚公平六面骰子，求点数和为 `7` 的概率。
2. 独立抛一枚公平硬币 `5` 次，求至少出现一次正面的概率。
3. 一个盒子中有 `3` 个红球和 `2` 个蓝球，不放回地取两次，求两次都是红球的
   概率。
4. 用指示变量说明：掷 `n` 枚公平六面骰子时，点数总和的期望是 $7n/2$。
