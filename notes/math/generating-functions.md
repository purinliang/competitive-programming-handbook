# 生成函数：基础

> 最近修订：2026-08-17 08:48 +10:00（未审阅）

有若干种互不相同的硬币，每种硬币都可以取任意枚。给定总金额 `target`，有多少种
取法的金额之和恰好等于 `target`？取硬币的先后顺序不影响方案，例如先取 2 再取
3，与先取 3 再取 2 是同一种方案。

一种硬币能够贡献哪些金额，多种硬币的选择又怎样合并？生成函数把“贡献多少”记录
成多项式的次数，把“有多少种选择”记录成对应系数。这样，组合对象的合并就变成了
多项式乘法。

本篇只讨论普通生成函数（ordinary generating function）的基础含义。这里的
多项式首先是一种记账工具，不要求把未知数 `x` 代入某个数值求值。

## 用系数记录答案

设数列：

$$
a_0,a_1,a_2,\ldots
$$

其中 $a_s$ 表示总量恰好为 $s$ 的方案数。它的普通生成函数写作：

$$
A(x)=a_0+a_1x+a_2x^2+\cdots
=\sum_{s\ge 0}a_sx^s.
$$

`x` 的指数记录总量，系数记录方案数。因此，若最终只关心不超过 `target` 的答案，
只需保留 $0$ 次到 `target` 次的系数，更高次项可以截去。

空选择的总量为 0，而且恰好有一种空选择，所以计数问题通常从：

$$
A(x)=1
$$

开始。这里常数项 1 不是随手补上的初始值，而是在记录一个真实方案。

## 一种硬币对应一个因子

面值为 $w$ 的硬币可以取 0、1、2、3 枚，分别贡献金额：

$$
0,w,2w,3w,\ldots
$$

每一种选择都只有一种，因此这类选择的生成函数是：

$$
1+x^w+x^{2w}+x^{3w}+\cdots.
$$

若只关心不超过 `target` 的金额，实际保留有限部分：

$$
1+x^w+x^{2w}+\cdots+x^{\lfloor target/w\rfloor w}.
$$

若一件物品最多只能选一次，对应因子会变成 $1+x^w$。若必须选一次，则只有
$x^w$。生成函数中的每一项，都对应这个局部对象的一种合法选择。

## 乘法合并独立选择

现在有面值 2 和面值 3 两种硬币。它们的生成函数分别是：

$$
A(x)=1+x^2+x^4+x^6+\cdots,
$$

$$
B(x)=1+x^3+x^6+x^9+\cdots.
$$

从第一种硬币选择贡献 $i$，从第二种硬币选择贡献 $j$，合并后的总金额是
$i+j$。多项式乘法恰好会把指数相加：

$$
x^i\cdot x^j=x^{i+j}.
$$

因此，乘积中 $x^s$ 的系数为：

$$
[x^s]A(x)B(x)=\sum_{i+j=s}a_i b_j,
$$

它枚举了所有把总金额 $s$ 拆成两部分的方式，并把相应方案数相乘后相加。这就是
卷积的组合意义。

例如只保留到 6 次：

$$
(1+x^2+x^4+x^6)(1+x^3+x^6).
$$

$x^6$ 可以由 $x^6\cdot1$ 和 $1\cdot x^6$ 得到，分别表示三枚面值 2 的硬币，
或两枚面值 3 的硬币，所以系数是 2。

## 多种硬币的生成函数

若不同硬币面值为 $w_1,w_2,\ldots,w_n$，每种都能取任意枚，完整的生成函数是：

$$
F(x)=\prod_{i=1}^{n}
\left(1+x^{w_i}+x^{2w_i}+\cdots\right).
$$

答案就是：

$$
[x^{target}]F(x).
$$

记号 $[x^k]F(x)$ 表示取出 $F(x)$ 中 $x^k$ 的系数。它不是除法，也不是数组
下标语法，只是一种常用数学记号。

直接逐项做多项式乘法能够忠实实现定义，但会重复枚举许多系数对。对于一个固定
面值 $w$，乘上：

$$
1+x^w+x^{2w}+\cdots
$$

以后，新系数满足：

$$
new_s=old_s+old_{s-w}+old_{s-2w}+\cdots.
$$

相邻的两个式子又满足：

$$
new_s=old_s+new_{s-w}.
$$

所以处理面值 `w` 时，只需让金额从小到大更新：

```cpp
for (int sum = w; sum <= target; sum++) {
    ways[sum] += ways[sum - w];
}
```

右侧的 `ways[sum - w]` 已经包含继续使用当前硬币的方案，因此自然允许取任意枚。
这正是完全背包计数递推，也是逐个乘生成函数因子的高效写法。

## 完整代码

输入互不相同的硬币面值和目标金额，输出不考虑顺序的方案数，答案模
`1000000007`。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const ll MOD = 1000000007;

void solve() {
    int n, target;
    cin >> n >> target;

    vector<int> coin(n + 5);
    for (int i = 1; i <= n; i++) {
        cin >> coin[i];
    }

    vector<ll> ways(target + 5, 0);
    ways[0] = 1;

    for (int i = 1; i <= n; i++) {
        int w = coin[i];

        for (int sum = w; sum <= target; sum++) {
            ways[sum] += ways[sum - w];
            if (ways[sum] >= MOD) {
                ways[sum] -= MOD;
            }
        }
    }

    cout << ways[target] << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```

外层依次处理硬币种类，所以一种方案不会因为硬币排列顺序不同而被重复统计。内层
金额从小到大，保证本轮已经得到的 `ways[sum - w]` 可以继续添加一枚当前硬币。

时间复杂度为 $O(n\cdot target)$，空间复杂度为 $O(target)$。

## 生成函数与动态规划

生成函数和动态规划并不是互相排斥的两套方法。

- 生成函数说明每个对象有哪些选择，以及不同对象的选择为什么通过乘法合并；
- 动态规划选择合适的顺序，高效计算所需系数；
- FFT 或 NTT 可以在多项式很长、需要批量合并时加速卷积。

对于硬币问题，$O(n\cdot target)$ 的背包递推通常比真的反复做卷积更简单、更快。
生成函数的价值在于提供统一的组合解释，并帮助我们从局部选择自然写出整体表达式。
当因子的形式不同、需要一次得到大量系数，或者需要进行代数变形时，这种语言会
更加重要。

## 常见错误

- 把 `x` 当成必须代入数值求解的未知数，忽略系数才是所需答案；
- 忘记常数项 1，导致无法表示“不选任何东西”；
- 合并独立选择时把生成函数相加，而不是相乘；
- 认为乘积系数只来自同次数项，忘记枚举所有指数和等于目标次数的组合；
- 求组合数时按硬币顺序重复计数，把同一组选取误当成多个排列；
- 输入中重复出现同一面值，却仍把它们当成一种硬币；
- 只需要低次系数时仍保留无限级数的形式，没有按目标次数截断。
