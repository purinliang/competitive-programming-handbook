# 代数：方程与不等式

> 最近修订：2026-08-17 01:30 +10:00（未审阅）

算法题常把未知答案写成方程，或要求寻找满足若干不等式的整数。代码并不会自动完成代数变形；我们需要先明确未知量的取值范围、哪些变形保持等价，以及最终要在整数还是实数中寻找解。

本篇只复习一元方程、简单方程组、不等式与区间。完整的代数课程不属于本书范围。

## 未知数、方程与解

含有未知量的等式称为方程。例如：

$$
2x+3=11.
$$

使等式成立的 $x$ 称为方程的解。这里 $x=4$，因为：

$$
2\times4+3=11.
$$

求解方程的目标不是让左右两边“看起来相似”，而是找到全部满足原等式的允许取值。

解集还取决于讨论范围。例如：

$$
2x=1
$$

在实数范围内有解 $x=1/2$，在整数范围内没有解。竞赛题若要求整数答案，不能算出小数后再随意截断。

## 一元一次方程

一元一次方程可以整理成：

$$
ax+b=c.
$$

当 $a\ne0$ 时，两边先减去 $b$，再除以 $a$：

$$
x=\frac{c-b}{a}.
$$

若只允许整数解，还必须满足：

$$
a\mid(c-b),
$$

也就是 `(c - b) % a == 0`。

当 $a=0$ 时，不能除以 $a$：

- 若 `b == c`，任意允许范围内的 $x$ 都满足方程，有无穷多个实数解；
- 若 `b != c`，没有任何解。

边界系数必须单独判断，不能把除以零留给程序运行。

## 等价变形

对方程两边进行相同的合法操作，应当保持解集不变。常见等价变形包括：

- 两边同时加上或减去同一个数；
- 两边同时乘以同一个非零数；
- 两边同时除以同一个非零数；
- 展开括号、合并同类项。

“非零”条件不能省略。若把：

$$
x(x-1)=0
$$

两边都除以 $x$，就会丢掉合法解 $x=0$。因为除法只在 $x\ne0$ 时合法，而原方程没有这个限制。

平方等操作也可能增加解。例如从 $x=1$ 平方得到 $x^2=1$，新方程还允许 $x=-1$。进行不保证等价的变形后，必须把候选答案代回原式检验。

## 二元一次方程组

两个未知数常由两条独立关系共同确定：

$$
\begin{cases}
x+y=7,\\
x-y=1.
\end{cases}
$$

两式相加得到 $2x=8$，所以 $x=4$；代回得到 $y=3$。

竞赛中不一定要手写通用方程组求解器。更重要的是把题意中的独立条件写出来，再用代入、消元或枚举减少未知量。

方程数量与未知数数量相同，并不自动保证唯一解。两条方程可能重复、矛盾或仍然不足以确定所有未知量。

## 不等式

不等式比较两边大小：

$$
x<5,
\quad
x\le5,
\quad
x>5,
\quad
x\ge5.
$$

严格不等式 `<`、`>` 不包含边界；非严格不等式 `<=`、`>=` 包含边界。

对不等式两边同时加减同一个数，不等号方向不变：

$$
x+3<8
\iff
x<5.
$$

同时乘除一个正数，方向也不变；同时乘除一个负数，方向必须反转：

$$
-2x<6
\iff
x>-3.
$$

反转的原因是负数乘法会颠倒数轴顺序。例如 $1<2$，同时乘以 $-1$ 后变成 $-1>-2$。

不能在不知道一个表达式正负时直接用它乘除不等式。必须分类讨论，或者采用不需要这步变形的方法。

## 同时满足多个条件

闭区间 `[l,r]` 表示：

$$
l\le x\le r.
$$

在 C++ 中必须拆成两个比较并用逻辑与连接：

```cpp
bool inside = l <= x && x <= r;
```

不能写：

```cpp
l <= x <= r
```

C++ 会先把 `l <= x` 算成 `bool`，再拿 `0` 或 `1` 与 `r` 比较，含义已经改变。

“满足条件 A 或条件 B”使用并集式的逻辑或；“同时满足”使用交集式的逻辑与。把不等式组看成多个解集的交集，有助于理解为什么每个条件都必须成立。

## 开区间与闭区间

常见区间记号：

| 数学记号 | 条件 | 是否包含端点 |
| --- | --- | --- |
| `[l,r]` | `l <= x && x <= r` | 两端都包含 |
| `(l,r)` | `l < x && x < r` | 两端都不包含 |
| `[l,r)` | `l <= x && x < r` | 包含左端，不包含右端 |
| `(l,r]` | `l < x && x <= r` | 不包含左端，包含右端 |

本书自定义算法默认使用闭区间 `[l,r]`。直接调用 C++ 与 STL 接口时，保留它们原生的左闭右开范围 `[first,last)`。

空区间也取决于约定：闭区间 `[l,r]` 在 `l > r` 时为空；左闭右开 `[l,r)` 在 `l >= r` 时为空。

## 实数解与整数解

不等式：

$$
x<3.7
$$

在实数范围内包含所有小于 `3.7` 的数；在整数范围内等价于：

$$
x\le3.
$$

类似地，整数条件 $x>3.7$ 等价于 $x\ge4$。

把实数边界转换成整数边界时会用到向下取整与向上取整。必须先确认严格或非严格关系，再决定是否还要移动一个整数单位；不能只看小数部分机械取整。

## 方程与算法

方程或不等式可以描述答案，但直接套公式不一定是唯一方法：

- 小范围整数未知量可以枚举并检查；
- 单调不等式的临界点可以使用二分答案；
- 多个线性条件可能转化为前缀和、差分或图模型；
- 整数整除条件可能需要最大公因数或同余方法。

选择算法以前，先说清楚解的范围和验证条件。一个候选答案通常应代回原条件检查，这比相信中间变形更稳妥。

## 完整代码

下面在整数范围内求解 `a * x + b = c`。输出唯一整数解、`No solution` 或 `Infinitely many solutions`。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

void solve() {
    ll a, b, c;
    cin >> a >> b >> c;

    if (a == 0) {
        if (b == c) {
            cout << "Infinitely many solutions" << '\n';
        } else {
            cout << "No solution" << '\n';
        }
        return;
    }

    ll difference = c - b;

    if (difference % a != 0) {
        cout << "No solution" << '\n';
        return;
    }

    cout << difference / a << '\n';
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
2 3 11
```

输出：

```text
4
```

## 需要记住什么

1. 一个方程有没有解为什么取决于讨论的数集？
2. 求解 `a * x + b = c` 时，为什么必须单独处理 `a == 0`？
3. 哪些方程变形保持等价？除以含未知数的表达式可能丢失什么？
4. 不等式两边乘除负数时为什么要反转方向？
5. 怎样把闭区间 `[l,r]` 翻译成 C++ 条件？
6. 严格实数边界转换为整数条件时，为什么要特别检查取整方向？
7. 得到候选解后，为什么代回原条件仍然有价值？
