# 数论：质因数分解

> 最近修订：2026-08-13 22:00 +10:00（未审阅）

[数论：算术基本定理](fundamental-theorem-of-arithmetic.md) 说明每个大于 $1$ 的正整数都有唯一的质因数分解。许多后续问题并不只需要知道分解存在，还要真正求出每个质数出现多少次：

- 用质因数指数判断整除关系；
- 计算正因数个数与正因数和；
- 计算欧拉函数；
- 比较多个整数在同一质数上的指数。

本篇用试除法分解单个正整数，返回按质数递增排列的 `(质因数, 指数)`。它适合数值不太大的单次或少量查询，不处理接近 64 位上限的大质数分解。

## 从一个因数开始

考虑：

$$
756.
$$

从最小可能质因数 $2$ 开始。因为 $756$ 能被 $2$ 整除，先除一次：

$$
756=2\times378.
$$

`378` 仍能被 `2` 整除：

$$
756=2^2\times189.
$$

`189` 不能继续被 `2` 整除，所以质因数 `2` 的指数恰好是 `2`。

发现一个因数后不能只除一次。若直接转向下一个候选，就会把 $2^2$ 错记成 $2^1$，也会让后续剩余值仍含已经处理过的质因数。

## 除到不能再除

用 `remaining` 保存尚未分解的部分，`exponent` 统计当前候选 `p` 出现多少次：

```cpp
int exponent = 0;

while (remaining % p == 0) {
    remaining /= p;
    exponent++;
}
```

循环结束时，`remaining` 已经不含因数 `p`。若指数大于零，保存这一项：

```cpp
if (exponent > 0) {
    factors.push_back({p, exponent});
}
```

`pair<ll, int>` 的第一个值是质因数，第二个值是指数。质因数本身使用 64 位整数，指数最多只有对数数量级，用 `int` 足够。

对 `756` 处理完 `2` 后：

```text
factors = {(2, 2)}
remaining = 189
```

## 继续尝试候选因数

接着令 `p = 3`。`189` 连续除以三次 `3`：

$$
189=3\times63=3^2\times21=3^3\times7.
$$

于是：

```text
factors = {(2, 2), (3, 3)}
remaining = 7
```

最直接的候选循环可以逐个尝试整数：

```cpp
for (ll p = 2; /* 边界稍后补充 */; p++) {
    int exponent = 0;
    while (remaining % p == 0) {
        remaining /= p;
        exponent++;
    }
    if (exponent > 0) {
        factors.push_back({p, exponent});
    }
}
```

这会检查一些合数，例如 `4`、`6`、`8`。它们不会被错误记录为质因数。

## 为什么记录到的一定是质数

候选 `p` 按照从小到大处理，而且每个较小因数都会从 `remaining` 中除到不能再除。

假设某个合数 `p` 仍能整除当前 `remaining`。合数 `p` 至少有一个小于 `p` 的质因数 `q`，于是 `q` 也应当整除 `remaining`。但 `q` 早已被处理并除尽，产生矛盾。

所以一个候选第一次真正整除当前剩余值时，它只能是质数。逐个尝试所有整数只是多做了一些无效余数判断，不会改变结果正确性。

基础代码保留这份简单循环。先单独处理 `2`、再只尝试奇数可以减少约一半候选，但不会改变渐进复杂度，也不是理解试除分解所必需。

## 只需尝试到平方根

若 `remaining` 是合数，可以写成：

$$
remaining=ab,
$$

其中至少一个因数不超过 $\sqrt{remaining}$。因此，只要当前候选满足：

$$
p^2\le remaining,
$$

就继续试除。若已经没有不超过平方根的因数，剩余值不可能还是合数。

代码不用直接计算 `p * p`，而写成：

```cpp
p <= remaining / p
```

它与 $p^2\le remaining$ 等价，同时避免 `p * p` 在接近 64 位边界时溢出。

完整候选循环变成：

```cpp
for (ll p = 2; p <= remaining / p; p++) {
    int exponent = 0;
    while (remaining % p == 0) {
        remaining /= p;
        exponent++;
    }
    if (exponent > 0) {
        factors.push_back({p, exponent});
    }
}
```

这里平方根边界针对不断缩小的 `remaining`，而不是固定的原数。已经提取出的质因数不需要再参与后续判定，剩余值变小后循环可以更早结束。

## 最后一个剩余质因数

`756` 在处理 `2`、`3` 后剩下 `7`。下一个候选是 `4`，但：

```text
4 > 7 / 4
```

循环结束。此时 `remaining = 7 > 1`。

根据上一节，若它还是合数，就应当存在一个不超过自身平方根的因数，而循环本来会继续并找到这个因数。因此退出后大于 `1` 的 `remaining` 必然是质数：

```cpp
if (remaining > 1) {
    factors.push_back({remaining, 1});
}
```

这个质因数的指数是 `1`。若它至少出现两次，那么它的平方仍整除退出前的 `remaining`，循环条件不会已经失败。

最终得到：

$$
756=2^2\times3^3\times7^1.
$$

## 数字 1

`1` 没有质因数。调用分解函数时，候选循环不会执行，最后的 `remaining > 1` 也不成立，因此返回空序列。

这与算术基本定理一致：大于 `1` 的正整数才写成非空质数乘积；`1` 可以看成空乘积。

输出格式不能把空序列误解为“没有答案”。本篇完整程序先输出质因数种类数，所以输入 `1` 时输出 `0`。

## 完整分解函数

```cpp
vector<pair<ll, int>> factorize(ll n) {
    vector<pair<ll, int>> factors;
    ll remaining = n;

    for (ll p = 2; p <= remaining / p; p++) {
        int exponent = 0;
        while (remaining % p == 0) {
            remaining /= p;
            exponent++;
        }
        if (exponent > 0) {
            factors.push_back({p, exponent});
        }
    }

    if (remaining > 1) {
        factors.push_back({remaining, 1});
    }

    return factors;
}
```

函数没有跨调用状态，只根据本次参数计算并返回结果，因此使用普通自由函数，不建立没有持续状态的 `struct`。

## 循环保持的关系

令输入原值为 `original`。处理下一个候选 `p` 以前：

- `factors` 保存所有已经发现的质因数及完整指数；
- `remaining` 不再含任何小于 `p` 的质因数；
- 已保存质数幂的乘积乘上 `remaining`，始终等于 `original`。

对当前 `p` 每除一次，就在结果中增加一个 `p`，同时把 `remaining` 除以 `p`，所以总乘积不变。除到不能再除后，`remaining` 也不含 `p`，不变量进入下一候选。

循环退出时，剩余值是 `1` 或一个尚未记录的质数。追加它以后，结果全部是递增质数，指数为正，并且乘积重建原数。算术基本定理保证这正是唯一质因数分解。

## 时间与空间复杂度

最坏情况是输入本身为质数，候选要一直尝试到它的平方根，因此时间复杂度是：

$$
O(\sqrt n).
$$

内层 `while` 看起来又是一层循环，但每次执行都会让 `remaining` 至少减半，因此全部成功除法总次数只有 $O(\log n)$，不会再把总复杂度乘上一个平方根。

除返回结果外，函数只使用固定数量变量，额外工作空间是 $O(1)$。不同质因数个数最多为 $O(\log n)$，所以返回序列占用 $O(\log n)$ 空间。

当 $n\le10^{12}$ 时，最坏约尝试一百万个候选，少量查询通常可以接受。若输入接近 $10^{18}$ 且本身是大质数，试除可能接近十亿次，不能仅因为变量能用 64 位整数保存就认为算法足够快。大量查询可先筛出质数再试除；更大的整数分解需要 Miller–Rabin、Pollard–Rho 等后续算法。

## 完整代码

下面的程序读入 $1\le n\le10^{12}$，先输出不同质因数个数，再按递增顺序逐行输出质因数和指数。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

vector<pair<ll, int>> factorize(ll n) {
    vector<pair<ll, int>> factors;
    ll remaining = n;

    for (ll p = 2; p <= remaining / p; p++) {
        int exponent = 0;
        while (remaining % p == 0) {
            remaining /= p;
            exponent++;
        }
        if (exponent > 0) {
            factors.push_back({p, exponent});
        }
    }

    if (remaining > 1) {
        factors.push_back({remaining, 1});
    }

    return factors;
}

int main() {
    ll n;
    scanf("%lld", &n);

    vector<pair<ll, int>> factors = factorize(n);
    int count = factors.size();

    printf("%d\n", count);
    for (auto [prime, exponent] : factors) {
        printf("%lld %d\n", prime, exponent);
    }
    return 0;
}
```

输入：

```text
756
```

输出：

```text
3
2 2
3 3
7 1
```

## 常见错误

### 每个因数只除一次

质因数可能重复出现。发现 `p` 后必须用 `while` 除到不能再除，指数才完整，后续剩余值才不再含 `p`。

### 循环一直到 remaining

合数一定有不超过平方根的小因数。试到 `remaining - 1` 会把质数输入从平方根时间退化成线性时间。

### 忘记最后的 remaining

退出循环时仍可能剩下一个大于平方根的质因数。若 `remaining > 1`，必须把它以指数 `1` 加入结果。

### 用 p * p 比较边界

题目以后若放宽到更大的 64 位输入，`p * p` 可能先溢出。使用 `p <= remaining / p` 表达相同条件。

### 把 1 当成质因数

`1` 不是质数，也不进入分解结果。输入 `1` 返回空序列，不能输出 `(1, 1)`。

### 认为 64 位类型代表时间可行

`ll` 只保证数值容量，不保证 $O(\sqrt n)$ 能在时限内完成。始终根据最大输入估算试除次数。

### 分解负数和零

本篇函数定义域是正整数。负数可以先单独记录符号再分解绝对值；`0` 能被任意非零整数整除，没有有限的质因数分解，不能直接传入当前函数。

## 基础练习

1. 手动分解 `1`、`2`、`36`、`756` 与一个质数，记录每次 `remaining` 的变化。
2. 用结果中的质数幂重新乘出原数，并检查每个底数确实为质数。
3. 枚举 $1..10^6$ 的整数，与独立最小质因数表得到的分解逐个对拍。
4. 修改循环：先处理质因数 `2`，再只尝试奇数候选，比较代码与候选次数。
5. 给定分解结果，计算正因数个数；先通过小范围枚举因数验证公式。
6. 对多个查询先筛出不超过最大平方根的质数，只用质数作为试除候选。
7. 估算 $10^{12}$ 与 $10^{18}$ 的最坏试除次数，说明同一函数为什么只适合前者的少量查询。

## 需要记住什么

1. 质因数分解为什么要保存质因数和指数两个量？
2. 发现候选因数后，为什么必须除到不能再除？
3. 逐个尝试整数时，为什么真正被记录的候选一定是质数？
4. 为什么只需要试除到当前 `remaining` 的平方根？
5. 循环结束后，为什么大于 `1` 的剩余值一定是质数且指数为 `1`？
6. 输入 `1` 时应返回什么？为什么？
7. `p <= remaining / p` 避免了什么数值问题？
8. 怎样用循环不变量说明结果乘积始终能重建原数？
9. 试除分解的时间与空间复杂度是什么？为什么 64 位输入不一定适用？

试除质因数分解只解决单个中等整数。筛法、最小质因数预处理、正因数个数与正因数和会在各自文章中复用本篇的指数表示；Miller–Rabin 与 Pollard–Rho 属于更大整数上的高级工具，不要求当前理解或记忆。
