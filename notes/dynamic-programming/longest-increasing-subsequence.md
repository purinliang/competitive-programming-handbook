# 最长上升子序列

> 最近修订：2026-08-16 14:14 +10:00（未审阅）

给定一个序列，删除其中任意一些元素但保持剩余元素的原有顺序，可以得到一个子序列。最长上升子序列（Longest Increasing Subsequence，LIS）要求找到长度最大的严格递增子序列。

本篇从枚举全部子序列出发，推导“恰好以位置 `i` 结尾”的 $O(n^2)$ 动态规划，并记录前驱恢复一种实际方案。$O(n\log n)$ 优化会改变状态保存的信息，作为直接配套扩展单独解释。

## 子序列

序列：

```text
3 1 2 5 4 7
```

选择位置 `2,3,4,6` 得到：

```text
1 2 5 7
```

位置严格递增，数值也满足：

$$
1<2<5<7,
$$

所以它是长度为 `4` 的上升子序列。选择位置 `2,3,5,6` 得到的 `1 2 4 7` 也是长度为 `4` 的答案。

子序列不要求在原序列中连续，只要求所选位置保持先后顺序。`3 5 4` 使用连续附近的元素，却因为 `5 < 4` 不成立而不是上升子序列。

本篇的“上升”固定表示严格递增，相邻选择值必须满足 `<`。若题目要求非递减，就允许相等值并使用另一套条件，不能混用。

## 枚举所有子序列

每个位置都有选择或不选择两种决定，长度为 `n` 的序列共有 $2^n$ 个子序列。枚举一个子集以后，再按位置顺序检查所选值是否严格递增，可以得到正确答案，但时间复杂度至少为 $O(n\cdot2^n)$。

许多不同子序列具有相同的最后位置。未来能否接上一个新值，只取决于最后选择的值和当前长度，不需要保留更早的完整选择过程。

由于最后值就是原数组某个位置 `a[i]`，可以按照“最后选择的位置”合并大量子序列。

## 信息不足的前缀答案

若只定义：

```text
best[i] = a[1..i] 中最长上升子序列的长度
```

就无法仅凭 `best[i - 1]` 判断 `a[i]` 能否接在那个答案后面。前缀中可能有多条相同长度的上升子序列，它们的最后值不同；最后值较小的一条更容易继续延伸。

与 [线性动态规划](maximum-subarray-sum.md) 中的最大子段和相同，直接保存前缀全局答案会丢掉转移所需的端点信息。需要先限制右端点，再从所有端点中选最终答案。

## 端点状态

定义：

$$
dp[i]=\text{所有恰好以位置 }i\text{ 结尾的上升子序列中的最大长度}.
$$

任何计入 `dp[i]` 的子序列都必须选择 `a[i]` 作为最后一个元素。因此：

- 它的最后值确定为 `a[i]`；
- 后续位置 `k` 只要满足 `a[i] < a[k]`，就能把 `a[k]` 接在后面；
- 不同历史到达同一个结尾位置时，只需保留其中最长的一条。

状态值只保存长度；原数组位置 `i` 已经同时确定顺序和最后值，不需要把最后值另设成一个状态维度。

## 单独选择当前位置

无论前面有哪些元素，只选择 `a[i]` 自己总能形成长度为 `1` 的上升子序列。因此每个状态的初始值都是：

$$
dp[i]=1.
$$

这个初始值同时处理“前面没有更小元素”的情况，不需要不可达哨兵。

## 枚举前一个位置

若以 `i` 结尾的上升子序列长度大于 `1`，在 `a[i]` 之前一定有一个最后选择的位置 `j`，满足：

```text
1 <= j < i
a[j] < a[i]
```

删除最后的 `a[i]` 后，剩余部分是一个以 `j` 结尾的上升子序列。其中最大长度已经保存在 `dp[j]`，重新接上 `a[i]` 后得到：

$$
dp[j]+1.
$$

枚举所有合法 `j` 并取最大值：

$$
dp[i]=\max\left(1,\ \max_{1\le j<i,\ a[j]<a[i]}(dp[j]+1)\right).
$$

代码从初始长度 `1` 开始更新：

```cpp
dp[i] = 1;

for (int j = 1; j < i; j++) {
    if (a[j] < a[i]) {
        dp[i] = max(dp[i], dp[j] + 1);
    }
}
```

条件必须是严格小于。写成 `a[j] <= a[i]` 求出的是最长非递减子序列，不是本文的 LIS。

## 计算顺序

`dp[i]` 只依赖更早位置 `j < i`，所以按照 `i = 1,2,...,n` 递增计算。处理 `i` 时，所有可能的 `dp[j]` 都已经完成。

外层枚举结尾位置，内层枚举它可能接在哪个更早位置以后：

```cpp
for (int i = 1; i <= n; i++) {
    dp[i] = 1;

    for (int j = 1; j < i; j++) {
        if (a[j] < a[i]) {
            dp[i] = max(dp[i], dp[j] + 1);
        }
    }
}
```

这是一种线性 DP：状态沿原序列位置推进，但一个状态可能依赖所有更早位置，并不要求只读取 `i - 1`。

## 最终答案

最长上升子序列可以结束在任意位置。`dp[n]` 只表示必须选择最后一个元素时的答案，所以最终长度是：

$$
\max_{1\le i\le n}dp[i].
$$

填表时同步保存最大长度：

```cpp
int answer_length = 0;

for (int i = 1; i <= n; i++) {
    // 计算 dp[i]
    answer_length = max(answer_length, dp[i]);
}
```

## 填表过程

对样例 `3 1 2 5 4 7`：

| `i` | `a[i]` | 可以接在其后的更早位置 | `dp[i]` |
| ---: | ---: | --- | ---: |
| `1` | `3` | 无 | `1` |
| `2` | `1` | 无 | `1` |
| `3` | `2` | `2` | `2` |
| `4` | `5` | `1,2,3` | `3` |
| `5` | `4` | `1,2,3` | `3` |
| `6` | `7` | `1,2,3,4,5` | `4` |

`dp[4] = 3` 可以对应 `1,2,5`，`dp[5] = 3` 可以对应 `1,2,4`。计算 `dp[6]` 时，两者都能接上 `7`，得到两种长度为 `4` 的答案。

## 记录前驱

只保存 `dp[i]` 能得到最长长度，却不知道具体选择了哪些位置。增加：

```text
previous[i] = 当前为 dp[i] 选择的前一个位置
```

单独选择 `a[i]` 时没有前驱，使用 `0` 表示结束：

```cpp
dp[i] = 1;
previous[i] = 0;
```

若从位置 `j` 得到更长状态，就同时记录：

```cpp
if (a[j] < a[i] && dp[j] + 1 > dp[i]) {
    dp[i] = dp[j] + 1;
    previous[i] = j;
}
```

这里只在严格变长时更新。出现相同长度的多个前驱时，保留最先枚举到的一种即可；题目只要求输出任意一条最长上升子序列。

还要记录全局答案结束在哪个位置：

```cpp
if (dp[i] > answer_length) {
    answer_length = dp[i];
    end_position = i;
}
```

## 反向恢复

从 `end_position` 开始沿 `previous` 走：

```text
当前结尾 -> 前一个位置 -> 更前一个位置 -> ... -> 0
```

得到的位置顺序与原子序列相反。先把值依次加入 `answer`，再整体反转：

```cpp
vector<ll> answer;

for (int u = end_position; u != 0; u = previous[u]) {
    answer.push_back(a[u]);
}
reverse(answer.begin(), answer.end());
```

`previous[u] < u`，所以下标每次严格减小，恢复过程一定到达哨兵 `0`。经过的节点数正好是 `answer_length`。

这里的 `answer` 是 STL `vector`，反转使用它的原生 0-based 迭代器范围；原序列和 DP 位置仍然使用 `1..n`。

## 正确性

先对 `i` 递增证明 `dp[i]` 符合定义。

只选择 `a[i]` 本身总能得到长度 `1`。任意更长、以 `i` 结尾的上升子序列都有唯一的倒数第二个位置 `j`，并且 `j < i`、`a[j] < a[i]`。删除 `a[i]` 后，前面部分是一个以 `j` 结尾的上升子序列，其最大长度由归纳假设等于 `dp[j]`，所以当前类别的最大长度为 `dp[j] + 1`。

枚举所有合法 `j` 加上单元素情况，恰好覆盖所有以 `i` 结尾的上升子序列，取最大值后 `dp[i]` 正确。

任意非空上升子序列都有唯一最后位置 `i`，所以全局 LIS 一定被某个 `dp[i]` 包含；每个 `dp[i]` 又确实对应一条合法上升子序列。因此对全部状态取最大值得到正确长度。

每次更新 `previous[i] = j` 时都满足 `a[j] < a[i]` 且 `dp[i] = dp[j] + 1`。沿前驱反向走得到严格递减的位置和严格递减的状态长度，反转后就是位置递增、数值严格递增且长度等于最优值的一条合法方案。

## 完整代码

输入保证 `1 <= n <= 5000`，序列元素能使用 64 位整数保存。程序输出 LIS 长度和任意一条实际方案。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int n;
vector<ll> a;
vector<int> dp;
vector<int> previous;

void solve() {
    scanf("%d", &n);

    a.assign(n + 5, 0);
    dp.assign(n + 5, 0);
    previous.assign(n + 5, 0);

    for (int i = 1; i <= n; i++) {
        scanf("%lld", &a[i]);
    }

    int answer_length = 0;
    int end_position = 0;

    for (int i = 1; i <= n; i++) {
        dp[i] = 1;

        for (int j = 1; j < i; j++) {
            if (a[j] < a[i] && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;
                previous[i] = j;
            }
        }

        if (dp[i] > answer_length) {
            answer_length = dp[i];
            end_position = i;
        }
    }

    vector<ll> answer;
    for (int u = end_position; u != 0; u = previous[u]) {
        answer.push_back(a[u]);
    }
    reverse(answer.begin(), answer.end());

    printf("%d\n", answer_length);
    for (int i = 0; i < answer_length; i++) {
        printf("%lld%c", answer[i], " \n"[i + 1 == answer_length]);
    }
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
6
3 1 2 5 4 7
```

按照代码固定的枚举和相同长度保留规则，输出：

```text
4
1 2 5 7
```

## 复杂度

每个位置 `i` 枚举所有 `j < i`，总比较次数为：

$$
0+1+2+\cdots+(n-1)=\frac{n(n-1)}{2},
$$

所以时间复杂度是 $O(n^2)$。`a`、`dp`、`previous` 和恢复出的答案共使用 $O(n)$ 空间。

恢复过程只沿最长子序列的前驱走一次，时间为 $O(n)$，不会改变总体复杂度。

## 常见错误

### 把子序列当成连续子段

LIS 可以跳过任意元素，只要求所选位置保持顺序。若只比较相邻原数组元素，会漏掉跨越中间元素的答案。

### 使用小于等于

严格上升必须检查 `a[j] < a[i]`。使用 `<=` 会把相等元素连续选入，求成最长非递减子序列。

### 把答案写成 `dp[n]`

LIS 可以在任意位置结束。必须对 `dp[1..n]` 取最大，并记录对应结束位置。

### 忘记单元素初始值

每个位置自身都是长度为 `1` 的上升子序列。若初始化为 `0`，所有状态长度都会少一。

### 更新长度却不更新前驱

当 `dp[i]` 改为来自 `j` 时，`previous[i]` 必须同时设为 `j`。否则恢复出的路径与最终长度不一致。

### 恢复后忘记反转

前驱指向更早位置，从结尾沿前驱得到的是倒序。输出前需要反转。

## 基础练习

1. 手动计算序列 `5 1 4 2 3` 的所有 `dp[i]` 和 `previous[i]`。
2. 对严格递减序列和全部相等序列运行程序，检查答案长度都为 `1`。
3. 把比较条件改为非递减，说明状态定义、转移和样例输出怎样变化。
4. 枚举所有子集并检查是否严格递增，与 $O(n^2)$ DP 随机对拍。
5. 修改相同长度时的前驱选择规则，观察恢复出的 LIS 可以怎样变化。
6. 只输出最长长度，删除所有方案恢复状态；比较仍然必须保留哪些信息。
