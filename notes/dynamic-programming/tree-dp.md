# 树形 DP

> 最近修订：2026-08-17 07:42 +10:00（未审阅）

线性动态规划通常按下标推进，DAG 上的 DP 按拓扑序推进。树没有天然的从左到右
顺序，但父节点的答案常常依赖所有儿子子树；这时 DFS 的返回顺序就是计算顺序。

本篇用“树上最大权独立集”说明最基础的树形 DP：每个节点有权值，选择若干节点，
要求任意一条边的两个端点不能同时选择，并最大化权值和。

## 为什么只记录子树答案

任选点 `1` 为根后，每个节点 `u` 的后代形成独立子树。不同儿子子树之间没有边，
它们只通过共同父节点 `u` 发生关系。

在决定儿子 `v` 能否被选择时，只需要知道父节点 `u` 是否被选择：

- 若选择 `u`，所有儿子都不能选择；
- 若不选择 `u`，每个儿子可以选择，也可以不选择。

更高祖先怎样选择，不会直接影响 `v`；它们对当前子树的影响已经浓缩成
“`u` 是否选择”。

## 两个状态

定义：

```cpp
f[u][0]
```

表示不选择节点 `u` 时，`u` 子树内能得到的最大权值和；

```cpp
f[u][1]
```

表示选择节点 `u` 时，`u` 子树内能得到的最大权值和。

状态必须明确包含“子树范围”和“根节点是否选择”两个条件。只写“`f[u]` 是
`u` 的答案”无法区分父子冲突，不能完成转移。

## 叶节点的初始状态

若 `u` 是叶节点：

- 不选择它，权值和为 `0`；
- 选择它，权值和为 `weight[u]`。

因此对所有节点进入 DFS 时统一初始化：

```cpp
f[u][0] = 0;
f[u][1] = weight[u];
```

非叶节点随后再把每个儿子的贡献合并进来。

这套定义允许一个节点都不选。如果所有权值都为负，根的最终答案可以是 `0`。
若题目要求至少选择一个节点，需要另外增加状态或单独处理。

## 合并一个儿子

先递归算完儿子 `v`。

若选择 `u`，根据独立集限制不能选择 `v`，所以只能加入：

```cpp
f[u][1] += f[v][0];
```

若不选择 `u`，儿子 `v` 选或不选都合法，应取较大值：

```cpp
f[u][0] += max(f[v][0], f[v][1]);
```

不同儿子子树之间没有边，选择互不影响，因此每棵子树的最优贡献可以直接相加。

## 后序计算

完整 DFS 为：

```cpp
void dfs(int u, int p) {
    f[u][0] = 0;
    f[u][1] = weight[u];

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }

        dfs(v, u);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}
```

递归调用 `dfs(v,u)` 返回以后，儿子状态已经完整计算，所以父节点可以立刻使用。
这种“儿子先完成、父节点后完成”的顺序称为后序计算。

代码在进入 `u` 时初始化状态，在退出每个儿子后合并贡献；不需要显式保存后序
序列。

## 一个具体例子

考虑有根树：

```text
        1(4)
       /    \
    2(2)    3(3)
    /  \
 4(5)  5(1)
```

括号中是节点权值。

叶节点：

```text
f[3] = {0, 3}
f[4] = {0, 5}
f[5] = {0, 1}
```

对点 `2`：

$$
f[2][0]=\max(0,5)+\max(0,1)=6,
$$

$$
f[2][1]=2+0+0=2.
$$

对根 `1`：

$$
f[1][0]=\max(6,2)+\max(0,3)=9,
$$

$$
f[1][1]=4+6+0=10.
$$

最终答案是 `10`，选择点 `1、4、5`。

## 阶段、状态与决策

- **阶段**：DFS 后序中已经算完哪些子树；
- **状态**：当前子树根 `u` 是否选择；
- **决策**：对每个儿子 `v`，选择它的 `0` 状态还是 `1` 状态。

父节点已选择时决策被限制为 `f[v][0]`；父节点未选择时可以取两个状态的最大值。

树形 DP 的关键不是“在树上写递归”，而是找到父子边上真正会影响后续决策的少量
信息，并让每棵子树只向父节点返回这些状态。

## 根的选择

无根树可以任选根。最大权独立集只关心相邻节点不能同时选择，与父子方向无关，
所以不同根会改变中间状态的组织方式，但不会改变最终最优值。

DFS 完成后，根没有父节点限制，选或不选都合法：

```cpp
ll answer = max(f[root][0], f[root][1]);
```

某些树形 DP 的状态依赖题目指定根，例如子树查询或祖先关系；这时不能随意换根。

## 恢复选择方案

若需要输出具体节点，可以从根状态向下恢复：

- 父节点选择，则儿子必须进入状态 `0`；
- 父节点不选，则儿子选择 `f[v][0]` 与 `f[v][1]` 中较大者；
- 相等时按题目要求任选或使用额外规则。

这不需要修改最优值转移，只需在第二次 DFS 中根据已算好的状态做决定。

## 正确性

对子树大小归纳。

叶节点的两个状态直接枚举“选”和“不选”，显然正确。

假设所有儿子 `v` 的 `f[v][0]`、`f[v][1]` 都正确。选择 `u` 时，每个儿子
必须不选，因此所有合法方案的最优值只能是
`weight[u] + sum(f[v][0])`。

不选择 `u` 时，不同儿子子树之间没有边；每棵子树都可独立取“选儿子”与“不选
儿子”的较大值，再把所有贡献相加。于是两个转移分别覆盖各自状态下的全部合法
方案，并取得最大值。

归纳到根后，两个根状态都正确，取最大值就是全树答案。

## 复杂度

DFS 访问每个点一次，每条无向边检查两个方向，时间复杂度为 $O(n)$。邻接表和状态
数组占 $O(n)$ 空间，递归栈最坏为 $O(n)$。

## 完整代码

程序读取一棵带点权无向树，输出最大权独立集的权值和。允许不选择任何节点。

```cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

int n;
vector<vector<int>> g;
vector<ll> weight;
vector<array<ll, 2>> f;

void dfs(int u, int p) {
    f[u][0] = 0;
    f[u][1] = weight[u];

    for (int v : g[u]) {
        if (v == p) {
            continue;
        }

        dfs(v, u);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}

int main() {
    scanf("%d", &n);

    weight.assign(n + 5, 0);
    for (int u = 1; u <= n; u++) {
        scanf("%lld", &weight[u]);
    }

    g.assign(n + 5, {});
    for (int i = 1; i <= n - 1; i++) {
        int u, v;
        scanf("%d%d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    f.assign(n + 5, {0, 0});
    int root = 1;
    dfs(root, 0);

    printf("%lld\n", max(f[root][0], f[root][1]));
    return 0;
}
```

## 常见错误

### 只有一个状态

父节点是否选择会改变儿子的合法选择，必须用状态保留这项信息。

### 父节点选择时仍取儿子的最大值

若选择 `u`，儿子 `v` 不能选择，只能加入 `f[v][0]`。

### 在儿子计算完成以前使用状态

父节点依赖整棵儿子子树，必须先递归，再合并。

### 无向树中忘记跳过父节点

邻接表保存双向边。只依赖 `v == p` 就足以避免返回父节点，因为输入保证是树。

## 需要记住什么

1. `f[u][0]` 与 `f[u][1]` 的完整含义是什么？
2. 选择父节点时，儿子为什么只能取状态 `0`？
3. 不选择父节点时，为什么不同儿子可以独立取最大值后相加？
4. DFS 的哪个时刻保证儿子状态已经完成？
5. 怎样从根的两个状态得到全树答案？
