# 动态规划：线性 DP

> 最近修订：2026-08-13 22:29 +10:00（未审阅）

[动态规划：状态与转移](dp-state-transition.md) 用楼梯位置排列状态，较大位置依赖较小位置。许多题目还会给出一条有顺序的数组或字符串，状态随着输入位置从左向右推进。这类模型通常称为线性 DP。

线性 DP 不等于“状态一定是一维”或“只依赖前一个位置”。它的共同特点是输入具有清晰的线性顺序，处理前缀以后继续加入下一个元素。本篇用最大子段和说明一种特别常见的状态设计：为了让下一步能够继续扩展，状态需要限定答案恰好在哪里结束。

## 最大子段和

给定一个长度为 $n$ 的整数数组 `a[1..n]`，选择一个非空连续子段，使其中元素之和最大。

例如：

```text
-2 3 -1 4 2 -6 1
```

选择闭区间 `a[2..5]`：

```text
3 -1 4 2
```

元素和为 `8`，这是所有非空连续子段中的最大值。

“非空”是题目条件。若数组是：

```text
-5 -2 -7
```

答案应为只选择 `-2`，而不是选择空子段得到 `0`。

## 朴素枚举

每个连续子段由左右端点 `l,r` 唯一确定。枚举 `1 <= l <= r <= n`，固定左端点后逐步向右累加：

```cpp
ll answer = a[1];

for (int l = 1; l <= n; l++) {
    ll sum = 0;
    for (int r = l; r <= n; r++) {
        sum += a[r];
        answer = max(answer, sum);
    }
}
```

共有 $O(n^2)$ 个子段，每次向右扩展只做一次加法，所以总时间复杂度是 $O(n^2)$。

[分治：基础](../algorithm-basics/divide-and-conquer.md) 已经把子段按照相对中点的位置分成三类，在 $O(n\log n)$ 时间内求解。本篇从数组左端向右扫描，寻找能够在加入一个新元素时复用的状态，把时间继续降到 $O(n)$。

## 信息不足的状态

一个看似直接的定义是：

$$
best[i]=\text{数组 }a[1..i]\text{ 中的最大非空子段和}.
$$

最终答案确实是 `best[n]`。但处理新元素 `a[i]` 时，只知道 `best[i - 1]` 还不足以计算 `best[i]`。

例如两个前缀的最大子段和都可能是 `10`：

```text
前缀 A：10 -100
前缀 B： 1    9
```

`best` 都只告诉我们前缀内部出现过和为 `10` 的最好子段，却没有说明这个子段是否延伸到前缀末尾。若下一个元素是 `5`：

- 前缀 A 的旧答案 `10` 与新元素之间隔着 `-100`，不能直接连成连续子段；
- 前缀 B 的旧答案 `1 + 9` 恰好位于末尾，可以继续接上 `5`。

状态值相同，加入新元素后的行为却不同，说明 `best[i - 1]` 丢失了转移需要的“是否贴着右端点”信息。

动态规划状态不仅要方便描述答案，还必须保留计算后续状态所需的全部信息。

## 限定右端点

新元素 `a[i]` 只能接在一个以 `i - 1` 结尾的连续子段后面。于是定义：

$$
dp[i]=\text{所有恰好以位置 }i\text{ 结尾的非空连续子段中的最大和}.
$$

“恰好以 `i` 结尾”是状态定义的关键。它暂时缩小了候选答案范围，却保证这个状态能够安全地接上 `a[i + 1]`。

例如数组：

```text
3 -1 4
```

- `dp[1] = 3`，对应 `[3]`；
- `dp[2] = 2`，对应 `[3, -1]`，虽然前两个数中的全局最好答案仍是 `3`；
- `dp[3] = 6`，可以把 `4` 接在 `dp[2]` 对应的子段后面。

`dp[i]` 不一定是前 `i` 个元素中的最终最好答案。它只负责保存“将来还能继续向右延伸”的最好候选。

## 状态转移

任意一个以 `i` 结尾的非空连续子段，根据是否包含前一个位置，只可能属于两类。

### 从当前位置重新开始

子段只包含 `a[i]`：

```text
[a[i]]
```

它的和是 `a[i]`。

### 延续前一个子段

若子段还包含更早元素，由于它必须连续并以 `i` 结尾，删除最后的 `a[i]` 后，剩余部分一定是一个以 `i - 1` 结尾的非空连续子段。

在所有这种前缀中，最大的和已经保存在 `dp[i - 1]`，所以延续后的最大值是：

```text
dp[i - 1] + a[i]
```

两类覆盖全部可能。选择较大者：

$$
dp[i]=\max(a[i],\ dp[i-1]+a[i]).
$$

代码直接对应“重新开始”和“继续延伸”两种决定：

```cpp
dp[i] = max(a[i], dp[i - 1] + a[i]);
```

也可以把 `a[i]` 提出来写成 `a[i] + max(0LL, dp[i - 1])`，但前一种写法更直接保留两类候选，并且不会让读者误以为题目允许选择和为 `0` 的空子段。

## 初始状态

位置 `1` 以前没有真实元素。以位置 `1` 结尾的非空连续子段只有 `[a[1]]`，所以：

$$
dp[1]=a[1].
$$

本题输入保证 `n >= 1`，可以直接使用这个初始状态。

没有必要凭空定义 `dp[0] = 0` 再把空子段混入转移。上一章的 `dp[0] = 1` 来自“到达地面的空走法确实是一种计数方案”；动态规划的初始值由具体状态语义决定，不存在所有题目通用的固定写法。

## 计算顺序

`dp[i]` 只依赖 `dp[i - 1]` 和当前输入 `a[i]`，所以先设置 `dp[1]`，再从左向右计算 `2..n`：

```cpp
vector<ll> dp(n + 5);
dp[1] = a[1];

for (int i = 2; i <= n; i++) {
    dp[i] = max(a[i], dp[i - 1] + a[i]);
}
```

这种依赖沿输入顺序不断向前推进，正是最基础的线性 DP 结构。

## 答案位置

题目允许最大子段结束在任意位置，而 `dp[n]` 只包含恰好以 `n` 结尾的子段。最终答案因此不是固定的 `dp[n]`，而是：

$$
\max_{1\le i\le n}dp[i].
$$

可以在填表时同步维护：

```cpp
ll answer = dp[1];

for (int i = 2; i <= n; i++) {
    dp[i] = max(a[i], dp[i - 1] + a[i]);
    answer = max(answer, dp[i]);
}
```

`answer` 必须初始化为 `dp[1]`，不能初始化为 `0`。这样即使所有元素都是负数，也会选择其中最大的一个真实元素。

这展示了动态规划中经常出现的两层含义：

- `dp[i]` 为了支持转移，回答一个带额外限制的子问题；
- 最终答案再从所有可能终止状态中选出。

## 填表过程

对数组：

```text
-2 3 -1 4 2 -6 1
```

逐项计算：

| `i` | `a[i]` | 重新开始 `a[i]` | 继续延伸 `dp[i-1]+a[i]` | `dp[i]` | 当前 `answer` |
| ---: | ---: | ---: | ---: | ---: | ---: |
| `1` | `-2` | — | — | `-2` | `-2` |
| `2` | `3` | `3` | `1` | `3` | `3` |
| `3` | `-1` | `-1` | `2` | `2` | `3` |
| `4` | `4` | `4` | `6` | `6` | `6` |
| `5` | `2` | `2` | `8` | `8` | `8` |
| `6` | `-6` | `-6` | `2` | `2` | `8` |
| `7` | `1` | `1` | `3` | `3` | `8` |

位置 `6` 的负数把可延伸子段和降为 `2`，但不会抹掉此前已经得到的全局答案 `8`。这也是必须区分 `dp[i]` 与 `answer` 的原因。

## 正确性

先证明每个 `dp[i]` 都符合定义。

当 `i = 1` 时，以位置 `1` 结尾的唯一非空连续子段是 `[a[1]]`，所以 `dp[1] = a[1]` 正确。

假设 `dp[i - 1]` 已经是所有以 `i - 1` 结尾的非空连续子段中的最大和。任意以 `i` 结尾的非空连续子段：

- 若只包含位置 `i`，和为 `a[i]`；
- 若还包含更早位置，删除最后一个元素后必然成为以 `i - 1` 结尾的非空连续子段，其中最大和为 `dp[i - 1]`，重新接上 `a[i]` 后最大和为 `dp[i - 1] + a[i]`。

两类不重不漏，取最大值得到正确的 `dp[i]`。按照 `i` 递增归纳，所有状态都正确。

任意非空连续子段都有唯一右端点 `i`，并被 `dp[i]` 的候选范围包含；每个 `dp[i]` 对应的又确实是一个非空连续子段。因此对 `dp[1..n]` 取最大值，恰好得到全局最大非空子段和。

## 完整代码

输入保证 `1 <= n <= 2 * 10^5`，所有连续子段和都能使用 64 位整数保存：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int main() {
    int n;
    scanf("%d", &n);

    vector<ll> a(n + 5);
    for (int i = 1; i <= n; i++) {
        scanf("%lld", &a[i]);
    }

    vector<ll> dp(n + 5);
    dp[1] = a[1];
    ll answer = dp[1];

    for (int i = 2; i <= n; i++) {
        dp[i] = max(a[i], dp[i - 1] + a[i]);
        answer = max(answer, dp[i]);
    }

    printf("%lld\n", answer);
    return 0;
}
```

输入：

```text
7
-2 3 -1 4 2 -6 1
```

输出：

```text
8
```

这份程序与分治文章处理的是同一个问题、采用相同的“非空子段”和 64 位整数约定，所以可以直接比较两种算法的结果。

## 复杂度

程序从左到右访问每个元素一次，每个状态只做固定数量的加法和比较，所以时间复杂度是 $O(n)$。

数组 `a` 和 `dp` 各自占用 $O(n)$ 空间。若题目只要求最大和，转移确实只需要前一个 `dp`，可以把额外 DP 空间压缩成 $O(1)$；本篇仍保留完整状态表，使 `dp[i]` 的定义、填表结果和答案范围直接可见。

若要恢复最大子段的左右端点，还需要在“重新开始”时记录新的左端点，并在更新全局答案时记录右端点。方案恢复具有独立的实现细节，不放进本篇基础代码。

## 与其他方法比较

| 方法 | 核心划分 | 时间复杂度 | 额外空间 |
| --- | --- | ---: | ---: |
| 枚举左右端点 | 按 `(l,r)` 枚举每个子段 | $O(n^2)$ | $O(1)$ |
| 分治 | 相对中点分为左、右、跨中点 | $O(n\log n)$ | $O(\log n)$ |
| 线性 DP | 按右端点合并可延伸子段 | $O(n)$ | 本文为 $O(n)$ |

三种方法解决同一个问题，但保留的信息不同。线性 DP 最快，是因为 `dp[i - 1]` 已经把所有可能左端点压缩成一个“以 `i - 1` 结尾的最大和”，加入 `a[i]` 时不必再次枚举左端点。

## 常见错误

### 状态没有限定结尾

“前 `i` 个元素中的最大子段和”不能直接延伸到 `i + 1`。需要额外保存“以 `i` 结尾”的最优值，才能保证连续性。

### 把答案固定为 `dp[n]`

最大子段可以在任意位置结束。`dp[n]` 只回答以最后一个元素结尾的受限问题，必须对所有终点取最大值。

### 允许空子段

把 `dp[1]` 或 `answer` 初始化为 `0`，会让全负数组错误输出 `0`。本题要求非空，初始值必须来自真实元素。

### 负贡献必须机械丢弃

状态转移不是“看到负数就重新开始”。即使 `a[i]` 为负，`dp[i - 1] + a[i]` 仍可能大于单独的 `a[i]`，并为后面更大的正数保留有价值的连续前缀。

### 只看样例中的正数段

最大子段内部可以包含负数，只要保留它能连接两侧并使总和更大。示例答案 `3 + (-1) + 4 + 2` 就包含 `-1`。

## 基础练习

1. 手动计算数组 `-5 -2 -7` 的全部 `dp[i]` 和最终答案。
2. 对每个位置枚举所有以它结尾的子段，验证其最大和等于线性转移得到的 `dp[i]`。
3. 修改代码，同时输出最大子段的左右端点；若有多个答案，选择左端点最小的一段。
4. 将问题改成最大子段积，观察负数会使“只保存一个最大值”为什么不再足够。
5. 将问题改成环形数组的最大非空子段和，分析普通线性状态遗漏了哪些跨越首尾的候选。
6. 分别运行二次枚举、分治和线性 DP，随机生成小数组对拍三份程序。

## 需要记住什么

1. 什么样的状态推进通常称为线性 DP？
2. 为什么“前 `i` 个元素中的最大答案”不足以直接转移？
3. `dp[i]` 中“恰好以 `i` 结尾”保留了什么必要信息？
4. 以 `i` 结尾的非空子段为什么恰好分成重新开始和继续延伸两类？
5. `dp[1]` 为什么必须等于 `a[1]`？
6. 为什么最终答案是 `max(dp[1..n])` 而不是 `dp[n]`？
7. 全负数组为什么能检验初始化是否错误？
8. 线性 DP 怎样把枚举所有左端点压缩成一次状态转移？

线性 DP 是一种组织状态的方向，不是一条固定公式。后续的状态机 DP、最长上升子序列和许多字符串 DP 都沿输入顺序推进，但会根据未来转移所需信息设计不同状态。
