# 数字三角形

> 最近修订：2026-08-16 16:26 +10:00（未审阅）

[动态规划的状态与转移](dp-state-transition.md) 已经说明：状态必须保留决定后续所需的信息，转移则要把所有候选按一次选择分成不重不漏的类别。本篇把一维楼梯换成二维排列的数字三角形，学习怎样从题目允许的移动方向反推前置状态。

## 问题

数字按照下面的形式排列，共有 $n$ 行，第 $i$ 行有 $i$ 个整数：

```text
        7
      3   8
    8   1   0
  2   7   4   4
4   5   2   6   5
```

从第一行的数字出发，每次只能走到下一行中正下方或右下方的数字。选择一条到达最后一行的路径，使经过的数字之和最大。

把第 $i$ 行第 $j$ 个数字记为 `a[i][j]`。从 `(i, j)` 出发时，两种移动分别是：

```text
(i, j) -> (i + 1, j)
(i, j) -> (i + 1, j + 1)
```

上面的例子可以选择：

```text
7 -> 3 -> 8 -> 7 -> 5
```

路径和为 `30`，这也是最大值。

## 为什么不能只看下一步

一个自然想法是：每次比较正下方和右下方，选择其中较大的数字。

这种贪心只比较了下一步，没有计算一次选择会把路径带到哪个位置。较大的相邻数字后面可能只能接上很小的数，较小的相邻数字后面反而可能出现更大的总和。

例如：

```text
    1
  9   8
0   0   100
```

第一步选择较大的 `9` 后，最后只能接到 `0`，路径和是 `10`；选择 `8` 却能继续走到 `100`，路径和是 `109`。

因此，当前位置的最好选择不能只由相邻数字决定。需要把走到每个位置以前已经得到的最好路径保存下来。

## 暴力搜索

每次向下一行都有至多两个选择。可以枚举所有路径，到达最后一行时计算路径和：

```cpp
ll dfs(int row, int column) {
    if (row == n) {
        return a[row][column];
    }

    ll downward = dfs(row + 1, column);
    ll down_right = dfs(row + 1, column + 1);
    return a[row][column] + max(downward, down_right);
}
```

递归方向虽然直观，但相同位置会被不同路径反复到达。例如 `(3, 2)` 既能从 `(2, 1)` 的右下方到达，也能从 `(2, 2)` 的正下方到达；从 `(3, 2)` 开始的后续问题却完全相同。

第 $1$ 行到第 $n$ 行一共做出 $n-1$ 次二选一，暴力递归的时间复杂度是 $O(2^n)$。三角形中实际只有：

$$
1+2+\cdots+n=\frac{n(n+1)}2=O(n^2)
$$

个位置。不同路径汇合到同一位置以后，后续问题发生了重叠，这正是动态规划可以合并的重复子问题。

## 状态

按照从上到下的阶段顺序，定义：

$$
dp[i][j]=\text{从顶端出发，恰好到达 }(i,j)\text{ 的最大路径和}.
$$

这里：

- 行号 `i` 是阶段，表示已经处理到第几行；
- 列号 `j` 区分同一阶段中的不同位置；
- `dp[i][j]` 是对应子问题的最优值。

不能只保存“到达第 `i` 行的最大路径和”。同一行中的不同位置具有不同的后继：从 `(i, j)` 只能走向 `(i + 1, j)` 与 `(i + 1, j + 1)`。如果把整行压成一个值，就会丢失下一步需要的位置。

## 从当前状态反推来源

为了计算 `dp[i][j]`，不必重新枚举从顶端到这里的全部路径。只要反过来问：最后一步可以从哪里走来？

根据题目的两种向下移动，到达 `(i, j)` 的最后一步只可能来自：

```text
(i - 1, j - 1) -> (i, j)
(i - 1, j)     -> (i, j)
```

删除最后一个数字以后，路径分别对应两个前置状态。选择其中较大的路径和，再加上当前位置的数字：

$$
dp[i][j]
=a[i][j]+\max\bigl(dp[i-1][j-1],\ dp[i-1][j]\bigr).
$$

这两个来源不重不漏：任意到达 `(i, j)` 的路径都有唯一倒数第二个位置，而题目只允许这两种移动。

## 边界位置

上面的公式只适用于一行中间的位置。第 `i` 行的有效列号是 `1..i`：

- 最左侧 `(i, 1)` 没有左上方，只能从 `(i - 1, 1)` 到达；
- 最右侧 `(i, i)` 没有正上方，只能从 `(i - 1, i - 1)` 到达；
- 中间位置 `2..i-1` 才有两个来源。

因此代码分成三类：

```cpp
dp[i][1] = dp[i - 1][1] + a[i][1];

for (int j = 2; j < i; j++) {
    dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + a[i][j];
}

dp[i][i] = dp[i - 1][i - 1] + a[i][i];
```

也可以把三角形以外的位置初始化为一个足够小的负数，再统一使用同一个转移式。但明确处理两个边界没有依赖“负无穷”哨兵，也不会因为数据范围改变而选错常量，本篇采用这种写法。

## 初始状态

第一行只有顶端 `(1, 1)`。从顶端出发并恰好到达顶端，路径只包含它本身：

$$
dp[1][1]=a[1][1].
$$

这里不能把 `dp[1][1]` 初始化为 `0`。状态值表示已经经过的数字之和，顶端数字必须被计入。

即使所有数字都是负数，初始状态和后续边界转移仍然会选择一条真实路径，不会偷偷引入和为 `0` 的空路径。

## 计算顺序

第 `i` 行只依赖第 `i - 1` 行，所以先计算顶端，再按照 `i = 2..n` 从上到下填表。每一行内部只读取上一行，同一行的计算顺序不会影响结果；为了与编号保持一致，仍按 `j` 从小到大计算。

```cpp
dp[1][1] = a[1][1];

for (int i = 2; i <= n; i++) {
    dp[i][1] = dp[i - 1][1] + a[i][1];

    for (int j = 2; j < i; j++) {
        dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + a[i][j];
    }

    dp[i][i] = dp[i - 1][i - 1] + a[i][i];
}
```

计算顺序不是由二维数组的存储形式决定，而是由状态依赖决定。若先计算第 `i` 行，再计算第 `i - 1` 行，转移读取的就仍是未完成的默认值。

## 答案位置

题目只要求路径到达最后一行，没有指定最后停在哪一列。`dp[n][j]` 表示终点恰好为 `(n, j)` 时的最好路径，因此最终答案是：

$$
\max_{1\le j\le n}dp[n][j].
$$

```cpp
ll answer = dp[n][1];
for (int j = 2; j <= n; j++) {
    answer = max(answer, dp[n][j]);
}
```

`dp[n][n]` 只代表一路走向右下方的路径，不是天然的全局答案。动态规划完成填表以后，仍要根据状态定义确认题目答案对应一个状态还是一组状态。

## 填表过程

对开头的例子，`dp` 表如下：

| 行 `i` | `dp[i][1..i]` |
| ---: | --- |
| `1` | `7` |
| `2` | `10 15` |
| `3` | `18 16 15` |
| `4` | `20 25 20 19` |
| `5` | `24 30 27 26 24` |

以 `dp[4][2]` 为例，它的两个来源是 `dp[3][1] = 18` 与 `dp[3][2] = 16`，当前位置数字是 `7`：

$$
dp[4][2]=\max(18,16)+7=25.
$$

最后一行的最大值是 `30`，所以最大路径和为 `30`。

## 题目共享状态

三角形大小、原始数字和状态表是本题全局唯一，并且可能被输入、转移和答案统计共同使用的状态，因此使用全局变量：

```cpp
int n;
vector<vector<ll>> a;
vector<vector<ll>> dp;
```

读入 `n` 后用 `assign` 分配并清空二维数组：

```cpp
a.assign(n + 5, vector<ll>(n + 5, 0));
dp.assign(n + 5, vector<ll>(n + 5, 0));
```

第 `i` 行只使用位置 `1..i`，其余格子只是统一容量留下的空位。再次调用 `solve` 时，`assign` 会同时重设尺寸和所有元素，不会保留上一次的数据。

## 正确性

按照行号归纳证明每个状态都符合定义。

第一行只有一条包含顶端数字的路径，所以 `dp[1][1] = a[1][1]` 正确。

假设第 `i - 1` 行的所有状态已经分别保存到达对应位置的最大路径和。任意到达 `(i, j)` 的路径，最后一步只能来自左上方 `(i - 1, j - 1)` 或正上方 `(i - 1, j)`；边界位置只保留其中实际存在的一种。

删除最后一步以后，路径与某个前置状态中的候选一一对应。根据归纳假设，两个来源各自的最好路径已经保存在对应 `dp` 值中。取其中较大者并加上 `a[i][j]`，就得到到达 `(i, j)` 的最大路径和，因此第 `i` 行的状态全部正确。

依次计算到第 `n` 行后，任何合法完整路径都恰好终止在其中一个 `(n, j)`；每个 `dp[n][j]` 又确实对应一条合法完整路径。对最后一行取最大值，便得到全局最大路径和。

## 完整代码

输入第一行是 `n`，随后第 `i` 行输入 `i` 个整数。保证 `1 <= n <= 500`，任意路径和都能使用 64 位整数保存：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

int n;
vector<vector<ll>> a;
vector<vector<ll>> dp;

void solve() {
    scanf("%d", &n);

    a.assign(n + 5, vector<ll>(n + 5, 0));
    dp.assign(n + 5, vector<ll>(n + 5, 0));

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            scanf("%lld", &a[i][j]);
        }
    }

    dp[1][1] = a[1][1];

    for (int i = 2; i <= n; i++) {
        dp[i][1] = dp[i - 1][1] + a[i][1];

        for (int j = 2; j < i; j++) {
            dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + a[i][j];
        }

        dp[i][i] = dp[i - 1][i - 1] + a[i][i];
    }

    ll answer = dp[n][1];
    for (int j = 2; j <= n; j++) {
        answer = max(answer, dp[n][j]);
    }

    printf("%lld\n", answer);
}

int main() {
    solve();
    return 0;
}
```

输入：

```text
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

输出：

```text
30
```

## 复杂度

三角形共有 $n(n+1)/2$ 个有效位置，每个位置只进行常数次比较和加法，所以时间复杂度是 $O(n^2)$。

`a` 与 `dp` 都按照二维方阵分配，各自占用 $O(n^2)$ 空间。只保存有效三角区域仍然是相同的渐进复杂度。

转移只依赖上一行，确实可以使用一维滚动数组把 `dp` 的空间降到 $O(n)$，甚至原地更新。但二维表最直接对应 `dp[i][j]` 的定义，也便于检查每个状态和恢复路径；本篇先保留完整表，空间优化另行讨论。

## 常见错误

### 每次选择相邻的较大数字

局部较大的下一步不一定连接全局最优后缀。除非能够证明贪心选择不会损失最优解，否则必须比较完整子问题的结果。

### 丢失列号

只保存“第 `i` 行的最大值”无法判断下一步能走到哪里。不同列的后继集合不同，列号必须成为状态的一部分。

### 把三角形外的零加入转移

若直接统一写 `max(dp[i - 1][j - 1], dp[i - 1][j])`，默认值 `0` 可能被负数路径错误选中。本篇显式处理最左和最右边界，避免把不存在的位置当成合法来源。

### 忘记顶端数字

`dp[1][1]` 应为 `a[1][1]`。初始化为 `0` 会让所有路径都漏掉第一个数字。

### 只输出右下角

完整路径可以在最后一行任意列结束，必须比较 `dp[n][1..n]`。

### 只看循环层数判断复杂度

内层循环在第 `i` 行只运行 $i$ 次，总次数是 $1+2+\cdots+n=O(n^2)$，不是 $O(n^3)$，也不是 $O(n)$。

## 基础练习

1. 手算示例中每个 `dp[i][j]`，并为 `dp[5][2] = 30` 找出对应路径。
2. 构造一个三行数字三角形，使“每次选择较大相邻数字”的贪心得到错误答案。
3. 修改程序，同时输出最大路径经过的列号。需要额外保存每个状态选择了哪个来源。
4. 把问题改为求最小路径和，说明转移和答案怎样改变。
5. 某些位置禁止经过时，设计一种不会与合法负数答案混淆的不可达状态表示。
6. 尝试只保存上一行和当前行，把状态表空间降到 $O(n)$；解释为什么更新前必须保留上一行。
