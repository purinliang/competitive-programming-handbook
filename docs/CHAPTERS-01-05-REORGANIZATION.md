## 为什么重新编号

“C++ 基础”和“C++ 进阶”是两个不同章节，不得为了避免编号迁移而压进同一章。
C++ 基础负责继续学习算法不可缺少的语言能力；C++ 进阶收录能够加深理解、但不学
也不会阻塞初中竞赛主线的语言机制。原第 02–06 章依次顺延一位：

1. `01 C++ 基础`；
2. `02 C++ 进阶`；
3. `03 算法入门`；
4. `04 初中基础`；
5. `05 初中进阶`；
6. `06 高中基础`；
7. `07 高中进阶`。

第 01–03 章已经经过多轮逐篇讨论、移动和回看，现阶段作为稳定基线；第 04、05 章
继续在正文规模逐渐明确以后迭代单元边界。原“高中基础”和“高中进阶”只是随编号
变成第 06、07 章，仍永久停止主动起草和重写；已有正文、模板、题库和目录条目全部
保留，全库检查可以读取它们。

“稳定基线”不表示第 01–03 章永远不能修改。文章内容、明确的依赖错误、遗漏链接和
局部顺序仍可逐项修订；但不能再为了阶段名称对仗、单元数量漂亮或一次性分类完整，
批量拆并单元或跨章移动文章。结构调整必须由已经出现的具体教学问题触发，并在一次
较小改动后重新阅读，而不是预先假定可以一次得到最终目录。

## 单元划分原则

- 先确定一次学习要解决的主题，再把文章放入单元；不得先看现有文件，再用文件名
  拼出貌似整齐的单元。
- 单篇文章继续保持聚焦；同一单元用于组织若干需要连续理解或反复对照的短文。
- 一个单元通常收录 3–8 篇正文。一个章节也应控制在能够完整浏览的数量；出现十余
  个并列单元时，优先检查是否把基础与进阶或不同难度层次混在同一章。
- 学习路线按教学顺序分组，模块目录按专题分组。同一文章在两套目录中的组名
  可以不同。
- 独立扩展使用前缀 `*`。它可以出现在适合阅读的章节和单元中，但不进入核心
  “上一篇 / 下一篇”；附属扩展继续跟随基础文章，不单独进入学习路线。

## 01 C++ 基础

本章只保留写竞赛程序和继续学习算法必需的能力，共八个单元：

1. 入门：Hello World!、A+B Problem；
2. 数值、变量与算术：整数、浮点数、变量、常量、字面量、类型转换、算术和复合
   赋值；
3. 进制与位运算：二进制、八进制、十六进制、机器表示和位运算；
4. 布尔、比较与逻辑；
5. 控制流：条件分支、循环、自增自减、`break` 与 `continue`；
6. 函数：定义、调用、返回值、参数、调用栈和递归；
7. 数组：一维数组、多维数组、初始化、越界和连续布局；
8. 字符、字符串与输入输出：字符、C 字符串、`string`、整行输入、标准输入输出、
   格式控制和文件重定向。

这里有意不再设置独立的“变量、常量与字面量”和“输入输出”单元。变量、常量和
字面量在具体数值类型与表达式中获得含义；最小输入输出从入门程序开始，文本输入
和完整格式控制在最后一个单元系统归纳。这样既保留必需知识，也不把同一概念拆成
重复回访的十一个并列单元。

数组能够作为函数实参；普通数组形参会调整为指针，因此不会自动保留第一维长度。
正文不得写成“数组不能作为函数参数传递”。

## 02 C++ 进阶

本章是独立、可跳过的进阶章节，共六个单元：

1. 名称与作用域：关键字、标识符、作用域、命名空间和类型别名；
2. 地址、指针与引用：字节寻址、指针、引用、相关 `const` 和完整参数传递；
3. 结构体、联合体与枚举；
4. 内存与存储期：常见内存分区、`static`、对象生命周期和少见修饰符；
5. 从源码到程序：预处理、`#include`、宏定义、条件编译、编译与链接；
6. 类与对象：成员、封装与访问权限、构造析构、函数重载、运算符重载、继承与
   多态。

这些文章继续标记为扩展。第 01 章最后一篇核心文章的“下一篇”直接进入第 03 章；
读者可以从目录主动进入第 02 章。函数重载和运算符重载在正文层面拆成两篇，不能
因为旧文件曾合并而永久共享一个主题。

初始化与存储期的正文必须准确区分：

- 无初始化器的局部内置标量和数组元素不会自动得到零；
- 静态存储期对象会先零初始化；
- 局部对象显式写 `{}` 仍可零初始化；
- `string`、`vector` 等类类型会执行默认构造，默认得到空对象；
- `vector<int>(n)` 创建并值初始化元素，`reserve(n)` 不改变元素数量。

## 03 算法入门

本章只完成进入正式解题以前的三项准备：

1. 复杂度：复杂度的基本口径和从代码分析复杂度；
2. 算法设计思想：枚举、模拟、递归与递推、分治、贪心的最小思想地图；
3. 标准库基础：`vector`、`fill`、`pair`、`tuple`、`sort` 和 `unique`，其中
   `array` 是可跳过扩展。

本章不提前塞入具体算法题型。子集、排列、组合和 DFS 枚举在学过状态空间与 DFS
以后展开；快速排序、归并排序具体展示分治；邻项交换和反悔策略进入后续贪心单元。
`memset` 是 `fill` 的按字节写入辨析，自定义排序是 `sort` 的下属内容，不另立篇。

## 04 初中基础

本章承接第 03 章的方法地图，第一次完整展开能够独立解决一类问题的算法和数据
结构。当前顺序保持以下依赖：

1. 前缀和：前缀和、差分；
2. 排序：冒泡、选择、插入、计数、快速、归并和方法比较；
3. 二分：查找、边界、标准库接口、答案二分和浮点数二分；
4. 离散化；
5. 线性表；
6. 栈；
7. 队列；
8. 双指针与滑动窗口；
9. 贪心的具体策略：邻项交换与反悔；
10. 数论基础；
11. 图的概念与存储；
12. 深度优先搜索、状态空间与具体枚举；
13. 广度优先搜索；
14. 树；
15. 动态规划基础；
16. 背包；
17. 字符串基础。

这里的十七项是本轮需要继续审计的候选顺序，不是用现有文章钉死的最终十七个并列
单元。前缀和、排序、二分、离散化和线性结构可以组成更高一层的连续教学段；图、
树、搜索、动态规划和字符串也要在正文规模稳定后重新检查章界。不得为了马上得到
漂亮数字而破坏已知前向依赖。

## 05 初中进阶

本章暂时保留七个相对独立的单元：

1. 二叉树；
2. 二叉堆；
3. 哈希表；
4. 标准库进阶；
5. 高精度整数；
6. 图搜索的应用；
7. 哈夫曼编码与格雷码。

二叉树和二叉堆相邻但不合并：完全二叉树的数组编号是堆的前置，二者解决的问题
不同。`priority_queue`、有序关联容器和无序关联容器属于标准库进阶；手写二叉堆
和哈希表分别解释它们支持的抽象操作与复杂度。

## 模块目录

模块目录不复制章节结构。C++ 至少拆成程序入门、数值与表示、变量与常量、运算符、
控制流、函数与递归、数组、字符与字符串、输入输出、名称与作用域、指针与引用、
复合类型、内存与存储期、标准库基础、标准库进阶、从源码到程序、类与对象等稳定
专题；算法基础至少拆成复杂度、设计思想、前缀和、排序、二分、双指针、贪心、搜索
与枚举等专题。专题通常保持 3–8 篇，超过十篇必须重新检查。
