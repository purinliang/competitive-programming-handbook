## 为什么重新编号

“C++ 基础”和“C++ 进阶”是两个不同章节，不得为了避免编号迁移而压进同一章。
C++ 基础负责继续学习算法不可缺少的语言能力；C++ 进阶收录能够加深理解、但不学
也不会阻塞初中竞赛主线的语言机制。原第 02–06 章依次顺延一位：

1. `01 C++ 基础`；
2. `02 C++ 进阶`；
3. `03 算法入门`；
4. `04 初中基础`；
5. `05 初中进阶`；
6. `06 高中基础`；
7. `07 高中进阶`。

第 01–03 章已经经过多轮逐篇讨论、移动和回看，现阶段作为稳定基线；第 04、05 章
继续在正文规模逐渐明确以后迭代单元边界。原“高中基础”和“高中进阶”只是随编号
变成第 06、07 章，仍永久停止主动起草和重写；已有正文、模板、题库和目录条目全部
保留，全库检查可以读取它们。

“稳定基线”不表示第 01–03 章永远不能修改。文章内容、明确的依赖错误、遗漏链接和
局部顺序仍可逐项修订；但不能再为了阶段名称对仗、单元数量漂亮或一次性分类完整，
批量拆并单元或跨章移动文章。结构调整必须由已经出现的具体教学问题触发，并在一次
较小改动后重新阅读，而不是预先假定可以一次得到最终目录。

## 单元划分原则

- 先确定一次学习要解决的主题，再把文章放入单元；不得先看现有文件，再用文件名
  拼出貌似整齐的单元。
- 单篇文章继续保持聚焦；同一单元用于组织若干需要连续理解或反复对照的短文。
- 一个单元通常收录 3–8 篇正文，但这只是检查主题是否聚焦的经验范围。一个章节
  可以包含十个以上真正独立的单元；不得为了减少单元数量，把字符与字符串、输入
  输出或其他仅有前置关系的主题强行合并。
- 学习路线按教学顺序分组，模块目录按专题分组。同一文章在两套目录中的组名
  可以不同。
- 独立扩展使用前缀 `*`。它可以出现在适合阅读的章节和单元中，但不进入核心
  “上一篇 / 下一篇”；附属扩展继续跟随基础文章，不单独进入学习路线。

## 01 C++ 基础

本章只保留写竞赛程序和继续学习算法必需的能力。单元按真实教学主题排列，不为
控制数量而合并：

1. 第一个程序：Hello World!、A+B Problem；
2. 整数类型：整数、算术表达式和复合赋值；
3. 浮点类型：浮点数、数值类型转换和 `<cmath>` 数学函数；
4. 布尔类型：`bool`、真假值、整数到布尔值的转换；
5. 条件语句：比较、连锁不等式陷阱、逻辑运算、短路求值、
   `if` / `else` 和 `switch`；
6. 循环语句：`while`、`for`、自增自减、`break`、`continue`、低频的
   `do while`；
7. 数组：常量与常量表达式、一维数组、多维数组、初始化、越界和行优先连续布局；
8. 字符类型：字符、ASCII、转义字符、字符分类和字符/数值转换；
9. 字符串：C 字符串、`string`、整行文本和空白处理；
10. 函数：定义、调用、返回值、形参与实参、函数原型、调用栈和递归；
11. 输入输出：`scanf`、`printf`、`cin`、`cout`、格式控制、流同步和文件重定向。

变量和字面量在第一次使用时先给最小解释：字面量跟随对应类型出现，变量从 A+B
Problem 开始使用。常量等到数组需要固定容量时，用 `const int MAXN = ...` 和
常量表达式正式引入；`constexpr` 仍为扩展。标识符、关键字、作用域和名称遮蔽在
已经见过函数和代码块以后整理，不再挤入数值单元。位、字节和类型宽度在整数文章中
只给当前需要的最小解释；完整进制表示、整数与浮点数的机器表示以及通用进制转换，
等读者学过循环、数组、字符、字符串和函数以后，在第 02 章作为首个单元学习。
进制输入输出和浮点格式可以在对应主题第一次出现时展示最小用法，再在输入输出单元
统一复习；这是螺旋式回访。

“表达式”和“运算符”不作为学习路线中的抽象单元。算术与复合赋值跟随数值计算，
比较、逻辑和短路求值跟随条件语句，自增自减跟随循环语句，按位与移位运算进入
第 02 章。数组则不能按同样方式被循环吸收：循环只是遍历数组的前置工具，数组还要
独立解释批量存储、下标、初始化、越界、多维结构和连续布局。

数组能够作为函数实参；普通数组形参会调整为指针，因此不会自动保留第一维长度。
正文不得写成“数组不能作为函数参数传递”。

## 02 C++ 进阶

本章共九个单元。前五个进入连续核心路线，后四个明确为扩展阅读：

1. 进制表示：位、字节、位权、二八十六进制、机器表示、纸笔转换和转换程序；
2. 位运算：按位运算、移位、位掩码，以及与整数宽度、无符号运算和溢出的关系；
3. 指针：地址、取地址、解引用和指针算术；相关 `const` 与多维数组参数作为扩展；
4. 引用：引用和完整参数传递，并比较值传递、指针传递与引用传递；
5. 结构体：成员、排序用途、`sizeof` 和结构体指针；内存对齐为附属扩展；
6. 类（扩展阅读）：成员、独立的封装正文、访问权限、友元、构造析构、函数重载、
   运算符重载、继承与多态；
7. 编译（扩展阅读）：预处理、宏、条件编译、编译与链接；
8. 名称（扩展阅读）：关键字、标识符、名称遮蔽、作用域、命名空间和类型别名；
9. 内存（扩展阅读）：程序内存布局、存储期、对象生命周期、初始化和局部
   `static`。

整数文章第一次使用 `typedef long long ll;` 时给出足够继续阅读的最小说明，名称
单元不构成后续前置。类中的 `static` 成员留在类成员文章，命名空间作用域的
`static` 留在链接文章；内存单元只讨论局部 `static`。

数组不是指针；数组表达式只是在多数语境中转换为首元素指针，数组形参也会调整为
指针。正文仍要明确引用不是指针的种类。“内存模型”
在 C++ 中已有涉及并发、原子操作和内存顺序的特定含义，不用它指代这里的程序内存
布局、存储期和生命周期。

进制表示、位运算、指针、引用和结构体使用核心身份；类、编译、名称和内存使用独立
扩展身份，核心上一篇/下一篇会跳过它们并进入第 03 章。函数重载和运算符重载在
正文层面拆成两篇，不能因为旧文件曾合并而永久共享一个主题。

初始化与存储期的正文必须准确区分：

- 无初始化器的局部内置标量和数组元素不会自动得到零；
- 静态存储期对象会先零初始化；
- 局部对象显式写 `{}` 仍可零初始化；
- `string`、`vector` 等类类型会执行默认构造，默认得到空对象；
- `vector<int>(n)` 创建并值初始化元素，`reserve(n)` 不改变元素数量。

## 03 算法入门

本章先完成进入正式解题以前的三项准备，再学习第一批能够直接解决问题的基础算法：

1. 复杂度：复杂度的基本口径和从代码分析复杂度；
2. 算法设计思想：枚举、模拟、递归与递推、分治、贪心的最小思想地图；
3. 标准库基础：`vector`、`fill`、`pair`、`tuple`、`sort` 和 `unique`，其中
   `array` 是可跳过扩展；
4. 前缀和：前缀和与差分；
5. 排序：冒泡、选择、插入、计数、快速、归并和性质比较；
6. 二分：二分查找、标准库边界接口、答案二分和实数二分；
7. 离散化；
8. 双指针：快速排序的相向扫描、归并排序的同向扫描、两数之和与滑动窗口。

子集、排列、组合和 DFS 枚举仍在学过状态空间与 DFS 以后展开；邻项交换和反悔
策略进入后续贪心单元。链表合并和环形链表快慢指针依赖链表，只从双指针单元提供
后向扩展。`memset` 是 `fill` 的按字节写入辨析，自定义排序是 `sort` 的下属内容，
不另立篇。

## 05 初中进阶

本章暂时保留七个相对独立的单元：

1. 二叉树；
2. 二叉堆；
3. 哈希表；
4. 标准库进阶；
5. 高精度整数；
6. 图搜索的应用；
7. 哈夫曼编码与格雷码。

二叉树和二叉堆相邻但不合并：完全二叉树的数组编号是堆的前置，二者解决的问题
不同。`priority_queue`、有序关联容器和无序关联容器属于标准库进阶；手写二叉堆
和哈希表分别解释它们支持的抽象操作与复杂度。

## 模块目录

模块目录不复制章节结构。C++ 至少拆成程序入门、数值与表示、变量与常量、运算符、
控制流、函数与递归、数组、字符与字符串、输入输出、名称、指针与引用、
复合类型、内存与存储期、标准库基础、标准库进阶、从源码到程序、类等稳定
专题；算法基础至少拆成复杂度、设计思想、前缀和、排序、二分、双指针、贪心、搜索
与枚举等专题。专题通常保持 3–8 篇，超过十篇必须重新检查。
