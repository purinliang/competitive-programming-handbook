## 总体章界

学习路线的前三章重新确定为：

1. `01 C++ 基础`：只包含继续学习算法不可缺少的语言与输入输出能力；
2. `02 C++ 进阶`：核心路线学习进制表示、位运算、指针、引用和结构体；类、编译、
   名称与内存明确作为不阻塞初中竞赛主线的扩展阅读；
3. `03 算法入门`：先介绍复杂度、算法设计思想和马上需要的标准库基础，再完整
   学习前缀和、排序、二分、离散化与双指针等第一批基础算法。

不单设内容含混的“算法进阶”章。枚举、分治、贪心等先在算法设计思想中建立最小
概念；其中快速排序与归并排序在本章的排序单元完整展示分治，其他具体枚举和完整
贪心从第 04 章开始分别展开。DFS 型枚举必须等到读者理解状态空间和深度优先搜索
以后。双指针在本章先以数组和排序过程为主线；依赖链表的双指针应用后向引用。

章节和单元数量不追求表面对称。一个章节可以超过十个单元；不得为了减少数量，
把字符与字符串、输入输出等只有前置关系的独立主题强行合并。学习路线的单元按
教学任务组织，模块目录的专题按知识分类组织，二者不要求同名。

## 主路线的投入产出原则

主学习路线只收录结构简单、思想优美，并且能够解决足够多自然问题的知识。
是否值得优先学习，不只看它在哪份大纲中出现，而要综合比较：

1. 能够解决多少常见且有现实意义的问题；
2. 方法能否从问题结构自然推导，而不是只能背诵模板；
3. 它的状态、不变量和复杂度优势能否迁移到其他题目；
4. 前置知识、实现长度和出错风险是否与收益相称。

一个常用、自然的问题配上一个简洁而可推导的算法，是主路线最理想的教学
节点。题目的限制应该来自问题本身；不为了排除其他方法，刻意叠加一串
细碎条件，再把被迫剩下的奇技淫巧伪装成普遍能力。

下列内容本身可以是正确的知识，但在主路线中优先学习它们，投入产出比很低：

- 替罪羊树等已有更简洁常用替代品的平衡树实现；
- 只服务超大整数的质数判定和质因数分解技巧；
- 针对少数数论函数或特殊询问定制的各种高级筛法；
- 为单一冷门边界情况增加大量模板与前置的专用实现。

这些内容不必从知识库删除，但应留在模块目录或标记为“推迟”。只有当它开始
反复解决真实问题，或成为更高价值知识的必要前置时，才重新评估是否进入主路线。

CCF 2025 年竞赛大纲中的 `[1]`–`[10]` 表示学习难度系数，不是学校年级或原有的
本书章节编号。官方给出的典型范围为：入门级 `1–5`、提高级 `5–8`、NOI 级
`7–10`，边界故意重叠。本书 04–05 对应入门级后半段并在难度 `5` 附近接触提高级，
06–07 覆盖提高级主干，其中 06 以高中组中争取约 150–200 分所需的高收益知识为
筛选尺度，07 再容纳依赖更完整、适用范围更专门的模型。官方难度只用于核对高中
范围和发现漏项，不直接决定后续阶段：第 08 章按区域赛银牌能力组织，第 09 章按
区域赛金牌能力组织；红色争冠内容
不建立第 10 章，只以“推迟”状态保留资料身份。详细规划见
[区域赛专题课程草案](topic-learning-curriculum.md)。

第 06–07 章默认按算法基础、数据结构、数学、图论、动态规划、字符串和计算几何等
较粗模块组成单元，不为一两篇文章制造空泛小节。树、最短路、最小生成树等边界
稳定、内部前置关系连续的算法家族可以独立成单元。并查集在模块目录中仍属于数据
结构，但在学习路线中放进最小生成树单元，作为 Kruskal 的直接前置。

## 第 01 章：C++ 基础

本章按以下顺序组织：

1. 第一个程序；
2. 整数类型；
3. 浮点类型；
4. 布尔类型；
5. 条件语句；
6. 循环语句；
7. 数组；
8. 字符类型；
9. 字符串；
10. 函数；
11. 输入输出。

这十一个单元按写程序时能力自然增长的顺序排列。整数、浮点数、布尔值和字符虽然
都属于基础语言知识，却具有不同的行为和用途，不为了减少单元数量互相收纳。
“条件语句”使用已经学过的布尔值、比较和逻辑运算选择语句；“循环语句”处理重复
执行；数组随后独立解释怎样连续存储、输入、遍历和修改一组元素。字符类型紧邻
字符串，使编码、转义和字符分类自然成为文本处理的前置，而不是字符串的下级标题。

函数必须位于循环语句和字符串之后，使参数文章能够直接使用数组、C 字符串和
`string`。输入输出最后系统整理此前已经见过的最小接口。

指针与引用不与数组合并。数组先通过下标和地址相邻关系解释连续布局，完整指针规则
后移到 C++ 进阶。

### 第一个程序

本单元包含 `Hello World!` 和 `A+B Problem`。

- `Hello World!` 只建立第一份程序的固定结构和输出换行习惯，不提前展开预处理、
  命名空间等完整规则。
- `A+B Problem` 先展示给两个 `int` 预设 `3` 和 `5`，再改成从输入读取；示例输入
  为 `3 5`，输出为 `8` 且末尾换行。
- 本单元解释最小 OJ 提交流程，以及 AC、WA、TLE、MLE、RE 等常见结果；不讲账户
  注册。
- 单元名统一使用“第一个程序”，不使用“第一个竞赛程序”或“前言”。

### 整数类型

本单元围绕整数的保存与计算组织，包括整数类型、算术表达式和复合赋值。

整数从最常用的 `int` 开始，再介绍 `long long` 和其他范围。正文区分 C++ 标准的
最低保证与现代竞赛环境的常见位宽；说明文字使用“32 位整数”“64 位整数”，代码
可以使用 `ll`。有符号溢出是未定义行为，不能依赖常见环境的成环现象。

算术表达式覆盖加、减、乘、除、余数、正负号和括号。必须说明：整数除法向零截断；
`^` 是按位异或，不是乘方；复合赋值仍会发生类型转换、截断和溢出。

### 浮点类型

本单元包含浮点类型、数值类型转换和 `<cmath>` 数学函数。浮点类型先解释“小数
为什么称为浮点数”，再介绍 `float`、`double`、科学计数法、定点形式输出和有效
数字。十进制精度只能给出合理数量级，不能写成所有数都固定精确到 7 位或 15 位。

数值转换比较整数之间、整数与浮点数之间的转换，并指出整数除法完成后再转换已经
无法恢复小数。

数学函数介绍 `sqrt`、`pow`、`floor`、`ceil`、`trunc` 和 `round`。`pow` 主要按
浮点语义工作，可能产生精度损失，不能替代保证精确的整数幂；整数幂先用循环，后面
再学习快速幂。向上取整除法公式必须注明符号范围和溢出前提。

变量和字面量在第一次使用时只给最小解释。各类字面量跟随对应类型出现，不在早期
设置重复的字面量总览；标识符和作用域的系统规则后移。常量等到数组容量第一次
需要固定的编译期值时正式学习。

### 布尔类型

本单元独立建立 `bool`、`false`、`true` 和整数到布尔值的转换。`bool` 通常占一
字节不表示它有 256 个逻辑值；它没有 `unsigned` 版本。`!!x` 只是连续两次逻辑
取反，把条件规范成布尔值，不包装成需要背诵的技巧。

### 条件语句

本单元包含比较运算、逻辑运算与短路求值、条件运算符 `?:`、`if` / `else` 和
`switch`。单元从
“程序需要根据当前情况选择不同语句”这一目标出发，再逐步解释条件怎样形成、怎样
组合，以及两种条件语句怎样使用它们。
- 必须专门解释 `1 <= x <= n` 为什么不能表示数学连锁不等式；正确写法是
  `1 <= x && x <= n`。
- 短路求值可以先检查边界或空值，但也意味着右侧表达式可能不执行，不能无意依赖
  右侧副作用。
- 条件运算符 `condition ? value_if_true : value_if_false` 产生一个表达式结果，
  俗称“三目运算符”；它适合在两个简单值之间选择，不替代多句 `if` / `else`。

- `if` / `else` 解释互斥分支、嵌套和悬空 `else`；`switch` 独立解释 `case`、
  `default` 和贯穿行为，并在这里第一次使用 `break` 阻止继续贯穿。

### 循环语句

本单元依次学习 `while`、`for` 和低频的 `do while`。数组依赖循环完成输入、遍历
和修改，但它具有独立的存储模型、初始化规则和边界问题，因此进入下一单元。

- `while` 处理次数暂时未知的重复过程；`for` 处理初始化、条件和更新明确的计数
  过程。自增、自减在循环语境中解释，普通计数优先把它们单独成句。
- 循环回访已经在 `switch` 中见过的 `break`，再与 `continue` 对比；二者不独立
  成篇。`do while` 只保留“循环体至少执行一次”的低频用途。
- `return` 属于函数，不为了凑齐“改变执行顺序”而塞进本单元。

### 数组

本单元先用数组容量引入常量和常量表达式，再学习一维数组与多维数组：

- 用 `const int MAXN = 1005;` 解释常量不能在初始化后被修改，以及标准 C++ 数组
  长度需要常量表达式。只讲定义固定容量所需的规则；`constexpr` 继续作为扩展。
- 区分常量对象与常量表达式：一个值不能被修改，不自动意味着它能用于所有要求
  编译期值的语境。

- 一维数组解释元素类型、容量、实际长度、下标、遍历、连续存放、初始化和越界。
- 初始化需要比较无初始化器、`{}` 和部分初始化列表；越界同时包括负下标和超过
  右边界。
- 多维数组在读者会写嵌套循环以后解释行列下标、各维容量、行优先连续布局和更高维
  数组。
- 本书自定义对象默认 1-based，C++ 原生数组接口保留 0-based；正文必须明确转换。
- “数组不能作为函数参数传递”是错误说法。数组形参会调整为指针、第一维长度不会
  自动保留等完整规则，放到学过函数和指针后的附属扩展。

### 字符类型

字符也是整数类型，但具有文本输入输出、编码和转义等独立行为。普通 `char` 的
有符号性由实现决定，并要区分 `char`、`signed char` 和 `unsigned char`。转义
字符至少包含空字符 `\0`、换行 `\n` 和制表符 `\t`。

字符分类包含空白、数字、字母、字母数字和大小写转换。数字字符和值的转换与进制
转换互相引用。

### 字符串

本单元的学习任务是表示、输入和处理字符串。C 字符串解释字符数组、末尾 `\0`、
容量与长度和 `<cstring>`；`string` 作为标准库类型保留 0-based 接口，学习常用
下标、拼接、比较、`substr` 和 `find`。

整行输入比较 `getline`、`cin.getline` 和 `fgets`。还要辨析：`%c` 默认不跳过
空白，`%s` 跳过开头空白后在下一个空白处停止，`cin >> ch` 默认跳过空白，
`cin.get` 不跳过。它们在文本语境中首次出现，通用接口随后在输入输出单元整理。

### 函数

函数位于循环语句和字符串之后，依次学习：

1. 定义与调用；
2. 返回值；
3. 形参与实参；
4. 函数原型与先声明后使用；
5. 调用栈；
6. 递归。

函数原型要用两个函数互相调用说明实际用途。参数文章先解释值参数，并使用已经学过
的数组、C 字符串和 `string` 比较接口；指针、引用和完整参数传递规则后移到 C++
进阶。调用栈先解释普通嵌套调用保存的状态，再把递归解释为函数调用自己的特殊情况。

第 03 章中的“递归与问题分解”讨论算法怎样通过较小问题定义当前问题，不重复 C++
函数语法。

### 输入输出

最小的 `cin` / `cout` 从第一份程序开始使用。本单元在已经学习整数、浮点数、字符
和字符串以后，系统整理：

1. `scanf` 与 `printf`；
2. `cin` 与 `cout`；
3. 格式控制；
4. 文件输入输出与重定向。

两套接口按家族分篇。输入覆盖空白处理、失败状态和常见格式说明符；输出覆盖精度、
科学计数、`fixed`、宽度、填充、左右对齐和显式正号。关闭同步以后不能随意混用
两套接口。整行输入与字符、字符串单元交叉引用；进制和浮点格式在这里统一复习，
不重复类型原理。

## 第 02 章：C++ 进阶

本章不作为第 03、04 章的强制前置，按以下顺序组织：

1. 进制表示；
2. 位运算；
3. 指针；
4. 引用；
5. 结构体；
6. `*类`；
7. `*编译`；
8. `*名称`；
9. `*内存`。

### 进制表示

本单元从位、字节和位权开始，依次学习二、八、十六进制、整数与浮点数的机器表示、
纸笔转换和通用转换程序。它不阻塞第 01 章的普通程序，却是随后位运算的直接前置。

`bit`（比特/位）是最小的信息单位；字节是 C++ 中 `sizeof` 和地址递增使用的基本
存储单位。存储单位文章区分 `b` 与 `B`，解释 KB、MB、GB、TB 的常用口径，以及
Mbps 与文件大小中“兆”的歧义。

进制表示从位权解释二进制、八进制、十进制和十六进制，并说明八进制和十六进制
是二进制的紧凑写法。这里学习阅读位串、手算小规模转换和 C++ 的 `0b`、前导 `0`
与 `0x` 字面量；十六进制示例统一使用常见的小写形式。

整数的机器表示通过固定长度的二进制位串解释原码、反码和补码，并推导二补码整数
的范围为什么不对称；不能错误地把二补码解释成“一个符号位加其余普通数值位”。

浮点数的机器表示先区分小数的定点表示与浮点表示，再把 IEEE 754 的符号、指数、
有效数字、隐藏位、正负零、无穷和 NaN 作为附属扩展；这些内容用于解释行为，不要求
任何读者理解和记忆全部编码。`std::fixed` 只是输出格式，不会把 `double` 改成
定点数类型。

最后把纸笔进制转换翻译成程序。实现拆成
“字符转数值”“数值转字符”“任意进制转十进制”“十进制转任意进制”等聚焦函数，
综合使用循环、数组或字符串和函数返回值。基础版本先处理非负整数；负数、任意精度
和小数转换在确有必要时进入扩展，不把它们混入第一份完整实现。

这篇综合练习回访已经见过的二进制机器表示和进制位权，但不重复推导补码、
IEEE 754 或位运算。机器表示回答同一串位怎样被类型解释；转换程序回答怎样把一种
书写方式转成另一种书写方式。

位运算在模块目录中仍属于 C++ 运算符专题。它依赖整数二进制表示，却不会帮助读者
学习早期条件、循环、字符串和函数，因此不阻塞第 01 章。按位运算和移位运算拆成
两篇文章，分别解释 `&`、`|`、`^`、`~` 与 `<<`、`>>`，再学习查询、设置、清除和
翻转某一位以及最小的位掩码应用。正文区分位运算和逻辑运算，强调 `^` 不是乘方，
并说明整数提升、`1LL << k`、移位位数范围、无符号运算按 $2^N$ 取模、有符号
溢出未定义，以及 C++17 中负有符号整数右移由实现决定。

“指针”单元用地址作为必要动机，依次解释取地址、解引用和指针算术。“引用”单元
从“希望直接修改已有对象，又不想在每次使用时解引用”引入，并明确引用不是指针的
种类；随后用参数传递正文回访形参（parameter）与实参（argument），比较值传递、
指针传递和引用传递。

数组不是指针。数组表达式只是在多数语境中发生数组到指针的转换，函数形参中的
`T a[]` 也会调整为 `T* a`。指针正文解释地址、取地址、解引用、指针算术以及
`a[i]` 等价于 `*(a + i)`；`i[a]` 只作为由定义推得的反常合法写法帮助理解，不
鼓励实际使用。多维数组形参、数组指针和高维声明进入数组的附属扩展，不能把
`T[M][N]` 错误地当作 `T**`。

“结构体”先解决把多项相关数据组成一个类型以及参与排序的问题，再学习成员、点
运算符、`sizeof`、结构体指针和箭头运算符。内存对齐是附属扩展。联合体和枚举不是
结构体的下级知识，因此不进入结构体单元；它们在本章末尾组成独立扩展单元，分别
成篇。

“类”是扩展阅读，只使用这个单元名，不再写“类与对象”。正文依次解释类、成员、
封装、访问权限、友元、构造与析构、函数重载、运算符重载、继承和多态。`struct`
与 `class` 的默认访问权限区别在这里准确说明。

“编译”同样是扩展阅读，按预处理、`#include`、`#define`、条件编译、编译和链接
拆篇。宏定义需要说明 `#undef`；条件编译指令属于独立主题。命名空间作用域中的
`static` 控制内部链接，在链接文章中解释，不与局部 `static` 或类的静态成员混写。

“名称”作为章末扩展阅读，整理关键字、标识符、作用域、名称遮蔽、命名空间以及
`typedef` / `using`。整数文章第一次写 `typedef long long ll;` 时，只说明它为
`long long` 引入短别名；早期程序中的 `using namespace std;` 继续先作为固定结构，
不把整套命名规则变成隐藏前置。

“内存”整理竞赛程序的内存布局、存储期、对象生命周期以及全局、局部和 `static`
对象的初始化规则。“内存模型”在 C++ 中已有涉及并发、原子操作和内存顺序的特定
含义，本书不使用它指代这些基础内容。必须准确区分：无初始化器的局部内置标量和
数组元素不会自动得到零；静态存储期对象先零初始化；显式 `{}` 可以零初始化；
`string` 和 `vector` 会执行默认构造得到空对象；`vector<int>(n)` 创建并值初始化
元素，`reserve(n)` 只改变容量。

`static` 局部变量的名称仍是块作用域，对象具有静态存储期，不能称为“局部作用域
的全局变量”。指针在常见 32/64 位环境中通常占 4/8 字节，但指针宽度、地址空间、
整数位宽和机器字长不是同一概念。`volatile` 只进入模块目录扩展，不能当线程同步
工具。类中的 `static` 成员属于类而非单个对象，在类成员文章中解释；这里只讨论
局部 `static` 的存储期与初始化。

类单元中的“封装”必须拥有独立正文，不能只藏在类的概述或访问权限文章中。函数
重载与运算符重载分篇；虚表只作为主流实现模型，不写成标准规定的固定布局。

## 第 03 章：算法入门

本章包含九个单元：复杂度、算法设计思想、标准库基础、线性表、前缀和、排序、
二分与倍增、离散化和双指针。前三个单元建立共同语言；线性表补齐后续算法依赖的
存储模型；最后五个单元第一次完整学习能够直接解决一类问题的基础算法。

### 复杂度

先学习输入规模、时间/空间复杂度、大 $O$、最坏情况和常见数量级，再学习从代码
分析复杂度：`i++`、`i *= 2`、`n /= 2`，顺序代码、嵌套循环、依赖边界的循环，
以及多个单调下标的总移动次数。`n >>= 1` 等价形式等到位运算以后再回访，不能让
可跳过的第 02 章成为算法入门的隐藏前置。

小 $o$、$\Omega$、$\Theta$ 等渐近记号进入配套扩展；均摊复杂度与势能法在高中
阶段组成第二个复杂度单元。

### 算法设计思想

本单元只建立方法地图：

- 枚举遍历候选；
- 模拟复现规则；
- 贪心只保留能够证明安全的当前选择；
- 递推按已知结果得到后续结果；
- 递归用较小问题定义当前问题；
- 分治拆分相对独立的子问题并合并；
- 动态规划保存重复子问题并按阶段复用。

这里只保留直接循环枚举和极小示例。子集、排列、组合和 DFS 枚举等到状态空间与
深度优先搜索；快速排序和归并排序具体展示分治；邻项交换和反悔策略进入后续贪心
单元。

### 标准库基础

本单元包含 `vector`、`fill`、`pair`、`tuple`、`min`、`max`、`swap`、`sort`
和 `unique`。`min` 与 `max` 共享“比较并返回较小/较大值”的主题；`swap` 的作用是
交换两个对象，独立成一篇很短的文章，不为贴合考纲的一行清单而混写。

`vector` 要辨析 `assign`、`resize`、`reserve` 和 `reverse`，并说明迭代器、引用
和指针在扩容或修改时可能失效。`fill` 只覆盖已有范围；`memset` 不是 STL，只作为
按字节写入的陷阱说明。自定义排序是 `sort` 的下级内容，包括逆序、多关键字、比较
函数和严格弱序；优先利用 `pair`、`tuple`、`array` 的字典序。`unique` 只处理相邻
重复元素，通常配合排序和 `erase`。

### 线性表

本单元比较连续存储与链接存储，依次学习数组、`array`、链表的基本概念、单向链表、
双向链表、循环链表和 `list`。这里回访 `vector`：它是动态连续数组，不是数组与
链表之间的混合结构；`list` 才是标准库双向链表。

### 前缀和

本单元先学习前缀和，再把差分解释为前缀和的逆过程。

- 前缀和从原数组累计出前缀数组，用两个前缀的差回答静态闭区间和；必须解释
  `prefix[0] = 0` 的边界语义、预处理复杂度和查询复杂度。
- 差分保存相邻元素的变化，在区间两端记录增量，再通过一次前缀和恢复最终数组；
  必须说明它适用于先完成一批修改、最后统一恢复的离线场景。
- 本书自定义数组继续使用 1-based 和闭区间。修改与查询在线交错时，应转向后面的
  树状数组或线段树，而不是继续套用普通前缀和或差分。

二维前缀和与二维差分作为本单元的附属扩展，不阻塞后面的核心路线。

### 排序

本单元依次学习冒泡排序、选择排序、插入排序、计数排序、快速排序与归并排序。

- 前三种排序通过明确的不变量解释 $O(n^2)$ 过程；计数排序说明它依赖较小的整数
  值域，不能与一般意义的桶排序完全混称。
- 快速排序完整展示划分过程；归并排序完整展示合并两个有序区间的过程。二者都是
  算法设计思想中“分治”的正式回访，也是双指针单元的重要前置例子。
- 排序性质对比必须列出最好、平均、最坏复杂度、额外空间和稳定性。选择排序、快速
  排序和堆排序通常不稳定；不能只背结论而不说明“相等元素相对顺序”的含义。
- 堆排序和基数排序作为扩展正文；希尔排序只登记名称和定位，不进入主学习路线。

`sort` 与自定义比较已经在标准库基础中出现；本单元关注排序算法如何形成，而不是
重复 API 清单。

### 二分与倍增

本单元包含二分查找、答案二分、浮点数二分和倍增。

- 二分查找在有序数组中学习手写闭区间模板，并对照 `binary_search`、
  `lower_bound` 和 `upper_bound` 的 0-based、左闭右开接口。
- 必须逐步解释循环不变量、答案所在区间、中点取整、边界更新和终止条件。右移常被
  用于非负整数的向下取整，整数除法则一般向零截断；两者不能在负数场景中无条件
  互换。
- 答案二分从“判定条件随答案单调变化”引入，不把它说成普通查找换了名字。
- 整数二分和实数二分分开说明；中点写法要检查溢出，复杂表达式不依赖容易误读的
  移位优先级。
- 倍增预处理或尝试 $1,2,4,\ldots$ 这些二的幂次步长，再用二进制分解组合所需
  步数。它与二分都利用二的幂，但不是“反过来的二分”，因此相邻学习、分别成篇。

### 离散化

离散化独立成单元，完整组合排序、去重和二分定位：只保留大小关系或相等关系，
把稀疏的大值映射到连续的小整数范围。必须区分“值的排名”“去重后的下标”和
“原位置”，并解释何时需要反向映射。它依赖已经学过的 `sort`、`unique` 与二分，
不提前塞入排序文章的 API 教学部分。

### 双指针

双指针先从数组和排序过程建立统一定义：两个下标按可证明的单调方向移动，每次移动
能够排除一批以后不必再次考虑的状态；代码里恰好出现两个下标并不自动构成双指针。

- 回访快速排序的相向扫描，说明左右指针怎样寻找划分位置；
- 回访归并排序的同向扫描，说明两个有序区间的指针为什么都只会前进；
- 再学习有序数组两数之和与滑动窗口，分别建立相向双指针和同向双指针的常用模型；
- 通过总移动次数证明线性复杂度，不能看到嵌套循环就机械判断为平方复杂度。

链表相关应用不作为本章前置：合并有序链表，以及在环形链表中使用快慢指针检测环，
放在学习链表以后作为本单元的扩展阅读，并从这里提供后向引用。

## 第 04 章：初中基础

本章先学习栈与队列，再保留一个独立的贪心单元。贪心不提前塞回第 03 章：
第 03 章的“贪心选择与正确性证明”负责建立最小框架，第 04 章再分别学习邻项交换
证明和反悔贪心。两种策略各自拥有完整模型、证明和实现，不合并成一篇总览。

图论部分先完成“图论：图”，依次学习点、边、路径、环、度数、图的存储、显式图
上的 DFS 与 BFS，以及连通分量。图的存储在基础概念后分别学习邻接矩阵和
`vector` 邻接表：前者用 $O(n^2)$ 空间换取 $O(1)$ 判边，后者作为普通稀疏图的
主线实现。DFS 和 BFS 都是图的两种基础遍历方式，不再分别占用只有一两篇文章的
单元。无向图的极大连通子图正式称为“连通分量”；“连通块”只作为竞赛口语别名
在首次定义时注明。breadth-first search 统一译为“广度优先搜索”，不在标题中
交替使用“宽度优先搜索”。

连通分量以后学习泛洪算法（Flood Fill）：它是在网格等空间中找出并处理一个连通
区域的问题模型，可以用 DFS 或 BFS 实现，不是第三种遍历方式。普通 BFS 之后再
学习多源 BFS：
把所有起点同时以距离 `0` 入队，不改变按距离分层扩展的核心不变量。二分图判定也
留在同一单元，作为 DFS 或 BFS 遍历每个连通分量并进行二染色的应用。

随后学习“图论：树”，再进入“算法基础：枚举”。枚举单元以完整且不重复地生成
候选为目标，包含状态空间与隐式图、子集与位掩码枚举、排列枚举、组合枚举，以及
DFS、回溯与剪枝。子集可以用位掩码遍历，也可以用逐项选择或不选择的 DFS；它留在
枚举单元，不为了把整个单元强行解释成“DFS 单元”而迁移。排列与组合集中展示 DFS
枚举，最后用回溯和剪枝收束搜索状态的维护。

“算法基础：贪心”紧随枚举，使本章两个算法基础单元相邻。它继续展开第 03 章建立
的贪心框架，但邻项交换证明和反悔贪心仍各自成篇，不合并成一篇笼统的贪心文章。

本章的字符串单元先用“字符串的基本概念”统一长度、空串、前缀、后缀、子串、
真子串、非空真子串、子序列和回文，再学习字符串比较与字典序，最后学习朴素模式
匹配。概念文章必须明确连续子串与只保持相对顺序的子序列之间的区别，也要说明
“真”只排除整个字符串，而“非空真子串”还同时排除空串。

本章末尾增加可跳过的“数学基础回顾”，只复习竞赛题面会直接使用的数系、集合、
方程与不等式、平面几何基础，不重写完整的初中数学课程。几何部分只解释点、线段、
角、三角形各元素与常见分类，常见图形的周长和面积、勾股定理，以及圆心、半径、
直径、圆周长和圆面积；不引入坐标、向量或直线方程等解析几何内容。

## 第 05 章：初中进阶

二叉树单元必须拆开三个容易混淆的层次：

1. “二叉树的基本概念”定义左、右位置，并区分完整二叉树、完全二叉树和完美
   二叉树；“满二叉树”存在术语歧义，正文不把它当作无需解释的正式名称使用；
2. “二叉树的存储”只讨论普通二叉树怎样显式保存左、右孩子。普通有根树的孩子
   列表不能表达只有一个孩子时它究竟位于左侧还是右侧，除非额外记录孩子位置；
3. “完全二叉树”单独推导层序编号、连续数组存储、父子下标公式和存在性判断，
   并为后续二叉堆建立直接前置；
4. 完成以上三篇以后，再学习二叉树的前序、中序和后序遍历。
5. 最后用“二叉搜索树的概念与构造”说明左、右子树的键值顺序，以及按输入顺序逐个
   插入怎样形成树；不同插入顺序可能产生不同形状，查找、删除和平衡不在本篇展开。

二叉堆单元依次学习二叉堆、标准库 `priority_queue` 和哈夫曼编码；哈夫曼编码用小根
堆反复取出两个最小权值，是二叉堆的直接应用。堆排序保留为本单元扩展。原“编码”
单元取消：格雷码作为递归反射构造与递推生成的附属扩展，移动到第 03 章“算法设计
思想”；哈夫曼编码不再与它仅因“编码”二字并列。

哈希表以前新增“哈希”，先解释哈希函数、输出范围、冲突与分布，再用简单整数映射
观察冲突概率和常见构造思路。下一篇“哈希表”才讨论拉链法、开放寻址和负载因子。
字符串哈希依赖字符串结构，继续归入字符串专题，不混入这里。

标准库进阶按 `set`、`map`、`multiset`、`multimap`、`unordered_set`、
`unordered_map` 排列：先学习最常用的唯一键容器，再学习允许重复键的变体，最后
学习建立在哈希表上的无序容器。

区间 DP 从高中基础前移到本章，作为普通动态规划之后的第一个区间模型。正文始终
使用“阶段、状态、决策”解释：区间长度 `len` 是阶段，`[l,r]` 是状态，分割点或
最后一次操作是决策。实现保存 `f[l][r]`，但仍按 `len` 从短到长枚举，不能把两个
数组下标机械地解释成阶段和状态。

高精度整数主线先使用“一格保存一位十进制数字”的表示，依次推导非负整数的比较、
加法、减法、乘法以及高精度整数除以低精度整数。除法模拟竖式从高位到低位生成商，
商仍可能是高精度整数，余数一定可以用低精度整数保存。

符号处理先用一格一位的版本解释绝对值比较、运算分派、低精度除法符号和负零
归一化。“压位高精度整数”作为初中级附属扩展，不再提供只支持非负数的过渡模板；
正文直接给出九位压位、三态符号、有符号比较、加减乘和除以低精度整数的完整日用
版本。压位篇不重新讲解竖式原理，而是严格根据数字块类型、中间变量类型与进位时机
推导安全位宽。乘法若每加入一个块乘积就立即进位，中间值上界与操作数总块数无关；
若先累加同一结果块的全部乘积再统一进位，上界还会乘上参与累加的块数，不能沿用
同一个 `BASE`。

高精度整数除以高精度整数和快速乘法属于高中级扩展，全部带有负号语义，但正文
重点是算法原理与经过验证的完整模板，不要求进入学习路线。高精度除法从十进制
竖式试商开始，再解释压位、规范化、最高块估商与修正；快速乘法从系数卷积开始，
比较 FFT 的舍入误差和 NTT 的模数回绕。仓库的完整快速模板优先使用多模数 NTT
与 CRT，在共同变换长度和模数乘积范围内精确恢复卷积，不以 `double` 的有效位数
代替误差证明。

组合数学在本章依次学习加法原理、乘法原理、排列数、组合数与二项式系数、二项式
定理和杨辉三角。组合数与二项式系数是同一个对象；杨辉三角从递推式推导，并作为
二维动态规划的直接例子。依赖模逆元的阶乘预处理继续留在高中基础。

ASCII 不独立成篇：字符类型正文负责解释字符与整数编码、常用 ASCII 范围和字符
转换，字符串正文再应用这些知识。完整码表只适合查阅，不要求记忆。

“编译”扩展必须先区分编译器与解释器：前者先把源程序翻译成目标程序或可执行程序，
后者在运行时读取并执行程序；实际语言实现可以混合两种策略，不能把差异写成所有
实现都必须遵守的二分法。“调试与调试器”说明编译错误、运行时错误和逻辑错误，并
介绍断点、单步执行、查看变量与调用栈；它与“编译”相邻，但不把调试误写成编译阶段。

“数学函数”完整覆盖官方入门清单：绝对值、四舍五入、向下取整、向上取整、平方根、
常用三角函数、对数函数与指数函数。正文同时保留竞赛常用的 `pow`、`trunc`、
`atan2`、`log2` 与 `log10`，强调三角函数使用弧度以及各函数定义域。

### 数学：数论基础

初中数论基础依次包含：

1. 整除、因数与倍数；
2. 质数与合数；
3. 试除法质数检测；
4. 算术基本定理；
5. 质因数分解；
6. 埃拉托斯特尼筛法；
7. 最大公约数、最小公倍数与欧几里得算法；
8. 普通快速幂。

首次使用时写“因数（也称约数）”，以后统一使用因数。质数概念和试除算法拆篇。
试除法必须比较从 2 到 `n - 1` 的 $O(n)$ 写法和只到平方根的 $O(\sqrt n)$ 写法，
并讨论 `i * i <= n`、`i <= n / i`、跳过偶数等变体。质因数分解比较相应循环变体，
解释反复相除、指数记录和最后剩余质因数。

埃氏筛在本阶段只负责筛出质数列表或质数个数，并使用 1 到 100 的例子。判断 100
以内的数时，只需检查 2、3、5、7，是因为任何不超过 100 的合数都有一个不超过
$\sqrt{100}=10$ 的质因数，而不超过 10 的质数只有这四个；这不表示合数只含这些
因数。

普通快速幂只依赖指数的二进制分解，可以放在初中数论基础末尾。费马小定理依赖
同余和质数模，与模逆元、组合数预处理连续放入高中进阶。

## 高中阶段的数论与矩阵

高中基础按专题组织，不使用含混的“数论进阶”大箱子。

### 数学：模运算与同余

学习模运算、负余数规范化、同余和模快速幂。费马小定理留给高中进阶的质数模
应用链。

### 高中进阶：扩展欧几里得家族

扩展欧几里得算法、二元线性不定方程、线性同余方程和模逆元连续学习。算法首先
说明能解决的典型问题，再推导裴蜀系数；实现优先用清晰返回值，不使用无必要的输出
引用参数。中国剩余定理及其扩展在该家族以后继续学习。

### 数学：欧拉筛与因数函数

欧拉筛移入高中进阶，解释每个合数由最小质因数唯一生成。正因数个数与正因数和
仍留高中基础：它们只使用质因数指数公式和乘法原理，不与筛法合篇。初中埃氏筛
不提前扩展成任意数论函数筛。

### 数学：矩阵与线性递推

依次学习矩阵表示、矩阵加减、矩阵乘法、矩阵快速幂和矩阵快速幂解线性递推。
矩阵快速幂算法与线性递推应用拆篇；线性变换不混入这一核心单元。
