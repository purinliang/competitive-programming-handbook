# 课程结构

> 更新日期：2026-08-16
>
> 本文是课程结构的唯一权威规划。它保留已经确认的教学关系和内容要求，但消除
> 讨论过程中的试探、重复与口语表达。逐篇迁移方式见
> [课程结构整改执行计划](curriculum-remediation.md)。

## 总体章界

学习路线的前三章重新确定为：

1. `01 C++ 基础`：只包含继续学习算法不可缺少的语言与输入输出能力；
2. `02 C++ 进阶`：核心路线学习进制表示、位运算、指针、引用和结构体；类、编译、
   名称与内存明确作为不阻塞初中竞赛主线的扩展阅读；
3. `03 算法入门`：只介绍复杂度、算法设计思想和马上需要的标准库基础，为后续
   正式学习算法建立共同语言与编码工具。

不单设内容含混的“算法进阶”章。枚举、分治、贪心等先在算法设计思想中建立最小
概念；前缀和、排序、二分、离散化、线性表、双指针和完整贪心从第 04 章开始按
前向依赖展开。快速排序与归并排序在那里正式展示分治；DFS 型枚举必须等到读者
理解状态空间和深度优先搜索以后；依赖链表的双指针应用必须位于链表之后。

章节和单元数量不追求表面对称。一个章节可以超过十个单元；不得为了减少数量，
把字符与字符串、输入输出等只有前置关系的独立主题强行合并。学习路线的单元按
教学任务组织，模块目录的专题按知识分类组织，二者不要求同名。

## 第 01 章：C++ 基础

本章按以下顺序组织：

1. 第一个程序；
2. 整数类型；
3. 浮点类型；
4. 布尔类型；
5. 条件语句；
6. 循环语句；
7. 数组；
8. 字符类型；
9. 字符串；
10. 函数；
11. 输入输出。

这十一个单元按写程序时能力自然增长的顺序排列。整数、浮点数、布尔值和字符虽然
都属于基础语言知识，却具有不同的行为和用途，不为了减少单元数量互相收纳。
“条件语句”使用已经学过的布尔值、比较和逻辑运算选择语句；“循环语句”处理重复
执行；数组随后独立解释怎样连续存储、输入、遍历和修改一组元素。字符类型紧邻
字符串，使编码、转义和字符分类自然成为文本处理的前置，而不是字符串的下级标题。

函数必须位于循环语句和字符串之后，使参数文章能够直接使用数组、C 字符串和
`string`。输入输出最后系统整理此前已经见过的最小接口。

指针与引用不与数组合并。数组先通过下标和地址相邻关系解释连续布局，完整指针规则
后移到 C++ 进阶。

### 第一个程序

本单元包含 `Hello World!` 和 `A+B Problem`。

- `Hello World!` 只建立第一份程序的固定结构和输出换行习惯，不提前展开预处理、
  命名空间等完整规则。
- `A+B Problem` 先展示给两个 `int` 预设 `3` 和 `5`，再改成从输入读取；示例输入
  为 `3 5`，输出为 `8` 且末尾换行。
- 本单元解释最小 OJ 提交流程，以及 AC、WA、TLE、MLE、RE 等常见结果；不讲账户
  注册。
- 单元名统一使用“第一个程序”，不使用“第一个竞赛程序”或“前言”。

### 整数类型

本单元围绕整数的保存与计算组织，包括整数类型、算术表达式和复合赋值。

整数从最常用的 `int` 开始，再介绍 `long long` 和其他范围。正文区分 C++ 标准的
最低保证与现代竞赛环境的常见位宽；说明文字使用“32 位整数”“64 位整数”，代码
可以使用 `ll`。有符号溢出是未定义行为，不能依赖常见环境的成环现象。

算术表达式覆盖加、减、乘、除、余数、正负号和括号。必须说明：整数除法向零截断；
`^` 是按位异或，不是乘方；复合赋值仍会发生类型转换、截断和溢出。

### 浮点类型

本单元包含浮点类型、数值类型转换和 `<cmath>` 数学函数。浮点类型先解释“小数
为什么称为浮点数”，再介绍 `float`、`double`、科学计数法、定点形式输出和有效
数字。十进制精度只能给出合理数量级，不能写成所有数都固定精确到 7 位或 15 位。

数值转换比较整数之间、整数与浮点数之间的转换，并指出整数除法完成后再转换已经
无法恢复小数。

数学函数介绍 `sqrt`、`pow`、`floor`、`ceil`、`trunc` 和 `round`。`pow` 主要按
浮点语义工作，可能产生精度损失，不能替代保证精确的整数幂；整数幂先用循环，后面
再学习快速幂。向上取整除法公式必须注明符号范围和溢出前提。

变量和字面量在第一次使用时只给最小解释。各类字面量跟随对应类型出现，不在早期
设置重复的字面量总览；标识符和作用域的系统规则后移。常量等到数组容量第一次
需要固定的编译期值时正式学习。

### 布尔类型

本单元独立建立 `bool`、`false`、`true` 和整数到布尔值的转换。`bool` 通常占一
字节不表示它有 256 个逻辑值；它没有 `unsigned` 版本。`!!x` 只是连续两次逻辑
取反，把条件规范成布尔值，不包装成需要背诵的技巧。

### 条件语句

本单元包含比较运算、逻辑运算与短路求值、`if` / `else` 和 `switch`。单元从
“程序需要根据当前情况选择不同语句”这一目标出发，再逐步解释条件怎样形成、怎样
组合，以及两种条件语句怎样使用它们。
- 必须专门解释 `1 <= x <= n` 为什么不能表示数学连锁不等式；正确写法是
  `1 <= x && x <= n`。
- 短路求值可以先检查边界或空值，但也意味着右侧表达式可能不执行，不能无意依赖
  右侧副作用。

- `if` / `else` 解释互斥分支、嵌套和悬空 `else`；`switch` 独立解释 `case`、
  `default` 和贯穿行为，并在这里第一次使用 `break` 阻止继续贯穿。

### 循环语句

本单元依次学习 `while`、`for` 和低频的 `do while`。数组依赖循环完成输入、遍历
和修改，但它具有独立的存储模型、初始化规则和边界问题，因此进入下一单元。

- `while` 处理次数暂时未知的重复过程；`for` 处理初始化、条件和更新明确的计数
  过程。自增、自减在循环语境中解释，普通计数优先把它们单独成句。
- 循环回访已经在 `switch` 中见过的 `break`，再与 `continue` 对比；二者不独立
  成篇。`do while` 只保留“循环体至少执行一次”的低频用途。
- `return` 属于函数，不为了凑齐“改变执行顺序”而塞进本单元。

### 数组

本单元先用数组容量引入常量和常量表达式，再学习一维数组与多维数组：

- 用 `const int MAXN = 1005;` 解释常量不能在初始化后被修改，以及标准 C++ 数组
  长度需要常量表达式。只讲定义固定容量所需的规则；`constexpr` 继续作为扩展。
- 区分常量对象与常量表达式：一个值不能被修改，不自动意味着它能用于所有要求
  编译期值的语境。

- 一维数组解释元素类型、容量、实际长度、下标、遍历、连续存放、初始化和越界。
- 初始化需要比较无初始化器、`{}` 和部分初始化列表；越界同时包括负下标和超过
  右边界。
- 多维数组在读者会写嵌套循环以后解释行列下标、各维容量、行优先连续布局和更高维
  数组。
- 本书自定义对象默认 1-based，C++ 原生数组接口保留 0-based；正文必须明确转换。
- “数组不能作为函数参数传递”是错误说法。数组形参会调整为指针、第一维长度不会
  自动保留等完整规则，放到学过函数和指针后的附属扩展。

### 字符类型

字符也是整数类型，但具有文本输入输出、编码和转义等独立行为。普通 `char` 的
有符号性由实现决定，并要区分 `char`、`signed char` 和 `unsigned char`。转义
字符至少包含空字符 `\0`、换行 `\n` 和制表符 `\t`。

字符分类包含空白、数字、字母、字母数字和大小写转换。数字字符和值的转换与进制
转换互相引用。

### 字符串

本单元的学习任务是表示、输入和处理字符串。C 字符串解释字符数组、末尾 `\0`、
容量与长度和 `<cstring>`；`string` 作为标准库类型保留 0-based 接口，学习常用
下标、拼接、比较、`substr` 和 `find`。

整行输入比较 `getline`、`cin.getline` 和 `fgets`。还要辨析：`%c` 默认不跳过
空白，`%s` 跳过开头空白后在下一个空白处停止，`cin >> ch` 默认跳过空白，
`cin.get` 不跳过。它们在文本语境中首次出现，通用接口随后在输入输出单元整理。

### 函数

函数位于循环语句和字符串之后，依次学习：

1. 定义与调用；
2. 返回值；
3. 形参与实参；
4. 函数原型与先声明后使用；
5. 调用栈；
6. 递归。

函数原型要用两个函数互相调用说明实际用途。参数文章先解释值参数，并使用已经学过
的数组、C 字符串和 `string` 比较接口；指针、引用和完整参数传递规则后移到 C++
进阶。调用栈先解释普通嵌套调用保存的状态，再把递归解释为函数调用自己的特殊情况。

第 03 章中的“递归与问题分解”讨论算法怎样通过较小问题定义当前问题，不重复 C++
函数语法。

### 输入输出

最小的 `cin` / `cout` 从第一份程序开始使用。本单元在已经学习整数、浮点数、字符
和字符串以后，系统整理：

1. `scanf` 与 `printf`；
2. `cin` 与 `cout`；
3. 格式控制；
4. 文件输入输出与重定向。

两套接口按家族分篇。输入覆盖空白处理、失败状态和常见格式说明符；输出覆盖精度、
科学计数、`fixed`、宽度、填充、左右对齐和显式正号。关闭同步以后不能随意混用
两套接口。整行输入与字符、字符串单元交叉引用；进制和浮点格式在这里统一复习，
不重复类型原理。

## 第 02 章：C++ 进阶

本章不作为第 03、04 章的强制前置，按以下顺序组织：

1. 进制表示；
2. 位运算；
3. 指针；
4. 引用；
5. 结构体；
6. `*类`；
7. `*编译`；
8. `*名称`；
9. `*内存`。

### 进制表示

本单元从位、字节和位权开始，依次学习二、八、十六进制、整数与浮点数的机器表示、
纸笔转换和通用转换程序。它不阻塞第 01 章的普通程序，却是随后位运算的直接前置。

`bit`（比特/位）是最小的信息单位；字节是 C++ 中 `sizeof` 和地址递增使用的基本
存储单位。存储单位文章区分 `b` 与 `B`，解释 KB、MB、GB、TB 的常用口径，以及
Mbps 与文件大小中“兆”的歧义。

进制表示从位权解释二进制、八进制、十进制和十六进制，并说明八进制和十六进制
是二进制的紧凑写法。这里学习阅读位串、手算小规模转换和 C++ 的 `0b`、前导 `0`
与 `0x` 字面量；十六进制示例统一使用常见的小写形式。

整数的机器表示通过固定长度的二进制位串解释原码、反码和补码，并推导二补码整数
的范围为什么不对称；不能错误地把二补码解释成“一个符号位加其余普通数值位”。

浮点数的机器表示先区分小数的定点表示与浮点表示，再把 IEEE 754 的符号、指数、
有效数字、隐藏位、正负零、无穷和 NaN 作为附属扩展；这些内容用于解释行为，不要求
任何读者理解和记忆全部编码。`std::fixed` 只是输出格式，不会把 `double` 改成
定点数类型。

最后把纸笔进制转换翻译成程序。实现拆成
“字符转数值”“数值转字符”“任意进制转十进制”“十进制转任意进制”等聚焦函数，
综合使用循环、数组或字符串和函数返回值。基础版本先处理非负整数；负数、任意精度
和小数转换在确有必要时进入扩展，不把它们混入第一份完整实现。

这篇综合练习回访已经见过的二进制机器表示和进制位权，但不重复推导补码、
IEEE 754 或位运算。机器表示回答同一串位怎样被类型解释；转换程序回答怎样把一种
书写方式转成另一种书写方式。

位运算在模块目录中仍属于 C++ 运算符专题。它依赖整数二进制表示，却不会帮助读者
学习早期条件、循环、字符串和函数，因此不阻塞第 01 章。按位运算和移位运算拆成
两篇文章，分别解释 `&`、`|`、`^`、`~` 与 `<<`、`>>`，再学习查询、设置、清除和
翻转某一位以及最小的位掩码应用。正文区分位运算和逻辑运算，强调 `^` 不是乘方，
并说明整数提升、`1LL << k`、移位位数范围、无符号运算按 $2^N$ 取模、有符号
溢出未定义，以及 C++17 中负有符号整数右移由实现决定。

“指针”单元用地址作为必要动机，依次解释取地址、解引用和指针算术。“引用”单元
从“希望直接修改已有对象，又不想在每次使用时解引用”引入，并明确引用不是指针的
种类；随后用参数传递正文回访形参（parameter）与实参（argument），比较值传递、
指针传递和引用传递。

数组不是指针。数组表达式只是在多数语境中发生数组到指针的转换，函数形参中的
`T a[]` 也会调整为 `T* a`。指针正文解释地址、取地址、解引用、指针算术以及
`a[i]` 等价于 `*(a + i)`；`i[a]` 只作为由定义推得的反常合法写法帮助理解，不
鼓励实际使用。多维数组形参、数组指针和高维声明进入数组的附属扩展，不能把
`T[M][N]` 错误地当作 `T**`。

“结构体”先解决把多项相关数据组成一个类型以及参与排序的问题，再学习成员、点
运算符、`sizeof`、结构体指针和箭头运算符。内存对齐是附属扩展。联合体和枚举不是
结构体的下级知识，因此不进入结构体单元。

“类”是扩展阅读，只使用这个单元名，不再写“类与对象”。正文依次解释类、成员、
封装、访问权限、友元、构造与析构、函数重载、运算符重载、继承和多态。`struct`
与 `class` 的默认访问权限区别在这里准确说明。

“编译”同样是扩展阅读，按预处理、`#include`、`#define`、条件编译、编译和链接
拆篇。宏定义需要说明 `#undef`；条件编译指令属于独立主题。命名空间作用域中的
`static` 控制内部链接，在链接文章中解释，不与局部 `static` 或类的静态成员混写。

“名称”作为章末扩展阅读，整理关键字、标识符、作用域、名称遮蔽、命名空间以及
`typedef` / `using`。整数文章第一次写 `typedef long long ll;` 时，只说明它为
`long long` 引入短别名；早期程序中的 `using namespace std;` 继续先作为固定结构，
不把整套命名规则变成隐藏前置。

“内存”整理竞赛程序的内存布局、存储期、对象生命周期以及全局、局部和 `static`
对象的初始化规则。“内存模型”在 C++ 中已有涉及并发、原子操作和内存顺序的特定
含义，本书不使用它指代这些基础内容。必须准确区分：无初始化器的局部内置标量和
数组元素不会自动得到零；静态存储期对象先零初始化；显式 `{}` 可以零初始化；
`string` 和 `vector` 会执行默认构造得到空对象；`vector<int>(n)` 创建并值初始化
元素，`reserve(n)` 只改变容量。

`static` 局部变量的名称仍是块作用域，对象具有静态存储期，不能称为“局部作用域
的全局变量”。指针在常见 32/64 位环境中通常占 4/8 字节，但指针宽度、地址空间、
整数位宽和机器字长不是同一概念。`volatile` 只进入模块目录扩展，不能当线程同步
工具。类中的 `static` 成员属于类而非单个对象，在类成员文章中解释；这里只讨论
局部 `static` 的存储期与初始化。

类单元中的“封装”必须拥有独立正文，不能只藏在类的概述或访问权限文章中。函数
重载与运算符重载分篇；虚表只作为主流实现模型，不写成标准规定的固定布局。

## 第 03 章：算法入门

本章只有三个单元：复杂度、算法设计思想和标准库基础。它们分别回答“怎样判断一份
方法能否在限制内运行”“常见算法从什么角度构造”和“后续代码依赖哪些最低限度的
标准库工具”。本章只建立共同语言，不把具体算法的完整学习过程塞进概念总览。

### 复杂度

先学习输入规模、时间/空间复杂度、大 $O$、最坏情况和常见数量级，再学习从代码
分析复杂度：`i++`、`i *= 2`、`n /= 2`，顺序代码、嵌套循环、依赖边界的循环，
以及多个单调下标的总移动次数。`n >>= 1` 等价形式等到位运算以后再回访，不能让
可跳过的第 02 章成为算法入门的隐藏前置。

小 $o$、$\Omega$、$\Theta$ 等渐近记号进入配套扩展；均摊复杂度与势能法在高中
阶段组成第二个复杂度单元。

### 算法设计思想

本单元只建立方法地图：

- 枚举遍历候选；
- 模拟复现规则；
- 递推按已知结果得到后续结果；
- 递归用较小问题定义当前问题；
- 分治拆分相对独立的子问题并合并；
- 贪心只保留能够证明安全的当前选择；
- 动态规划保存重复子问题并按阶段复用。

这里只保留直接循环枚举和极小示例。子集、排列、组合和 DFS 枚举等到状态空间与
深度优先搜索；快速排序和归并排序具体展示分治；邻项交换和反悔策略进入后续贪心
单元。

### 标准库基础

本单元包含 `vector`、`fill`、`pair`、`tuple`、`sort` 和 `unique`；`array` 是
同层扩展。

`vector` 要辨析 `assign`、`resize`、`reserve` 和 `reverse`，并说明迭代器、引用
和指针在扩容或修改时可能失效。`fill` 只覆盖已有范围；`memset` 不是 STL，只作为
按字节写入的陷阱说明。自定义排序是 `sort` 的下级内容，包括逆序、多关键字、比较
函数和严格弱序；优先利用 `pair`、`tuple`、`array` 的字典序。`unique` 只处理相邻
重复元素，通常配合排序和 `erase`。

## 第 04 章中的基础算法与线性结构

第 04 章先把第 03 章的方法地图展开成能够完整解决问题的算法，再进入数论、图论、
动态规划与字符串。前半章按以下顺序组织：

1. 前缀和：先学习静态闭区间和，再把差分解释为前缀和的逆过程；
2. 排序：依次学习冒泡、选择、插入、计数、快速和归并排序，并在快速排序与归并
   排序中正式回访分治；
3. 二分：先学习有序数组上的二分查找，再学习答案二分和浮点数二分；
4. 离散化：组合已经学过的排序、`unique` 和二分定位；
5. 线性表：从操作及复杂度重新理解数组与链表；
6. 双指针：先回访快速排序与归并排序的指针移动，再学习有序数组两数之和、滑动
   窗口和位于链表之后的链表应用；
7. 栈与队列：先学习抽象结构，再学习对应标准库接口和典型应用；
8. 贪心：展开邻项交换证明与后悔策略，后者先用线性扫描表达，优先队列只是后续
   的加速工具。

前缀和继续使用 1-based 和闭区间，并解释 `prefix[0] = 0`；二维前缀和与二维差分
是附属扩展。排序性质比较必须覆盖复杂度、额外空间和稳定性，计数排序不能与一般
桶排序混称。二分必须解释循环不变量、中点取整、边界更新、溢出和标准库左闭右开
接口。双指针必须用总移动次数证明复杂度，不能因为代码有两个下标或嵌套循环就只看
表面结构。

具体枚举位于图的深度优先搜索之后：先用“状态空间与隐式图”连接普通循环枚举和
DFS 枚举，再学习子集、排列、组合、回溯与剪枝。这样第 03 章的算法思想总览不会
倒置成为具体技巧的隐藏前置。

## 第 04 章中的数论基础

初中数论基础依次包含：

1. 整除、因数与倍数；
2. 质数与合数；
3. 试除法质数检测；
4. 算术基本定理；
5. 质因数分解；
6. 埃拉托斯特尼筛法；
7. 最大公约数、最小公倍数与欧几里得算法；
8. 普通快速幂。

首次使用时写“因数（也称约数）”，以后统一使用因数。质数概念和试除算法拆篇。
试除法必须比较从 2 到 `n - 1` 的 $O(n)$ 写法和只到平方根的 $O(\sqrt n)$ 写法，
并讨论 `i * i <= n`、`i <= n / i`、跳过偶数等变体。质因数分解比较相应循环变体，
解释反复相除、指数记录和最后剩余质因数。

埃氏筛在本阶段只负责筛出质数列表或质数个数，并使用 1 到 100 的例子。判断 100
以内的数时，只需检查 2、3、5、7，是因为任何不超过 100 的合数都有一个不超过
$\sqrt{100}=10$ 的质因数，而不超过 10 的质数只有这四个；这不表示合数只含这些
因数。

普通快速幂只依赖指数的二进制分解，可以放在初中数论基础末尾。费马小定理依赖
同余和质数模，留在高中基础，不能因为经常与模快速幂一起使用就提前。

## 高中基础中的数论与矩阵

高中基础按专题组织，不使用含混的“数论进阶”大箱子。

### 数学：模运算与同余

学习模运算、负余数规范化、同余、模快速幂和费马小定理。费马小定理必须明确质数
模与互质条件。

### 数学：扩展欧几里得家族

扩展欧几里得算法、二元线性不定方程、线性同余方程和模逆元连续学习。算法首先
说明能解决的典型问题，再推导裴蜀系数；实现优先用清晰返回值，不使用无必要的输出
引用参数。中国剩余定理及其扩展在该家族以后另成单元。

### 数学：欧拉筛与因数函数

欧拉筛留在高中基础，解释每个合数由最小质因数唯一生成。正因数个数与正因数和
跟随该专题；先由质因数指数公式推导，再讨论批量筛法。初中埃氏筛不提前扩展成
任意数论函数筛。

### 数学：矩阵与线性递推

依次学习矩阵表示、矩阵加减、矩阵乘法、矩阵快速幂和矩阵快速幂解线性递推。
矩阵快速幂算法与线性递推应用拆篇；线性变换不混入这一核心单元。
