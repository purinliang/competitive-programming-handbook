# 旧模板目录追赶清单

本文比较 2019 年、2021 年的个人模板目录与当前 `notes/catalog.md`。它只记录旧目录
已经出现、但当前模块目录尚未登记的内容，不表示这些内容已经进入近期学习路线。

当前目标不是机械恢复旧代码，而是重新理解算法不变量、按本仓库的命名和接口重写，
最终得到自己能够解释、修改和扩展的正文与模板。已经登记但尚无可复制模板的内容，
继续由模块目录中的“计划”状态管理，不在这里重复罗列。

每次只核对一个模块。完成一个模块后，应同时更新本文件和模块目录，避免一次展开
整个知识库后遗漏上下文。

## 数学

### 当前目录尚未登记

旧标题不是新文章标题。下表先判断它背后的稳定问题，再决定以后应当补一篇、并入
现有文章，还是等待找到旧代码后重新辨认。

| 旧目录中的名称 | 更稳定的抽象 | 处理方式 |
| --- | --- | --- |
| 质数的 $k$ 次方和 | 质数计数与质数幂和 | 暂不独立建篇；以后作为高级数论函数求和的具体目标 |
| 积性函数前缀和 | 数论函数求和 | 值得建立总览，统一解释杜教筛、Min_25 筛各自解决的条件 |
| 类欧几里得 | 整除递归与取整和 | 保留为高级数论问题；正文应先定义问题，算法名只作检索词 |
| $n$ 次剩余 | 模方程 $x^k\equiv a\pmod m$ | 保留稳定问题，不把某个人名实现当作一级分类 |
| 单位根反演 | 有限循环群上的变换与反演 | 先放远期数学清单，待多项式与群论基础稳定后再拆边界 |
| 调和数 | 调和数及其渐近性质 | 可独立成短篇，归组合数学或数论的交叉入口 |
| Euler 数 | Euler 数与排列统计 | 保留问题；编写时必须先消除 Euler 数、Euler 多项式等重名 |
| 整数划分 | 整数划分与生成函数 | 保留，组合数学与动态规划可以共享正文入口 |
| 普通型、指数型生成函数 | 普通生成函数与指数生成函数 | 应拆成稳定专题，不继续埋在一个笼统“生成函数基础”里 |
| 字典序第 $k$ 个排列 | 排列的排名与还原 | 与康托展开合并为同一稳定问题，不按旧技巧名拆散 |
| 逆矩阵 | 可逆线性变换与逆矩阵 | 保留在线性代数 |
| 特征值、特征向量 | 线性变换的不变量 | 属于线性代数扩展；不因旧模板存在就提前进入竞赛主线 |
| 常系数非齐次线性递推 | 线性递推求值 | 与矩阵快速幂、生成函数、BM 的适用范围统一比较后再拆篇 |
| 高次代数方程求根 | 数值求根 | 保留在数值方法，不归线性代数 |
| 不平等博弈、均衡 | 原名称含义不足 | 找到旧代码或原题后再辨认，不依据模糊标题新建文章 |
