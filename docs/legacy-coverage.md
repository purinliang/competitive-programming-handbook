# 旧模板目录追赶清单

本文比较 2019 年、2021 年的个人模板目录与当前 `notes/catalog.md`。它只记录旧目录
已经出现、但当前模块目录尚未登记的内容，不表示这些内容已经进入近期学习路线。

当前目标不是机械恢复旧代码，而是重新理解算法不变量、按本仓库的命名和接口重写，
最终得到自己能够解释、修改和扩展的正文与模板。已经登记但尚无可复制模板的内容，
继续由模块目录中的“计划”状态管理，不在这里重复罗列。

每次只核对一个模块。完成一个模块后，应同时更新本文件和模块目录，避免一次展开
整个知识库后遗漏上下文。
