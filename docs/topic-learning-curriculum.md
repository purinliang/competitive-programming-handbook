## 依据与边界

本轮优先参考 CCF 发布的《NOI 大纲（2025 年修订版）》。官方原件见
[NOI 大纲（2025 年修订版）正式发布](https://www.noi.cn/xw/2025-04-18/841584.shtml)，
检索时辅助使用
[2025 年大纲文字排版版](https://lailai.one/zh-Hans/docs/contest/contest/noi-syllabus)，
最终以官方 PDF 为准。杜老师的技能树和仓库旧模板目录留到下一轮，用来补充官方
大纲没有细分的实战专题。

官方难度系数 `8`、`9`、`10` 不是三个具有统一前后关系的学习阶段。后缀自动机、
半平面交、群作用计数和动态树分属不同知识分支，难度数字不能替代真实前置。因此，
第 08–10 章合并为一个阶段：

> `08 专题学习`

完成第 01–07 章的共同基础以后，读者按需要选择单元。单元之间默认没有严格顺序，
只在单元内部维护真实依赖。官方难度系数以后可以作为文章元数据保留，不编码进章号、
单元号或导航顺序。

这里的“单元”表示一整片值得连续学习的方向，不为每一种复杂树、堆或算法单独制造
一层目录。可持久化数据结构拥有共享方法，单独成单元；分块、离线处理和莫队围绕
处理粒度与处理顺序形成另一个单元；其他零散高级结构收进“数据结构专题”，再在正文
内部区分。

大纲中的面向对象程序设计复用第 02 章已有的类专题，不在第 08 章重复。熵、互信息、
信息复杂度、描述复杂度和通讯复杂度不进入第 08 章。线性规划和单纯形法具有明确的
问题模型、几何解释与算法过程，保留在数学专题中。

## 第 08 章：专题学习

### 单元 01：分块与离线处理

这一单元围绕两个共同变化展开：把对象划分成较大的块，以及知道全部操作以后改变
处理顺序。

#### 分块与块状结构

1. 分块思想与序列分块；
2. 整块处理与零散处理；
3. 块状链表；
4. 块的分裂与合并。

先用数组分块建立共同模型，再把块内存储换成可以拆分、合并的序列块。链上分块和
树上分块不因为名称相似就自动进入核心。

#### 离线处理与莫队

1. 离线处理思想；
2. 询问重排与答案恢复；
3. 莫队算法；
4. 带修改莫队与树上莫队。

正文先解释为什么知道全部询问以后可以改变处理顺序，再推导莫队怎样用较小的端点
移动代价交换整体处理效率。变体分别成篇。

#### 其他离线方法

扫描线、CDQ 分治和整体二分也依赖离线处理，但各自拥有独立的不变量和应用范围。
它们进入本单元的后半部分，不写成一篇罗列名称的“离线算法大全”。

### 单元 02：可持久化数据结构

这一单元只研究一个共同问题：怎样保留历史版本，同时让不同版本共享没有改变的
部分。

1. 历史版本与版本根；
2. 共享不变部分与路径复制；
3. 可持久化线段树；
4. 权值线段树上的区间第 k 小；
5. 可持久化数组；
6. 可持久化并查集；
7. 可持久化无旋 Treap；
8. 其他值得保留的可持久化结构。

基础文章先解释持久化方法，再进入具体结构。“主席树”是可持久化权值线段树的重要
应用，不能与所有可持久化线段树未经说明地视为同一个概念。后续结构复用已经建立的
版本共享思想，不重复讲一遍路径复制。

### 单元 03：数据结构专题

这一单元收录不能自然组成另一大片主线、但仍值得单独学习或查阅的高级数据结构。
它们不因为共同放在这里就获得虚假的依赖关系。

#### 复合与多维结构

1. 树套树的两层索引；
2. 线段树套线段树；
3. 线段树套平衡树；
4. KD 树的空间划分、最近邻与矩形查询。

树套树通过组合结构维护多个关键字；KD 树通过空间划分处理多维点。两者可以相邻
查阅，但不共享实现。

#### 可合并堆

1. 可合并堆的抽象操作；
2. 左偏树；
3. 二项树与二项堆。

左偏树是更常见的竞赛实现。二项堆（binomial heap）不是二叉堆（binary heap）：
前者是若干棵二项树组成的森林，“二项”来自各层节点数对应的二项式系数；后者是
通常用数组存储的完全二叉树。二项堆使用频率很低，是否保留正文继续审核。斜堆和
配对堆暂时只保留模块计划。

#### 动态树

1. Splay 所需的局部旋转；
2. 原树中的实链与虚链；
3. 辅助树；
4. `access`、`makeroot` 和 `split`；
5. Link-Cut Tree 维护路径信息。

动态树需要读者理解树上路径、换根和动态维护。Splay 只讲 LCT 真正需要的部分，
不要求先完成所有平衡树专题。

#### 树上数据结构

1. 树链剖分；
2. 把树上路径与子树拆成连续区间；
3. 使用线段树等结构维护这些区间。

树链剖分服务于树上查询与修改，但核心任务是把树上对象转化成适合数据结构维护的
区间，因此归入数据结构，而不放进图论专题。

### 单元 04：字符串专题

字符串部分内部存在前置，但没有必要把每一种自动机或后缀结构抬成一个学习单元。

Z 函数就是竞赛资料中常说的扩展 KMP 所属方法。它只依赖基础字符串匹配，与自动机
没有直接关系，因此作为第 06 章中紧跟 KMP 的独立扩展，不迁入本单元。回文自动机
也保留为第 07 章的独立扩展；“回文树”只作为正文中的常见别名。

#### 自动机与多模式匹配

1. 有穷自动机的最小概念；
2. Trie 上的失败链接；
3. AC 自动机；
4. 多模式匹配与出现次数统计。

失败链接在 AC 自动机内部解释，不另写一篇脱离具体结构的“后缀链接”。

#### 后缀结构

1. 后缀数组与最长公共前缀；
2. 后缀树；
3. 后缀自动机；
4. `endpos` 等价类、状态的 `len`、后缀链接与克隆；
5. 本质不同子串、出现次数、第 k 小子串等典型应用。

三种后缀结构解决的问题有交集，但表示方式不同，分别成篇。后缀自动机虽然被官方
列为难度 `10`，仍可能比某些数学专题更适合熟悉字符串结构的读者。

### 单元 05：网络流

1. 流网络、容量、流量与流量守恒；
2. 残量网络、反向边与增广路；
3. 最大流与最小割；
4. Edmonds–Karp 与 Dinic；
5. 费用流；
6. 可行流与上下界网络流。

网络流必须从问题模型和残量网络推导，再进入算法。费用流和上下界分别成篇，不能
塞进第一篇最大流模板。

### 单元 06：匹配

1. 二分图最大匹配与匈牙利算法；
2. 带权二分图匹配与 KM 算法；
3. 一般图匹配。

三类匹配分别成篇。二分图中的最大独立集和最小点覆盖关系可以作为最大匹配的应用，
但不能冒充一般图中的全部相关问题。

### 单元 07：图论专题

网络流和匹配已经各自形成完整问题族，其余尚未形成大片的高级图论内容集中在本单元。

1. 虚树；
2. 2-SAT；
3. 有向最小生成树；
4. 支配集、独立集与覆盖集。

2-SAT 从布尔变量和蕴含关系建立蕴含图，再用强连通分量判断可行性。官方难度只作为
审核元数据，不强制迁移。官方“支配集、独立集与覆盖集”的具体范围仍需核实，确认
以前不写正文。

### 单元 08：动态规划专题

1. 单调队列优化；
2. 单调栈优化；
3. 斜率优化；
4. 决策单调性与分治优化；
5. 四边形不等式优化。

本单元从阶段、状态和决策出发，用典型问题解释建模取舍与优化来源。每一种稳定优化
仍独立成篇，不把全部技巧塞入一篇“高级 DP”。

### 单元 09：数论专题

1. 原根、指数与离散对数；
2. BSGS；
3. 模质数平方根：判断 $x^2\equiv a\pmod p$ 是否有解并求出一个解。

莫比乌斯反演作为莫比乌斯函数的附属扩展，其中按需解释狄利克雷卷积，不在这里
重复建立 NOI 级入口。模质数平方根先解释“二次剩余”表示什么，再在正文内部使用
勒让德符号判定可解性，并推导 Cipolla 等求解方法；这些名称不各自占据课程入口。

### 单元 10：组合数学专题

1. 群及其基本性质；
2. 置换群与循环群；
3. Burnside 引理与 Polya 定理；
4. 母函数；
5. Stirling 数；
6. Prufer 序列。

先完成群与置换，再学习群作用计数。母函数、Stirling 数和 Prufer 序列是相对独立的
组合专题，不按照官方表格顺序强行串成一条依赖链。

### 单元 11：线性代数专题

1. 行列式；
2. 逆矩阵；
3. 向量空间与线性相关；
4. 基；
5. XOR 线性基。

“基”是线性代数概念，竞赛中的 XOR 线性基是二进制向量空间中的具体实现。课程从
高斯消元和行列式建立一般语言，再进入可复制的 XOR 线性基模板。

### 单元 12：多项式与快速变换

1. 多项式函数的导数与积分；
2. 复数与单位根；
3. 离散傅里叶变换与 FFT；
4. 卷积与多项式乘法；
5. Taylor 级数；
6. NTT 与形式幂级数操作。

普通多项式函数的微积分不等同于形式幂级数中的形式导数和积分。FFT 与 NTT 也不是
同义算法：前者依赖复数并需要控制误差，后者在有限域中精确计算但受模数限制。

### 单元 13：最优化专题

1. 决策变量、线性约束和可行域；
2. 线性目标函数；
3. 二维问题的几何解释；
4. 标准形式与松弛变量；
5. 单纯形法；
6. 无解、无界和存在最优解。

从能够画出可行域的二维线性规划开始，再解释单纯形法怎样沿相邻基本可行解改进
目标。完整模板必须等到对象和转移过程能够解释清楚以后再加入。

### 单元 14：博弈论专题

1. 公平组合游戏；
2. Nim 博弈；
3. SG 函数。

概率论不单独建立一个只有数学定义而没有明确算法目标的专题。组合计数或概率与期望
DP 真正需要概率、期望和条件概率时，在对应文章中补足前置。

### 单元 15：计算几何专题

1. 点、线、面之间位置关系的判定；
2. 一般图形面积；
3. 二维凸包；
4. 半平面与有向直线；
5. 半平面交；
6. 旋转卡壳、圆和其他已经形成稳定问题的几何算法。

点、向量、叉积、直线交点和凸包当前已分布在第 06–07 章。正式重排时保留早期基础，
只把真正依赖完整几何工具链的内容放到专题学习。

## 审核原则

人工审核依次回答：

1. 该知识是否值得进入本书，而不是仅仅出现在官方大纲；
2. 它应进入连续学习路线、带星扩展，还是只进入模块目录；
3. 一个单元是否确实覆盖一整片连续学习方向；
4. 现有文章是否适合保留在第 01–07 章；
5. 文章是否需要改名、拆篇或补充前置；
6. 单元内部的真实依赖是什么。

审核完成后，再统一修改 `notes/learning-path.md`、文章六位 ID、模块目录和网站导航。
在此之前不临时迁移编号，也不让官方难度替代教学判断。
