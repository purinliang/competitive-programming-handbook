## 依据与边界

本轮优先参考 CCF 发布的《NOI 大纲（2025 年修订版）》。官方原件见
[NOI 大纲（2025 年修订版）正式发布](https://www.noi.cn/xw/2025-04-18/841584.shtml)，
检索时辅助使用
[2025 年大纲文字排版版](https://lailai.one/zh-Hans/docs/contest/contest/noi-syllabus)，
最终以官方 PDF 为准。杜老师的技能树和仓库旧模板目录留到下一轮，用来补充官方
大纲没有细分的实战专题。

官方难度系数 `8`、`9`、`10` 不是三个具有统一前后关系的学习阶段。后缀自动机、
半平面交、群作用计数和动态树分属不同知识分支，难度数字不能替代真实前置。因此，
原来的第 08–10 章草案合并为一个阶段：

> `08 专题学习`

完成第 01–07 章的共同基础以后，读者按需要选择专题。专题之间默认没有先后关系，
只在专题内部维护真实依赖。官方难度系数以后可以作为文章元数据保留，不编码进章号、
单元号或导航顺序。

大纲中的面向对象程序设计复用第 02 章已有的类专题，不在第 08 章重复。熵、互信息、
信息复杂度、描述复杂度、通讯复杂度、线性规划和单纯形法不进入第 08 章：它们与
本书的竞赛学习主线距离太远，不能只因出现在官方大纲里就制造空泛文章。模块目录中
是否继续保留查阅入口以后单独审核。

## 第 08 章：专题学习

### 单元 01：算法设计：分块与离线处理

1. 分块思想与序列分块；
2. 离线处理思想；
3. 询问重排与答案恢复；
4. 莫队算法；
5. 扫描线、CDQ 分治等典型离线方法之间的联系。

先用数组分块建立“整块处理、零散处理”的共同模型，再解释知道全部询问以后为何
可以改变处理顺序。具体算法分别成篇，不写成一篇罗列名称的离线算法总览。

### 单元 02：算法设计：复杂分治与构造

1. 复杂分治思想；
2. 平衡规划思想；
3. 构造思想。

这些是能力型条目，必须依靠典型问题解释不变量和设计过程。在找到合适问题以前保持
计划，不编写空泛定义。“平衡规划思想”的官方含义还需结合原 PDF 和典型例题核实，
暂不擅自等同于某一种熟悉的优化算法。

### 单元 03：数据结构：块状结构

1. 块状链表；
2. 块的分裂与合并；
3. 区间访问与序列修改。

块状链表建立在分块思想之上，但学习目标是维护可修改序列，因此与算法设计单元分开。
链上分块和树上分块不由这个条目自动转为核心。

### 单元 04：数据结构：可持久化数据结构

1. 历史版本查询；
2. 共享不变部分与路径复制；
3. 版本根；
4. 可持久化线段树；
5. 权值线段树上的区间第 k 小；
6. 可持久化并查集、Treap 等代表性结构。

基础文章先解释持久化方法，再进入具体结构。“主席树”是可持久化权值线段树的重要
应用，不能与所有可持久化线段树未经说明地视为同一个概念。其他结构只选择确有代表性
且值得维护的实现。

### 单元 05：数据结构：复合与多维结构

1. 树套树的两层索引；
2. 线段树套线段树；
3. 线段树套平衡树；
4. KD 树的空间划分；
5. 最近邻与矩形查询。

树套树通过组合结构维护多个维度；KD 树通过空间划分完成多维查询。两者不共享实现，
但共同回答“数据拥有多个坐标或关键字时怎样组织查询”，可以相邻学习。

### 单元 06：数据结构：可合并堆

1. 可合并堆的抽象操作；
2. 左偏树；
3. 二项树与二项堆。

左偏树是常见竞赛实现。二项堆虽然被官方列为更高难度，但使用频率很低；是否进入
连续阅读顺序留待审核。二项堆（binomial heap）不是二叉堆（binary heap）：前者是
若干棵二项树组成的可合并森林，“二项”来自各层节点数对应的二项式系数；后者是通常
用数组存储的完全二叉树。斜堆和配对堆继续只在模块目录保留计划。

### 单元 07：数据结构：动态树

1. Splay 所需的局部旋转；
2. 原树中的实链与虚链；
3. 辅助树；
4. `access`、`makeroot` 和 `split`；
5. Link-Cut Tree 维护路径信息。

动态树不依赖树链剖分的代码，却需要读者已经理解树上路径、换根和动态维护。Splay
只讲 LCT 真正需要的部分，不要求先完成所有平衡树专题。

### 单元 08：图论：树上进阶结构

1. 树链剖分；
2. 虚树；
3. 基环树。

树链剖分与虚树依赖 DFS 序、LCA 和路径关系。基环树的概念与基础遍历当前位于第 06
章，教学上可能确实适合保留较早位置；官方难度只作为审核元数据，不强制迁移。

### 单元 09：字符串：自动机与多模式匹配

1. 有穷自动机的最小概念；
2. Trie 上的失败链接；
3. AC 自动机的构造；
4. 多模式匹配与出现次数统计。

本单元依赖 Trie、BFS 和字符串匹配。失败链接在 AC 自动机内部解释，不另写一篇
脱离具体结构的“后缀链接”。

### 单元 10：字符串：后缀结构

1. 后缀数组；
2. 最长公共前缀；
3. 后缀树；
4. 后缀自动机；
5. `endpos` 等价类、状态的 `len`、后缀链接与克隆。

三种后缀结构解决的问题有交集，但表示方式不同，分别成篇。后缀自动机虽然被官方
列为难度 `10`，仍可能比某些数学专题更适合熟悉字符串结构的读者，不把它放在所有
难度 `9` 内容之后。

### 单元 11：字符串：匹配边界

1. Z 函数与扩展 KMP；
2. 前缀、后缀与匹配长度；
3. 与 KMP 前缀函数的比较。

Z 函数当前位于第 06 章。它只依赖基础字符串匹配，可能无需迁入第 08 章；本单元先
保留审核入口，最终按真实前置决定位置。

### 单元 12：图论：逻辑建模

1. 布尔变量与蕴含关系；
2. 蕴含图；
3. 强连通分量；
4. 2-SAT 的可行性与方案构造。

2-SAT 的核心是把二元逻辑限制翻译成图，而不是背诵连边模板。

### 单元 13：图论：网络流

1. 流网络、容量与流量；
2. 流量守恒；
3. 残量网络与反向边；
4. 增广路；
5. 最大流与最小割；
6. Edmonds–Karp 与 Dinic；
7. 费用流、可行流和上下界网络流。

网络流必须从问题模型和残量网络推导，再进入算法。费用流和上下界是后续文章，不能
塞进第一篇最大流模板。

### 单元 14：图论：匹配

1. 二分图最大匹配；
2. 匈牙利算法；
3. 带权二分图匹配与 KM 算法；
4. 一般图匹配。

二分图匹配、带权匹配和一般图匹配分别成篇。不能把二分图中的最大独立集、最小点
覆盖关系冒充一般图的支配集、独立集与覆盖集。

### 单元 15：图论：高级图结构

1. 有向最小生成树；
2. 支配集、独立集与覆盖集。

有向最小生成树可以围绕最小树形图及其算法展开。官方“支配集、独立集与覆盖集”
究竟要求概念、问题还是算法范围仍需核对；确认以前不拆出正文。

### 单元 16：动态规划：复杂模型与优化

1. 复杂动态规划模型的构建；
2. 复杂动态规划模型的优化；
3. 已规划的单调队列、斜率、分治和四边形不等式等优化之间的适用条件。

本单元从阶段、状态和决策出发，用典型问题解释建模取舍与优化来源。每一种稳定优化
仍独立成篇，不把全部技巧塞入一篇“高级 DP”。

### 单元 17：数学：数论专题

1. 原根、指数与离散对数；
2. BSGS；
3. 算术函数与狄利克雷卷积；
4. 莫比乌斯反演；
5. 二次剩余与二次同余方程；
6. 勒让德符号和典型求解算法。

数论专题同时收纳此前第 06–07 章遗漏但确有价值的数论文章。内部顺序按对象组织：
先建立算术函数和卷积，再学习反演；二次剩余先讲数学对象与可解性，再选择 Cipolla
等竞赛实现，不从人名模板开始。

### 单元 18：数学：群与组合计数

1. 群及其基本性质；
2. 置换群与循环群；
3. Burnside 引理与 Polya 定理；
4. 母函数；
5. Stirling 数；
6. Prufer 序列。

先完成群与置换，再学习群作用计数。母函数、Stirling 数和 Prufer 序列是相对独立的
组合专题，不按照官方表格顺序强行串成一条依赖链。

### 单元 19：数学：线性代数

1. 行列式；
2. 逆矩阵；
3. 向量空间与线性相关；
4. 基；
5. XOR 线性基。

“基”是线性代数概念，竞赛中的 XOR 线性基是二进制向量空间中的具体实现。课程从
高斯消元和行列式建立一般语言，再进入可复制的 XOR 线性基模板。

### 单元 20：数学：概率与博弈

1. 概率的基本概念；
2. 离散随机变量；
3. 期望与方差；
4. 条件概率与贝叶斯公式；
5. 公平组合游戏；
6. Nim 博弈与 SG 函数。

概率和博弈并无直接依赖；正式路线可以拆成两个单元。这里暂时相邻，是因为二者都已
在当前数学模块形成短专题，便于先统一检查已有文章是否过度合并。

### 单元 21：数学：多项式与快速变换

1. 多项式函数的导数与积分；
2. 复数与单位根；
3. 离散傅里叶变换；
4. FFT；
5. 卷积与多项式乘法；
6. Taylor 级数；
7. NTT 及后续形式幂级数操作。

普通多项式函数的微积分不等同于形式幂级数中的形式导数和积分。FFT 与 NTT 也不是
同义算法：前者依赖复数并需要控制误差，后者在有限域中精确计算但受模数限制。

### 单元 22：计算几何：进阶

1. 点、线、面之间位置关系的判定；
2. 一般图形面积；
3. 二维凸包；
4. 半平面与有向直线；
5. 半平面交。

点、向量、叉积、直线交点和凸包当前已分布在第 06–07 章。计算几何拥有连续前置，
正式重排时应保留早期基础，只把真正依赖完整几何工具链的半平面交放到专题学习。

## 审核原则

人工审核依次回答：

1. 该知识是否值得进入本书，而不是仅仅出现在官方大纲；
2. 它应进入连续学习路线、带星扩展，还是只进入模块目录；
3. 单元是否拥有共同学习目标，而不只是同属一个大类；
4. 现有文章是否适合保留在第 01–07 章；
5. 文章是否需要改名、拆篇或补充前置；
6. 专题内部的真实依赖是什么。

审核完成后，再统一修改 `notes/learning-path.md`、文章六位 ID、模块目录和网站导航。
在此之前不临时迁移编号，也不让官方难度替代教学判断。
