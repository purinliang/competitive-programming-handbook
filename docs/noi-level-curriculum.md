# NOI 级课程草案

> 更新日期：2026-08-17
>
> 本文是第 08–10 章的待审核草案，不直接改动当前学习路线中的文章编号和位置。

## 依据与边界

本轮只使用 CCF 发布的《NOI 大纲（2025 年修订版）》整理难度 `8`、`9`、`10`。
官方原件见 [NOI 大纲（2025 年修订版）正式发布](https://www.noi.cn/xw/2025-04-18/841584.shtml)，
检索时辅助使用 [2025 年大纲文字排版版](https://lailai.one/zh-Hans/docs/contest/contest/noi-syllabus)，
最终以官方 PDF 为准。杜老师的技能树和仓库旧模板目录暂不参与本轮归级；完成官方
大纲映射以后，再用它们补充大纲没有细分的实战专题。

难度系数不是严格的前置等级，也不是对每个人都成立的绝对难度。一个人可能已经掌握
难度 `10` 的后缀自动机，却尚未系统学习难度 `9` 的群论或概率。本草案把官方难度
转换成课程章号，目的只是得到稳定的审核坐标：

- 第 08 章收录官方难度 `8`；
- 第 09 章收录官方难度 `9`；
- 第 10 章收录官方难度 `10`。

官方一个条目可以拆成多篇聚焦文章，例如“网络流”应从流网络、残量网络和增广路
开始，再进入具体算法。反过来，已经在第 01–07 章出现的文章不会因为官方标为
`8`–`10` 就在本轮立即迁移；表格先记录建议归属，待人工审核教学顺序以后统一重编号。

## 第 08 章：NOI 级难度 8

### 单元 01：面向对象程序设计

官方条目是面向对象程序设计思想。课程复用第 02 章已经规划的类、封装、继承和多态
文章，不另写一套重复正文。这里更关心对象、接口、封装和动态分派怎样组成一种程序
设计方法；竞赛代码是否值得使用这些机制继续由具体场景决定。

### 单元 02：分块结构

1. 分块思想；
2. 序列分块；
3. 块状链表。

官方分别从算法策略和线性结构列出分块与块状链表。课程先用数组分块建立“整块处理、
零散处理”的共同模型，再把块内存储换成可拆分、可合并的序列块。现有“分块”计划
可以成为本单元入口；链上分块和树上分块不由官方这一条自动纳入核心。

### 单元 03：树上结构

1. 树链剖分；
2. 虚树。

树链剖分把路径或子树拆成少量连续区间；虚树只保留一组关键点及连接它们所需的
分叉点。二者都建立在 DFS 序、LCA 和树上路径关系之上，可以相邻学习，但各自仍应
独立成篇。

树链剖分当前位于第 07 章，待审核是否保留较早位置；虚树当前在扩展索引中。

### 单元 04：可合并堆

1. 可合并堆的抽象操作；
2. 左偏树；
3. 合并、插入、取最值与删除最值。

本单元只把左偏树作为官方难度 `8` 的可合并堆实现。斜堆、配对堆和二项堆不因为
接口相似而一起进入本单元。

### 单元 05：可持久化线段树

1. 历史版本查询；
2. 路径复制；
3. 版本根；
4. 单点修改与区间查询；
5. 权值线段树上的区间第 k 小。

官方条目是可持久化线段树。基础文章先解释持久化方法本身，再选择主席树作为重要
应用；不能把“可持久化线段树”和“主席树”未经说明地当成完全相同的概念。

### 单元 06：离线处理

1. 离线处理思想；
2. 询问重排与答案恢复；
3. 典型离线算法之间的共同结构。

本单元先解释为什么知道全部询问以后可以改变处理顺序，再把莫队、扫描线、CDQ 分治
等方法留给各自专题。当前第 07 章已有“离线算法”；是否迁移取决于正文实际深度，
而不是仅凭标题移动。

### 单元 07：字符串结构

1. 扩展 KMP（Z 函数）；
2. 有穷自动机的概念；
3. AC 自动机；
4. 后缀数组。

Z 函数当前位于第 06 章，AC 自动机和后缀数组当前位于第 07 章。官方难度可以作为
审核参考，但不否定较早学习一个写法清晰、前置充分的专题。正式重排时应分别检查：

- Z 函数是否只使用已经掌握的字符串匹配知识；
- AC 自动机是否已经具备 Trie、BFS 和失败链接前置；
- 后缀数组是否已经具备排序、倍增和最长公共前缀前置。

### 单元 08：图论模型与算法

1. 基环树；
2. 2-SAT；
3. 网络流；
4. 二分图最大匹配与匈牙利算法。

网络流不能只登记一个算法名。正文至少应依次解释流网络、容量与流量、流量守恒、
残量网络、反向边、增广路和最大流，再进入 Edmonds–Karp 或 Dinic。匈牙利算法只
解决二分图匹配，不与一般图匹配合并。

基环树当前位于第 06 章；它的结构概念和基础遍历可能确实适合更早学习，待审核时
可以保留在原位并把官方难度 `8` 只作为元数据。

### 单元 09：数论中的离散对数

1. 原根和指数；
2. 离散对数问题；
3. BSGS。

原根不只是 BSGS 的语法前置，两篇应先分别建立问题。BSGS 用时间和空间交换，把
指数拆成“大步”和“小步”；更进一步的 Pohlig–Hellman 不由官方条目自动转为核心。

### 单元 10：概率基础

1. 随机试验、样本空间和事件；
2. 概率的基本性质；
3. 计数与概率。

当前第 06 章已有“概率与期望基础”，需要检查它是否同时讲了官方难度 `8` 的概率
概念和难度 `9` 的期望、方差。若跨度过大，应拆篇而不是整篇机械迁移。

### 单元 11：多项式的微积分运算

1. 多项式函数的导数；
2. 多项式函数的积分。

这里讨论普通多项式函数的微分和积分，不等同于形式幂级数中的形式导数和形式积分。
二者公式相似，但对象、收敛语义和用途不同，正式文章需要明确边界。

### 单元 12：计算几何基础算法

1. 点、线、面之间位置关系的判定；
2. 一般图形面积的计算；
3. 二维凸包。

这些文章当前已分布在第 06–07 章。计算几何依赖更像一条连续主线，正式重排时可以
保留较早的点、向量和叉积基础，再决定凸包是否迁入第 08 章。

## 第 09 章：NOI 级难度 9

### 单元 01：复合数据结构

1. 树套树的基本组合方式；
2. 线段树套线段树；
3. 线段树套平衡树。

本单元解释两层索引各自负责什么维度，以及时间、空间为何会相乘。具体选择哪一种
树套树作为主实现留待审核，不为覆盖名称维护多份几乎不会使用的模板。

### 单元 02：多维空间搜索

1. k-d 树的空间划分；
2. 建树与维度选择；
3. 最近邻和矩形查询；
4. 剪枝条件。

k-d 树处理多维点，不是“树套树”的另一种实现，因此单独成单元。

### 单元 03：可持久化数据结构

1. 版本之间共享不变部分；
2. 路径复制；
3. 可持久化并查集；
4. 可持久化 Treap 等典型结构。

“其他可持久化数据结构”是官方的集合性条目，不应直接成为一篇空泛正文。课程先
解释通用方法，再分别选择确有代表性的结构；哪些实现进入主线留待审核。

### 单元 04：复杂算法设计思想

1. 复杂分治思想；
2. 平衡规划思想；
3. 构造思想。

这些是能力型条目，不宜只写概念定义。正式课程必须为每一种思想选择足以暴露其
不变量和设计过程的典型问题；在找到合适问题以前保持“计划”，不写成空泛总论。

“平衡规划思想”的官方含义还需要结合原 PDF 和典型例题进一步核实，本轮不擅自把它
等同于某一种熟悉的优化算法。

### 单元 05：后缀树

1. 压缩 Trie 与后缀树的定义；
2. 边标签、显式节点与隐式位置；
3. 构造思想与典型查询。

后缀树和后缀数组、后缀自动机有共同用途，但结构并不相同。正文不能把三者合并成
一篇“后缀结构大全”。

### 单元 06：复杂动态规划

1. 复杂动态规划模型的构建；
2. 复杂动态规划模型的优化。

这同样是能力型条目。课程应从已学过的阶段、状态、决策出发，分别选择几个能解释
建模取舍和优化来源的专题；不把所有高级 DP 技巧不加选择地塞入一个单元。

### 单元 07：数论函数与卷积

1. 算术函数；
2. 狄利克雷卷积；
3. 单位元、逆元与常见函数之间的卷积关系。

它是莫比乌斯反演的自然前置。正文需要先建立“定义在正整数上的函数”这一对象，
不能一上来只给卷积公式。

### 单元 08：群与置换

1. 群及其基本性质；
2. 置换；
3. 置换群；
4. 循环群。

本单元只建立后续群作用计数所需的最小抽象，不扩写成完整抽象代数课程。

### 单元 09：组合数学进阶

1. 母函数；
2. 莫比乌斯反演；
3. Burnside 引理；
4. Polya 定理；
5. Stirling 数；
6. Prufer 序列。

这些条目不能按照官方表格顺序直接阅读。建议先完成狄利克雷卷积再学习数论语境的
莫比乌斯反演；先完成群与置换再学习 Burnside 和 Polya。Stirling 数和 Prufer
序列可以成为相对独立的组合计数单元。

### 单元 10：线性代数进阶

1. 行列式；
2. 逆矩阵；
3. 向量空间；
4. 线性相关；
5. 基；
6. XOR 线性基。

“基”是线性代数概念，竞赛中的 XOR 线性基是它在二进制向量空间中的具体实现。
课程先从高斯消元和行列式建立一般语言，再进入可复制的 XOR 线性基模板。

### 单元 11：概率进阶

1. 离散随机变量；
2. 期望；
3. 方差；
4. 条件概率；
5. 贝叶斯公式。

期望和方差属于随机变量，不能只作为动态规划公式的装饰。概率与期望 DP 可以引用
本单元，但不替代基础概率定义。

### 单元 12：博弈论

1. 公平组合游戏；
2. Nim 博弈；
3. SG 函数。

正文先说明局面、行动、终止和胜负，再从 Nim 的异或结论进入 SG 函数；不把所有
博弈题都误写成 SG 模板题。

### 单元 13：半平面交

1. 有向直线与半平面；
2. 半平面的交集；
3. 双端队列维护候选边；
4. 有界、无界与空交集的边界处理。

本单元直接依赖二维向量、叉积、直线交点、极角排序和凸多边形。

## 第 10 章：NOI 级难度 10

### 单元 01：动态树

1. 实链与虚链；
2. 辅助树；
3. `access`、`makeroot` 和 `split`；
4. Link-Cut Tree 维护路径信息。

LCT 需要先掌握 Splay 的局部旋转，再区分原树中的实链、虚链与辅助树中的父子关系。

### 单元 02：二项堆

1. 二项树；
2. 二项堆的森林表示；
3. 合并；
4. 插入、取最值与删除最值。

二项堆依赖可合并堆的抽象操作，与动态树没有共同学习目标，因此单独成单元。

### 单元 03：后缀自动机

1. `endpos` 等价类；
2. 状态的 `len`；
3. 后缀链接；
4. 转移、克隆与在线构造；
5. 出现次数和本质不同子串等典型应用。

后缀自动机虽然被官方列为难度 `10`，仍可能比某些难度 `9` 的数学更适合已经熟悉
字符串结构的读者。它不应因此被描述成必须最后学习的终点。

### 单元 04：图论进阶

1. 有向最小生成树；
2. 支配集、独立集与覆盖集；
3. KM 算法；
4. 一般图匹配。

需要进一步核对官方“图的支配集、独立集与覆盖集”指的是概念、问题还是算法范围，
不能把二分图中的最大独立集、最小点覆盖关系直接冒充完整的一般图内容。

### 单元 05：二次剩余

1. 二次剩余；
2. 二次同余方程；
3. 勒让德符号；
4. 典型求解算法。

算法实现可以选择适合竞赛的 Cipolla 等方法，但官方条目首先要求数学对象与可解性，
不能只留下一个人名模板。

### 单元 06：高等数学与快速变换

1. Taylor 级数；
2. 快速傅里叶变换；
3. 卷积与多项式乘法应用。

FFT 需要复数、单位根和离散傅里叶变换前置。NTT 是竞赛中更便于精确计算的变体，
但它不是官方“FFT”条目的同义替换，两者应在正文中明确联系与差别。

### 单元 07：线性规划

1. 线性规划模型；
2. 可行域、目标函数和最优解；
3. 单纯形法。

本单元先讲建模对象，再决定是否值得维护竞赛模板；不从一份难以解释的单纯形代码
开始。

### 单元 08：信息论与复杂度

1. 熵；
2. 条件熵、互信息和相对熵；
3. 信息复杂度；
4. 描述复杂度；
5. 通讯复杂度。

这些内容与常见 OI 模板的距离较远。它们因为官方列为难度 `10` 而进入审核范围，
但是否进入连续学习路线、只保留概念文章，还是仅作为模块查阅内容，必须单独审核。

## 审核顺序

人工审核不需要逐项判断“会不会”，而应依次回答：

1. 官方难度是否抄录正确；
2. 这个官方条目是否值得拆成多篇文章；
3. 它是否真的适合按官方难度迁移，还是应保留在更早的教学位置；
4. 单元是否拥有共同学习目标，而不只是同属一个大类；
5. 它应进入连续学习路线、带星扩展，还是只进入模块目录；
6. 现有文章能否复用，是否需要改名、拆篇或补充前置。

审核完成后，再统一修改 `notes/learning-path.md`、文章六位 ID、模块目录和网站导航。
在此之前，不用临时编号制造第二轮迁移。
