# 在线学习平台界面规范

本文记录在线学习平台的共享界面语言。它以同一作者的 Arctic Aria 成熟组件体系为母版，移除项目管理业务耦合以后移植到 handbook；本站不另造一套按钮、表单、面板或弹窗规范。

## 设计目标

- 界面安静、清楚，视觉层级服务于长文阅读。
- 同一种交互只出现一种稳定画法，功能页面不得自己重新设计按钮或表单。
- 桌面优先，同时保证手机浏览、答题和留言可用。
- 浅色与深色使用相同的语义角色，避免组件内部散落主题判断。
- 公开文章不受登录页面、登录弹窗或鉴权重定向阻挡。

## 视觉基础

### 色彩角色

颜色来自 Arctic Aria 的蓝色与中性灰方向，但在代码中只引用以下语义角色：

- 页面背景
- 面板背景
- 面板悬停背景
- 面板标题背景
- 列表分隔线
- 强边框
- 主要文字、次要文字、弱化文字
- 主要按钮及悬停状态
- 次要按钮及悬停状态
- 输入框背景、边框和聚焦边框
- 代码背景和边框
- 错误、成功、提醒等少量语义状态

页面和业务组件不得直接使用新的十六进制颜色。新增颜色先进入全局角色，再由共享组件引用。文章状态默认使用次要文字，不使用成排的彩色标签。

### 字体

- 中文正文使用 `Inter`、`Noto Sans SC`、`PingFang SC`、`Microsoft YaHei` 和系统无衬线回退。
- 代码使用稳定的等宽字体栈。
- 普通界面只使用正常、中等和半粗字重；正文不依赖极粗字体制造层级。
- UI 正文以 `14px` 为基础，教程正文以 `16px` 为基础并采用约 `1.85` 的行高。

### 间距与形状

- 基本间距序列为 `4px`、`8px`、`12px`、`16px`、`20px`、`32px`。
- 页面、面板和栏之间通常使用 `16px` 或 `20px`。
- 普通按钮高度为 `40px`，紧凑图标按钮为 `36px`。
- 面板和主要控件使用温和圆角；弹窗、面板和代码块的圆角必须来自共享规格。
- 列表分隔线弱于面板外框，悬停背景弱于面板标题背景。

## 页面结构

### 公开站点外壳

顶部栏包含站点名称、学习路线、模块目录、搜索和主题切换。匿名读者直接访问所有公开文章。用户功能上线以后，登录入口可以加入顶部栏，但登录状态不得改变公开内容路由。

### 阅读页

桌面阅读页使用三栏：

```text
模块文章导航 | 教程正文 | 本文目录
```

中等宽度隐藏本文目录，小屏隐藏两侧导航。正文保持稳定的最大宽度，表格、公式和代码块在自身区域横向滚动，不撑宽整个页面。

### 管理与学习页面

题目管理、考试记录、学习统计和未来教师工具沿用 Arctic Aria 的页面布局：页面标题下放置一个或多个面板；需要左右详情时使用弹性主面板加固定侧面板，空间不足时纵向堆叠。

## 共享组件

下列组件体系整体继承 Arctic Aria。组件可以按本站实际功能逐步落地，但不得用临时业务组件绕开这些角色。

### 文字

- `Text`：统一字号、行高、字重和文字角色。
- `TextStack`：标题、说明和辅助信息的稳定垂直关系。
- `PageTitle`、`SectionTitle`、`LabelText`：页面标题、章节标题和表单标签。
- `DescriptionText`、`SupportingText`：说明与辅助信息。

### 按钮与操作

- `Button`：主要、次要和无边框次要三种表现。
- `IconButton`：图标操作，尺寸与点击区域固定。
- `ActionMenu`：低频操作集合，避免把大量按钮平铺在页面上。
- 禁用状态使用专门颜色，不仅依赖透明度。

### 面板、卡片与内容段

- `Panel`：页面中的主要内容块，拥有外框、背景和内部节奏。
- `PanelHeader`：标题、说明、图标及右侧操作。
- `Card`、`CardHeader`：重复的小型对象，不用于包裹整页章节。
- `ContentSection`：不需要独立面板外观的正文分区。

### 列表

- `List`、`ListItem`：统一行间距、分隔线、悬停与选中状态。
- `ExpandableListItem`：标题行和展开内容保持在同一列表项中。
- `PagedList`：长管理列表分页。
- `ManagerList`：弹窗内的紧凑管理列表。
- 列表标题、正文和辅助信息使用共享文字组件，不由业务页面手写字号。

### 表单

- `InputField`、`PasswordField`、`NumberField`、`TextAreaField`。
- `SelectionField`：自定义单选下拉、复选行和复选组。
- `ChoiceGroup`：少量选项直接可见时使用，也是 takeaway 选择题的基础控件。
- `DatePickerField`、`TimePickerField`、`EstimatedDurationField`。
- `Switch`：普通二元设置；导航栏主题切换仍使用菜单或图标按钮。
- 聚焦主要改变现有边框，不额外绘制厚重的外圈。
- 校验错误靠近字段显示；用户重新聚焦编辑时恢复正常聚焦边框。

### 弹窗与浮层

- `DialogOverlay`、`DialogFrame`、`DialogHeader`、`DialogActionRow`。
- `CrudEditorDialog`：标准的新建、编辑和删除流程。
- `ConfirmDialog`：需要明确确认的危险操作。
- `FloatingPopover`：选择器、操作菜单等短浮层。
- 点击半透明遮罩不关闭含未保存内容的编辑弹窗；关闭必须来自明确按钮。
- 保存、删除期间禁用会冲突的操作，并保留清楚的文字状态。

### 状态与反馈

- `NotificationStack`：非阻塞成功、提醒和错误反馈。
- `LoadingLine`：面板或列表中的加载状态。
- `HorizontalProgressBar`：文章、课程或考试进度。
- `Tag` 仅保留给真正需要的语义状态；普通文章元数据使用文字。
- `VersionStatus`：内容修订版本或旧版本提示，可用于段落留言重新定位失败的情况。

### 导航与容器

- `Tabs`：同一路由下的同级视图，不代替全局导航。
- `ScrollArea`：侧栏和长列表的统一滚动行为。
- `SettingsControlRow`：左侧说明、右侧控件的设置行。
- 移动端导航使用覆盖式侧栏或底部导航，不能缩窄正文到不可阅读。

## 本站新增组件

### MarkdownArticle

- 支持 GFM 表格、代码块、相对链接、SVG 和 LaTeX。
- 构建时生成标题锚点、本文目录、`content_revision` 和可留言的 `block_key`。
- 内联代码、代码块、表格、引用和公式只使用共享颜色角色。

### TakeawayQuestion

- 使用 `ChoiceGroup` 展示选项。
- 未提交时不泄露正确选项的视觉状态。
- 练习区放在正文以后、文章上一篇与下一篇导航以前；默认直接显示，不把整区折叠起来。
- 一次只展示一道题，小型题号导航始终显示；题号、上一题和下一题只切换当前题，不改变文章路由。
- 每道题独立提交。提交后用全局成功色和错误色标出正确选项与读者选择，同时显示图标或明确文字，保证不依赖颜色辨认结果。
- “查看解析”只在当前题提交后可用，解析由读者主动展开；选项变化后重新提交前恢复未判定状态。
- 题号导航、题目正文、选项和底部操作在题目之间保持固定位置，避免切题时界面明显跳动。
- 可以使用浏览器本地状态恢复匿名读者的选择、提交结果和解析展开状态。
- 单篇文章的题目是低压力检查，不使用阻塞弹窗。

### ExamSession

- 用于 CSP 模拟，包含题目导航、计时、答题状态、统一提交和结果讲解。
- 提交确认使用共享弹窗；断网、保存失败等非阻塞问题使用通知。
- 正确答案由服务端判定，不随未提交试卷发送到浏览器。

### DiscussionThread

- 可以附着于整篇文章或一个 `block_key`。
- 使用共享列表、输入框、按钮、通知和确认弹窗。
- 旧版本引用、删除状态和审核状态使用统一版本/状态提示，不创造局部标签体系。

## 移植规则

- Arctic Aria 仓库只作为只读上游设计来源，不在 handbook 工作中修改。
- 优先移植共享 primitive，再组合本站功能；不复制项目、任务等业务模型。
- 上游组件依赖 Arctic Aria 的本地化、数据库或业务类型时，只保留视觉和交互契约，在本站重新定义最小接口。
- 当前页面已出现的共同模式必须立即抽成共享组件；尚未出现的复杂组件可以等对应阶段实现，但本文件中的视觉契约从第一版起生效。
