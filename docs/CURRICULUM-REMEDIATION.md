## 整改原则

1. 先确定单元要完成的学习任务，再决定复用、收窄、拆分或新建哪些文章。
2. 一个章节可以超过十个单元。3–8 篇只是检查单元是否聚焦的经验值，不是合并
   不同主题的理由。
3. 已审阅或定稿正文中的正确讲解继续保留，但状态不保护错误的篇章边界。拆分后，
   原语义文件保留最接近标题的核心职责，新主题使用新的语义文件。
4. 字面量跟随对应类型第一次出现；变量、常量、输入输出先给最小用法，后面再系统
   整理。这是螺旋式教学，不要求第一篇程序先解释完整语言标准。
5. 正文不维护“上一篇”“下一篇”。需要依赖其他知识时直接写文章名和真实关系。
6. 学习路线按单元组织教学任务；模块目录按专题组织知识关系。同一文章可以进入
   不同专题，但只维护一份正文和稳定身份。
7. 每篇正文至少核对：问题背景、逐步定义、最小片段、完整 C++17 代码、复杂度、
   边界、常见错误、需要记住的内容和四选项小测。并非每篇机械使用同一组标题。

## 第 01 章：C++ 基础

目标顺序固定为：第一个程序 → 整数与浮点数 → 条件语句 → 循环语句 → 字符串 →
函数 → 输入输出。

### 单元 1：第一个程序

#### `Hello World!`（复用 `cpp/hello-world.md`）

- 保留已经审阅的最小程序，不把它扩成语法总览。
- 展示 `#include <bits/stdc++.h>`、`using namespace std;`、`solve`、`main`、
  `return 0` 和 `cout << "Hello World!" << '\n';`。
- 只说明 `cout` 用于输出、`'\n'` 表示换行；其他部分先作为固定结构。
- 小测只检查能够识别正确输出和换行，不考尚未学习的预处理或命名空间规则。

#### `A+B Problem`（复用 `cpp/a-plus-b-problem.md`）

- 先用 `int a = 3; int b = 5;` 展示可以给整数预先确定值，再改成 `cin >> a >> b`。
- 示例输入必须是 `3 5`，示例输出必须是 `8`，输出末尾换行。
- 解释 `int` 只到“声明一个整数”，完整整数规则留到下一单元。
- 说明 OJ 只比较输入输出，并介绍 AC、WA、TLE、MLE、RE 等最常见结果。
- 洛谷提交作为练习的一部分，不讲账户注册。

### 单元 2：整数与浮点数

#### 位、字节与存储单位（提升 `cpp/bits-bytes-and-storage-units.md` 为核心）

- `bit`（比特/位）是最小的信息单位；字节是 C++ 中 `sizeof` 和地址递增使用的
  基本存储单位，二者不得混称。
- 解释 1 字节通常为 8 位，以及 B、KB、MB、GB、TB 的中文名和常见换算口径。
- 表格保持简洁；“计算机资料也常写 KB”等说明放在表格下方。
- 解释 Mbps 中 `b` 与文件大小中 `B` 的区别，以及中文“兆”的歧义。

#### 整数类型（收窄 `cpp/integer-types.md`）

- 从最常用的 `int` 开始，说明竞赛环境中通常为 32 位、4 字节，并用 `sizeof`
  观察；同时区分标准最低保证和常见环境事实。
- 核心只建立 `int`、`long long`、取值范围、十进制字面量和溢出边界。
- 正文说明使用“32 位整数”“64 位整数”；代码可用 `ll`，说明文字不把类型简称
  当作数学范围。
- 有符号溢出是未定义行为；常见二补码现象只能作为观察，正确代码不能依赖成环。
- `short`、`long`、完整平台位宽和特殊整数类型移到现有附属扩展。
- 二/八/十六进制字面量跟随本单元的“进制表示”；完整转换程序留到函数末尾。

#### 进制表示（新建 `cpp/base-notation.md`）

- 从位权解释二进制、八进制、十进制和十六进制，说明八进制和十六进制是二进制
  的紧凑写法。
- 介绍 C++ 的 `0b`、前导 `0` 和 `0x` 字面量；十六进制示例统一使用小写字母。
- 只学习阅读位串和纸笔完成小规模转换；通用转换程序等到函数单元末尾。

#### 有符号整数的机器表示（提升 `cpp/signed-integer-representations.md` 为核心）

- 分别解释原码、反码、补码，不把二补码错误说成“符号位加 31 个普通数值位”。
- 推导 32 位二补码整数的最小值与最大值为什么不对称。
- 说明初赛可能考查，要求理解原理；不要求依赖有符号溢出行为写程序。
- 本文只需要读懂给定的二进制位串；通用进制转换程序在函数以后学习。

#### 浮点类型（收窄 `cpp/floating-point-types.md`）

- 从“小数为什么叫浮点数”开始，介绍 `float` 与 `double` 的用途和大致十进制
  有效数字，不写成每个数都固定精确到 7 位或 15 位。
- 解释科学计数法字面量与输出、`fixed` 和 `setprecision` 的最小用法。
- 明确浮点数保存近似值；具体 IEEE 754 字段、隐藏位、移码、正负零、无穷和 NaN
  进入附属扩展，不要求理解和记忆。

#### 浮点数的机器表示（配套现有 `cpp/ieee-754.md`）

- 先用二进制小数位权解释有限与无限展开，再区分定点表示和浮点表示。
- IEEE 754 的符号、指数、有效数字、隐藏位、正负零、无穷和 NaN 作为附属扩展，
  只用于解释行为，不要求理解和记忆完整编码。
- 明确 `std::fixed` 只是输出格式，不会把 `double` 变成定点数类型。

#### 算术表达式（收窄 `cpp/arithmetic-operators.md`）

- 覆盖加、减、乘、除、余数、一元正负号和括号。
- 解释整数除法向零截断，包含正负数例子；除数不能为零。
- 明确 `^` 是按位异或，不是乘方；乘方和开方交给数学函数文章。
- 只介绍当前需要的优先级，复杂表达式优先加括号，不要求背完整表。

#### 复合赋值（复用 `cpp/compound-assignment-operators.md`）

- 解释“读取旧值、计算、再写回”，而不是只列 `+=`、`-=`、`*=`、`/=`、`%=`。
- 说明复合赋值不会消除除零、截断、范围和溢出问题，最后仍转换回左侧类型。
- 自增自减不在这里展开，移动到控制流单元。

#### 数值类型转换（收窄 `cpp/type-conversions.md`）

- 覆盖初始化、赋值、混合算术和返回值发生的隐式转换。
- 明确整数除法完成以后再转浮点已经来不及；至少一个操作数先变成浮点数。
- 浮点转整数是向零截断，不是四舍五入；上取整、下取整和四舍五入由数学函数完成。
- 说明窄化和有符号/无符号混合风险；不用生僻强制转换写法污染竞赛示例。

#### 数学函数（新建正文）

- 介绍 `<cmath>` 中当前真正需要的 `sqrt`、`pow`、`floor`、`ceil`、`trunc` 和
  `round`，并给出输入、返回值和典型用途。
- `pow` 主要按浮点语义工作，返回结果可能有舍入误差，不能代替保证精确的整数幂。
- 整数指数先用循环，快速幂在算法/数论阶段学习。
- 向上取整除法公式必须注明正整数前提和加法溢出风险，不宣称
  `(a + b - 1) / b` 对任意整数成立。

### 单元 3：条件语句

本单元按学习任务自顶向下组织：先提出“程序需要根据当前情况选择不同语句”，再用
布尔类型、比较运算和逻辑运算构造条件，最后落实到 `if` / `else` 与 `switch`。

#### 布尔类型（复用 `cpp/boolean-type.md`）

- `bool` 只有 `false` 和 `true`；整数转布尔时零为假、非零为真。
- `sizeof(bool)` 通常是一字节不表示有 256 个逻辑值；`bool` 没有 `unsigned` 版本。
- `!!x` 只表示连续两次逻辑取反，把条件规范成布尔值，不包装成背诵技巧。

#### 比较运算（复用 `cpp/comparison-operators.md`）

- 六种比较、严格/非严格边界、赋值与相等的区别。
- 必须用独立小节解释 `1 <= x <= n` 为什么错误：第一次比较先得到 `bool`；正确
  写法是 `1 <= x && x <= n`。
- 浮点比较的误差边界保持为配套内容，不让它掩盖整数比较主线。

#### 逻辑运算与短路求值（复用 `cpp/logical-operators.md`）

- `!`、`&&`、`||` 从题意逐步组成条件。
- 短路用于先检查边界或空值，也意味着右侧副作用可能不执行。
- 区分逻辑与、或和按位与、或；混合条件用括号提高可读性。

#### `if` 与 `else`（复用现有正文）

- 直接使用前面得到的布尔表达式选择互斥分支。
- 解释单分支、二分支、连续条件、嵌套和悬空 `else`，不把条件语句与分支语句当成
  两类不同结构。

#### `switch`（复用现有正文）

- 解释选择表达式、`case`、`default` 和贯穿行为，并在这里第一次使用 `break`
  阻止继续贯穿。
- 与 `if` / `else` 比较适用场景，不把 `switch` 说成能替代任意复杂布尔条件。

### 单元 5：排序

#### 三种平方复杂度排序（按聚焦程度保留或拆分现有正文）

- 冒泡排序、选择排序、插入排序分别解释每轮确定了什么，不只给三段模板。
- 三者都分析 $O(n^2)$，同时比较交换次数、最好情况和稳定性。

#### 计数排序

- 从整数值域较小的条件引入计数数组，说明时间和空间都依赖值域。
- 与广义桶排序保持术语边界：本文学习的是每个整数值直接计数的计数排序。

#### 快速排序（移动现有正文）

- 从选择基准、划分区间、递归处理两侧逐步推导。
- 展示相向双指针怎样找到需要交换或停止的位置，给后面的双指针单元留下正式回访。
- 说明平均、最坏复杂度、递归深度和通常不稳定。

#### 归并排序（移动现有正文）

- 从合并两个有序区间推导完整分治过程。
- 展示两个同向指针如何各自只前进，并为后面的双指针单元提供第二个核心例子。
- 说明稳定性、$O(n \log n)$ 时间与 $O(n)$ 辅助空间。

#### 排序性质比较

- 统一比较最好、平均、最坏时间复杂度、额外空间和稳定性。
- 选择排序、快速排序和堆排序通常不稳定；其余结论以正文所教的具体实现为准。
- 堆排序、基数排序为扩展正文；希尔排序只登记名称和定位。

### 单元 6：二分

#### 二分查找（移动现有正文）

- 在有序数组上从排除一半候选推导手写闭区间模板。
- 对照 `binary_search`、`lower_bound`、`upper_bound` 的左闭右开迭代器接口。
- 明确循环不变量、中点取整、更新方向、终止条件和不存在答案时的返回语义。
- 说明右移和整数除法在负数时的舍入差异，并避免中点加法溢出。

#### 答案二分（移动现有正文）

- 从答案空间和单调判定函数引入，说明它与“在数组中找一个值”不同。
- 分别整理求最小可行值与最大可行值的闭区间模板。
- 整数与实数二分分开处理；实数版本说明迭代次数或误差终止方式。

### 单元 7：离散化

#### 离散化（移动 `algorithm-basics/coordinate-compression.md`）

- 从数值很大但不同值很少、只关心相对次序的问题引入。
- 按排序、`unique`、二分定位三步形成完整算法。
- 区分原数组位置、去重后下标和值的排名；需要恢复原值时保存反向映射。
- 明确离散化保留哪些关系、丢失哪些数值距离，不能无条件替代原坐标。

### 单元 8：双指针

#### 双指针（重写 `algorithm-basics/two-pointers.md` 的主线）

- 统一定义为两个下标按可证明的单调方向移动，并在移动时永久排除一批状态。
- 第一组回访快速排序的相向扫描；第二组回访归并排序合并阶段的同向扫描。
- 再用有序数组两数之和建立相向双指针的独立解题模型。
- 所有例子都用总移动次数分析复杂度，不能机械按嵌套层数判断。

### 试除法：质数检测（新建正文）

- 第一种典型写法：从 2 检查到 `n - 1`，时间复杂度 $O(n)$。
- 第二种典型写法：只检查到 $\sqrt n$，用因数成对出现推导 $O(\sqrt n)$。
- 比较 `i * i <= n`、`i <= n / i`、先处理 2 后只枚举奇数等常见变体和溢出边界。
- 对 $n < 2$、2、完全平方数分别测试。
- 必须回答：判断 100 以内的质数或合数时，任何合数都有不超过
  $\sqrt{100}=10$ 的质因数，而不超过 10 的质数只有 2、3、5、7，所以只需检查
  这四个候选；不是说所有因数只有这四个。

### 算术基本定理（复用现有正文）

- 每个大于 1 的正整数都能唯一分解为质数幂乘积；存在性与唯一性分开解释。
- 用指数坐标为最大公约数、最小公倍数、因数个数与因数和建立前置。

### 质因数分解（扩充现有正文）

- 对比从 2 一直尝试、只到平方根、先处理 2 再枚举奇数三类写法。
- 每找到质因数就反复相除并记录指数；循环后剩余值大于 1 时它本身是质因数。
- 解释为什么记录到的候选一定是质数，以及 1、0、负数的边界。

### 埃拉托斯特尼筛法（从高中基础移入本单元）

- 从“逐个试除会重复工作”引入批量标记合数。
- 用 1 到 100 的表格或 SVG 找出全部质数；解释为什么标记一个质数的倍数可以从
  $p^2$ 开始、外层只需到平方根。
- 在例子中再次解释 2、3、5、7 足以发现 100 以内所有合数的理由。
- 本阶段只筛出质数列表或质数个数，不提前把筛法扩展成任意数论函数预处理。

### 最大公约数、最小公倍数与欧几里得算法（复用现有两篇）

- 用质因数指数的最小值/最大值解释 gcd/lcm，本质对应 `min` / `max`。
- 推导乘积关系、0 的约定和避免先乘溢出。
- 欧几里得算法从公约数集合不变推导递归与循环写法。

### 快速幂的阶段决定

- 普通快速幂只依赖整数乘法、指数的二进制分解和循环，可以放在初中数论基础末尾，
  或作为算法技巧紧邻本单元；它不依赖费马小定理。
- 费马小定理依赖同余、质数模和模意义下乘法，保留在高中基础。不能为了名称相近
