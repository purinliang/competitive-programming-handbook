# 文章编号与语义路径

> 生效日期：2026-08-16

本文定义课程结构、文章编号和文件路径的稳定关系。它取代早期按模块临时分配四位编号、文件名又部分携带编号的开荒规则。

## 章、单元与文章

学习路线中的每篇文章使用六位 `CCUUPP` 编号：

- `CC` 是两位章号；
- `UU` 是两位单元号；
- `PP` 是文章在该单元中的两位顺序。

例如 `030405` 表示“第 03 章第 04 单元的第 05 篇”。三段都从 `01` 开始并始终保留两位，因此日常可以稳定地称“01 章 01 单元”或“01 章 01 节”。

`learning-path.md` 中的单元标题写作 `### 单元 01：第一个程序`，网站目录显示为 `01 第一个程序`。单元号是章内顺序，进入新章后重新从 `01` 开始。

ID 编码文章的权威主入口。同一正文在模块目录中可以属于多个专题，也可以在学习路线中提供次要入口；这些入口不重复分配 ID，只保留各自的导航上下文。

## 扩展阅读

星号是分类前缀，不是脚注后缀。目录顶部统一说明：`*` 前缀表示扩展阅读，难度通常更高或使用频率更低，暂时不学也不影响后续主线。

- 进入学习路线的独立扩展按权威入口编码，例如 `*020601`。
- 整个单元都是扩展时，源文写作 `### 单元 06：*类`，网站显示为 `06 *类`；不使用“类（扩展阅读）”。
- 不进入学习路线的独立扩展使用 `*99MMPP`，其中 `MM` 是模块号，`PP` 是该模块扩展索引中的顺序。`99` 是保留区，不表示存在第 99 章。
- 附属扩展共享基础篇的六位 ID，再追加 `e1`、`e2` 等后缀，例如 `*010201e1`。附属扩展不进入学习路线或独立扩展索引。

导航中的扩展文章名同样使用前缀，例如 `*封装`，不再显示为“封装*”或“封装（扩展阅读）”。

## 语义路径

正文文件名是文章中文主题的简洁英文翻译：

- 全部小写，单词之间使用短横线；
- 不携带六位 ID；
- 不重复“学习路线”、模块或单元等导航层级；
- 通行英文算法名保留原名的小写拼写。

例如“冒泡排序”使用 `bubble-sort.md`，“最短路：Dijkstra”使用 `dijkstra.md`。模块正文、学正文和小测共享同一语义文件名；内部链接、模板引用和前端路由必须随路径迁移同步更新。

## 迁移边界

2026-08-16 的统一迁移允许直接重编号和重命名，不保留旧 ID、旧 URL、已读标记或数据库状态的兼容层。迁移完成的证据必须同时包括：

1. 目录中没有旧四位 ID 或带编号的文件名；
2. 学习路线的章号、单元号和篇序与六位 ID 一致；
3. 模块目录、学习路线、正文、小测、模板和前端不存在旧路径引用；
4. 全量目录、链接、内容身份、类型和构建检查通过。

本次 439 篇文章的旧 ID、新 ID、旧路径和新路径保存在 [迁移清单](article-identity-migration.json) 中，用于审计本次一次性重构，不作为运行时重定向表。
