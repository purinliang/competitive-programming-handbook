# YAML Schema v1

`cp-diagram/v1` 的第一版只解决前缀和教程需要的单行数组图。它提供数组格、下标、数组名、单点箭头和范围标记，不提前加入树状数组、线段树或任意坐标系统。

## 完整示例

```yaml
schema: cp-diagram/v1
type: array
background: white
label: a
index: 1-based
cells:
  - 3
  - 1
  - 4
  - 1
  - 5
  - 9
annotations:
  - type: range
    from: 2
    to: 5
    label: 1 + 4 + 1 + 5 = 11
    color: red
```

## 顶层字段

| 字段 | 必需 | 类型 | 说明 |
| ---- | ---- | ---- | ---- |
| `schema` | 是 | 字符串 | 固定为 `cp-diagram/v1` |
| `type` | 是 | 字符串 | v1 固定为 `array` |
| `background` | 否 | 枚举 | `transparent` 或 `white`，默认 `transparent` |
| `label` | 否 | 字符串 | 数组左侧的名字 |
| `index` | 否 | 枚举 | `0-based`、`1-based` 或 `none`，默认 `1-based` |
| `cells` | 是 | 非空列表 | 从左到右的数组格 |
| `annotations` | 否 | 列表 | 格子强调、单点箭头和范围标记 |

未列出的字段都视为错误。v1 不接受标题、画布大小、坐标、字体、线宽或任意 CSS 颜色。

## background

数组格本身始终是透明的，只绘制边框和文字。整张 SVG 的背景由顶层字段控制：

```yaml
background: white
```

- `transparent`：不绘制背景，默认值。
- `white`：在所有图形下面绘制一个覆盖画布的白色背景。

背景不属于颜色强调系统，不能写成 `default`、`red` 或十六进制颜色。

## 文字命名

v1 把三类文字明确分开：

- `value`：数组格内部的内容。
- `index`：渲染器自动生成的下标。
- `label`：图形外部的说明文字，包括数组名、箭头说明和范围说明。

因此，不把数组格里的数也叫 `label`。`value` 是主要数据；数组名和 `index` 都是辅助信息，使用相同的较小字号；箭头和范围的 annotation label 使用介于两者之间的字号并略微加粗。这些字号比例由主题固定，不能由单张图修改。

## index

```yaml
index: 1-based
```

支持三种显示方式：

- `1-based`：显示 `1` 到 `n`，也是 handbook 正文的统一约定。
- `0-based`：显示 `0` 到 `n - 1`，只作为绘图器预留能力，handbook 正文不采用这种写法。
- `none`：不显示下标。

`annotations` 中的 `at`、`from` 和 `to` 按显示下标解释。`index: none` 没有显示下标，此时按从 1 开始的格子序号解释。

## cells

每个格子直接写成字符串或数字：

```yaml
cells: [3, 1, 4, 1, 5, 9]
```

`cells` 是纯数据层，不接受 `color` 或其他样式字段。布尔值、空值、列表和映射不能作为格内 `value`。需要强调某个格子时，使用 `annotations` 中的 `type: cell`。

## 颜色

`color` 只接受以下令牌：

```text
default
red
blue
green
```

作者不能填写十六进制颜色、RGB、颜色名称或透明度。颜色令牌只出现在 annotation 中，并由版本化主题解释：

- `default`：黑色边框和黑色文字。
- `red`、`blue`、`green`：annotation 的边线和关联文字使用对应颜色。

格子填充始终透明；是否有白色底色只由顶层 `background` 决定。

图中绝大多数对象应保持 `default`。需要强调一组对象时优先使用 `red`；同一张图已经使用红色、还需要表达第二组对照时再使用 `blue`；`green` 只留给第三组或明确的成功、成立等语义。不要为了让图片更鲜艳而给普通格子逐个上色。

annotation 的边线和文字保持完全不透明。透明 SVG 可能放在不同背景上，50% 或 75% 的前景透明度会产生不稳定的对比度。未来如果增加区间底色填充，只有填充层适合使用较低透明度，边线和文字仍保持不透明。

基础数组边框使用全局 `stroke width`。annotation 的箭头、范围线和格子强调框统一使用基础线宽的 1.25 倍；annotation label 使用 `600` 字重。格子强调框始终覆盖在其他几何线条之上。所有文字使用同一个手写印刷体字体栈；数组名、annotation label 和下标使用固定的字号层级。主题可以在渲染器版本中整体调整，但 YAML 不能逐对象覆盖这些值。

## cell annotation

格子变色属于注释层，不写进 `cells`：

```yaml
annotations:
  - type: cell
    at: 1
    color: red
```

字段：

| 字段 | 必需 | 说明 |
| ---- | ---- | ---- |
| `type` | 是 | 固定为 `cell` |
| `at` | 是 | 目标下标或格子序号 |
| `color` | 是 | 颜色令牌 |

渲染器先画普通黑色格子，再在目标格子上叠加统一加粗的彩色边框。强调边框位于所有基础边框、箭头和范围线之上；格内 `value` 仍保持 `default` 黑色，避免注释层修改数据层文字。

## arrow

单点箭头从上方或下方指向格子对应外边框的中点：

```yaml
annotations:
  - type: arrow
    at: 5
    side: top
    length: 2
    label: r
    color: red
```

字段：

| 字段 | 必需 | 说明 |
| ---- | ---- | ---- |
| `type` | 是 | 固定为 `arrow` |
| `at` | 是 | 目标下标或格子序号 |
| `side` | 否 | `top` 或 `bottom`，默认 `top` |
| `length` | 否 | 正整数，表示箭头使用的离散长度层级 |
| `label` | 否 | 字符串或数字，作为箭头外侧的短说明 |
| `color` | 否 | 颜色令牌，默认 `default` |

箭头的目标锚点在 v1 固定为外边框中点：上方箭头接触上边框，下方箭头接触下边框。YAML 不提供 `anchor` 或坐标微调。

同一侧指向同一个格子的箭头最多允许 3 个。渲染器把落点均匀分配在格子宽度内：两个箭头使用 `1/3`、`2/3`，三个箭头使用 `1/4`、`1/2`、`3/4`。省略 `length` 时，同组箭头按 YAML 顺序自动使用 `1, 2, 3, ...`；显式填写时使用作者指定的正整数。

绘图器仍支持 `side: bottom`，但 handbook 的数组通常在下方显示下标，因此教程示例优先使用上方箭头，避免箭头穿过下标。

## range

范围标记表示一个包含左右端点的闭区间：

```yaml
annotations:
  - type: range
    from: 2
    to: 5
    label: sum(2, 5) = 11
    color: red
```

渲染器从第一个格子的左边线和最后一个格子的右边线向上延长竖线，再从中间向两侧绘制两个箭头，箭头分别指向两条竖线。

可选 `label` 自动使用两种布局：短文字能放进中间且左右仍有足够箭身时，文字与箭头共用一条水平线，两个箭头在文字两侧断开；长文字放在箭头上方，两个箭头从同一个中心点出发并连接在一起。判断依据是主题字号和范围实际宽度，不按固定字符数。

字段：

| 字段 | 必需 | 说明 |
| ---- | ---- | ---- |
| `type` | 是 | 固定为 `range` |
| `from` | 是 | 闭区间左端点 |
| `to` | 是 | 闭区间右端点 |
| `label` | 否 | 字符串或数字，作为范围说明 |
| `color` | 否 | 颜色令牌，默认 `default` |

`from` 必须小于或等于 `to`，两个端点都必须存在。v1 的范围标记固定画在数组上方。

range annotation 不额外绘制包围整段格子的矩形。两条端点竖线已经完整定义闭区间；重复外框会与基础格子边框和 `cell` annotation 混淆。确实需要强调某个格子时，作者可以另外组合 `type: cell`。

## 布局与输出

- 数组横向排列，同一行的格子等宽。格高、最小格宽和内边距都按 `value` 字号的固定比例计算；遇到较长的值时，整行格宽根据最长值自动增大。
- 数组名与格内 `value` 使用同一条水平中心线。
- 下标文字顶缘与格子下边框之间保留约 `0.4` 倍下标字体高度的距离。
- 图片宽高根据数组长度、数组名、下标和标记自动计算。
- 多个标记按 YAML 顺序分配竖直轨道，不允许手写坐标。
- 几何线条的 `roughness`、`bowing` 和随机偏移全部为 `0`，数组边框、箭头和范围线保持精确几何。相同输入必须生成相同 SVG。
- 数组值、下标和 `label` 保持为原生 SVG 文本，优先使用 `Comic Neue`，中文回退到 `AR PL KaitiM GB`。文字本身不额外抖动。
- v1 只输出 SVG。

## 严格校验

- 使用 `yaml.safe_load`，不执行自定义 YAML 对象、脚本或表达式。
- 未知字段直接报错，避免拼写错误被忽略。
- `schema`、`type`、颜色、下标模式和标记类型都必须来自固定枚举。
- 越界下标、倒置范围和错误字段类型直接报错。
- 所有文字按纯文本处理，不解释 HTML。

## 版本演进

树状数组、线段树、多行数组、任意连线和多帧动画都不属于当前 v1。先用前缀和教程审核 YAML 是否好写、图片是否好读，再决定哪些能力进入兼容扩展，哪些变化需要升级为 `cp-diagram/v2`。
